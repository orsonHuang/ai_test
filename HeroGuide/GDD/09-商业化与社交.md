# 09 · 商业化与社交

## 1. 变现模式：IAA 为主

### 1.1 收入结构

| 来源 | 占比预期 | 说明 |
|------|----------|------|
| 激励视频 | 80% | 核心收入，玩家主动观看换取奖励 |
| 插屏广告 | 15% | 关卡间自然停顿点展示 |
| 内购 | 5% | 去广告包（可选，V2 考虑） |

### 1.2 IAA 设计原则

1. **不打断核心体验**：广告只在"自然停顿点"出现（结算后、失败后）
2. **激励视频必须给真实价值**：玩家看完广告必须获得有意义的回报
3. **广告频率可控**：同一场景不连续弹两次广告
4. **失败不强制看广告**：玩家可选择直接重试，广告是"加速选项"而非"唯一出路"

## 2. 激励视频广告点

### 2.1 失败复活

| 属性 | 说明 |
|------|------|
| 触发 | 执行阶段失败后 |
| 奖励 | 原地复活，继续从失败前 2 格重走 |
| 频率 | 每关限 1 次（避免无限复活） |
| 文案 | "看视频复活，继续战斗！" |

**设计要点**：复活不是"回到准备阶段重新放物品"，而是"执行阶段从失败前继续"。这让玩家不必重新看整段路径，体验更流畅。

### 2.2 关卡提示

| 属性 | 说明 |
|------|------|
| 触发 | 准备阶段，玩家卡关时 |
| 奖励 | 显示一个物品的正确放置位置（提示 1 步） |
| 频率 | 每关限 2 次 |
| 文案 | "看视频获取提示" |

**设计要点**：提示只给"下一步"而非完整解法，保留玩家思考乐趣。

### 2.3 双倍奖励

| 属性 | 说明 |
|------|------|
| 触发 | 胜利结算后 |
| 奖励 | 金币奖励 ×2 |
| 频率 | 每次胜利可选 |
| 文案 | "看视频双倍金币" |

### 2.4 解锁关卡（可选）

| 属性 | 说明 |
|------|------|
| 触发 | 玩家想跳过当前卡住的关卡 |
| 奖励 | 直接解锁下一关 |
| 频率 | 限 3 次（避免滥用） |
| 文案 | "看视频跳过本关" |

> MVP 建议不开放跳关，鼓励玩家正常通关。V2 再考虑。

## 3. 插屏广告

### 3.1 展示时机

| 时机 | 频率控制 |
|------|----------|
| 关卡胜利结算后 → 下一关加载时 | 每 3 关展示 1 次 |
| 失败重试第 3 次时 | 每 5 次失败展示 1 次 |

### 3.2 频率限制

- 同一 5 分钟内最多展示 1 次插屏
- 玩家刚看完激励视频后 60 秒内不展示插屏

## 4. 社交功能（微信小游戏）

### 4.1 分享复活

| 属性 | 说明 |
|------|------|
| 触发 | 失败后 |
| 机制 | 分享到群/好友 → 好友点击 → 玩家获得复活 |
| 频率 | 每关限 1 次 |
| 文案 | "我的勇者又蠢死了，快来救救他！" |

**分享文案设计**（病毒传播关键）：
- "我的勇者又走陷阱里了...帮帮他吧！"
- "蠢勇者第 99 次死于守卫视野，谁来救救他"
- "这个迷宫太难了，我需要你的帮助！"

### 4.2 分享拉新

| 属性 | 说明 |
|------|------|
| 触发 | 通关后 / 主界面 |
| 机制 | 分享游戏 → 好友点击进入 → 玩家获金币 |
| 奖励 | 每次有效拉新 +50 金币（V2） |

### 4.3 排行榜（V2）

- 微信开放数据域绘制好友排行
- 排行维度：总星数 / 关卡进度 / 最少物品通关记录
- MVP 不实现，V2 加入

## 5. 留存设计

### 5.1 短期留存（首日-3日）

- 12 关 MVP 内容，每关 1-3 分钟
- 前 3 关强教学引导，确保新手不流失
- 星级收集驱动重复挑战

### 5.2 中期留存（7日）

- 3 星完美通关奖励（金币/成就）
- 每日挑战关（V2）
- 分享解锁隐藏关（V2）

### 5.3 长期留存（30日+）

- V2 内容更新（新章节、新物品、新敌人）
- 关卡编辑器 + 创意工坊（Steam 版）
- 赛季排行（V2）

## 6. 内购设计（V2 考虑）

| 商品 | 价格 | 说明 |
|------|------|------|
| 去广告包 | ¥6-12 | 移除所有广告，激励视频奖励改为免费领取 |
| 金币包 | ¥1-30 | 购买金币（用于提示/皮肤） |
| 皮肤包 | ¥6-18 | 勇者/守卫皮肤（纯外观） |

> MVP 不做内购，纯 IAA 验证。留存数据达标后再加内购。

## 7. 数据埋点（验证用）

MVP 需采集的关键指标：

| 指标 | 用途 |
|------|------|
| 关卡通过率 | 判断难度曲线是否合理 |
| 关卡重试次数 | 判断哪些关卡过难 |
| 平均通关时长 | 判断单局节奏 |
| 激励视频观看率 | 判断广告点设计是否合理 |
| 分享率 | 判断社交传播力 |
| 次日/7日留存 | 判断游戏是否值得继续投入 |
| 星级分布 | 判断最优解难度是否合适 |

> 微信小游戏 Analytics 或自建埋点。MVP 上线后观察 1-2 周数据决策后续方向。
