# 10 · 关卡数据格式

> 关卡数据为 JSON 格式，存放在 `assets/levels/` 目录下，每关一个文件。

## 1. 完整数据结构

```json
{
  "version": "1.0",
  "levelId": "1-01",
  "chapter": 1,
  "name": "第一次引导",
  "size": { "w": 8, "h": 8 },

  "hero": { "x": 0, "y": 0 },
  "demonKing": {
    "x": 7, "y": 2,
    "facing": "left",
    "visionRange": 0
  },

  "walls": [
    [2, 0], [2, 1], [2, 2], [2, 3]
  ],

  "traps": [
    { "x": 3, "y": 2, "type": "spike", "visible": true }
  ],

  "guards": [
    {
      "id": "g1",
      "x": 4, "y": 4,
      "facing": "up",
      "type": "static",
      "visionRange": 3
    }
  ],

  "patrolGuards": [],

  "dragons": [],

  "playerItems": {
    "stone": 2,
    "portal": 0
  },

  "starThresholds": {
    "3star": 1,
    "2star": 2,
    "1star": 3
  },

  "tutorial": {
    "enabled": true,
    "steps": [
      { "type": "tip", "text": "勇者会走最短路径找魔王", "target": "hero" },
      { "type": "tip", "text": "虚线红色表示危险，试试放石头堵住陷阱", "target": "trap" },

  }
}
```

## 2. 字段说明

### 2.1 基础信息

| 字段 | 类型 | 说明 |
|------|------|------|
| `version` | string | 数据格式版本号（向前兼容） |
| `levelId` | string | 关卡唯一 ID（格式：章节-序号） |
| `chapter` | number | 章节号 |
| `name` | string | 关卡显示名称 |
| `size` | {w, h} | 地图尺寸（格数） |

### 2.2 角色

| 字段 | 类型 | 说明 |
|------|------|------|
| `hero` | {x, y} | 勇者起始位置 |
| `demonKing` | object | 魔王信息 |
| `demonKing.x/y` | number | 魔王位置 |
| `demonKing.facing` | string | 朝向（MVP 无视野，预留） |
| `demonKing.visionRange` | number | 视野范围（MVP=0） |

### 2.3 地图元素

| 字段 | 类型 | 说明 |
|------|------|------|
| `walls` | number[][] | 墙壁坐标数组，每个元素 [x, y] |
| `traps` | object[] | 陷阱列表 |
| `traps[].type` | string | 陷阱类型（MVP 只有 "spike"） |
| `traps[].visible` | boolean | 是否可见（MVP 恒 true，V2 有隐藏陷阱） |

### 2.4 守卫

| 字段 | 类型 | 说明 |
|------|------|------|
| `guards` | object[] | 静态守卫列表 |
| `guards[].id` | string | 守卫唯一 ID |
| `guards[].x/y` | number | 守卫位置 |
| `guards[].facing` | string | 朝向："up"/"down"/"left"/"right" |
| `guards[].type` | string | "static"（MVP 只有静态） |
| `guards[].visionRange` | number | 视野格数（默认 3） |

### 2.5 V2 预留元素

| 字段 | 类型 | 说明 |
|------|------|------|
| `patrolGuards` | object[] | 巡逻守卫（V2） |
| `patrolGuards[].route` | number[][] | 循环路线坐标 |
| `patrolGuards[].speed` | number | 每格耗时（秒） |
| `patrolGuards[].facingMode` | string | "movement"（跟随移动）/ "cycle"（固定周期） |
| `dragons` | object[] | 飞龙（V2） |
| `dragons[].x/y` | number | 飞龙位置 |
| `dragons[].destination` | number[] | 飞行目的地 [x, y] |

### 2.6 玩家物品

| 字段 | 类型 | 说明 |
|------|------|------|
| `playerItems.stone` | number | 石头数量 |
| `playerItems.portal` | number | 传送门对数 |

### 2.7 星级与奖励

| 字段 | 类型 | 说明 |
|------|------|------|
| `starThresholds` | object | 各星级所需物品数上限 |
| `starThresholds.3star` | number | 3 星：使用物品 ≤ 此值 |
| `starThresholds.2star` | number | 2 星：使用物品 ≤ 此值 |
| `starThresholds.1star` | number | 1 星：使用物品 ≤ 此值 |
| `rewards.coins` | object | 各星级金币奖励 |

### 2.8 教学引导

| 字段 | 类型 | 说明 |
|------|------|------|
| `tutorial.enabled` | boolean | 是否启用教学 |
| `tutorial.steps` | object[] | 教学步骤序列 |
| `steps[].type` | string | "tip"（文字提示）/ "highlight"（高亮元素） |
| `steps[].text` | string | 提示文案 |
| `steps[].target` | string | 高亮目标（"hero"/"trap"/"startButton" 等） |

## 3. TypeScript 类型定义

```typescript
// core/LevelData.ts

type Direction = 'up' | 'down' | 'left' | 'right';

interface Point { x: number; y: number; }

interface LevelData {
  version: string;
  levelId: string;
  chapter: number;
  name: string;
  size: { w: number; h: number };

  hero: Point;
  demonKing: {
    x: number;
    y: number;
    facing?: Direction;
    visionRange?: number;
  };

  walls: Point[];
  traps: Array<{
    x: number;
    y: number;
    type: 'spike';
    visible: boolean;
  }>;

  guards: Array<{
    id: string;
    x: number;
    y: number;
    facing: Direction;
    type: 'static';
    visionRange: number;
  }>;

  patrolGuards: Array<{
    route: Point[];
    speed: number;
    facingMode: 'movement' | 'cycle';
    visionRange: number;
  }>;

  dragons: Array<{
    x: number;
    y: number;
    destination: Point;
  }>;

  playerItems: {
    stone: number;
    portal: number;
  };

  starThresholds: {
    '3star': number;
    '2star': number;
    '1star': number;
  };

  tutorial?: {
    enabled: boolean;
    steps: Array<{
      type: 'tip' | 'highlight';
      text: string;
      target: string;
    }>;
  };

  rewards: {
    coins: { '3star': number; '2star': number; '1star': number };
  };
}
```

## 5. 关卡数据验证流程

```
关卡设计师编辑 JSON
      ↓
运行 LevelSolver（Node.js 脚本）
      ↓
  ├── hasSolution? → 否 → 修改关卡
  ├── findOptimalSolution → 获取最优物品数 → 更新 starThresholds
  └── findAllSolutions → 验证至少 2 种解法
      ↓
通过 → 关卡数据入库
```

**验证脚本使用**：
```bash
# 在项目根目录执行
npx ts-node src/validate-levels.ts assets/levels/
```

> 验证脚本在 MVP 开发阶段实现，关卡设计师每编辑一关跑一次。
