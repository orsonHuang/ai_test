# 06 · UI 与交互规范

> 本文档基于 `DragonQuest-Maze/GDD/02-UI参考喵喵消消乐.md` 的配色与风格规范，针对本项目的**双阶段玩法**进行适配设计。

## 1. 整体风格

延续喵喵消消乐的萌系卡通风格：

- **基调**：明亮奇幻卡通
- **圆角**：所有按钮/卡片/面板 16-24px 圆角
- **描边**：关键元素 2-4px 深色描边
- **阴影**：轻投影（y:4, blur:8, 透明度 15%）

### 配色方案（沿用旧 GDD）

| 用途 | 色值 | 说明 |
|------|------|------|
| 主背景 | `#FFF8E7` | 暖米色 |
| 主按钮 | `#FF8C42` | 活力橙（出发/确定） |
| 次要按钮 | `#4ECDC4` | 青绿色（返回/取消） |
| 危险/失败 | `#FF6B6B` | 红色（重开/警告） |
| 成功/金币 | `#FFD93D` | 金黄 |
| 草地绿 | `#7CB342` | 地面底色 |
| 石墙灰 | `#8D8D8D` | 墙壁描边 |
| 文字主色 | `#4A4A4A` | 深灰 |
| **安全路径** | `#7CB342` | 绿色虚线 |
| **危险路径段** | `#FF6B6B` | 红色虚线段 |
| **守卫视野** | `#FF6B6B` 半透明 | 红色覆盖 |

## 3. 核心交互：虚线路径显示

这是本项目最关键的 UI 元素。

### 3.1 路径状态

| 状态 | 视觉 | 触发条件 |
|------|------|----------|
| 安全 | 绿色虚线 | 路径存在且不经过任何致命格 |
| 危险 | 绿色虚线 + 红色段 + 图标 | 路径存在但经过陷阱/视野格 |
| 无路 | 无虚线 + "无可达路径"提示 | A* 找不到通往魔王的路径 |

### 3.2 危险标注

路径经过致命格时，在该格上方显示危险图标：

| 致命类型 | 图标 | 颜色 |
|----------|------|------|
| 陷阱 | ⚠️ | 红色闪烁 |
| 守卫视野 | 👁️ | 红色闪烁 |

虚线在该格段变为红色实线 + 闪烁，其余安全段保持绿色虚线。

### 3.3 实时更新

- 玩家放置物品 → 路径立即重算（< 50ms）→ 虚线更新
- 玩家移除物品 → 同上
- 勇者位置/魔王位置固定（本关不变）

## 4. 守卫视野显示

| 操作 | 效果 |
|------|------|
| 默认 | 守卫视野格红色半透明覆盖（始终可见） |
| 长按守卫 | 视野范围高亮加粗 + 显示视野格数 |

**视野截断**：视野遇到墙壁/石头/边界时截断，不穿透。

## 5. 操作流程

### 5.1 准阶段操作

```
点击物品栏物品 → 选中（高亮）
    ↓
点击地图空格 → 放置物品（若合法）
    ↓ 路径实时更新
    ├── 路径安全 → 出发按钮亮起
    ├── 路径危险 → 虚线标红 + 图标
    └── 无路 → 提示 + 出发禁用
    
点击已放置物品 → 移除（退还物品栏）
    ↓ 路径实时更新

点击出发 → 进入执行阶段
```

### 5.2 放置合法性反馈

- 合法放置：物品图标出现 + 缩放动画
- 非法放置（墙壁/守卫/视野格）：格子闪红 + 震动反馈 + 不放置

## 6. 动效规范

| 场景 | 动效 |
|------|------|
| 物品放置 | 缩放 0.5→1.0 + 弹跳，100ms |
| 物品移除 | 缩放 1.0→0 + 淡出，100ms |
| 路径更新 | 虚线淡入淡出过渡，150ms |
| 勇者移动 | 平滑位移 200ms + 轻微弹跳 |
| 守卫击杀 | 勇者挥剑 → 守卫倒地 → 星星旋转，500ms |
| 传送 | 勇者缩小消失 → 出口放大出现，300ms |
| 陷阱死亡 | 陷阱弹起 + 勇者弹飞 + 屏幕震动，400ms |
| 视野死亡 | 守卫扑向勇者 + 屏幕震动，400ms |
| 击杀魔王 | 冲刺 + 闪白 + 魔王倒下 + 宝箱弹出，800ms |
| 胜利结算 | 星星依次点亮 + 金币飞入，600ms |
| 失败 | 红色渐变覆盖 + 屏幕震动，300ms |

## 7. 微信小游戏适配

- 顶部保留微信胶囊按钮安全区，HUD 下移 88px
- 竖屏单手操作，物品栏在底部拇指可达区
- 分享按钮使用微信标准分享组件
- 激励视频按钮统一文案："看视频获取奖励"
- 排行榜（V2）使用微信开放数据域绘制

## 8. 字体规范

- **标题**：圆润卡通字体（站酷快乐体 / 优设标题黑）
- **正文**：系统黑体 / PingFang SC / HarmonyOS Sans
- **数字**：粗圆数字字体（步数、金币）
- **字号**：大标题 48-64px / 关卡标题 36px / 按钮 32-36px / HUD 数字 40px / 提示 24px
