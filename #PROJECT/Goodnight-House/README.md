# 晚安小屋

## 项目描述

Cocos 2D 竖屏轻量逻辑解谜，首发微信小游戏。玩家依据睡前约定安排动物入住；主线长期更新，每日挑战提供省份参与榜。当前阶段：设计与执行文档 v0.1；已有初始引擎目录，本轮未实现或运行验证。

## 工作规则

- 先读本索引；玩法与交互以 `GDD/设计文档.md` 为准，任务与验收以 `执行文档.md` 为准。
- 按用户要求精简为两份正文，不展开通用 GDD 模板的多层 analysis/design 文件；已确认、建议默认、待定事项明确区分。
- 引擎采用 Cocos；现有工程package.json配置Creator 3.8.8，后续核实编辑器匹配。建议 TypeScript，规则层独立于引擎。
- 文本、设施图标和判定共用结构化规则；关卡上线前必须通过唯一解与可解释推理检查。
- 用户最后一次文字修订优先于参考图；不把概念图当作切好的生产素材或已实现的界面。
- 任务状态依据实际结果更新；本地预览、微信真机、正式上线分别验收。

## 注意事项

首发微信小游戏已确认。本轮仅交付立项文档；编辑器可用性、AppID、广告位与服务端方案尚未核实，不填写虚构配置。先完成规则原型与可玩切片，再批量铺关卡和接入地区榜。文档提交与引擎子仓分别处理，不将引擎目录误纳入文档提交。
