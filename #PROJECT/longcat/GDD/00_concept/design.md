# 概念设计：longcat（工作代号）

> 状态：本文依据 `00_concept/analysis.md` 推导，analysis 全部问题块状态为 `user_confirmed`，**本文已定稿**。
> 正式产品名待定——参考对象 Martin Magni 的《Longcat》已发行，直接沿用同名存在混淆与商标风险。

## 一句话概念

《longcat》是一款微信小游戏：玩家操控一只银渐层猫咪，划线选方向让它一路滑行，走过的草地长出白色蒲公英，目标让整片草地开满花。通过每日挑战、好友排行榜和分享奖励，与朋友比拼谁走得更远。

## 设计锚点

- 核心幻想：我明明只是划了个方向，这猫怎么就让整片草地开满了花。
- 目标体验：用极少的输入做出有意义的空间决策，在社交比拼中获得乐趣。
- 玩家动机：短期验证这一关的路线，长期在每日挑战和好友排行榜中攀升。
- 核心循环：进入关卡 → 观察规划 → 划线滑行 → （撤销？）→ 填满草地 → 通关或困死 → 下一关/每日挑战。
- 跑偏风险：膨胀成数值养成、动作化操作会掩盖"用最少输入解空间谜题"的核心承诺。
- 非目标：不做实时操作、数值养成、重度构筑、剧情叙事。

## 概念边界

Concept 阶段只定义核心幻想、目标用户、体验基调和排除方向。

以下推迟给 Top Design：单次 run 的关卡数、命数与回收规则、能力数量、关卡总量与章节结构、系统清单与 MVP 范围。

以下推迟给 Architecture：关卡数据如何远程加载、求解器与生成器的工程形态、微信包体与提审的应对方案。

以下推迟给 Systems：滑行的具体结算规则、能力的完整列表、每日挑战的匹配规则。

**本阶段不定**：一切数值（命数、关卡数、能力数量、概率）、一切 UI 布局、一切美术规格、正式产品名。

## 核心幻想

玩家应该不断产生一个念头：

> "我明明只是按了个方向，这猫怎么就绕成了一团——但换个顺序，我肯定能填满。"

前半句是**奇观**（长猫绕满全屏的视觉满足），后半句是**再来一次的冲动**（失败归因于决策而非操作）。这两句必须同时成立——少了前半句，游戏变成枯燥的路径规划；少了后半句，玩家困死一次就走。

猫不是装饰。它的身体长度就是进度、就是分数、就是奖励，它同时承担了进度条、成就感和传播素材三个职责。

## 目标用户

**核心定位：休闲用户，偶尔打开来玩两把解压。**

目标用户与 Longcat / Snek Left / Apple Worm 一类滑行填充解谜的受众高度重合：

- 喜欢规则一句话能讲完、但越玩越深的解谜。
- 喜欢短段落推进，每一关结束都有清楚反馈。
- 在通勤、排队、睡前等碎片时间游玩，单次不愿超过 20 分钟。
- 能接受失败，但不接受"失败让我一无所有"。

**辅助定位：提供收集向内容，给予情绪价值。**

收集向内容（如关卡成就、猫咪皮肤、草地主题）不承担数值成长职责，只提供"我在慢慢积累"的情绪满足。

明确拒绝的受众需求：
- 想要重操作、手速、反应力挑战的玩家（本项目零操作门槛，会让他们觉得没挑战）。
- 想要长期养成、角色数值成长的玩家（本项目无数值系统）。
- 想要深度构筑、Build 优化的玩家（能力是规则修正，不构成构筑树）。

## 玩家身份

玩家是这只猫的"驾驶者"——不直接控制它走路，只划线告诉它往哪拐。

每关开始时面对一片草地，观察木箱子的分布，在脑中推演路线，然后划线让猫咪滑行。走过的地方长出蒲公英，填满了，通关；把自己堵死了，困死，重来。划错了？没关系，每关有 3 次撤销机会，点一下就能回退。

每天早上，玩家打开每日挑战：全服同一关，比谁用的步数少，看看自己在好友排行榜排第几。

## 体验目标

玩家应该感到：

1. 我不是在操作一个角色，而是在解一道看得见摸得着的题——划线选方向就是我全部的武器。
2. 我填的每一格都是不可逆的承诺，所以每次划线都值得想一秒。
3. 困死了不是"我手残"，而是"我这个顺序不对"——换个顺序我就能过。
4. 划错了也不怕，还有 3 次撤销机会，让我大胆尝试。
5. 通关时那片开满蒲公英的草地，是我自己规划出来的作品。
6. 我想看看在好友排行榜上能不能超过那个人。
7. 明天还有每日挑战，我想看看能不能比今天少走两步。

## 情绪基调

轻松、可爱、烧脑。可以有一点"就差一格"的懊恼，但边界是**"我再试一次"**，不是"我打不过"。

它不是硬核受苦解谜（不靠高难度劝退），也不是无脑消磨休闲（每步都要想）。玩家会担心"这关会不会把我堵死"，但不会害怕"困死一次今天白玩了"。

失败的正确语义是「**我这个顺序不对**」，不是「我输了」。

**辅助情绪：收集向内容提供"我在慢慢积累"的情绪价值。**

除了关卡解谜的即时满足外，游戏通过能力图鉴、关卡成就、皮肤外观等收集元素，为玩家提供"我在慢慢变多"的长期情绪支撑。这些内容不承担数值成长职责，只提供情绪价值——让玩家在偶尔打开游戏时，看到自己已经积累了多少东西，产生满足感。

## 不是什么

| 不是 | 原因 |
|---|---|
| 不是 Longcat 换皮 | 有独立的社交系统（每日挑战、好友排行榜、分享奖励）；美术风格完全不同 |
| 不是贪吃蛇 | 无实时推进、无吃道具增长、无时间压力；本作是回合制空间解谜 |
| 不是推箱子 | 木箱子不可推动，是固定障碍；每一步都是不可逆承诺 |
| 不是幸存者类割草 | 无自动战斗、无数值成长、无刷怪 |
| 不是三消 / 无脑休闲 | 每一步都需要空间推理，不是消磨时间的点击游戏 |
| 不是硬核受苦解谜 | 失败只是重来，没有惩罚，换个顺序就能过 |
| 不是剧情向游戏 | 无世界观叙事、无角色养成、无文本分支 |

## 概念定稿

《longcat》的核心不是"滑行的猫"这么泛，而是：

> 划线让银渐层猫咪在草地上滑行，走过的地方长出白色蒲公英，让整片草地开满花。在每日挑战和好友排行榜中，与朋友比拼谁走得更远。

后续 Top Design 必须围绕这个概念展开：
- **循环要短**——单关 20 秒到 2.5 分钟，适配碎片时间。
- **输入要少**——只有划线选方向，不增加任何操作维度。
- **谜题要纯**——胜利条件是填满全部格子，不做覆盖率妥协，不引入数值。
- **差异在社交**——每日挑战、好友排行榜、分享奖励是核心差异化，不做 Roguelike 元层。
- **直线通关**——关卡线性排列，通关即解锁下一关，类似开心消消乐。
- **网格循环**——网格尺寸按节奏循环变化，提供节奏感与变化感。

## 美术方向

- **格子** = 草地
- **起点** = 银渐层猫咪
- **移动方式** = 划线移动猫
- **填充效果** = 猫走过的地方长出白色蒲公英
- **阻挡物** = 木箱子
- **目标语义** = 让整个草地开满花
