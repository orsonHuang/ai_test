## 问题：局外成长的主体是什么——能力池、章节，还是别的？

状态：agent_proposal

### 广度分析

- **候选 A · 能力池解锁为主体**：每次 run 结束按表现解锁新能力进入池子。
  能提供：与核心玩法强耦合——新能力 = 新的解题方式，等于**用一次开发成本获得内容复用**（旧关卡在新的能力组合下是新题）；成长感直接可玩。
  但会带来：解锁完毕后长期目标消失。

- **候选 B · 章节进度为主体**：通关推进章节，解锁新关卡内容。
  能提供：清晰的进度可视化（"我到第三章了"）。
  但会带来：本质是关卡量的包装，不产生新的玩法价值；且关卡由生成器供给，章节只是切分方式。

- **候选 C · 皮肤/收集为主体**：
  能提供：成本最低，视觉反馈强。
  但会带来：不承担玩法价值，撑不起核心循环；且与"不做数值养成"的定位匹配但吸引力不足。

- **候选 D · 排行榜名次为主体**：
  能提供：社交竞争驱动。
  但会带来：依赖用户基数，冷启动无意义；且名次是零和游戏，多数玩家会挫败。

### 深度分析

判断标准是：**哪种成长能反向增强核心玩法，而不只是"额外的内容"？**

候选 A 是唯一有**乘数效应**的：
- 解锁 1 个新能力 → 该能力可与已有的 N 个能力组合 → 后续 run 的可能性空间扩大
- 更重要的是：**新能力让旧关卡产生新解法**。玩家在第 5 关用"允许掉头"重玩，体验与第一次完全不同

这意味着能力池解锁**不只是成长，它同时是内容复用机制**——这对内容消耗极快的解谜游戏是决定性的优势。

候选 B、C、D 都是**加法**（多一章、多一个皮肤、多一个名次），只有 A 是**乘法**。

关于 A 的短板（解锁完毕后目标消失）：
- 短期：能力池 12–15 个（MVP）→ 30+（长期），配合每 run 只拿十几关，解锁周期足够长
- 长期：接棒给每日挑战与排行榜（P1）

顶层设计已定成长主轴优先级为「能力池解锁 > 章节进度 > 皮肤 > 排行」，本题的结论与之完全一致。

### 综合判断

**采用候选 A：局外成长的主体是能力池解锁。**
章节进度作为辅助的进度可视化；皮肤与排行榜排在 P1/P2。
关键认知：**能力池解锁同时是内容复用机制**——新能力让旧关卡产生新解法，这是它优于其他成长方式的根本原因。

## 问题：解锁按什么触发——run 表现、累计进度，还是纯登录？

状态：agent_proposal

### 广度分析

- **候选 A · 按单次 run 表现**（走到第几段决定解锁什么）：
  能提供：强激励，"这次走远点就能解锁新能力"。
  但会带来：失败的 run 毫无产出 → 与"失败 = 少赚不是毁档"矛盾？不矛盾，但会惩罚新手（早期走不远 = 解锁慢 = 更走不远，形成负循环）。

- **候选 B · 按累计进度**（累计通关关数、累计 run 次数）：
  能提供：稳定可预期的解锁节奏；新手也能稳步解锁（正循环）；完全兼容失败（失败的 run 也累计了关数）。
  但会带来：缺乏"这一局很重要"的张力。

- **候选 C · 混合（累计为主 + 里程碑奖励）**：累计进度驱动常规解锁；达成特定里程碑（首次到达第 3 段、首次无伤通关一章）额外解锁。
  能提供：稳定的基础节奏 + 高光时刻的额外激励。
  但会带来：两套解锁逻辑，需维护里程碑表。

- **候选 D · 纯登录/时长**：
  能提供：最简单。
  但会带来：与玩法完全脱钩，玩家没有玩的动力。

### 深度分析

判断标准是：**解锁机制如何与"失败要接住"共存？**

候选 A 有一个隐蔽但致命的问题：**马太效应**。
新手走不远 → 解锁慢 → 能力池小 → 更难走远 → 解锁更慢。
这与"接住失败"的设计意图完全相反——它惩罚的正是最需要帮助的玩家。

候选 B 天然避免这个问题：**失败的 run 也有产出**（它累计了通关关数、累计了 run 次数）。
玩家 run 失败后依然看到解锁进度条前进了 → "这次没白玩" → 这正是"失败 = 少赚"的落地点。

候选 C 在 B 的基础上加里程碑，能制造高光时刻，且成本可控（里程碑表是配置数据不是逻辑）。

值得注意的是，候选 B/C 还有一个好处：**它们不需要"评价"玩家的表现**，因此不会产生"系统说我打得差"的负面感受。

### 综合判断

**采用候选 C：以累计进度（累计通关关数 / run 次数）驱动常规解锁，以里程碑（首次到达某段、首次通关某章）提供额外解锁。**
明确排除候选 A（按单次 run 表现）——它会造成马太效应，惩罚最需要帮助的新手玩家。
具体里程碑表归数值表/配置表。

## 问题：广告位如何预留而不破坏体验？

状态：agent_proposal

### 广度分析

- **候选 A · 关卡间隙插屏**：每 N 关强制插屏。
  能提供：展示量最大。
  但会带来：打断解谜心流——本游戏的核心体验是连续思考，强制打断伤害极大。

- **候选 B · 纯激励视频（提示 / 复活 / 双倍解锁）**：玩家主动选择观看。
  能提供：零打扰；玩家有获得感；且与"接住失败"的设计意图一致（提示与复活本身就是救助机制）。
  但会带来：展示量取决于玩家意愿，收入较低。

- **候选 C · 激励视频为主 + run 结算后一次插屏**：
  能提供：收入与体验的平衡；结算后是天然的内容断点，打断感最小。
  但会带来：仍需谨慎处理"结算后立即弹广告"的观感。

- **候选 D · Banner 常驻**：
  能提供：稳定展示。
  但会带来：长期占据屏幕——对本游戏的全图可读性是致命伤害（空间解谜需要完整视野）。

### 深度分析

判断标准是：**本游戏最不能被打断的是什么？**

答案是**思考的连续性**。玩家在观察地形、脑内推演路径时被打断，等于把已经建立的思维模型清空。
因此候选 A（关卡间隙插屏）和候选 D（常驻 Banner）都不可接受：
- A 打断心流
- D 侵占视野（违反"可读性优先"）

候选 B 是唯一"零打扰"的：玩家主动选择，且看广告换来的是**他此刻正需要的东西**（我卡住了 → 看广告得提示；我快没命了 → 看广告复活）。
这甚至不是"广告"，而是"救助机制"——它与"失败要接住"的设计意图完全一致。

候选 C 在 B 的基础上加结算后插屏。结算后确实是天然断点，但要注意：**结算是"再来一局"的发射台**，如果玩家结算后立刻被广告打断，很可能就不来了。

因此 MVP 阶段建议**只做候选 B**，把 C 的插屏留到 P1 并根据数据决策。

### 综合判断

**采用候选 B（MVP）：只做激励视频，广告位与救助机制合一。**
三个预留点位：
1. **提示**：卡关时看广告获得参考解下一步
2. **复活**：命耗尽时看广告续命
3. **双倍解锁**：run 结算时看广告使本次解锁进度翻倍

**明确排除**：关卡间隙强制插屏（打断心流）、常驻 Banner（侵占视野）。
run 结算后的插屏列为 P1，视数据决定。
