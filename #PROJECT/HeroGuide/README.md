# HeroGuide · 勇者引路人

> **项目代号**：HeroGuide
> **暂定中文名**：勇者引路人（备选：蠢勇者 / 勇者别死）
> **一句话定位**：你是一个"勇者导航员"——勇者很蠢但很勇敢，他只走最短路，你的工作是让最短路别害死他。

---

## 核心玩法

玩家通过放置有限物品（石头、传送门等），引导一个**只会走最短路径**的勇者，绕过陷阱、死胡同和守卫视野，安全抵达魔王面前完成击杀。

**双阶段循环**：
1. **准备阶段**：观察地图 → 放置物品 → 实时查看勇者预计路径（虚线）→ 调整策略
2. **执行阶段**：勇者按最短路径自动行走 → 触发机关/遭遇守卫 → 胜利或失败
