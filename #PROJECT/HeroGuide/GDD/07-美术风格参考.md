| 维度 | 规范 |

## 4. 角色设计规范

### 4.1 勇者

```
外观要点：
- 蓝色冒险者服饰 + 金色头发
- 手持银色长剑
- 表情：坚定但略带呆萌（大眼睛）
- 朝向：4 方向（上下左右）
- 动画：待机（轻微晃动）、行走（4帧）、挥剑（3帧）、传送（缩小）、死亡（弹飞）
```

**待机动画**：身体轻微上下浮动（呼吸感），1.5 秒循环。
**行走动画**：4 帧循环，腿部交替 + 身体轻微弹跳。
**挥剑动画**：举剑 → 劈砍 → 收剑，3 帧。

### 4.2 静态守卫

```
外观要点：
- 紫色皮肤 + 红色眼睛
- 手持三叉戟
- 表情：凶恶
- 朝向：4 方向
- 动画：待机（持叉晃动）、被抓（扑向勇者）、倒地（眩晕）
```

**视野指示**：守卫前方红色半透明覆盖，始终可见。

### 4.3 魔王

```
外观要点：
- 深红色身体 + 金色弯角
- 体型比勇者大 30%
- 表情：威严
- 动画：待机（呼吸）、被击杀（倒地 + 宝箱弹出）
```

## 5. 地图元素美术

### 5.1 地面

- 草地底色 + 随机点缀小花/小草（每格 0-2 个装饰，程序化随机）
- 装饰不影响功能，纯视觉

### 5.2 墙壁

- 石墙风格，顶部高光 + 底部阴影
- 连续墙壁自动拼接（Tilemap 自动规则）

### 5.3 陷阱

- 尖刺从地面突出，灰色金属感
- 准备阶段：可见（半收回状态）
- 执行阶段触发：完全弹出 + 红色闪光

| 特效 | 表现 | 时长 |
|------|------|------|
| 物品放置 | 落地灰尘 + 缩放弹跳 | 200ms |
| 路径更新 | 虚线流光（从勇者流向魔王） | 300ms |
| 传送 | 蓝色粒子旋涡 → 勇者消失/出现 | 300ms |
| 守卫击杀 | 剑光闪 + 守卫倒地 + 星星旋转 | 500ms |
| 陷阱触发 | 尖刺弹出 + 红色溅射 | 400ms |
| 视野被抓 | 守卫冲刺影子 + 红色拖尾 | 400ms |
| 魔王击杀 | 屏幕闪白 + 爆炸粒子 + 宝箱弹出 | 800ms |
| 胜利 | 满屏星星 + 金币雨 | 1000ms |
| 失败 | 红色渐变 + 屏幕震动 | 300ms |

## 9. Steam 版美术升级方向（V2）

- 像素规格升级：64px → 128px
- 增加角色表情系统（待机/紧张/开心/失败）
- 地图增加昼夜/天气变化
- 守卫增加多种造型（龙、骷髅、史莱姆等）
- 魔王多阶段外观变化
- 关卡背景（森林/洞穴/城堡/火山）
