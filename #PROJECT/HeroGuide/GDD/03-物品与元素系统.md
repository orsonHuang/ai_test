# 03 · 物品与元素系统

## 1. 设计原则

物品是玩家影响勇者路径的**唯一手段**。每关给玩家的物品数量有限，迫使玩家做取舍。

**核心设计**：每个物品同时可能有"空间用途"（改变路径形状）和"时间用途"（V2 巡逻守卫引入后，改变勇者到达某格的时机）。MVP 阶段只有空间用途。

---

## 2. MVP 物品清单

MVP 只需 2 种物品即可验证核心玩法：

### 2.1 石头 🪨

| 属性 | 说明 |
|------|------|
| 功能 | 堵住一个格子，使其变为障碍 |
| 寻路影响 | 该格不可通行，迫使寻路绕行 |
| 放置限制 | 不可放在墙壁、守卫本体、魔王格上；**不可放在守卫视野格内** |
| 移除 | 可点击已放置石头移除，退还物品栏 |
| 数量 | 每关定额（通常 2-5 个） |

**核心用途**：
- 堵住陷阱捷径 → 迫使勇者绕路
- 堵住守卫视野格 → 勇者无法走正面，被迫绕后
- 堵住死胡同入口 → 防止勇者走进去
- 增加路径长度 → （V2）延迟勇者到达某格的时机

**示例**：
```
魔王 M
  ↑
  陷阱 T    ← 最短路会走这里（T 权重=1=普通地面）
  ↑
  勇者 H

解法：在 T 放石头 → T 变障碍 → 勇者绕路 → 安全到达
```

### 2.2 传送门 🌀

| 属性 | 说明 |
|------|------|
| 功能 | 成对放置，入口 A ↔ 出口 B，勇者踩入口瞬移到出口 |
| 寻路影响 | A 的邻居额外包含 B，A→B 边权重=0（见 02 文档 2.4） |
| 放置限制 | 入口/出口都不可放在墙壁、守卫本体、魔王格上；不可放在守卫视野格内 |
| 移除 | 移除一个则成对消失，退还 1 对到物品栏 |
| 数量 | 每关定额（通常 0-2 对） |

**核心用途**：
- 跨越障碍/墙壁 → 捷径
- 跨越危险区域（陷阱群、守卫视野区）→ 安全跳跃
- 改变路径长度 → 缩短或延长

**示例**：
```
        墙墙墙墙墙
魔王 M   墙        勇者 H
        墙 陷阱群 墙
        墙墙墙墙墙

无传送门：勇者无路可走 → 失败
放传送门：A(勇者侧) ↔ B(魔王侧) → 勇者走 A → 瞬移 B → 到达魔王
```

**传送门的寻路决策**：A* 会自动比较"走传送门"和"走普通路"哪个更短。如果传送门不划算，勇者不会走。玩家需要确保传送门是更优选择（或唯一选择）。

## 4. 物品栏 UI

```
┌─────────────────────────────┐
│                             │
│        地图区域              │
│                             │
├─────────────────────────────┤
│  物品栏                      │
│  ┌───┐ ┌───┐               │
│  │🪨 ×3│ │🌀 ×1│              │
│  └───┘ └───┘               │
│  [出发 →]                   │
└─────────────────────────────┘
```

- 物品以图标 + 剩余数量显示
- 点击选中（高亮），再点地图空格放置
- 已放置的物品在地图上显示为对应图标
- 点击已放置物品可收回（退还数量）
- 物品栏数量为 0 时该物品灰显

## 6. 物品放置合法性汇总

| 目标格 | 石头 | 传送门 |
|--------|------|--------|
| 普通地面 | ✅ | ✅ |
| 墙壁 | ❌ | ❌ |
| 陷阱 | ✅ | ✅ |
| 石头（已有） | ❌（已占用） | ❌ |
| 传送门（已有） | ❌ | ❌ |
| 守卫本体 | ❌ | ❌ |
| 守卫视野格 | ❌ | ❌ |
| 守卫背后格 | ✅ | ✅ |
| 魔王格 | ❌ | ❌ |
| 魔王相邻格 | ✅ | ✅ |
| 勇者起始格 | ❌ | ❌ |

> **守卫视野格不可放置物品**是核心规则——玩家不能直接堵住守卫视野，必须通过堵其他路来间接引导。
