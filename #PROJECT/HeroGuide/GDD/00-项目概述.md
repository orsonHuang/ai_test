# 00 · 项目概述

## 1. 项目定位

**项目代号**：HeroGuide
**暂定名称**：勇者引路人（备选：蠢勇者 / 勇者别死）
**游戏类型**：策略解谜 / 路径引导
**核心体验**：用有限物品改造地图，让"蠢勇者"的最短路变成安全路。

玩家不直接操控勇者，而是扮演"导航员"角色——勇者具备自主寻路能力（永远走最短路径），但完全无视危险。玩家通过放置石头、传送门等物品改变地图拓扑，间接引导勇者绕过陷阱、死胡同、守卫视野，安全抵达魔王面前。

---

## 2. 目标平台与演进路线

### 当前阶段：MVP 快速验证

| 维度 | 决策 |
|------|------|
| 平台 | 微信小游戏 |
| 变现 | IAA（激励视频广告为主） |
| 开发模式 | 个人开发 |
| 目标 | 最小成本验证"引导寻路"玩法是否有趣 |
| 画面 | 2D 网格制，参考喵喵消消乐画风 |

### 未来阶段：Steam 精品版

玩法验证通过后迭代为 Steam 版本，扩展方向：

- 更精细的美术与动画
- 更复杂的关卡机制（时序机关、多勇者、Boss 战）
- 关卡编辑器 + 创意工坊
- 成就系统、云存档

**架构预留原则**：当前 MVP 的数据驱动设计（关卡 JSON、逻辑与渲染分离）需保证可平滑迁移至 Steam 版本，但不提前实现 Steam 特性。

## 3. MVP 范围定义

### MVP 必须包含 ✅

| 模块 | 内容 |
|------|------|
| 核心玩法 | 双阶段循环（准备 → 执行） |
| 寻路系统 | 纯最短路径 A* 算法 |
| 物品 | 石头、传送门（2 种即可验证核心） |
| 敌人 | 静态守卫、陷阱、魔王 |
| 关卡 | 10-15 关（覆盖基础教学到中级解谜） |
| UI | 准备阶段物品栏 + 虚线路径显示 + 执行阶段播放 + 结算 |
| 变现 | 激励视频（复活、提示、双倍奖励） |
| 社交 | 微信分享复活 |

### MVP 不包含 ❌（留待后续版本）

- 巡逻守卫（时序谜题）→ V2
- 飞龙（固定传送点）→ V2
- 弹簧、诱饵、冰面等高级物品 → V2
- 关卡编辑器 → Steam 版
- 排行榜、成就系统 → Steam 版
- 多勇者机制 → 远期

> **原则**：MVP 只验证一个核心假设——"用有限物品改造勇者最短路径"这个玩法是否有趣且可重复。一切非必要功能推迟。

## 4. 目标用户

| 画像 | 特征 |
|------|------|
| 主力 | 微信小游戏休闲玩家，喜欢解谜/策略类（推箱子、数独受众） |
| 次要 | 碎片时间娱乐需求，单局 1-3 分钟 |
| 付费意愿 | 低（IAA 为主，少量内购可选） |
| 留存驱动 | 关卡解锁 + 星级收集 + 社交分享 |

---

## 5. 核心体验目标

1. **"啊哈"时刻**：玩家放下一块石头，虚线路径瞬间改变，绕开了陷阱——这一刻必须爽快、即时、视觉清晰。
2. **观看张力**：执行阶段勇者按规划路径行走，经过危险区域时玩家"提心吊胆"，安全通过时"松一口气"。
3. **优化驱动**：星级评定鼓励玩家用更少物品通关，产生重复挑战动力。
4. **失败友好**：失败即时反馈，3 秒内可重开，不惩罚试错。

## 6. 商业模式概要

| 收入来源 | 说明 | 详细设计见 |
|----------|------|-----------|
| 激励视频 | 复活、提示、双倍奖励、解锁关卡 | `09-商业化与社交.md` |
| 插屏广告 | 关卡切换时展示（频率可控） | `09-商业化与社交.md` |
| 内购（可选） | 去广告、皮肤包 | V2 考虑 |

**IAA 设计原则**：广告不打断核心体验，只在"自然停顿点"出现（结算后、失败后），且激励视频必须给玩家真实价值。

## 7. 风险与对策

| 风险 | 影响 | 对策 |
|------|------|------|
| 核心玩法不够有趣 | 致命 | MVP 10 关内测，收集留存数据决策 |
| 寻路可视化不清晰 | 高 | 虚线路径 + 危险标注 + 实时更新，反复打磨 UX |
| 关卡难度曲线失控 | 中 | 关卡求解器自动验证有解性 + 最优解 |
| 个人开发产能瓶颈 | 中 | MVP 聚焦最小范围，美术用程序化/素材库 |
| 微信小游戏包体限制 | 低 | 数据驱动 + 纹理压缩 + 分包 |
