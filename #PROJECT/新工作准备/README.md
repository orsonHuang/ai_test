# 新工作准备

> 求职全流程管理：基础简历维护、目标岗位分析、知识点学习、模拟面试。

---

## 目录结构

```
新工作准备/
├── 我的简历/          # 基础简历，以"姓名-整理日期"格式存放
├── 目标公司/          # 目标岗位分析，按公司名分文件夹
├── 知识点/            # 针对岗位需要学习的知识
└── 模拟面试/          # 模拟面试流程与总结
```

---

## 各目录使用规范

### 我的简历

- 存放 Orson 的基础简历（通用版）
- 命名格式：`Orson-YYYYMMDD.md`（如 `Orson-20260728.md`）
- 修改简历时以最新日期版本为准，旧版本保留不删

### 目标公司

- 按公司名新建子文件夹分类（如 `目标公司/腾讯/`、`目标公司/网易/`）
- 岗位描述文件命名：`公司名-岗位名-岗位.md`
- 针对岗位修改的简历命名：`公司名-岗位名-简历.md`
- 公司背景信息命名：`公司名-BaseInformation.md`（如 `腾讯-BaseInformation.md`），收录公司基本信息、成就/成果、负面信息、工商信息与口碑信息
- **规则**：存放岗位资料前，先确认是否已有对应公司文件夹，避免重复建

### 知识点

- 存放针对岗位需要学习的知识文档
- 命名格式：`公司名-岗位名-知识点-知识命名.md`
- 如知识不针对特定公司/岗位，可省略公司名和岗位名

### 模拟面试

- 记录模拟面试的流程、问题和总结
- 命名格式：`公司名-岗位名-模拟面试.md`（通用题可省略公司/岗位前缀）
- 默认模式 A（岗位定向面试）；跨项目通用对比题用模式 B
- 提供简历时，结合 JD 对匹配经历进行压力测试

---

## 工作流程

1. **投递准备**：维护基础简历 → 分析目标岗位（含公司背景信息整理） → 针对岗位改简历 → 学习相关知识
2. **面试准备**：学习岗位知识 → 模拟面试 → 总结复盘
