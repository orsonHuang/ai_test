# 吉事屋-高级系统策划-知识点-暗黑类装备系统与副本设计

> 针对岗位：吉事屋 · 高级系统策划（第三人称 RPG · 装备/技能/副本）
> 核心缺口：暗黑类装备词缀系统、副本系统、第三人称动作战斗
> 参考产品：暗黑破坏神4、流放之路(PoE)、最后纪元、恐怖黎明

---

## 一、暗黑类（Diablo-like）游戏的本质

暗黑类 = **装备驱动的动作 RPG**。核心不是剧情、不是操作，而是**"刷装备 → 搭流派 → 变强 → 刷更强装备"的无限循环**。

```
击杀怪物 → 随机掉落 → 词缀组合 → 构建流派(build) → 挑战更强内容 → 更强装备
     ↑                                                              ↓
     └──────────────── 正反馈循环（多巴胺钩子）──────────────────────┘
```

**和回合制 MMO 装备的本质区别**：

| 维度 | 回合制 MMO 装备 | 暗黑类装备 |
|---|---|---|
| 核心乐趣 | 长线养成、交易保值 | 随机掉落、流派构建 |
| 属性来源 | 固定 + 强化成长 | 随机词缀 |
| 追求目标 | 强化等级/套装 | 极品词缀组合 |
| 交易 | 强（摆摊/拍卖） | 弱/无（或赛季制） |
| 装备更替 | 缓慢（强化可继承） | 频繁（刷到更好的就换） |

## 二、装备系统深度拆解（岗位核心）

### 2.1 装备品质分级

```
白(普通) → 蓝(魔法) → 黄(稀有) → 橙(传奇) → 绿(套装) → 暗金(神话/远古)
```

- 品质越高，词缀数量越多、数值上限越高
- 品质也决定稀有度（掉率）：白色满屏掉，暗金万里挑一

### 2.2 词缀系统（灵魂）

词缀是装备上的**随机属性**，分为三类：

| 类型 | 作用 | 示例 |
|---|---|---|
| 前缀(Prefix) | 进攻/基础属性 | +火焰伤害、+暴击率 |
| 后缀(Suffix) | 生存/功能属性 | +生命、+抗性、+移速 |
| 传奇词缀 | 改变技能形态的独特效果 | "火球分裂成3个""冰冻新星自动释放" |

**词缀等级**：每个词缀有多个 tier（等级），tier 越高数值越大。极品 = 高 tier + 对流派有用的词缀组合。

### 2.3 掉落设计（刷宝的核心体验）

| 机制 | 作用 | 设计要点 |
|---|---|---|
| 掉落率 | 品质越高掉率越低 | 传奇掉率通常 <1% |
| 智能掉落(Smart Loot) | 偏向掉当前职业能用的 | 减少挫败感 |
| 保底机制 | 连续不出传奇，概率递增 | 防止极端非酋流失 |
| 掉落音效/光效 | 情绪正反馈 | 暗黑"掉传奇"的爽感很大程度靠表现 |

### 2.4 流派构建（build 深度）

**核心公式**：

```
流派(build) = 装备词缀 × 技能选择 × 天赋/职业 × 传奇效果
```

**设计目标**：让"看起来没用的装备"在特定流派里变强，制造搭配深度。

**经典案例**：
- 一件"冰伤+暴击"词缀装备 → 对火法无用，对冰法流派是核心
- 一个"旋风斩范围扩大"传奇词缀 → 让旋风蛮流派质变
- 流派数量 = 设计深度，流派越多，装备系统的"搭建"乐趣越强

## 三、技能系统设计

### 3.1 技能树 / 技能升级

- 技能分级解锁，等级越高效果越强
- 技能形态变化：同一技能多种形态（你的 Hero 经验可直接迁移）

### 3.2 技能与装备的联动

- 技能符文/精魂系统（暗黑3）：改变技能的表现和效果
- 技能伤词缀：装备上的"+XX% 技能伤害"
- 联动是 build 深度的关键：技能 × 装备词缀 × 天赋 = 无数组合

## 四、副本系统设计（经验空白，重点补）

### 4.1 副本类型

| 类型 | 目的 | 特点 |
|---|---|---|
| 主线副本 | 剧情推进 | 引导玩家，难度平缓 |
| 挑战副本 | 刷装备 | 高难度，掉好装备 |
| 组队副本 | 多人协作 | 职业搭配、配合 |
| 赛季副本 | 周期性重置 | 赛季新内容、冲榜 |

### 4.2 副本设计四要素

1. **关卡结构**：清怪 → 精英 → Boss 战（三段式节奏）
2. **怪物配置**：小怪（炮灰）→ 精英（机制）→ Boss（压轴）
3. **难度曲线**：难度分层（普通/困难/噩梦/地狱），逐层加词缀/数值
4. **掉落配置**：副本掉落对应装备词缀池，掉率和难度挂钩

### 4.3 副本的"可重复刷"设计

暗黑类副本的核心是**可重复刷性（replayability）**：
- 随机地图（Roguelike 元素）
- 随机怪物组合
- 掉落随机性
- 难度自选（越高掉落越好）

## 五、第三人称动作战斗基础（品类缺口）

### 5.1 打击感四要素

| 要素 | 作用 | 实现 |
|---|---|---|
| 命中帧 | 击中瞬间的停顿 | 命中时短暂冻结/hit stop |
| 硬直 | 受击反馈 | 被击者的僵直动画 |
| 击退/位移 | 力量感 | 击退距离、击飞 |
| 表现 | 视听强化 | 镜头震动、音效、特效、数字飘字 |

### 5.2 操作手感

- 响应延迟：输入到出招的时间，越短手感越好
- 动作前摇/后摇：前摇体现蓄力，后摇可用取消机制衔接
- 取消机制：攻击后摇可被闪避/技能取消，是动作游戏手感的精髓

### 5.3 第三人称视角

- 镜头跟随：跟随玩家 + 目标锁定
- 锁定目标：软锁定/硬锁定，影响操作方式

## 七、面试速记

### 一句话总结暗黑类装备设计
> **品质分层 + 随机词缀 + 掉落平衡 + 流派构建**，让"刷装备"成为无限循环的核心乐趣。

### 必背框架
- **装备**：白蓝黄橙绿品质 → 前缀/后缀/传奇词缀 → 掉落率/保底 → build
- **技能**：技能树 + 形态变化 + 装备词缀联动
- **副本**：清怪→精英→Boss + 难度分层 + 随机掉落
- **动作**：打击感(命中帧/硬直/击退) + 手感(前摇后摇/取消)

### 面试前必须做的三件事
1. **深玩一款暗黑类游戏**（推荐暗黑4或流放之路），能说出它的装备词缀是怎么设计的
2. **用 Axure 画一个系统原型**（比如装备界面），确保现场不翻车
3. **准备一个副本设计思路**（从 0 到 1，包含关卡结构、怪物配置、掉落设计）
