## 一、Roguelike 战斗框架总览

### 核心设计原则
Roguelike 战斗框架和回合制/MMO 的根本区别：

| | 回合制 RPG | MMO | **Roguelike** |
|---|---|---|---|
| 运行模式 | 离散帧（等待输入） | 实时 | **实时 + 高频率** |
| 技能驱动方式 | 手动选择→释放 | 手动按键 | **手动+自动混合** |
| 数值来源 | 固定养成 | 固定养成+装备 | **单局临时词条+永久养成** |
| 平衡方式 | 关卡预设难度 | 生态平衡 | **随机曲线+软保底** |
| 最复杂系统 | 技能状态机 | 网络同步 | **Buff 叠加+构筑计算** |

### 框架架构图（十大系统）

```
┌──────────────────────────────────────────────────────┐
│                  CombatManager（战斗总控）              │
│  - Run 生命周期管理 / Pause/Resume / GameOver         │
├──────────────────────────────────────────────────────┤
│  ┌──────────┐ ┌──────────┐ ┌──────────┐ ┌─────────┐ │
│  │SkillMgr  │ │BuffMgr   │ │DamageCalc│ │AI/Behavior│ │
│  │ 技能管理 │ │ Buff管理 │ │ 伤害计算 │ │  行为系统 │ │
│  └──────────┘ └──────────┘ └──────────┘ └─────────┘ │
│  ┌──────────┐ ┌──────────┐ ┌──────────┐ ┌─────────┐ │
│  │WeaponMgr │ │RNGSystem │ │RoomGen   │ │EventBus │ │
│  │ 武器管理 │ │ 随机系统 │ │ 地图生成 │ │  事件总线│ │
│  └──────────┘ └──────────┘ └──────────┘ └─────────┘ │
│  ┌──────────┐ ┌──────────┐                           │
│  │MetaProg  │ │PoolMgr   │                           │
│  │永久进度  │ │ 对象池   │                           │
│  └──────────┘ └──────────┘                           │
└──────────────────────────────────────────────────────┘
```

**十大系统的职责一句话：**

| 系统 | 一句话职责 |
|---|---|
| CombatManager | 控制整局战斗的生命周期（开始/暂停/结束） |
| SkillSystem | 管理技能从配置→实例化→释放→结算全流程 |
| BuffSystem | 管理所有临时效果（增伤/减速/点燃/DOT/护盾）的叠加和结算 |
| DamageCalculator | 唯一致命入口：输入攻方/守方/技能→输出最终伤害 |
| WeaponSystem | 管理武器类型/词条/组合/联动，肉鸽核心 |
| RNGSystem | 控制随机种子，决定掉落/地图/敌人/词条 |
| AI/BehaviorSystem | 怪物的行为树+技能释放策略 |
| RoomGenerator | 房间模板+随机组合+敌人生成 |
| EventBus | 解耦系统间通信（击杀事件/技能事件/结算事件） |
| MetaProgression | 跨局永久数据（解锁/强化/图鉴） |
| PoolManager | 对象池，子弹/特效/飘字复用，防卡顿 |

## 二、核心系统详细拆解

### 1. CombatManager（战斗总控）

**职责**：控制整局战斗的「生命周期状态机」

```
状态机：
  Init → Running → Paused → Running → GameOver
          ↑                      ↓
          └──────── Resume ──────┘
```

**核心数据结构**（伪代码）：
```csharp
public class CombatManager {
    RunConfig runConfig;        // 本局参数（难度/种子/时长限制）
    List<Hero> aliveHeroes;     // 存活玩家
    List<Enemy> aliveEnemies;   // 存活敌人
    float runTimer;             // 本局计时
    RunState state;             // 当前状态
    
    // 关键方法
    void StartRun(RunConfig cfg);    // 开一局
    void OnHeroDead(Hero h);         // 玩家死亡处理
    void OnEnemyDead(Enemy e);       // 敌人死亡处理
    void OnRoomCleared();            // 房间清空→奖励选择
    void GameOver(bool win);         // 结算→永久进度→返回大厅
}
```

**举例**：开一局《弹壳特攻队》
1. `StartRun` 被调用，传入 `RunConfig`（难度=普通，种子=12345，可用英雄=火女）
2. RNGSystem 用种子初始化随机数发生器
3. RoomGenerator 生成第一关一房间 → 刷怪
4. 玩家击败所有敌人 → CombatManager 触发 `OnRoomCleared`
5. 弹出「选择一个增强」UI（技能三选一 / 武器升级）
6. 循环到第 6 关 Boss → 击败 → GameOver(true)

### 2. RNGSystem（随机系统）—— 肉鸽的核心引擎

**核心原则**：不是完全随机，而是「**控制性随机**」（Controlled Random）

```
随机颗粒度：
├── 地图级随机：房间模板、房间顺序、房间大小
├── 战斗级随机：敌人波次、敌人类型、精英怪概率
├── 掉落级随机：武器掉落、词条掉落、恢复品
└── 构筑级随机：升级三选一、商店刷新、锻造结果
```

**伪代码实现**：
```csharp
public class RNGSystem {
    int seed;                       // 种子（同一种子=同一体验）
    System.Random rng;              // 随机数生成器
    
    // ===== 核心方法 =====
    
    // 加权随机（常见需求）
    T WeightedPick<T>(List<T> pool, List<float> weights) {
        float total = sum(weights);
        float roll = rng.NextFloat() * total;
        float cursor = 0;
        for (int i = 0; i < pool.Count; i++) {
            cursor += weights[i];
            if (roll <= cursor) return pool[i];
        }
        return pool.Last();
    }
    
    // 不放回随机（连抽不重复）
    List<T> PickWithoutReplacement<T>(List<T> pool, int count) {
        var copy = new List<T>(pool);
        var result = new List<T>();
        for (int i = 0; i < count && copy.Count > 0; i++) {
            int idx = rng.Next(copy.Count);
            result.Add(copy[idx]);
            copy.RemoveAt(idx);
        }
        return result;
    }
    
    // 软保底（连续 N 次不出→强制暴击）
    bool PityCheck(ref int badLuckStreak, int threshold, float baseRate) {
        badLuckStreak++;
        if (badLuckStreak >= threshold) {
            badLuckStreak = 0;
            return true;  // 强制暴击
        }
        return rng.NextFloat() < baseRate;
    }
}
```

**举例：升级三选一**
```csharp
// 玩家击败精英怪 → OnRoomCleared → 弹出 buff 三选一
List<Skill> allUnlockedSkills = metaProgression.GetUnlockedSkills();
List<Skill> candidates = rngSystem.PickWithoutReplacement(
    allUnlockedSkills, 3
);
// 如果玩家已经选了 N 次都没出想要的 → PityCheck 强制出一次
if (pityCounter >= 5) {
    candidates[0] = forcePick;  // 软保底
    pityCounter = 0;
}
ShowChoiceUI(candidates);  // UI 弹三选一
```

### 3. DamageCalculator（伤害计算器）—— 唯一致命入口

**原则**：只有一个类负责伤害计算，**所有技能/Buff/武器都只调用它**，保证一致性。

```csharp
public class DamageCalculator {
    
    // ===== 主入口 =====
    public DamageResult Calculate(Unit attacker, Unit defender, SkillCfg skill) {
        var result = new DamageResult();
        
        // Step 1: 基础伤害
        float baseDmg = attacker.ATK * skill.coefficient;
        
        // Step 2: 攻击方加成（乘区 1）
        float attackerBonus = 1.0f;
        foreach (var buff in attacker.activeBuffs) {
            if (buff.type == BuffType.DamageBonus) 
                attackerBonus *= (1 + buff.value);
        }
        
        // Step 3: 防御方减伤（乘区 2）
        float defReduce = 1 - (defender.DEF / (defender.DEF + DEF_CONSTANT));
        foreach (var buff in defender.activeBuffs) {
            if (buff.type == BuffType.DamageReduce)
                defReduce *= (1 - buff.value);
        }
        
        // Step 4: 易伤（乘区 3）—— 这是肉鸽构筑的关键乘区
        float vulnerability = 1.0f;
        foreach (var buff in defender.activeBuffs) {
            if (buff.type == BuffType.Vulnerability)
                vulnerability *= (1 + buff.value);  // 易伤=受伤增加
        }
        
        // Step 5: 暴击判定
        float critRate = attacker.CritRate;
        foreach (var buff in attacker.activeBuffs) {
            if (buff.type == BuffType.CritRate) critRate += buff.value;
        }
        bool isCrit = Random.value < critRate;
        float critMultiplier = isCrit ? (1 + attacker.CritDmg) : 1.0f;
        
        // Step 6: 最终伤害
        result.damage = baseDmg * attackerBonus * defReduce * vulnerability * critMultiplier;
        result.isCrit = isCrit;
        result.isKill = (defender.HP - result.damage <= 0);
        
        // Step 7: 广播事件
        EventBus.Emit("OnDamageDealt", attacker, defender, result);
        
        return result;
    }
}
```

**举例：一个完整的伤害链**
```
玩家攻击力 100
技能"火焰斩"系数 1.5
玩家Buff：+30%火伤、+20%通用增伤
敌人DEF 150（K=100，减伤=150/250=60%）
敌人Buff：-20% 减伤（破甲）、+50% 易伤（点燃效果）
暴击率 25%，暴击伤害 +150%

计算：
基础 = 100 × 1.5 = 150
攻击方加成 = (1+0.3) × (1+0.2) = 1.56
防御方减伤 = (1 - 0.6) × (1 - 0.2) = 0.4 × 0.8 = 0.32
易伤 = 1 + 0.5 = 1.5
假设暴击 → 暴击倍率 = 1 + 1.5 = 2.5

最终伤害 = 150 × 1.56 × 0.32 × 1.5 × 2.5 = 150 × 1.872 = 280.8
飘字：**280**（暴击黄色+大号字体）
```

### 4. BuffSystem（Buff 管理系统）—— 肉鸽构筑的基石

**职责**：管理一切临时效果——增伤/减速/点燃/护盾/无敌/沉默/回复/复活。

**核心设计**：Buff 不是「一个数值」，而是一个**完整的对象**，有生命周期、叠加规则、表现层。

```csharp
public class BuffInstance {
    int buffId;              // 配置表 ID
    string buffName;         // "火焰强化"
    BuffType type;           // DamageBonus/Speed/Slow/DOT/Shield/Invincible...
    BuffStackRule stackRule; // Add/Replace/Refresh/MaxCap
    int maxStack;            // 最大叠加层数
    int currentStack;        // 当前层数
    float duration;          // 剩余持续时间（秒）
    float tickInterval;      // 间隔（DOT用）
    float valuePerStack;     // 每层数值
    
    Unit source;             // 来源
    Unit target;             // 挂载目标
    
    // 生命周期方法
    void OnApply();          // 挂载时触发（播放特效）
    void OnTick(float dt);   // 每帧/每秒触发（DOT 扣血）
    void OnRemove();         // 移除时触发（清除特效）
    void OnStackChange();    // 层数变化（刷新 UI）
}

public class BuffManager {
    List<BuffInstance> activeBuffs;
    
    void ApplyBuff(int buffId, Unit source, Unit target, int stackCount) {
        BuffInstance existing = FindBuff(buffId, target);
        BuffConfig cfg = GetConfig(buffId);
        
        if (existing != null) {
            // 已有 → 按叠加规则处理
            switch (cfg.stackRule) {
                case StackRule.Add:
                    existing.currentStack += stackCount;
                    existing.currentStack = min(existing.currentStack, cfg.maxStack);
                    existing.duration = cfg.duration;  // 刷新时长
                    break;
                case StackRule.Replace:
                    existing.currentStack = stackCount;
                    existing.duration = cfg.duration;
                    break;
                case StackRule.Refresh:
                    existing.duration = cfg.duration;  // 只刷新时长
                    break;
            }
            existing.OnStackChange();
        } else {
            // 新的 → 创建实例
            var buff = new BuffInstance(cfg, source, target, stackCount);
            activeBuffs.Add(buff);
            buff.OnApply();
        }
    }
    
    void TickAll(float dt) {
        for (int i = activeBuffs.Count - 1; i >= 0; i--) {
            var buff = activeBuffs[i];
            buff.duration -= dt;
            if (buff.tickInterval > 0) buff.OnTick(dt);
            if (buff.duration <= 0) {
                buff.OnRemove();
                activeBuffs.RemoveAt(i);
            }
        }
    }
}
```

**举例：DOT（持续伤害）的完整流程**
```
技能"毒箭"击中敌人：
1. ApplyBuff(buffId=3001, source=玩家, target=敌人, stackCount=1)
2. BuffInstance 创建，type=DOT，duration=5秒，tickInterval=1秒，valuePerStack=20
3. 每 1 秒 Tick：敌人 HP -= 20，飘字"20"（绿色）
4. 5 秒后 duration 归零 → OnRemove → 飘字消失
5. 如果毒箭又击中：stackRule=Add → currentStack=2 → 伤害 40/tick
```

### 5. EventBus（事件总线）—— 让系统解耦

**为什么需要**：击杀事件 → 触发 Buff 叠加 → 触发 UI 更新 → 触发成就 → 触发音效。5 个系统不该互相引用。

```csharp
public class EventBus {
    // key = "OnEnemyKilled"  value = [CombatManager, BuffSystem, UISystem, ...]
    Dictionary<string, List<Action<EventData>>> listeners;
    
    void Emit(string eventName, EventData data) {
        if (listeners.ContainsKey(eventName)) {
            foreach (var handler in listeners[eventName]) {
                handler(data);
            }
        }
    }
    
    void On(string eventName, Action<EventData> handler) {
        // 注册监听
    }
}

// 使用（各系统注册监听，不互相引用）
EventBus.On("OnEnemyKilled", data => {
    // BuffSystem：击杀回血 Buff 触发
    if (data.killer.HasBuff("吸血")) {
        data.killer.HP += data.killer.ATK * 0.1;
    }
});
EventBus.On("OnEnemyKilled", data => {
    // CombatManager：检查是否清空房间
    CheckRoomCleared();
});
EventBus.On("OnEnemyKilled", data => {
    // UISystem：连杀计数+1
    UpdateKillStreak();
});
```

## 三、技能系统实现（数据驱动 + 组件化）

### 设计原则

Roguelike 的技能系统不能硬编码。因为：
- 肉鸽有**大量武器词条+技能**（50+ 个），每个都写一个类会爆炸
- 词条随机叠加**极其灵活**，需要组合式技能
- 海外运营需要**热更新技能**，不能走客户端版本

### 方案：数据驱动 + 组件化

```
┌─────────────────────────────────────────────┐
│          SkillConfig（策划配表）               │
│  基础参数 + 效果列表 + 表现层参数              │
├─────────────────────────────────────────────┤
│          SkillInstance（运行时实例）           │
│  读取 Config → 初始化 Effects → 执行生命周期  │
├─────────────────────────────────────────────┤
│          SkillEffect（效果组件）               │
│  DamageEffect / DOTEffect / HealEffect /     │
│  SpawnProjectile / AoE / Teleport / Buff     │
│  → 每个 Effect 是一个可组合的独立模块          │
└─────────────────────────────────────────────┘
```

### 核心代码

```csharp
// ===== 1. SkillConfig =====
[CreateAssetMenu]
public class SkillConfig : ScriptableObject {
    public int skillId;
    public string skillName;
    public SkillType type;           // Active/Passive/Ultimate/WeaponSkill
    public float cooldown;
    public float energyCost;
    public float castTime;           // 前摇
    public float activeFramesDelay;  // 前摇后多少秒触发效果
    public float recovery;           // 后摇
    public bool canBeInterrupted;
    public TargetType targetType;    // Enemy/Self/Ally/Ground/Nearest
    public float range;
    public RangeShape rangeShape;    // Circle/Sector/Rect/Self
    public List<SkillEffectConfig> effects;  // 效果列表（可组合）
    
    // 表现层
    public string animTrigger;       // 动画触发器
    public string vfxOnCast;         // 施法特效
    public string vfxOnHit;          // 命中特效
    public string sfxOnCast;         // 施法音效
    public string sfxOnHit;          // 命中音效
    public float hitFreezeMs;        // 顿帧
    public float cameraShake;        // 震屏强度
    public string floatingTextColor; // 飘字颜色
}

// ===== 2. SkillEffectConfig =====
[System.Serializable]
public class SkillEffectConfig {
    public EffectType type;           // Damage/DOT/Heal/Buff/Debuff/SpawnProjectile/...
    public float value;               // 数值（伤害系数/治疗量/DOT 每跳...）
    public float duration;            // 持续时间（DOT/Buff用）
    public float tickInterval;        // 间隔（DOT用）
    public int buffId;                // 关联的 Buff ID（Buff/Debuff 用）
    public int projectileId;          // 关联的弹幕 ID（远程技能用）
    public TargetType targetType;     // 这个 Effect 的作用目标
    public ConditionConfig condition; // 触发条件（敌人血量<30%时额外伤害等）
}

// ===== 3. SkillInstance（运行时） =====
public class SkillInstance {
    SkillConfig cfg;
    Unit caster;
    float cdRemaining;
    SkillState state;  // Ready/Casting/Active/Recovery/Cooldown
    
    public void TryCast() {
        if (state != SkillState.Ready) return;
        if (cdRemaining > 0) return;
        if (caster.Energy < cfg.energyCost) return;
        
        state = SkillState.Casting;
        caster.Energy -= cfg.energyCost;
        cdRemaining = cfg.cooldown;
        
        // 播放前摇动画
        caster.Animator.SetTrigger(cfg.animTrigger);
        VFXManager.Play(cfg.vfxOnCast, caster.position);
        AudioManager.Play(cfg.sfxOnCast);
        
        // 前摇结束后执行效果
        StartCoroutine(ExecuteAfterDelay(cfg.activeFramesDelay));
    }
    
    IEnumerator ExecuteAfterDelay(float delay) {
        yield return new WaitForSeconds(delay);
        state = SkillState.Active;
        
        foreach (var effectCfg in cfg.effects) {
            ExecuteEffect(effectCfg);
        }
        
        yield return new WaitForSeconds(cfg.recovery);
        state = SkillState.Cooldown;
        StartCoroutine(CooldownRoutine());
    }
    
    void ExecuteEffect(SkillEffectConfig cfg) {
        List<Unit> targets = GetTargets(cfg.targetType, cfg.range);
        foreach (var target in targets) {
            switch (cfg.type) {
                case EffectType.Damage:
                    DamageResult dmg = DamageCalculator.Calculate(caster, target, cfg.value);
                    target.TakeDamage(dmg);
                    VFXManager.PlayAt(cfg.vfxOnHit, target.position);
                    FloatingText.Spawn(dmg.damage.ToString(), target.position, cfg.floatingTextColor);
                    break;
                    
                case EffectType.DOT:
                    BuffSystem.ApplyBuff(cfg.buffId, caster, target, 1);
                    break;
                    
                case EffectType.Heal:
                    float heal = caster.ATK * cfg.value;
                    target.HP += heal;
                    FloatingText.Spawn("+" + heal.ToString(), target.position, "#00FF00");
                    break;
                    
                case EffectType.Buff:
                    BuffSystem.ApplyBuff(cfg.buffId, caster, target, 1);
                    break;
                    
                case EffectType.SpawnProjectile:
                    ProjectileManager.Spawn(cfg.projectileId, caster, target, cfg.value);
                    break;
            }
        }
    }
}
```

## 五、完整举例：一个肉鸽技能从配置到运行的完整链路

### 需求
设计一个技能「**爆裂弩箭**」——远程武器技能，发射一支弩箭，命中后穿透并点燃敌人，如果敌人血量低于 30%，伤害翻倍。

### Step 1：配表

**`skill_config`** 写入一行：
```
skill_id=10005, name="爆裂弩箭", type=WeaponSkill, cooldown=4.0, energy_cost=0,
cast_time=0.2, effect_delay=0.15, recovery=0.3, target_type=Nearest, range=12,
range_shape=Line, anim_trigger="Skill_Crossbow", hit_freeze_ms=50,
camera_shake=0.2, float_color="#FF8800", tags="弩,穿透,点燃"
```

**`skill_effect`** 写入两行（一个技能两个效果）：
```
effect_id=20010, skill_id=10005, order=1, type=SpawnProjectile, value=2.0,
  value_type=ATK_Multiplier, projectile_id=5005

effect_id=20011, skill_id=10005, order=2, type=DOT, value=25,
  value_type=ATK_Percent, buff_id=3001, duration=3.0, tick_interval=1.0,
  condition_id=9002, target_filter="HP<30%: multiply_value=2.0"
```
> effect_id=20010 负责射出弹幕（伤害系数=2.0 ATK）
> effect_id=20011 负责 DOT+斩杀：敌人 HP<30% 时 DOT 翻倍

**`buff_config`** 写入一行（DOT Buff）：
```
buff_id=3001, name="烈焰灼烧", type=DOT, stack_rule=Add, max_stack=5,
duration=3.0, tick_interval=1.0, value_per_stack=25, value_type=ATK_Percent,
vfx_on_target="VFX/Buff/Burning"
```

**`projectile_config`** 写入一行：
```
projectile_id=5005, name="弩箭弹幕", speed=15, lifetime=2.0, 
  behavior="Penetrate", max_penetrations=3, vfx="VFX/Projectile/CrossbowBolt",
  hit_vfx="VFX/Hit/CrossbowHit", sfx_hit="SFX/Crossbow/Hit"
```

### Step 2：运行时流程

```
1. 玩家按技能键
2. SkillInstance.TryCast()
   → cdRemaining 检查（pass）
   → 播放 anim_trigger "Skill_Crossbow"
   → 播放 vfx_cast 施法特效
   → 播放 sfx_cast 施法音效
3. 等待 effect_delay 0.15s
4. ExecuteEffect(effect 20010)：
   → SpawnProjectile(projectile_id=5005)
      ├─ 弹幕以 speed=15 沿方向飞行
      ├─ 命中敌人 → 调用 DamageCalculator.Calculate(skill.coefficient=2.0)
      ├─ behavior=Penetrate → 穿透，找下一个敌人
      └─ max_penetrations=3 → 最多穿 3 个
5. ExecuteEffect(effect 20011)：
   → 检查 target_filter "HP<30%"
   → 如果敌人 HP < 30% → multiply_value=2.0 → DOT value = 25×2 = 50
   → BuffSystem.ApplyBuff(buff_id=3001, stack=1)
      └─ 敌人获得"烈焰灼烧"Buff：每 1 秒扣 ATK×50% 伤害
6. 等待 recovery 0.3s
7. 技能进入 Cooldown 状态（4.0 秒）
8. 表现层同步：
   → hit_freeze_ms=50 → 顿帧 50ms
   → camera_shake=0.2 → 轻微震屏
   → float_color="#FF8800" → 飘字橙色
   → vfx_hit → 命中特效
   → sfx_hit → 命中音效
```

### Step 3：肉鸽构筑亮点

这个技能在构筑上的精彩之处：
- 基础形态：单支弩箭 + DOT，无强化 → 中庸技能
- 词条「**穿透弹**」→ 改为穿透 → 输出提高 3 倍（穿 3 个）
- 词条「**连锁**」→ 穿透改成弹射 → 命中数再翻
- Buff「**火伤+50%**」→ DOT 享受火伤加成 → DOT 价值翻倍
- 词条「**燃烧扩散**」→ 击杀后 DOT 传染给相邻敌人 → 清屏级
- 流派闭环：**弩箭+穿透+火伤+扩散 = 清屏流**

**面试话术**：
> 一个肉鸽技能的深度不在于单次的伤害系数，而在于**它跟武器词条 / Buff / 其他技能的组合空间**。我设计的不是 "一个技能"，是 "一个技能 × N 个词条 × M 个 Buff" 的构筑空间。

## 六、面试高频问题（技能实现方向）

### Q1：「技能怎么实现多段伤害？」
```csharp
// 方案：同一个 skill_effect 走 DO..WHILE 循环
int totalSegments = 3;  // 总共 3 段
float segmentInterval = 0.1f;  // 每段间隔 0.1 秒

for (int i = 0; i < totalSegments; i++) {
    yield return new WaitForSeconds(segmentInterval);
    // 每段独立判定命中/暴击
    ExecuteEffect(damageEffect);
}
// 这样实现的 3 段伤害有 3 次独立飘字和 3 次独立暴击判定
```

### Q2：「怎么实现技能升级？（肉鸽核心）」
```csharp
// 每个技能有 upgrade_level（1-5），配表里每个 level 有独立的数值组
SkillUpgradeConfig upgradeCfg = GetUpgrade(skillId, level);

// Level 1: coef=1.5, range=6, no dot
// Level 2: coef=1.8, range=7, no dot  
// Level 3: coef=2.0, range=8, dot=30%atk, 3s
// Level 4: coef=2.2, range=8, dot=40%atk, 4s, 穿透
// Level 5: coef=2.5, range=10, dot=50%atk, 5s, 穿透, 斩杀
```

### Q3：「武器词条怎么跟技能联动？」
用**事件驱动的插件式架构**：
```csharp
// 武器词条监听"技能命中"事件
EventBus.On("OnSkillHit", data => {
    // 武器词条"火焰强化"：火系技能命中时 +30% 伤害
    if (data.skill.HasTag("火系") && weapon.HasAffix(6005)) {
        data.damage *= 1.3f;
    }
    // 武器词条"连锁"：弩箭命中后弹射到最近敌人
    if (weapon.HasAffix(6002)) {
        Unit nearest = FindNearestEnemy(data.target);
        if (nearest != null) {
            ProjectileManager.Spawn(data.projectileId, data.target, nearest);
        }
    }
});
```

### Q4：「配置表用 Excel 还是 ScriptableObject？」
```
Excel → 策划容易改 / 数值建模方便 / 热更新友好
SO   → 程序直接绑定 / Unity 编辑器可视化 / 表现层参数配置

建议分工：
- 数值类（技能系数 / CD / 伤害 / Buff值）→ Excel + 服务器下发
- 表现类（动画 / 特效 / 音效 / 模型）→ ScriptableObject + 本地包
```

## 总结金句

> "肉鸽战斗框架的核心不是做一个技能，是设计一套能自我繁衍的 **技能 × 词条 × Buff** 三位一体构筑系统。我定义的是规则和接口，真正的内容深度来自组合的爆炸空间。"

> "数据驱动的技能系统意味着——策划在 Excel 里改一个系数，立刻生效；加一个新技能类型，不需要程序改一行代码，只需要新增一个 EffectType 枚举值。这就是模块化设计。"

> "俯视角 3D 肉鸽的打击感和第三人称不一样，顿帧要短（30-80ms），数字飘字要夸大（看不清角色表情只能用数字反馈），清屏反馈要整（不要让信息轰炸玩家）。"
