# 《三角洲行动》系统框架分析

> 整理目的：大梦龙途 / 萨罗斯 面试准备——理解大型竞技射击游戏的系统框架
> 整理时间：2026-08-03

---

## 一、产品概览

| 维度 | 详情 |
|---|---|
| 开发商 | 腾讯天美 J3 工作室 · 琳琅天上团队 |
| 游戏类型 | 战术撤离射击 + 大规模攻防 + PVE 战役 |
| 发行时间 | 2024年9月上线，覆盖全球170+国家 |
| 平台 | PC / 移动 / 主机（全平台互通） |
| DAU | **3000万**（2025年10月里程碑） |
| 引擎 | UE5 + 自研底层框架 |
| 核心定义 | 以"高风险高收益"为核心，融合资源搜集、装备构筑与战术对抗的 PVPVE 体验 |

**一句话定位**：腾讯在《和平精英》与《穿越火线》之后，通过"玩法融合"策略攻占硬核 FPS 市场的关键落子。

## 二、三大核心模式

### 2.1 烽火地带（生存撤离）—— 高留存核心

**玩法本质**：搜 → 打 → 撤（战术撤离射击 Extraction Shooter）

**核心循环**：
```
战前配装 → 进入战区 → 搜索资源/交战 → 路线重规划 → 撤离判定(成功/失败)
    ↑                                                                   ↓
    └──────────── 资产增长/损失 → 影响下一局决策 ←─────────────────────────┘
```

**核心驱动力**：
- **战局驱动**：地图、出生点、撤离点制造不确定性
- **装备驱动**：战前投入决定战中上限与失败成本
- **经济驱动**：每局结果回流局外资产并影响下一局策略

**风险-收益模型**：
- 单局期望收益：`E = p × (L - C) - (1 - p) × D`
  - p：撤离成功率
  - L：撤离价值
  - C：装备投入成本
  - D：装备损失
- 玩家优化目标是 E 的长期最大化，而非单纯的击杀数

**曼德尔砖机制**（核心高潮触发器）：
- 地图中的高价值物品，拾取后位置全图广播
- 强制玩家从"猎人"变为"猎物"
- 有效解决大地图战斗密度不足的问题

**撤离点设计**：
- 固定撤离点：形成最终博弈，撤离路线可被预判
- 条件撤离点：增加不确定性（如需要特定钥匙或任务条件）
- S6 赛季"共享监狱"事件：玩家自发形成合作博弈 → 官方干预 → 舆论反噬 → 核心玩家留存波动不大

**玩家生态分化**：
| 类型 | 行为特征 | 对生态的影响 |
|---|---|---|
| 鼠鼠 | 避战，搜刮为主 | 提供低风险经济来源 |
| 猛攻哥 | 高强度战斗 | 制造战斗密度 |
| 老鼠 | 伏击 | 增加不确定性 |
| 整活 | 娱乐玩法 | 提供内容传播 |

### 2.2 全面战场（大规模攻防）—— 电竞化潜力

**玩法本质**：32v32 载具步兵协同作战，对标《战地》系列

**核心设计**：
- **票数系统**：每死亡消耗票数，票数归零判负
- **扇区占领机制**：将 64 名玩家交火范围限制在狭小区域，保证战斗密度
- **攻方时间紧迫感**：通过票数 + 扇区倒计时制造压迫感

**载具生态（克制链条）**：
```
坦克 > 步兵与轻载具 > 直升机 > 坦克
```
鼓励步坦协同，而非个人英雄主义

**电竞化规划**：
- 开放式席位制联赛
- 2026 烽火世界杯

### 2.3 黑鹰坠落（PVE 战役）—— 情怀与商业化护城河

**玩法**：7 个线性关卡，敌人 AI 攻击欲望强、会包抄，强调小队兵种配合

**商业逻辑**：
- 3A 级品质但**免费发行**
- 本质是"高级新手教程" + 广告素材
- 目的：降低获客成本，将泛用户转化为 PVP 模式活跃玩家

## 三、核心系统拆解

### 3.1 经济系统

**货币体系**：

| 货币 | 类型 | 获取方式 | 用途 | 设计意图 |
|---|---|---|---|---|
| 三角币 | 付费货币 | 充值 | 皮肤、通行证 | 核心盈利来源，不触及 Pay-to-Win |
| 哈弗币 | 免费货币 | 出售战利品、任务 | 升级能力、购买装备 | 核心流通货币，经济循环的血液 |

**核心模块**：
- **特勤处（基础模块）**：经济循环起点，低价出售战利品、升级角色能力、制造物资、收藏室消耗
- **交易行（核心模块）**：玩家间交易平台，高价出售高价值物资，用哈弗币购买其他玩家上架装备
- **三角币商店（盈利模块）**：皮肤和通行证销售

**商业化模型**（设计克制）：
- 战斗通行证
- 枪械与载具外观皮肤（第一人称下展示频次高）
- 安全箱月卡（死亡后保留更多物资的"保险服务"，功能性付费但未触及 P2W）

**灰色产业问题**：
- 护航、代练、陪玩 → 线下真实货币交易
- 引发外挂、脚本号等问题

### 3.2 装备系统（养成系统）

**核心设计思想**：装备不是成长，而是每一次行动的**赌注**

| 装备类型 | 内容 | 说明 |
|---|---|---|
| 战斗力装备 | 武器、护甲、头盔 | 决定战斗力上限 |
| 容量型装备 | 背包、胸挂、**安全箱**、卡包 | 安全箱是重要的保底机制 |
| 消耗品 | 药品、针剂、子弹、房卡 | 一次性使用 |
| 干员 | 突击/侦察/支援/工程 | 战术工具+容错补偿+信息能力插件 |

**改枪台系统**（核心子系统）：
- 金钱 → 枪械性能的转化通道
- 玩家需在后坐力、操控性、精度、重量、隐蔽性等参数间做最优解
- 支持方案分享，降低门槛
- 驱动局内搜刮和市场交易的核心动力

### 3.3 战局系统

**搜索系统**（风险驱动的资源分配）：
- 通过空间分布和容器稀有度制造"风险-收益梯度"
- 高价值资源集中在地图中心（漏斗型结构）
- 引导玩家进行路径决策

**交战系统**：
- 闭环：信息处理 → 决策 → 执行 → 恢复
- **信息优先级 > 枪法优先级**
- PVPVE 混合增加不确定性

**撤离系统**（终极判定层）：
- 只有成功撤离，局内所得才作数
- 撤离失败 → 装备全部损失（除安全箱）

### 3.4 匹配系统（重点分析）

**多维匹配体系**：

```
段位门槛 + 隐藏分(ELO/TrueSkill) + 行为数据建模(SBMM) + 动态调节
```

| 层级 | 作用 | 详情 |
|---|---|---|
| 段位 | 基础范围 | 青铜→传说，7个段位划定匹配池边界 |
| 隐藏分(MMR) | 真实实力 | 基于 K/D、撤离率、赚损比等计算 |
| SBMM | 行为建模 | 分析近期表现，异常数据玩家单独处理 |
| 动态调节 | 自适应 | 连胜/连败快速调整匹配强度 |

**匹配的特殊机制**：

- **"养蛊"机制**：将异常/极端数据玩家分配到同一局
- **"神人局"**：命中率、撤离率等关键数据过低的玩家匹配到一起
- **"高压局"**：连续带出超高价值物资后进入全是高手的对局
- **隐藏分暴增**：频繁"清图"或高价值撤离后，即使段位未提升，也会匹配到更强对手

**排位系统**：

两条独立排位线路：
- 全面战场排位
- 烽火地带排位

段位结构：
```
青铜 → 白银 → 黄金 → 铂金 → 钻石 → 传说
```

| 维度 | 全面战场排位 | 烽火地带排位 |
|---|---|---|
| 积分来源 | 击杀/助攻 + 目标贡献 + 存活时长 + 胜负 | 撤离成功 + 物资价值 + 击杀/助攻 + 情报 |
| 扣分场景 | 排名过低 + 表现差 + 退出 | 撤离失败 + 无有效物资 + 挂机退出 |
| 保底机制 | 低段位保分，高段位扣分趋严 | 安全箱物资不计入扣分评估 |
| 赛季重置 | 每赛季下降 1-2 个大段 | 同步赛季节奏 |

## 五、关键设计洞察

### 5.1 "玩法融合"策略

不是做一个单一玩法的游戏，而是把三个不同体验融合在一个客户端：
- 烽火地带：高投入高风险，留核心玩家
- 全面战场：低挫败高爽快，拉泛用户
- 黑鹰坠落：情怀 + 教学，做获客入口

**好处**：
- 用户漏斗极大：PVE 获客 → 全面战场转化 → 烽火地带沉淀
- 内容更新空间大：三个模式轮流更新，避免内容空窗
- 玩家不流失：某个模式玩腻了可以切另一个

### 5.2 "信息优先"的战斗设计

不是拼枪法，而是拼信息获取和处理能力：
- 声音、枪线、痕迹决定谁先发现谁
- 降低枪法门槛，提高策略深度
- 对不同水平玩家都有参与感

### 5.3 "损失厌恶"的经济驱动

核心不是奖励，而是惩罚：
- 撤离失败 → 装备全损失（除安全箱）
- 这种"痛感"让成功撤离的爽感加倍
- 安全箱作为保底机制 + 付费点，设计巧妙

### 5.4 匹配系统的"分段对待"

不是统一的匹配规则，而是根据数据异常程度分段处理：
- 正常玩家：段位 + MMR 匹配
- 异常玩家：养蛊局 / 神人局 / 高压局
- 避免正常玩家被外挂/脚本污染体验

## 六、对面试的参考价值

### 与萨罗斯岗位的关联

萨罗斯要求的是"匹配排位方向"的系统策划。三角洲的匹配系统提供了**最前沿的参考**：

1. **多维匹配**：段位 + 隐藏分 + 行为建模 + 动态调节——不是单一维度
2. **异常数据处理**：养蛊局/神人局/高压局的"分段对待"策略
3. **两条独立排位线路**：不同模式不同积分逻辑
4. **隐藏分与段位的分离**：MMR 用于匹配，段位用于展示

### 与大梦龙途岗位的关联

大梦龙途要求的是"玩家生态"设计。三角洲是**玩家生态的教科书级案例**：

1. **玩家分化**：鼠鼠/猛攻哥/老鼠/整活——不同玩家有不同生态位
2. **经济循环**：特勤处 → 交易行 → 三角币商店，三环流转
3. **用户漏斗**：PVE → 全面战场 → 烽火地带，层层转化
4. **社交系统**：好友 + 大厅 + AI 对话

## 七、优缺点总结

### 优点

- 搜打撤循环设计合理，赌博式快感强
- 经济系统稳定，扩展性强
- 改枪台自由度高，策略深度丰富
- 信息优先的战斗结构合理，降低枪法门槛
- 成功构建了多元化的玩家生态
- 3000 万 DAU 证明了玩法融合策略的成功

### 缺点

- 经济管控性过强，物价波动不合理
- 撤离失败惩罚过于刚性，除安全箱外无保底
- 外挂、脚本、护航等灰色产业严重
- 匹配机制导致对局体验波动过大
- 部分内容更新缓慢
