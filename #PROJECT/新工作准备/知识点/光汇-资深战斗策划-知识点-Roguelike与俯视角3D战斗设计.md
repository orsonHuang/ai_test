# Roguelike + 俯视角 3D 战斗设计突击 · 光汇面试专项

> 根据补充版 JD 修订：这款产品是**俯视角 3D + Roguelike（肉鸽）+ 海外休闲竞技**
> 重点补强：肉鸽机制 / 俯视角 3D 战斗设计 / 武器系统 / 海外用户偏好

---

## 一、Roguelike 五大核心机制（必须背）

### 1. **永久死亡（Permadeath）**
单局死亡后**永久清空**这一局的成长，回到最初状态重新开始。
- 设计目的：让每次决策都有"重量"
- 平衡点：死亡惩罚太大→挫败感强，太小→决策无意义
- 肉鸽手游的折中：**单局保留基础货币 + 永久解锁树**（参考 Hades / 死亡细胞）

### 2. **随机构筑（Procedural Run）**
每局地图、敌人、奖励组合都**随机生成**。
- 关键设计：**多样性 × 可控性**
  - 完全随机→每局体验不同但可能很烂
  - 模板化随机→每局有结构但同质化
- 优秀做法（Hades）：**手编关卡 × 随机模块**：每大关手编小结构，关卡内房间随机排序

### 3. **局内成长（In-Run Progression）**
单局内通过击败敌人/开宝箱获得**临时 buff**：
- 武器、技能、词条、属性强化
- 关键：**build（构筑）**——多个 buff 的叠加产生质变
- 经典案例：《吸血鬼幸存者》一个武器 + 词条 = 清屏；《弹壳特攻队》武器组合 = 流派

### 4. **永久解锁（Meta Progression）**
跨局保留：角色、技能、武器、图鉴的解锁
- 设计目的：**软死亡保护**——肉鸽手游必须做
- 关键指标：**Meta 解锁强度曲线**（解锁到 50% 时玩家已经可以全通关）

### 5. **单局循环（Run Loop）**
一局内完整的**战斗循环 + 决策循环 + 成长循环**：
```
开局 → 选择技能 → 战斗 → 选 buff → 战斗 → 选 buff → ...
  → BOSS → 结算（解锁/获取资源）→ 下局
```

### 肉鸽手游 vs 端游肉鸽的关键区别
| 维度 | 端游肉鸽 | 手游肉鸽 |
|---|---|---|
| 单局时长 | 30-90 分钟 | **10-20 分钟**（通勤友好） |
| 操作复杂度 | 高（键盘+鼠标） | **低**（摇杆 + 一两个按键） |
| 数值深度 | 极深（构筑几十种） | 中（构筑 5-10 种主流） |
| 死亡惩罚 | 硬（清零） | **软**（保留 30-50% 进度） |
| 商业化 | 买断 / DLC | **抽卡 + 月卡 + 通行证**（参考《弹壳特攻队》） |

## 二、俯视角 3D 战斗设计要点

### 俯视角 vs 第三人称 vs 第一人称

| 维度 | 第一人称 | 第三人称 | **俯视角** |
|---|---|---|---|
| 视野 | 角色所见 | 角色身后 | **全局** |
| 战斗操作 | 准星 | 准星 + 走位 | **摇杆走位** |
| 信息密度 | 低（你看不到背后） | 中 | **高（全场可见）** |
| 决策复杂度 | 1v1 | 1v1~1v2 | **1vN** |
| 代表作 | FPS / 恐怖 | ARPG / ACT | **MOBA / 肉鸽** |

### 俯视角 3D 的核心设计语言

**① 空间感**
- 玩家位置感强（看到全场），但角色动作幅度小（看不见表情）
- 用**角色轮廓 + 颜色 + 技能特效**做识别
- 技能范围要**地面贴花**清楚（圆形/扇形/矩形）

**② 节奏感**
- 玩家可以同时处理"移动 + 攻击 + 技能 + 走位"
- 操作密度比第一人称**高 2-3 倍**
- 单局节奏：移动 30% + 战斗 50% + 决策 20%

**③ 镜头**
- **固定俯视**（最常见）：《弹壳特攻队》、《吸血鬼幸存者》
- **斜 45 度跟随**：《元素地牢》、《弓箭传说》
- **半锁定跟随**（MOBA）：《无尽对决》、《王者荣耀》

**④ 走位/闪避**
- 俯视角 3D 必须有**闪避/翻滚**技能，否则 1vN 走不开
- 闪避 = 无敌帧 0.3 秒 + 短位移 + 短 CD
- 与"动作游戏"的区别：**俯视角不需要完美操作**（自动瞄准辅助常见）

### 俯视角 3D 的打击感要点（和 3D 足球不一样）

| 维度 | 3D 足球（近景大动作） | 俯视角 3D（小角色+大场景） |
|---|---|---|
| 顿帧 | 50-150ms | **30-80ms**（更短，否则画面卡） |
| 特效 | 角色身上精细 | **地面/技能贴花大、角色身上相对简单** |
| 镜头反馈 | 慢动作、镜头推拉 | **镜头快速 zoom + 屏幕震屏 + 屏幕光斑** |
| 音效 | 命中音 + 角色惨叫 | **命中音 + 数字飘字 + 清屏反馈** |
| 数字飘字 | 较少用 | **核心反馈**（俯视角看不见表情，必须用数字） |
| 操作感 | 动作融合精细 | **走位流畅性优先**（不要让顿帧影响走位） |

## 三、武器系统设计（俯视角 3D 肉鸽专项）

JD 明确要求"武器系统"。俯视角肉鸽的武器系统和卡牌/MMO 的武器系统不一样，**核心是"武器 = 战斗构筑的核心载体"**。

### 武器系统的三层结构

```
┌─────────────────────────────────┐
│ Layer 1：武器库（Weapon Pool）   │ ← 玩家可用的武器总数
├─────────────────────────────────┤
│ Layer 2：武器类型（Archetype）   │ ← 大剑/弓/法杖/匕首 等
│   每类武器有独立动作集          │
├─────────────────────────────────┤
│ Layer 3：武器实例（Instance）    │ ← 玩家当前持有的 1-3 把武器
│   + 词条 + 强化等级 + 联动       │
└─────────────────────────────────┘
```

### 武器词条体系

| 词条类型 | 作用 | 举例 |
|---|---|---|
| **基础属性** | 攻击/攻速/暴击 | +10% ATK |
| **特殊机制** | 改变攻击形态 | 穿透 / 弹射 / 连锁 |
| **资源循环** | 影响技能/能量 | 击中回复 CD |
| **环境互动** | 与地形/敌人联动 | 敌人着火时 +30% 伤害 |
| **流派核心** | 决定 build 方向 | 暴击流 / DOT 流 / 召唤流 |

### 武器组合（构筑核心）
**《弹壳特攻队》的成功**：
- 玩家持 1 主武器 + 1 副武器 + 1 宠物
- 不同武器组合产生质变（手枪 + 火箭筒 + 燃烧犬 = 燃烧爆炸流）
- 玩家会主动查攻略、试组合 → 留存高

**你的简历迁移话术**：
> "我做的一技能多形态本质上和武器系统同构——武器=装备技能化。在俯视角肉鸽里，我会设计**武器改变技能形态**而非只改变技能数值，这是质变不是量变。"

### 武器获取/成长的循环

```
局内掉落（临时武器）→ 局外保留（元武器）+ 词条强化 → 永久图鉴解锁
  ↑                                                  ↑
  └──────── 失败代价小，玩家敢试 ──────────────────┘
```

### 海外玩家偏好（光汇目标市场）

**美国玩家**：
- 喜欢**夸张特效 + 清晰数字反馈**（数字一定要飞起来）
- 单局节奏快（3-5 分钟很常见）
- 不喜欢复杂的技能描述，喜欢**看图说话**
- 付费意愿：解锁英雄 > 皮肤 > 通行证

**日本玩家**：
- 喜欢**美术风格化、IP化、收集**
- 接受较长的肉鸽（30 分钟 OK）
- 付费：抽卡 + 联动
- 重视**角色设计感**（不是简单火/水/木）

**韩国玩家**：
- 喜欢**强对抗** + **社交元素**（即使是单机也想看到好友排名）
- ARPG / 肉鸽都吃
- 付费：抽卡 + 通行证

### 适合光汇的肉鸽玩法组合

俯视角 3D + 单局 10-15 分钟 + 武器构筑 + 永久解锁 + 海外美术风格（美/日韩通吃）

## 六、Roguelike 战斗设计的常见面试题

### Q：「肉鸽战斗和 MMORPG 战斗最大区别？」
> **单局长度 × 决策密度 × 死亡代价**三角完全不一样：
> - 单局：肉鸽 10-30 分钟；MMO 通关 50+ 小时
> - 决策：肉鸽每 30 秒一次 build 决策；MMO 装备策略以天为单位
> - 死亡：肉鸽死 = 这局清零（但能换 build 重来）；MMO 死 = 装备掉耐久
> → 肉鸽的战斗设计必须**让每局都有新意**，build 自由度比 MMO 大，但深度比 MMO 浅

### Q：「肉鸽武器系统怎么设计？」
> 三层结构：
> 1. **武器类型**（剑/弓/法杖）：决定动作集 + 攻击节奏
> 2. **武器实例**：基础属性 + 词条 + 强化等级
> 3. **武器组合**（核心）：武器 × 武器 × 词条 = 流派
> 关键设计：**武器不是改数值，是改战斗形态**——这是肉鸽武器系统的灵魂

### Q：「怎么设计一个肉鸽技能让玩家想选？」
> 四点：
> 1. **强反馈**：选择后立即可见的效果（数字飘字、屏幕反馈）
> 2. **强组合性**：跟其他技能有乘法组合（点燃+火伤=双倍）
> 3. **短冷却可见**：高频率触发，让玩家感受到"我选的技能在用"
> 4. **流派闭环**：跟某个武器/词条组合后形成完整 build

### Q：「俯视角 3D 战斗怎么做打击感？」
> 与第三人称不同——**小角色 + 大场景**：
> 1. **数字飘字**：比第三人称更重要（玩家看不清角色表情）
> 2. **地面贴花**：技能范围必须清晰可见
> 3. **屏幕震屏 + 镜头 zoom**：代替近景镜头推拉
> 4. **短顿帧**：30-80ms 而非 50-150ms（画面不能卡太久）
> 5. **清屏反馈**：击杀一群怪时给整体特效（避免信息轰炸）

### Q：「肉鸽 + 海外发行要注意什么？」
> 1. **美术风格化**：不写实不写卡通，**风格化最安全**（《弹壳》《弓箭》都是风格化）
> 2. **单局短**：海外玩家通勤/碎片时间多，3-15 分钟单局最合适
> 3. **强反馈**：海外玩家喜欢夸张数字、夸张特效
> 4. **通行证是标配**：抽卡 + 月卡 + 战令 = 海外标配三件套
> 5. **本地化是差异**：不同市场的奖励/英雄设计都要调整

### Q：「随机性太强，玩家觉得不公平怎么办？」
> 平衡三原则：
> 1. **手编结构 + 随机模块**（Hades 范式）：大关结构固定，关内房间随机
> 2. **软保底**：连续 N 次不出某个关键 buff，强制下一次必出
> 3. **Meta 解锁保护**：即使单局很烂，永久进度保留

## 七、肉鸽战斗策划的核心能力模型（加分用）

当面试官问"肉鸽战斗策划的核心能力"时，按这个五维模型讲：

```
┌────────────┬──────────────────────────┐
│ 维度       │ 核心能力                   │
├────────────┼──────────────────────────┤
│ 设计层     │ 构筑系统设计 / 随机算法    │
│            │ build 平衡 / Meta 解锁曲线 │
├────────────┼──────────────────────────┤
│ 数值层     │ 武器词条数值 / 强化曲线    │
│            │ 平衡性 AB 测试 / 胜率模型  │
├────────────┼──────────────────────────┤
│ 表现层     │ 短顿帧设计 / 数字飘字      │
│            │ 镜头反馈 / 清屏特效        │
├────────────┼──────────────────────────┤
│ 程序层     │ 状态机 / ScriptableObject  │
│            │ 帧事件 / 行为树（怪物 AI） │
├────────────┼──────────────────────────┤
│ 协作层     │ 关卡策划 / 系统策划        │
│            │ 美术 / 商业化 / 发行       │
└────────────┴──────────────────────────┘
```

**金句**："肉鸽战斗策划不是做个技能就完——是设计**构筑系统 + 随机算法 + Meta 曲线**的循环。我看重的不是单个技能多炫，是**整个 build 体系能不能让玩家每局都有新体验**。"

## 八、面试话术：「为什么选择俯视角 3D + 肉鸽方向」

> "我在奕兆做过 Roguelike 活动玩法（参考神觉者魔方神迹），但当时是回合制的表达。俯视角 3D 肉鸽是 Roguelike 在即时战斗里的最佳形态——**构筑深度 × 短单局 × 强反馈**这三件事做到了完美平衡，是过去 5 年全球手游出海最稳的方向（《弓箭》《弹壳》都是这个公式）。
>
> 我自己有 3D 引擎经验（足球项目）、回合 RPG 深度、即时制卡牌经验，加上计算机科班能跑战斗模拟。我觉得这个组合对俯视角肉鸽这个品类**是有差异化价值的**——既能上手，也能做出深度。"
