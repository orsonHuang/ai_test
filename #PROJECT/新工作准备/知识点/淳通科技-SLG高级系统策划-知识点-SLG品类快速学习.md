## 一、先建立 SLG 品类的底层认知

### 1.1 SLG 的演进脉络（先知道这五款产品）

| 时间 | 产品 | 意义 |
|---|---|---|
| 2012 | COC（部落冲突） | 把 SLG 带到手游赛道 |
| 2014 | COK（列王的纷争） | 开创 **COK-like** |
| 2015 | 率土之滨 | 创造 **率土-like** 全新品类 |
| 2019 | 三国志战略版 | 率土-like 的优化+商业化大成 |
| 2023+ | 重返帝国/三国谋定天下 | 赛季制 SLG 的持续演进 |

**你必须先搞懂两个流派**，这是 SLG 策划的基础语言：

### 1.2 COK-like vs 率土-like 的核心区别

| 维度 | COK-like（列王的纷争） | 率土-like（率土之滨/三战） |
|---|---|---|
| **付费点** | 卖资源、卖加速 | 武将抽卡 |
| **资源产出** | 可交易、可掠夺 | 严格控制、玩家间独立 |
| **战斗胜负** | 大R靠钱碾压，1个R打一个盟 | 体力限制，胜负靠活跃玩家 |
| **平衡性** | 差（贫富悬殊） | 好（平民能玩） |
| **赛季** | 无/弱 | 强赛季制 |
| **社交** | PVP 个体对抗 | GVG 联盟对抗 |

**一句话总结**：COK-like 是"谁充钱多谁赢"，率土-like 是"谁运营得好谁赢"。

### 1.3 你入职大概率做哪个流派？

- 淳通科技做的是 SLG，JD 提到"大地图沙盘、赛季制玩法"
- 这两个关键词指向**率土-like**（赛季制是率土-like 的标志）
- 但也可能是 COK-like + 赛季制的混合（很多新 SLG 都做融合）
- **入职后先确认公司在做哪个流派，这决定了你的系统设计方向**

## 二、SLG 的核心系统拆解（入职必懂）

### 2.1 大地图沙盘系统

**是什么**：一张超大地图（百万格子级别），几百到几千玩家同在一张图上。

**核心机制**：

| 机制 | 说明 | 设计要点 |
|---|---|---|
| **地块** | 地图被切成无数小块，玩家可占领 | 地块等级决定资源产出 |
| **连地** | 只能攻打自己/同盟领地的相邻地块 | 制造战略纵深，强化铺路平民的价值 |
| **迷雾** | 未探索区域隐藏信息 | 制造信息差和探索乐趣 |
| **关口** | 山脉河流形成的天然关卡 | 兵家必争之地，制造战略要冲 |
| **行军** | 军队在图上移动，有时间和士气 | 士气血低→伤害降低→需要营帐 |

**你已有的经验能迁移什么**：
- 你做过 Hero 的"竞技场匹配"，本质是"让玩家公平对抗"——大地图沙盘的"连地机制"本质也是"让对抗有战略层次"
- 你做过 Zodiac 的"战前策略"，本质是"策略在局外决策"——SLG 的地块争夺也是"局外长线决策"

### 2.2 赛季制系统（这是率土-like 的灵魂）

**是什么**：每个赛季（3-6个月）玩家从零开始抢地盘，赛季结束部分重置。

**赛季制的核心设计**：

```
赛季开始 → 玩家进入新地图（零起点）
    ↓
开荒期（前1-2周）：抢地、发育、结盟
    ↓
争霸期（中期）：联盟对抗、攻城略地
    ↓
决战期（末期）：霸业争夺、统一/淘汰
    ↓
赛季结算 → 重置地图，保留部分养成（武将/装备）
    ↓
新赛季开始（部分玩家重新洗牌分盟）
```

**赛季制的设计目的**：
1. **解决"后期无聊"**：SLG 养成本来是长线，到后期大R无对手，赛季重置让所有人重新竞争
2. **保留核心付费**：武将、装备跨赛季保留，但地图、资源、建筑重置
3. **创造新鲜感**：每赛季新地图、新机制、新武将，玩家有回来的理由

**赛季重置的"保留/重置"设计（关键）**：

| 内容 | 保留还是重置 | 原因 |
|---|---|---|
| 武将 | ✅ 保留 | 付费核心，必须保留 |
| 装备 | ✅ 保留 | 付费核心 |
| 武将等级 | ✅ 保留 | 避免重复养成 |
| 地图/地块 | ❌ 重置 | 重新竞争 |
| 建筑 | ❌ 重置 | 重新开荒 |
| 资源 | ❌ 重置 | 重新积累 |
| 段位/排行 | ❌ 重置 | 重新争夺 |

### 2.3 武将/养成系统

**率土-like 的养成核心是武将**，六维属性：

| 属性 | 功能 |
|---|---|
| 武力 | 物理攻击 |
| 智力 | 谋略攻击 + 谋略防御（唯一攻防一体） |
| 统率 | 物理防御 |
| 速度 | 决定行动顺序，先手优势大 |
| 政治 | 内政加成 |
| 魅力 | 铸造/寻访/驯马品质 |

**兵种克制**（克制方+20%伤害）：
```
骑兵 → 克盾兵 → 被枪兵克
盾兵 → 克弓兵 → 被骑兵克
弓兵 → 克枪兵 → 被盾兵克
枪兵 → 克骑兵 → 被弓兵克
器械 → 被所有兵种克，但攻城伤害高
```

**战法系统**（6类）：控制、物攻、法攻、被动、兵种、辅助

**羁绊系统**：
- 阵营加成：同阵营同队伍最高+10%
- 武将列传：3名指定武将触发额外加成
- 衍生经典搭配：桃园盾、五虎枪、蜀智、赤壁弓

### 2.4 经济系统（和搜打撤完全不同）

**SLG 的五种资源**：
- 木材、铁矿、石料、粮食（四大基础资源）
- 铜钱（通用货币）

**资源产出**：
- 地图资源矿（地块）
- 主城建筑
- 联盟城市加成

**率土-like 的经济控制（关键）**：
- ❌ 玩家间**不能交易资源**（扼杀资源商）
- ❌ 没有"掠夺"概念（用"俘虏"替代）
- ✅ 资源产出玩家间完全独立
- ✅ 资源购买有较低上限
- ✅ 屯田资源与地块等级挂钩

**征兵控制（平衡关键）**：
- 兵力 = 时间 + 资源，两者都严格控制
- 除升级征兵处外无加速手段
- 这是率土-like 平衡性的核心——**大R有钱也不能无限征兵**

## 三、SLG 用户分层（JD 明确要求）

### 3.1 分层标准

| 用户层 | 占比 | 付费特征 | 核心诉求 | 系统设计要点 |
|---|---|---|---|---|
| **大R** | 1-5% | 月充1万+ | 碾压、炫耀、霸服 | 快速养成、稀有武将、PVP地位 |
| **中R** | 10-20% | 月充500-5000 | 跟随、社交地位 | 中度养成、阶段奖励 |
| **平民** | 70-80% | 不充/小额 | 参与感、归属 | 公平环境、零氪玩法、社区 |
| **回流** | 5-10% | 流失后回归 | 追赶、补偿 | 召回福利、追赶机制 |

### 3.2 大R 和平民的良性关系（这是率土-like 的精髓）

**关键设计：让大R和平民互相依赖，而不是对立**

**大R 的局限**（设计出来的）：
- 行动力受限（体力限制），能做的事情有限
- 百万格子的沙盘无法一个人兼顾所有
- 军队调动需要时间，不能瞬移

**平民的价值**（被设计的）：
- 铺路、拆营帐、攻城器械
- 一个赛季也能养成成型主力
- 攻城战设"杀敌榜"和"攻城榜"，前三都有奖励

**良性生态闭环**：
```
大R 给平民发福利（迁城补贴、红包）
    ↓
平民 帮大R 铺路、攻城、做苦力
    ↓
大R 享受"指挥百万大军"的快感
    ↓
平民 获得联盟归属感和使命感
```

**面试/工作要点**：
- SLG 平衡性的核心标准：**平民可以比大R弱，但不能弱太多**
- "如果一个R能吃掉一个盟，就是严重失衡"——这是 SLG 的平衡红线
- 率土2020年6月"法宝系统"因付费坑深、平衡差、武将贬值遭玩家抗议——反面教材

### 3.3 三个"有钱有闲"维度（率土-like 的经典分层）

| 类型 | 特征 | 游戏角色 |
|---|---|---|
| 有闲 | 时间自由（如大学生） | 主要活跃群体 |
| 有钱 | 资金充裕但时间不自由 | 花钱雇代练 |
| 有钱有闲 | 两者兼备 | 通常当盟主 |

**关键洞察**：SLG 的支撑主体是**中小R平民**，不是大R。大R是付费来源，但平民是活跃来源，缺一不可。

## 四、SLG 商业化设计

### 4.1 率土-like 的付费核心：武将抽卡

**为什么用抽卡而不是明码标价**：
- 一张五星卡明码标价1500块，买的人少
- 抽卡出货率1%，十连150块，理论上同样1500，但"每个玩家付出不同"
- 概率机制让玩家觉得"自己付出少、获得多"，且被认为公平

**抽卡成功的关键要素**：
1. 卡池够大且差异化明显
2. 卡牌间存在关联（触发收集欲）
3. 存在最强卡（树立抽卡目标）
4. 可拓展（新卡与旧卡联动，而非替代）

### 4.2 持续消费刺激机制（内嵌而非运营活动）

| 机制 | 设计 |
|---|---|
| 限时卡包 | 随服务器进度解锁，特定卡概率更高 |
| 赛季末抽卡潮 | 新赛季卡池稀释旧卡，大R付费保关键卡满红 |
| 新赛季限定卡 | 限时过后永不再出（如S2司马懿），强制大R付费 |

**要点**：SLG 的付费刺激是**内嵌在赛季和卡池机制里的**，不是靠频繁运营活动。这和你做过的休闲游戏（红包、活动刺激）完全不同。

### 4.3 养成深度付费坑

成型队伍所需消耗（三战为例）：
- 橙卡：3张核心×6（5张进阶）+6张觉醒+6张战法 = **30张橙卡**
- 紫卡：3×2×14（战法）+3×10（兵书）= **114张紫卡**

**养成系统**：
| 系统 | 消耗 | 功能 |
|---|---|---|
| 进阶 | 重复卡牌 | 提升属性 |
| 觉醒 | 2张同品质卡 | 解锁第三战法槽 |
| 战法传承 | 武将转化 | 获取战法 |
| 战法点 | 白蓝武将转换 | 升级战法（赛季清零） |
| 兵书 | 10张紫卡 | S2开启，提升战力 |
| 典藏卡 | 8换1 | 解决大R垃圾橙卡过剩 |

## 六、面试/入职高频问题（如果是内推，可能直接进入工作场景）

### 问题1："你怎么理解 SLG 的赛季制？"

> 赛季制是解决 SLG "后期无聊"的钥匙。SLG 养成本来是长线的，但到后期大R无对手、平民被碾压，如果没有赛季重置，游戏会快速流失。赛季制的核心是"部分重置"——地图、资源、建筑重置，让所有人重新竞争；武将、装备保留，保护付费。每赛季开荒→争霸→决战的节奏，配合新地图新武将，给玩家持续的新鲜感。

### 问题2："大R和平民怎么平衡？"

> 核心是让两者互相依赖而不是对立。用体力限制、征兵控制、沙盘规模这些设计，让大R"有钱也不能为所欲为"——他需要平民帮他铺路、攻城、运营联盟。同时给平民足够的生存空间和成长路径——一个赛季也能养成成型主力。平衡的红线是"平民可以比大R弱，但不能弱太多，一个R不能吃掉一个盟"。

### 问题3："COK-like 和率土-like 你倾向哪个？为什么？"

> 率土-like 是更成熟、更可持续的方向。COK-like 的付费点（卖资源、卖加速）导致贫富悬殊，大R碾压一切，平衡性差。率土-like 把付费转移到武将抽卡，严格控制资源产出，引入赛季制，让胜负更多依赖活跃玩家而非单一大R，生态更健康。但率土-like 的上手门槛更高，需要更强的引导设计。
