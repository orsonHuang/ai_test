# 明日互联-游戏研发主策划-知识点-回合制MMO核心体系

> 针对岗位：明日互联 · 游戏研发主策划（回合制 MMO 方向）
> 核心缺口：回合制 MMO 的经济系统、装备系统、社交体系
> 参考产品：梦幻西游、大话西游、问道、神武

---

## 一、回合制 MMO 的本质

回合制 MMO ≠ 回合制单机。它和普通回合制 RPG 的核心区别在**三个"多人"**：

| 维度 | 普通回合制 RPG | 回合制 MMO |
|---|---|---|
| 社交 | 无/弱 | 核心（聊天挂机、组队、帮派、结婚、师徒） |
| 经济 | 单向养成 | 自由交易、摆摊、拍卖行 |
| 长线 | 通关即结束 | 无限长线（等级/装备/宠物无限追求） |

**一句话**：回合制 MMO 玩的是"养成的长线目标 + 社交的陪伴感 + 经济的自循环"。

---

## 二、经济系统（命脉，最易翻车）

### 2.1 三大口

```
产出端 ──→ 库存/流通 ──→ 消耗端
(任务/活动/副本/挖宝)  (摆摊/拍卖行)  (强化/洗炼/修理/升级)
```

### 2.2 通货膨胀的根源与解法

| 问题 | 根源 | 解法 |
|---|---|---|
| 货币贬值 | 产出 > 消耗 | 控制产出口上限 + 强化消耗口 |
| 道具贬值 | 掉落泛滥 | 稀有度分层 + 限时活动产出 |
| 物价失控 | 自由交易无约束 | 摆摊/拍卖抽税 + 绑定机制 |

**核心原则**：产出要有"阀值"，消耗要有"黑洞"（永远不够用的消耗口，如强化、洗炼）。

### 2.3 绑定 vs 非绑定

- **绑定**：任务奖励、系统产出 → 防止经济被刷
- **非绑定**：副本掉落、打造产出 → 支撑自由交易
- 平衡点：让玩家"有得交易"，但不能"全都能交易"

## 三、装备系统（JD 点名模块）

### 3.1 五条成长线

| 线 | 玩法 | 付费/消耗点 | 类比 |
|---|---|---|---|
| 打造 | 材料 + 运气出装备 | 材料消耗 | 梦幻打造 |
| 强化 | 等级提升，失败风险 | 强化石 + 保护符 | 问道强化 |
| 洗炼/鉴定 | 属性随机刷新 | 洗炼石，追求极品 | 梦幻鉴定 |
| 镶嵌 | 宝石孔 + 等级 | 宝石合成消耗 | 通用 |
| 套装 | 集齐多件触发 | 收集驱动 | 梦幻套装 |

### 3.2 装备的"运气成分"设计

回合制 MMO 装备的爽点在于**随机性**：
- 鉴定：装备属性随机，可能出"极品"（类似开盲盒）
- 打造：材料 + 运气 → 品质浮动
- 洗炼：反复刷属性，追求极限

**设计要点**：随机性带来"搏一搏"的付费动力，但要设保底，避免挫败感。

### 3.3 装备保值

- 继承：低级装备强化等级可继承到高级
- 分解：废装备分解为材料，材料再进入打造循环
- 交易：极品装备可在拍卖行流通

## 四、社交体系（留存命脉）

### 4.1 核心社交模块

| 模块 | 作用 | 设计要点 |
|---|---|---|
| 组队 | 副本、任务、挂机 | 降低门槛，方便快捷 |
| 帮派 | 归属感 + 集体目标 | 帮派战、帮派技能、帮派活动 |
| 好友 | 陪伴感 | 好友度、送礼、组队加成 |
| 结婚/师徒 | 强关系 | 情感绑定 + 成长互助 |
| 聊天 | 挂机社交 | 世界频道、帮派频道、组队频道 |

### 4.2 回合制 MMO 的"挂机社交"

回合制 MMO 的一大特点是**低操作强度 → 高社交时长**：玩家可以一边挂机刷怪一边聊天。这是回合制 MMO 留存的核心机制。

---

## 五、宠物/伙伴系统（另一大付费点）

1. 捕捉：野外遇怪捕捉
2. 洗资质：刷新宠物资质，追求极品
3. 打书：给宠物学技能，有概率顶掉旧技能
4. 进阶/合宠：宠物合成，追求更强

宠物系统和装备系统一样，核心是**随机性 + 养成长线 + 交易流通**。

## 七、面试速记

- **经济**：产出有阀值、消耗有黑洞、交易要抽税、数据要监控
- **装备**：打造 + 强化 + 洗炼 + 镶嵌 + 套装，随机性 + 保底 + 保值
- **社交**：组队、帮派、好友、结婚/师徒、挂机聊天
- **宠物**：捕捉、洗资质、打书、合宠，和装备一样靠随机性 + 交易

### 面试前必须做的一件事

**深度体验至少一款回合制 MMO**（推荐梦幻西游手游或问道），至少玩到能回答：
1. 它的经济系统怎么防止通胀？
2. 它的装备系统有几条成长线？
3. 它的社交体系靠什么留住玩家？
