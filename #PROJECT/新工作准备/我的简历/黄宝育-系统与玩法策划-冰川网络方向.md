## 精选玩法原型

### 《骰子怪兽》｜骰子构筑 Roguelike Demo
**2026.08｜独立开发，AI 辅助**

- **核心循环：** 设计“投掷 5 颗骰子—选择重摇—选取 3 颗组成牌型—结算伤害”的战斗规则，将回合内的随机结果选择与局内骰子池养成结合。
- **构筑与资源选择：** 以骰子作为随机源及养成载体，设计不同面数、词条、附魔与替换规则；通过战斗奖励、商店和事件提供调整骰子池的机会，形成持续构筑过程。
- **数值与反馈：** 以“牌型基础值、有效点数、能力倍率”组织伤害公式；通过出牌前伤害预览与怪物意图展示，为玩家提供操作和构筑的决策依据。
- **原型落地：** 独立完成 GDD、Lua 实现和数值配置，开发战斗 UI 布局及怪物数值编辑器；怪物、词条、能力、事件配置化，支持快速调整，设计文档按系统记录验证标准与范围边界。

### 《未命名文档》｜AI-NPC 对话解谜 Demo
**2026.07｜独立开发，AI 辅助**

- 实现玩家与机器人角色的自由输入对话，支持游戏命令识别及闲聊处理；通过游戏进度拓展角色知识范围，使对话内容与解谜过程衔接。
- 使用角色卡 Prompt 约束角色知识，结合知识库、Embedding 模型与关键词检索答复，对未覆盖内容调用 AI API 兜底，完成可运行的对话原型。
