### 2026.8 · 独立游戏 — 《骰子怪兽》demo

**项目定位**：一款骰子构筑肉鸽爬塔游戏——玩家用 5 颗骰子投掷、重摇、恰好选 3 颗组成牌型（三条/顺子/对子/散牌）对怪物出伤；在 3 层×8 行的行进度尖塔地图上选择路线，通过奖励替换、商店附魔对骰子池进行养成、构筑，击败最终 Boss 通关。单局 20~40 分钟。

**负责范围**：结合 AI 独立完成全部工作——概念设计、GDD（四阶段：概念/顶层/架构/系统）、Lua 程序实现、数值配置表、自研可视化 UI 调参工具。

**★ 核心亮点**

- **骰子=构筑载体的差异化定位**：对标《小丑牌》《杀戮尖塔》，但不用卡牌、不用筹码经济——骰子既是随机源也是养成载体，"面数定天花板、词条定构筑方向、替换定演进路径"，每场胜利都在回答"池子要不要换血"
- **"投掷→重摇→选3组牌型"的核心循环**：重摇只作用于选中骰子、恰好 3 颗才可出牌（超选警告清空）、牌型判定命中即停（三条>顺子>对子>散牌），配合出牌前实时伤害预览，把每回合压成一次 ≤30 秒的轻判断
- **换血式池演进经济**：奖励必给骰子、满池进替换界面（可放弃）、商店三槽（买骰/附魔/词条骰）+ 休息三选一 + 5 个随机事件，全部领取式奖励、不做一锤子买卖，给玩家主动干预构筑的完整抓手

**<系统设计>**

- **骰子与词条体系**：设计 D4~D12 骰子，玩家可 DIY 骰子池、骰子附魔、骰子数字，构筑专属骰子池
- **行进度地图**：3 层×8 行、每行 23 候选节点的轻量路线取舍，替代树状分叉地图，控制决策密度与单局时长
- **战斗意图系统**：怪物按意图序列行动，回合阶段机驱动"展示意图→玩家出牌→反击"的可预测博弈
- **伤害公式**：`final = (牌型基础值 + Σ有效点数) × 能力倍率`，加法骨架保证散牌回合仍有"点数兜底"手感

**<工程与工具>**

- **配置表驱动**：数值、怪物、词条、能力、事件全部走配置表，改平衡不改代码
- **自研可视化工具**：战斗 UI 布局编辑器、怪物数值编辑器，支撑独立开发下的 UI 快速迭代

### 2026.7 · 独立游戏 — AI对话《未命名文档》· 独立完成

**核心定位**：基于"游戏 AI 策划"实战演示项目，实现一款 AI-NPC 对话解谜游戏。

1. **AI-NPC 人格演化系统**：设计 AI 角色 5 阶段人格状态机，每阶段有独立的知识边界、对话风格、主动行为。通过密码解锁 + 文件读取进度驱动状态切换，AI 随故事深度自然演化——不是"一个 prompt 走到底"，而是受游戏进度约束的"活角色"
2. **混合回复引擎**："预烘焙响应库 + 学习闭环 + RAG + AI兜底"四层架构——响应库智能匹配引擎（四维打分：话题命中+章节匹配+文件条件+Jaccard相似度），未覆盖问题自动调用 LLM 生成并入库学习；AI 仅在兜底时触发并限流。尝试解决"单机游戏用 AI 成本高 + 纯规则太笨"的矛盾
3. **RAG 知识库 + 记忆系统**：搭建 AI-NPC 的记忆管理模块，AI 可访问文件范围随游戏进度动态扩展；使用 embedding 模型在知识库中检索 Top-3 片段，注入 prompt 实现上下文感知回复。NPC 只知道自己"该知道的"，不会剧透
4. **意图识别 + 文件别名系统**：设计关键词驱动的意图识别层，配合完整的文件别名系统，自由对话灵活响应
