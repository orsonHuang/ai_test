# 大梦龙途 JD 职责逐条拆解 · 怎么做

> 整理目的：针对大梦龙途 JD 的 5 条职责，逐条分析"这个职责到底要做什么"和"我能怎么做"
> 参考产品：《三角洲行动》系统框架

---

## 职责 1：基于项目目标和功能具体定位，负责核心玩法匹配规则的设计，输出方案并落地，持续跟进维护

### 这条职责到底要做什么

**核心词**："匹配规则的设计"

这不是让你设计一个匹配算法就完了，而是**围绕核心玩法，设计一套让不同水平的玩家能公平、有趣地匹配到一起的规则体系**。

**在休闲射击品类中，"匹配规则"包括**：

| 层次 | 内容 | 举例 |
|---|---|---|
| 局外匹配 | 段位/隐藏分匹配、组队权重 | 王者荣耀的 ELO |
| 局内分配 | 出生点分配、资源分配 | PUBG 的跳伞路径 |
| 动态调节 | 连胜/连败难度调节 | 三角洲的"高压局"机制 |
| 特殊处理 | 异常玩家分流 | 三角洲的"养蛊局" |

### 怎么做（结合三角洲 + 你的经验）

**第一步：定义匹配目标**

不是"找到实力接近的人"，而是定义清楚：
- 这个游戏的匹配**核心体验**是什么？（公平竞技？还是休闲娱乐？）
- 休闲射击的玩家分层：新手（保护期）→ 普通玩家（正常匹配）→ 高端玩家（放宽匹配）→ 异常玩家（隔离）

**第二步：设计匹配规则**

可以参考三角洲的多维匹配体系：

```
段位门槛 + 隐藏分(MMR) + 行为建模(SBMM) + 动态调节
```

- **段位门槛**：划定匹配池边界（±1~2段）
- **隐藏分**：K/D、撤离率、赚损比等，真实实力评估
- **行为建模**：识别异常数据玩家（外挂、脚本、代练）
- **动态调节**：连胜→难度提升，连败→难度降低

**第三步：休闲射击的特殊设计**

休闲射击不是纯竞技，匹配规则要考虑：
- **新手保护**：前 N 局只匹配新手 + 机器人填充
- **组队公平**：高手带新手时，按最高分匹配还是平均分？
- **出生点公平**：不同水平玩家分配到不同出生点？（远离资源区 vs 靠近资源区）
- **撤离点设计**：匹配段位影响撤离点难度？

**第四步：输出方案**

你已有的经验可以直接复用：
- Hero of Taslinia V1.7.0 的三层匹配公式设计方法
- 5 参数变量（R、Rmin、Rmax、a、C）的思路
- 连胜/连败闭环调节的设计思路
- 机器人填充策略（概率公式含段位+连胜+排名）

**第五步：持续跟进维护**

- 上线后监控：匹配时长、匹配成功率、段位差分布
- 玩家反馈收集：匹配不公平的投诉
- A/B 测试：不同匹配窗口的效果对比
- 迭代：根据数据调整匹配参数

### 面试怎么说

> "匹配规则不是孤立的一个算法，而是围绕核心玩法的一整套体系。我在 Hero of Taslinia 做过三层匹配，包含 5 个参数变量和连胜/连败闭环调节。对于休闲射击品类，我觉得匹配规则还需要考虑局内分配——出生点、资源点、撤离点的分配逻辑，这些也是匹配规则的一部分，会影响玩家的核心体验。三角洲的多维匹配体系给了我很多启发——段位+隐藏分+行为建模+动态调节，四层联动，并且对异常玩家做'分段对待'。"

## 职责 2：持续跟进优化局内玩家体验，结合出生撤离点设计、匹配玩家配比、动线规划等角度，构建并迭代"玩家生态"

### 这条职责到底要做什么

**核心词**："局内玩家体验"和"玩家生态"

这是 JD 中最核心的一条。要求你**不是从单个系统出发，而是从玩家在局内的完整体验出发**，设计和优化整个生态。

**三个关键角度**：

| 角度 | 含义 | 在三角洲中的体现 |
|---|---|---|
| 出生撤离点 | 玩家从哪里开始、从哪里结束 | 固定撤离点形成最终博弈，条件撤离点增加不确定性 |
| 匹配玩家配比 | 不同水平/类型的玩家如何组成一局 | 鼠鼠+猛攻哥+老鼠+整活 自然配比 |
| 动线规划 | 玩家在局内/局外的引导路径 | 高价值资源集中在地图中心，引导玩家路径决策 |

### 怎么做

**第一步：理解"玩家生态"的完整结构**

```
玩家生态 = 核心循环 + 玩家分化 + 经济流转 + 社交关系 + 活动运营
```

不是设计一个系统，而是设计**不同玩家类型在这个游戏里怎么共存**。

三角洲的玩家分化案例：

| 类型 | 行为 | 在生态中的作用 |
|---|---|---|
| 鼠鼠（避战搜刮） | 低风险搜集 | 提供经济基础，供养交易行物资 |
| 猛攻哥（高强度战斗） | 高风险交战 | 制造战斗密度和紧张感 |
| 老鼠（伏击） | 中风险伏击 | 增加不确定性，惩罚大意玩家 |
| 整活（娱乐玩法） | 非主流 | 提供内容传播，降低新手门槛 |

**第二步：出生撤离点设计**

这不是地图策划的事，而是系统策划要考虑的：
- 出生点是否公平？（新手 vs 老手分配到不同区域？）
- 撤离点是否制造了足够的博弈？（固定撤离点可被预判 → 形成蹲守博弈）
- 是否有条件撤离点？（需要钥匙/任务 → 增加不确定性和策略深度）
- 三角洲 S6"共享监狱"事件的启示：官方设计的"合作博弈"可能被玩家抵制，要充分测试

**第三步：匹配玩家配比**

一局 32 人里怎么分配不同水平/类型的玩家？

```
推荐配比（假设）：
- 鼠鼠型（低风险）30%：保证经济基础
- 正常玩家 50%：核心体验
- 猛攻型（高风险）15%：制造战斗密度
- 异常玩家 5%：隔离处理
```

关键不是"都匹配同水平的人"，而是**让一局的体验有起伏、有故事**。

**第四步：动线规划**

玩家从进入地图到撤离，路径是设计出来的，不是随机的：
- 资源分布引导路径（高价值资源在中心，边缘资源少）
- 出生点决定初始方向
- 撤离点决定终点
- 中间的事件（空投、BOSS、曼德尔砖）制造路径变化

**第五步：迭代"玩家生态"**

生态不是设计一次就完事的：
- 监控各类玩家比例变化（鼠鼠太多→战斗密度不够）
- 监控经济流转是否健康（物资通胀/通缩）
- 监控社交是否活跃（好友组队率、战队活跃度）
- 根据数据调整出生点、撤离点、资源分布、匹配配比

### 面试怎么说

> "玩家生态不是单一系统，而是不同玩家类型在游戏里怎么共存。以三角洲为例，它的生态里自然分化出了鼠鼠、猛攻哥、老鼠、整活这四种玩家类型，每种都有自己的生态位。作为系统策划负责人，我的工作是通过出生撤离点、匹配配比、动线规划这三个抓手，设计和调控这个生态的平衡。比如，如果发现某段时间'鼠鼠'比例过高，战斗密度不够，我就需要调整资源分布——把更多高价值资源放在交战区，或者增加曼德尔砖这类'冲突触发器'。我之前的竞技场经验也涉及生态调控——通过匹配公式的参数调整，可以控制竞技场里'碾压局'和'均衡局'的比例。"

## 职责 3：针对各个系统内容提出程序与美术需求，跟进并验收

### 这条职责到底要做什么

**核心词**："提出需求、跟进、验收"

这条看似是执行层的事，但作为系统策划负责人，你的工作不只是提需求，而是**确保需求被正确理解和执行**。

### 怎么做

**第一步：需求标准化**

你已经有这个经验（奕兆执行主策期间"制定文档输出规范/模板，审核输出的需求文档"）：
- 每个系统需求包含：设计目的 → 功能描述 → 交互流程 → 边界条件 → 验收标准
- 用统一模板，让程序/美术不用反复问

**第二步：跨部门沟通**

- **程序**：说清楚逻辑，而不是说效果。"这个按钮点击后调用匹配接口，返回结果后在 UI 上显示"——而不是"这个按钮要好看"
- **美术**：给参考图，说清楚风格和用途。"参考三角洲的改枪台 UI，简洁风格，主要展示武器参数变化"——而不是"做个好看的界面"

**第三步：跟进节奏**

- 每日站会同步进度
- 关键节点检查（原型 → 开发 → 联调 → 测试）
- 发现问题立即沟通，不要等到验收时才发现

**第四步：验收标准**

- 功能验收：所有功能点是否实现
- 体验验收：玩家视角走一遍完整流程
- 边界验收：异常情况是否处理（断网、快速点击、极端数值）
- 数据验收：埋点是否正确上报

### 面试怎么说

> "我在奕兆做执行主策期间，负责审核团队的需求文档，制定输出规范。我的原则是——需求文档要让程序和美术看完不用再问我。另外跨部门沟通时，对程序说逻辑、对美术说效果，不同角色用不同语言。验收方面，我会从玩家视角走完整流程，同时关注边界条件。"

## 职责 4：从已有"玩家生态"出发，能在长线运营活动上输出想法和建议，并通过数据分析不断优化各系统内容以及持续产出新内容

### 这条职责到底要做什么

**核心词**："长线运营活动"和"持续产出新内容"

这是要求你**在玩家生态已经搭建好的基础上，用活动和内容让生态持续活跃**。

### 怎么做

**第一步：活动设计方法论**

活动不是拍脑袋想点子，而是有明确目的：

| 活动目的 | 活动类型 | 举例 |
|---|---|---|
| 拉活跃 | 日常/周常任务 | 每日登录奖励、每周挑战 |
| 拉付费 | 限时促销/抽奖 | 限定皮肤、通行证 |
| 拉回流 | 回归活动 | 回归礼包、回归任务 |
| 拉社交 | 组队活动 | 好友组队加成、战队战 |
| 拉内容消耗 | 新玩法限时 | 新地图限时开放、新 BOSS |

**第二步：活动节奏规划**

参考三角洲的节奏：

```
每日：日常任务（拉登录）
每周：周常任务 + 限时活动（给目标感）
每月：大型活动（拉活跃+付费）
每季：赛季更新（新内容+段位重置）
节日：节日限定（拉回流+社交传播）
```

**第三步：基于数据优化**

- 活动参与率 → 活动设计是否有吸引力
- 活动完成率 → 难度是否合理
- 活动带来的留存变化 → 活动是否有长期价值
- 活动带来的付费变化 → 商业化效果

**第四步：持续产出新内容**

- 内容不是越多越好，要有节奏
- 新内容上线 → 观察数据 → 决定下一个内容方向
- 内容类型轮换：新地图 → 新英雄 → 新玩法 → 新赛季，避免审美疲劳

### 面试怎么说

> "活动设计要从玩家生态出发，而不是孤立地做活动。比如，如果生态里'鼠鼠'型玩家比例高，活动就应该鼓励他们尝试战斗——设计'击杀奖励翻倍'类的活动。如果'猛攻哥'太多导致新手流失，活动就应该设计'保护新手'类的任务。我在 Hero of Taslinia 做过 Roguelike 活动、世界 BOSS 活动、竞技场季奖励规划，每个活动都有明确的生态目的。数据分析方面，我在腾讯做过游戏数据分析，能从大盘数据定位问题。"

## 职责 5：关注玩家反馈，通过数据分析不断优化各系统内容以及持续产出新内容

### 这条职责到底要做什么

**核心词**："玩家反馈"和"数据分析"

这是要求你**建立一套从玩家反馈到数据验证再到方案落地的完整闭环**。

### 怎么做

**第一步：建立玩家反馈收集渠道**

| 渠道 | 获取的信息 | 特点 |
|---|---|---|
| 游戏内反馈 | 具体问题/BUG | 直接、具体 |
| 社区/论坛 | 情绪/趋势 | 有情绪放大效应 |
| 客服数据 | 高频问题 | 可量化 |
| 主播/UP主 | 深度体验 | 有影响力 |
| 核心玩家群 | 深度反馈 | 代表核心用户 |

**第二步：区分情绪反馈和行为反馈**

三角洲 S6"共享监狱"事件的启示：
- 玩家情绪上强烈反对 → 不代表行为上会流失
- 最终核心玩家留存波动不大
- 但负面舆论可能影响新用户获取

**判断方法**：
- 情绪反馈 → 听，但要等数据验证
- 行为反馈（留存/付费/活跃数据变化）→ 这是真实的，立即行动

**第三步：数据分析闭环**

```
发现问题（玩家反馈/数据异常）
    ↓
定位根因（漏斗分析/用户分群）
    ↓
提出方案（系统优化/活动调整/内容更新）
    ↓
A/B 测试（小流量验证）
    ↓
全量上线
    ↓
监控效果（数据对比）
    ↓
继续迭代
```

**第四步：关键监控指标**

| 指标类型 | 具体指标 | 看什么 |
|---|---|---|
| 留存 | 次日/7日/30日留存 | 玩家是否愿意回来 |
| 活跃 | DAU/MAU、在线时长 | 玩家是否在玩 |
| 付费 | ARPU/ARPPU、付费率 | 商业化健康度 |
| 社交 | 好友数、组队率 | 社交是否活跃 |
| 匹配 | 匹配时长、匹配成功率 | 匹配系统健康度 |
| 生态 | 各类型玩家比例、经济流转速度 | 生态是否平衡 |

### 面试怎么说

> "玩家反馈要分两层看：情绪反馈和行为反馈。玩家说'这游戏太烂了'可能是情绪，但如果他的登录频率下降了，那就是真的问题。我在腾讯做过游戏数据分析，习惯用数据验证假设。另外，三角洲 S6'共享监狱'事件给了我一个启示——玩家情绪上强烈反对的设计，行为上不一定流失，但负面舆论对新用户获取有影响。所以在处理玩家反馈时，要同时关注'核心用户留存'和'新用户获取'两个维度。"

## 五条职责的关系总结

这五条职责不是孤立的，而是一个**完整闭环**：

```
职责1（匹配规则）──→ 职责2（局内体验/玩家生态）──→ 职责3（推进落地）
      ↑                                                    ↓
      └──── 职责5（玩家反馈+数据分析）←──── 职责4（长线运营+新内容）
```

- 职责1和2是**设计层**：设计匹配规则和玩家生态
- 职责3是**执行层**：把设计变成可落地的需求
- 职责4和5是**运营层**：通过活动和数据分析让生态持续健康运转
