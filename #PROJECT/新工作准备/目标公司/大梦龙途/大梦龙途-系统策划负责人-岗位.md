## 二、关键词解读

### 「玩家生态」是什么

"玩家生态"不是单一系统，是**围绕核心玩法的一套完整体系**：

```
玩家生态 = 核心循环 + 匹配规则 + 玩家成长 + 社交关系 + 经济系统 + 活动运营
```

**核心循环**：玩家每局/每天在做什么
**匹配规则**：让对的人匹配到一起（休闲射击里有"出生撤离点"这种机制）
**玩家成长**：从新手到核心玩家的成长路径
**社交关系**：好友、战队、公会等
**经济系统**：资源、货币、皮肤、外观
**活动运营**：日常、周常、赛季、节日活动

### 「出生撤离点」「匹配玩家配比」「动线规划」

这是大梦龙途的产品方向——可能是**休闲射击 / 大逃杀 / 战术撤离类**游戏（比如搜打撤、武斗吃鸡）：

| 概念 | 含义 | 类比产品 |
|---|---|---|
| **出生点** | 玩家初始位置设计 | PUBG / 和平精英 / 暗区突围 |
| **撤离点** | 玩家对局结束出口 | 暗区突围 / 塔科夫 |
| **匹配配比** | 不同水平玩家的组队比例 | 王者荣耀 / 永劫无间 |
| **动线规划** | 玩家在局内/局外的引导路径 | 大多数 3A 大世界游戏 |
