## 🃏 卡片 1 · 打击感五维矩阵（JD 核心，必须流畅讲）

| 维度 | 关键词 | 实战案例 |
|---|---|---|
| **视觉** | 顿帧 30-100ms、震屏、镜头推拉、命中特效 | 足球射门命中后顿帧 + 镜头 zoom in |
| **听觉** | 命中音分层（普攻/暴击/处决）、低频垫音 | 暴击加低频"砰"声，区别于普通"啪" |
| **触觉** | 手柄震动（轻/重分级）、移动端震动 | 大招震动时长=施法时长×1.5 |
| **动效** | 预备动作→攻击→回收，动作融合 | 调整球员击球帧，前摇收短、打击帧拉长 |
| **数值** | 飘字颜色/大小/浮空，伤害数字弹跳节奏 | 暴击飘字放大 1.5x + 金黄色 + 停留多 0.2s |

**口诀**：顿帧拉近 + 数字放大 + 音效砸实 + 镜头给到 + 敌人给反应。五件事要**同时发生**，不能有先后感。

## 🃏 卡片 2 · 连招系统（简历无直接经验，必背框架）

```
┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
│  起手    │ →  │  衔接    │ →  │  终结    │ →  │  回收    │
│(低硬直)  │    │(浮空/击退)│    │(高伤害)  │    │(长后摇)  │
└──────────┘    └──────────┘    └──────────┘    └──────────┘
```

**核心概念表**：

| 概念 | 定义 | 设计意义 |
|---|---|---|
| **硬直** | 受击后无法操作的时间窗口 | 连招窗口的长度决定最大段数 |
| **浮空** | 角色离开地面，可接空中技 | 空中高度越低→可选连段越多 |
| **取消窗口** | 动作中可提前中断进入下招（典型 10-20f） | 轻→重 cancel 是连招手感核心 |
| **霸体** | 免疫硬直但不减伤 | 给进攻方容错，但仍有风险 |
| **无敌帧** | 闪避/翻滚的不可命中帧 | 防守方博弈工具 |
| **倒地保护** | 倒地后几帧不可命中 | 防止无限连，强制节奏重置 |

**话术**："连招本质是给玩家一个**练习→熟练→表演**的成长曲线。设计上我关注三件事：帧表决定可行性，硬直窗口决定上限，counter机制保证博弈。"

## 🃏 卡片 3 · 战斗公式（必须会口算）

**标准伤害公式**：
```
Dmg = ATK × SkillCoeff × (1 - DEF/(DEF + K))
```
K = 常数（如 K=100，当 DEF=100 时减伤 50%）

**独立结算公式**（你简历里做过的，必讲）：
```
每段独立计算：miss / 命中 / 暴击 → Sum(各段结果)
```

**乘区隔离模型**（MOBA/竞技类标准）：
```
最终伤害 = 基础伤害 × 增伤乘区 × 减伤乘区 × 易伤乘区
```
各乘区独立相乘，避免加算导致的膨胀。

**DPS 速算**：
```
单技能DPS = (基础伤害 × 命中率 × (1+暴击率×暴击倍率)) / (CD + 施法时间)
角色总DPS = Σ技能DPS + 普攻DPS
```

## 🃏 卡片 4 · 技能设计检查清单（白板题必问）

一个新技能从无到有，按这个顺序讲（5 分钟讲完）：

1. **设计意图**："这个技能解决什么问题？"（缺位移补位移 / 缺爆发补爆发 / 缺控制补控制）
2. **基础三维**：数值（伤害/治疗/时长）× 空间（范围/距离/形状）× 时间（CD/施法/帧）
3. **交互规则**：可否被打断、可否被驱散、无敌帧能否躲、霸体能否扛
4. **反馈表现**：顿帧 ms 数、命中 SFX 分层、VFX、镜头、飘字
5. **反制设计**：对手怎么应对、技能互斥
6. **数值闭环**：DPS × 能耗比 × 风险收益——这三个数要自洽
7. **落地**：状态机 / AnimMontage / ScriptableObject / 帧事件

**技能字段标准表**：ID | 名 | 等级 | 系数 | CD | 能量 | 施法 | 范围 | 目标 | 派生 | 状态限制

## 🃏 卡片 5 · 武器系统迁移话术（简历无此经验）

**如实说 + 迁移论证**：

> "我没有专门做过武器系统，但我做过装备系统 + 技能形态系统。武器可以理解为'装备技能化'——武器不只是属性载体，它自带技能模组/派生技/被动。我设计的'一技能多形态'其实就是武器×技能耦合的雏形：同一件装备改变技能的表现形态和释放逻辑，本质上和武器系统同构。"

**武器系统关键设计维度**（需要会用这些词）：

| 维度 | 说明 |
|---|---|
| 武器分类 | 近战/远程/法系 → 专属动作集 |
| 武器词条 | 基础属性 + 随机词条 + 套装效果 |
| 武器技能 | 被动光环 / 主动技 / 充能大招 |
| 武器羁绊 | 武器×角色 特殊互动（可做差异化核心卖点）|
| 武器成长 | 获取→养成→精炼→升星 的产耗闭环 |

## 🃏 卡片 6.5 · Roguelike 五大机制（肉鸽品类专属）

> 这岗位的核心品类是 Roguelike，必背

| 机制 | 一句话 | 设计要点 |
|---|---|---|
| **永久死亡** | 单局死亡 → 清零 | 手游要做**软死亡**（保留 30-50% 进度） |
| **随机构筑** | 每局武器/敌人/地图都变 | **手编结构 + 随机模块**（Hades 范式） |
| **局内成长** | 单局临时 buff（武器/技能/词条） | **build 自由度高**才有反复玩的动力 |
| **永久解锁** | 跨局保留（角色/武器/图鉴） | **解锁曲线** 是关键：50% 解锁应已能通关 |
| **单局循环** | 一局内的战斗 + 决策 + 成长循环 | 手游单局 10-15 分钟最佳 |

**金句**：肉鸽战斗策划的核心能力 = **设计「构筑系统 + 随机算法 + Meta 曲线」**的循环，不是做一个炫技技能。

**武器 = 形态而非数值**：肉鸽武器的灵魂是**武器改变技能形态**（穿透/弹射/连锁），不是只改数值。

**你的迁移话术**："我做过的'一技能多形态'本质上就是武器系统——武器=装备技能化。"

## 🃏 卡片 6.6 · 俯视角 3D 打击感要点（与第三人称不同）

> 俯视角 3D 的打击感**和足球项目那种第三人称不一样**

| 维度 | 第三人称（足球） | **俯视角 3D**（光汇产品） |
|---|---|---|
| 顿帧 | 50-150ms | **30-80ms**（更短，否则画面卡） |
| 特效位置 | 角色身上精细 | **地面/技能贴花大**、角色身上相对简单 |
| 镜头反馈 | 慢动作 + 镜头推拉 | **快速 zoom + 震屏 + 光斑** |
| 数字飘字 | 较少用 | **核心反馈**（俯视角看不清角色表情） |
| 操作感 | 动作融合精细 | **走位流畅性优先**（顿帧不能影响走位） |

**俯视角 3D 打击感口诀**：**数字 + 贴花 + 短顿帧 + 清屏反馈**——四件套同时给到。
