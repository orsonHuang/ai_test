## 三、要复习的核心知识点（按优先级）

### 1. 战斗系统设计流程（必须能画出来）

```
立项 → 战斗风格定位（轻/中/重、动作/策略比例、目标玩家）
  → 核心循环设计（1局多少秒、攻防比、技能资源分配）
  → 战斗公式建模（伤害/治疗/位移/控制公式）
  → 技能结构（技能ID + 系数 + CD + 资源消耗 + 作用范围 + 目标类型 + 帧数据）
  → 战斗规则（霸体/硬直/打断/无敌/护盾 的优先级表）
  → 表现层（顿帧/震屏/特效/音效/镜头/UI反馈）
  → 数值平衡（自检表+ 胜率模型 + 单局时长模型）
  → 程序对接（状态机/动画montage/事件广播/ScriptableObject）
  → 内测调优（数据+手感反馈）
  → 上线监控（战斗数据看板）
```

### 2. 战斗公式（必须会口算）

- 基础伤害：`Damage = ATK × SkillCoeff × (1 - DEF/(DEF+K))`（典型K=常数）
- 暴击：`Dmg × (1 + CritDmg)`，独立暴击率
- 命中/闪避：分段结算、命中=1-Miss-Dodge
- 真实伤害 / 穿透：固定值或百分比穿甲
- DPS计算：`单次伤害 / 平均CD`，考虑命中率和资源循环
- MOBA/MMO常用：`真实伤害 = 基础 × 增伤乘区 × 减伤乘区 × 易伤乘区`（乘区隔离）

**准备一道题**：给你一个角色的3个技能（DPS分别为800/600/1200，平均CD分别为3/5/8秒），问一个标准战斗的DPS怎么算、怎么和对手T平衡？

### 3. 技能设计结构（背熟，立刻能讲）

| 字段 | 作用 |
|---|---|
| 技能ID / 名称 / 图标 / 描述 | 标识+可读性 |
| CD / 法力消耗 / 资源消耗 | 资源循环入口 |
| 施法时间 / 前摇 / 后摇 | 决定是否可被打断 |
| 作用范围（圆形/扇形/矩形/单体/链式） | 决定空间感 |
| 目标类型（友/敌/自身/地形） | 决定策略 |
| 伤害/治疗/位移/控制时长 | 决定峰值 |
| 命中帧/特效帧/SFX帧 | 决定打击感 |
| 派生技能 / 强化分支 | 决定成长 |
| 状态机（可释放/冷却/沉默/封印） | 决定异常 |

### 4. 连招系统（重点突击）

- **状态机表**：Idle → Casting → ActiveFrames → Recovery → Cooldown
- **硬直 / 浮空 / 击退 / 击飞 / 倒地**：每一类对应不同接招窗口
- **段数取消**：轻击→重击的cancel窗口（典型动作游戏）
- **空中连段**：浮空高度/坠落速度决定最大段数
- **霸体**：吸收硬直但不掉血
- **无敌帧**：常见于翻滚/dodge
- **打断阈值**：伤害累计到一定值打断当前动作

### 5. 打击感五维矩阵（面试话术）

| 维度 | 关键元素 |
|---|---|
| 视觉 | 顿帧（命中freeze 30-100ms）、顿帧长度差、命中特效、震屏、镜头推拉、减速 |
| 听觉 | 命中音效分层（命中/爆击/特殊）、低频反馈、停止其他音轨 |
| 触觉 | 手柄震动（轻重区分）、移动端震动 |
| 动效 | 动作融合、pre-anticipation（预备动作）、follow-through（惯性回收）、位移 |
| 数值 | 数字飘字（颜色/大小/浮空时长）、节奏曲线（HIT1最快、HIT3最强）|

**口诀**：顿帧拉近 + 数字飘字放大 + 命中音砸实 + 相机给到 + 敌人给到反应。

### 6. 战斗节奏控制

- 节奏=玩家"操作密度 × 决策密度 × 反馈密度"在三段时间的分布
- **呼吸点**：大招完后的减速、子弹时间
- **峰值-低谷曲线**：参考皇室战争开局/单局/收尾
- **博弈循环**：移动→试探→交锋→决策→结果（5步黄金法则）

### 7. 数值建模（Excel向）

- 自建战斗数值表：基础属性、增伤乘区、Buff/Debuff、最终输出
- 模拟战数据：每10秒tick一次的伪战斗模拟
- 数据透视：每个英雄在每个段位的胜率/出场率/被针对率
- 平衡循环：微调技能系数→跑模拟→上AB测试
- **VLOOKUP/INDEX-MATCH/数据透视/条件格式**必须熟练

### 8. 武器系统（要补的知识点）

- 武器分类：近战/远程/法系/特殊 → 各自专属动作集
- 武器词条：基础属性 + 随机词条 + 套装效果
- 武器技能：被动光环 / 主动技能 / 充能大招
- 武器羁绊：武器×角色 的特殊互动
- 武器获取/养成/精炼/升星
- 与角色技能**耦合设计**：武器改变技能？还是角色技能不变、武器做数值扩展？

### 9. Unity / Unreal 战斗相关（加分）

- 动画系统：State Machine / AnimMontage（UE）/ Timeline / Playable
- 触发帧事件：Animation Event / Notify
- 物体池（Object Pool）防卡顿
- ScriptableObject 存技能数据
- 帧同步 vs 状态同步（联网战斗）

### 10. 竞品分析框架

每款产品按以下维度拆解：
- 战斗核心循环（1局时长/操作密度/决策点）
- 职业体系（多少职业/定位分布/策略空间）
- 战斗公式（伤害类型/乘区/硬控软控占比）
- 打击感语言（顿帧/sfx/震屏节奏）
- 资源循环（能量/技能/CD/位置）
- 留存机制（皮肤/赛季/段位）
- 创新点 + 痛点

**准备拆解**：
- 《荒野乱斗》/《皇室战争》/《王者荣耀》（必须）
- 《原神》战斗（次要）/《英雄联盟手游》/《无畏契约：源能行动》

### Q4：怎么设计一个战斗技能？（白板题）
按这个结构答（5–8分钟）：
1. **设计意图**（这技能解决什么问题：缺乏位移？缺乏控制？缺乏爆发？）
2. **基础三维**：数值（伤害/治疗/控制时长）、空间（范围/距离）、时间（CD/施法/帧）
3. **交互规则**：打断、可否被驱散、能否被无敌躲
4. **反馈/表现**：顿帧、HIT帧、SFX、VFX、镜头、飘字
5. **反制设计**：有没有被counter、技能互斥
6. **数值闭环**：DPS、能耗比、风险收益
7. **落地**：程序实现方案、ScriptableObject、动画Montage位置

### Q5：打击感怎么调？
1. 五维矩阵（视觉/听觉/触觉/动效/数值）一顿讲；
2. 实战举例：把"顿帧80ms、命中SFX垫低频、敌人给到反应动作"三件套说到一起；
3. 数据验证：玩家命中后到下一次操作的间隔，叫做**hit-tap latency**，衡量是否"上头"。

### Q6：连招怎么设计？（要突击准备）
- **设计目标**：让玩家"练习 → 熟练 → 表演"三阶段
- 状态表 + 帧表（pre-anim/active/recovery）× 角色硬直状态（normal/浮空/倒地/受击）
- 给一段可取消窗口（典型10f~20f）
- 设计counter：高伤害招式必有长后摇或硬直，给对手窗口
- 案例：DNF/Diablo ARPG 在浮空高度做连段上限；ACT游戏（鬼泣/猎天使）对"目录式招式"的设计

### Q7：数值怎么平衡？
- **胜率模型**：每个分段每个英雄的胜率，目标50±3%
- **出场率**：太高→强势→微砍；太低→疲弱→给数值或机制
- **DPS曲线**：每30秒一轮，技能DPS、普攻DPS、被动DPS
- **节奏曲线**：单局时长目标（比如90-120秒）、爆发点分布
- **ab测试**：单一变量原则，每次只动1-2个数值
- **Excel实践**：表结构 = 英雄×属性×系数×场景

### Q8：最有成就感的项目？
> 选 **Zodiac Heroes 战斗框架** 或 **3D足球打击感**。故事结构：
> - **背景**：当时问题是什么
> - **我的角色**：独立/牵头/协助
> - **做了什么**：具体方案（不是形容词）
> - **结果**：数据/反馈/同事评价
> - **如果重来一次**：复盘一句话

### Q9：怎么和程序、美术协作？
- 立文档规范：模板、字段表、版本号、变更日志
- 立 review 流程：需求评审会、技术评审、视觉评审
- 立里程碑：方案 lock-in、动效白模、功能完成、表现完成
- 立沟通节奏：站会、版本会、调优周
- 程序需要：状态机、动画帧事件、ScriptableObject结构
- 美术需要：动效时长、命中点、SFX标签、震屏参数

### Q10：你还有什么想问我们的？（必问 2–3 个）
1. 这款产品的当前阶段？**Demo / 开发中 / 调优 / 已上线** —— 决定你进去做的事
2. 战斗团队多大？我进去是独立负责，还是有主策带着？
3. 数值是用Excel还是自研工具？
4. 上线/调优期数据是怎么看？
5. 立项时你们对标的是哪款产品？（很重要，帮你判断设计语言）

## 五、面试官几乎一定问的反向陷阱题

### 1）「你用 Excel 做过什么？」 —— JD第一个硬标签
准备一段：用Excel搭过一个**技能数值表**（列：技能ID/等级/系数/CD/能量/范围/目标/派生；行：每个技能每级），用VLOOKUP + 数据透视 + 条件格式**一秒定位超标技能**，并能给你show一下我做的真实表（把奕兆项目里用的表截图带去）。

### 2）「怎么和数值策划协作？」 —— 你面试的是资深战斗
准备话术：你自己的数值表，**对自己武器的DPS负责**，策划会给你"胜率/出场/时长"宏观反馈，你再去调。**不是数值策划帮你调，是你调完让数值验证**。

### 3）「说一个失败案例 / 你做错的决定」
准备一个真实的（Zodiac某个技能上线后过强、Hero的天赋系统规则太复杂导致玩家摸不着头脑都行）。
模板：**背景 → 我做了什么 → 结果是什么 → 我现在怎么处理这个问题**。

### 4）「你最有意见的产品是什么？为什么？」 —— 看你有没有体系化思考
避免"我不喜欢XX"。准备拆某款产品**战斗设计上1-2个明确的失败点**，并给出"我会怎么做"。

### 5）「你玩了哪些肉鸽/俯视角 3D？为什么没做？」 —— 看你有没有"用户视角"
**必玩清单**（按 JD 偏好）：
- **《吸血鬼幸存者》/《弹壳特攻队》** ← 俯视角 3D + 肉鸽 + 海外爆款，**面试必谈**
- **《元素地牢》** ← 俯视角 3D + 肉鸽 + 国内产品，对标中文市场
- **《弓箭传说》** ← 俯视角 3D + 单指操作，**对标海外休闲竞技方向**
- **《Hades》/《死亡细胞》** ← 端游/PC 上对标，**讲清构筑和成长**
- **《无尽对决》（Mobile Legends）** ← MOBA 俯视角 3D，讲清职业和地图
- **《荒野乱斗》/《皇室战争》** ← 俯视角休闲竞技老三样

准备格式：「产品/玩了多久/喜欢哪里/讨厌哪里/战斗什么做得好」+ 「如果我来做俯视角肉鸽，我会怎么设计战斗循环」。

### 6）「薪资期望？」 —— JD 20-35K，你现执行主策
- 你简历gap补强足+主导过 0-1 战斗系统 + 计算机背景，可以要 **25-30K**（中位偏上）
- 现金+股权/奖金一并问
- 反问："贵司这个岗位的薪资带宽是怎么分的？跟资历/项目阶段挂钩吗？"

## 七、临场突发情况应对

| 情况 | 应对 |
|---|---|
| 被问到完全不懂的（比如UE5具体某个模块） | "这块我用的是Unity的等价方案，UE5的X模块我没实操过，但我能快速上手——我学UE这个模块要多久？"（诚实+学习意愿） |

| 被问到加班 | 看个人意愿。我倾向**反对无效加班但接受冲刺期**——趁机问"贵司项目节奏？" |
