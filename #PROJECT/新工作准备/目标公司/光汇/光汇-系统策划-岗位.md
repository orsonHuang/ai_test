### 拆解每个系统在肉鸽中的具体内容

**① 养成系统（肉鸽里叫「Meta Progression」）**
- 角色养成：角色解锁、角色等级、角色技能升级（跨局保留）
- 武器养成：武器获取、武器升级、武器精炼、武器图鉴
- 词条系统：词条解锁、词条升级、词条组合效果
- 天赋树/科技树：全局永久 Buff（攻击+1%/移速+1%...）
- ⚠️ 肉鸽特有：养成不是无限堆数值——要设计**养成天花板**，避免老玩家碾压

**② 经济系统**
- 货币设计：软币（金币/钻石）+ 硬币（付费钻石/赛季币）
- 这个品类常见的货币矩阵：
  ```
  金币（局内获取）→ 养成的底层消耗
  钻石（局内少量获取 + 付费）→ 加速/抽卡/复活
  赛季币（赛季任务）→ 赛季专属奖励
  友情点（好友互动）→ 社交货币
  ```
- 产耗平衡：产出表（每个行为给多少）vs 消耗表（升级要多少）
- ⚠️ 海外常见：双货币制（金币+宝石）+ 看广告

**③ 商业化**
- 抽卡：角色/武器 gacha（日韩市场必备）
- 通行证（Battle Pass）：免费线 + 付费线 → 海外标配
- 月卡：每日签到领钻 → 高留存工具
- 皮肤/外观：不卖数值，卖情绪价值
- 礼包：限时/新手/节日/等级礼包
- ⚠️ 关键：肉鸽的商业化**不能卖构筑优势**——这是玩家底线

**④ 社交系统**
- 好友：加好友/送体力/友情点（参考《弹壳特攻队》）
- 排行榜：通关时间榜/最高层数榜/赛季积分榜
- 公会/战队：公会任务 + 公会Boss + 公会商店
- 合作模式（可选）：双人合作肉鸽（参考《元素地牢》）
- ⚠️ 海外玩家偏好「轻度社交」——排行榜比公会更重要

**⑤ 活动系统**
- 日常活动：每日任务/每日副本/每日签到
- 周常活动：周任务/周末双倍/限时副本
- 赛季活动：赛季通行证 + 赛季排名 + 赛季限定
- 节日活动：海外节日（圣诞/万圣/感恩）+ 联动活动
- ⚠️ 出海注意：**不要用春节做主力活动**——海外玩家不过春节

**⑥ 任务/成就**
- 主线任务：引导玩家理解 Meta 系统
- 日常任务：上线动力（「今天不做就亏了」）
- 周常任务：长线目标
- 成就系统：里程碑式一次性奖励（「通关第 10 层」「收集 50 把武器」）
- 隐藏成就：探索型玩家偏好

**⑦ 新手引导**
- 第一印象：前 30 秒决定留存——3 步教学（移动 → 攻击 → 选技能）
- 引导节奏：第 1 天（学会玩）→ 第 3 天（发现深度）→ 第 7 天（养成循环）
- 留存漏斗：D1 40% / D3 20% / D7 10% / D30 5%（肉鸽品类标准）
- 软引导：不打断操作、不强制阅读、渐进式解锁

**⑧ 数据配置/中台**
- 做一个系统策划，你的核心产出物是 **Excel + 配表 + 流程图**
- 中台系统设计（如果团队小，你可能要兼）：公告、邮件、物品、礼包码、客服
- ⚠️ 跨界公司：光汇不是纯游戏厂，中台大概率是新人搭，**这是你的机会也是挑战**

## 二、系统策划核心能力模型

面试官考察系统策划，核心是三个问题：
1. 你能不能**从 0 定义清楚一个系统**？（设计能力）
2. 你的系统能不能**跟其他系统不打架**？（架构能力）
3. 你的系统能不能**在给定的资源内上线**？（执行能力）

### 五维能力雷达

```
         设计层
          / \
         /   \
   执行层    架构层
       \     /
        \   /
    数据层   协调层
```

| 维度 | 能力 | 面试怎么展示 |
|---|---|---|
| **设计层** | 从需求到方案到文档 | 拿一份真实的设计文档去（哪怕是旧项目的） |
| **架构层** | 系统之间的数据流、逻辑边界 | 画一张「这个项目的系统全景图」给面试官看 |
| **数据层** | Excel 配置表、数值表、条件格式 | 带你的数值表截图 |
| **执行层** | 跟进、协调、上线、调优 | 讲一个「从文档到上线」的完整故事 |
| **协调层** | 跟战斗策划/程序/美术/运营的接口 | 讲一个跨部门推动的案例 |

## 三、系统框架从 0 开始搭建（用户附加问题 1）

这是面试官的送命题——「给你一个空项目，你怎么搭系统框架？」答得好直接封神。

### 完整流程（8 步走）

```
Phase 1：定义（1-2 天）
  Step 1: 明确「这个游戏是什么」
  Step 2: 画出「玩家每日/每周在做什么」

Phase 2：架构（3-5 天）
  Step 3: 拆出「所有系统」→ 画全景图
  Step 4: 排「优先级」→ 画 Gantt 图
  Step 5: 定义「系统间的数据流」

Phase 3：设计（2-4 周/系统）
  Step 6: 逐个系统出「设计文档」
  Step 7: 出「配置表模板 + 字段映射」

Phase 4：跟进（整个开发周期）
  Step 8: 跟进 + 调优 + 复盘
```

### Step 1：明确「这个游戏是什么」

你作为系统策划，在立项初期要先明确三个问题：

```
Q1: 核心体验是什么？
    → 俯视角 3D 肉鸽 =「每局不一样的构筑 + 清屏快感 + 永久成长」

Q2: 玩家的核心循环是什么？
    → 开一局 → 打怪选技能 → 死亡/通关 → 看广告复活/结算奖励
       → 用奖励升级武器/角色/天赋 → 再开一局

Q3: 目标玩家是谁？
    → 海外 25-40 岁碎片时间玩家（通勤/午休/睡前 10 分钟）
```

### Step 2：画出「玩家每日/每周在做什么」

```
玩家的一天（Daily Loop）：
  登录 → 领签到奖励 → 领挂机收益 → 做每日任务（开 N 局/升 1 级/看 3 个广告）
       → 开一局通关/刷刷 → 领通行证进度 → 升级武器 → 下线

玩家的一周（Weekly Loop）：
  周一：领周任务 → 冲排行榜
  周三：限时副本开放 → 刷稀有材料
  周五：周末双倍活动开始 → 拉在线时长
  周日：排行榜结算 → 领奖励
```

这件事情直接决定了**每个系统的刷新频率**：日/周/月/赛季。

### Step 4：排「优先级」

肉鸽手游的系统优先级：

| 阶段 | 必做系统 | 为什么 |
|---|---|---|
| **MVP（2-3个月）** | 战斗核心 + 武器养成 + 金币钻石 + 抽卡 + 新手引导 | 可玩的最小闭环 |
| **Beta（+2个月）** | 天赋树 + 每日任务 + 通行证 + 排行榜 + 好友 | 提升留存和付费 |
| **上线（+1个月）** | 赛季系统 + 活动模板 + 成就 + 邮件/公告 | 运营基础设施 |
| **上线后** | 公会 + 合作模式 + 限时活动 + 联动 | 老玩家留存 |

### Step 5：定义「系统间的数据流」

**关键原则**：上游系统只产出、下游系统只消耗。**不要让系统 A 和 B 互相依赖**。

```
例：货币数据流

战斗局 → 金币/钻石/材料 → 养成系统（消耗货币升级武器）
  ↑                              ↓
  │                        养成进度 → 战力提升 → 通关更高层数
  │                                              ↓
  └──────────────────── 更高层数 = 更多掉落 ←──────┘

错误设计：养成系统需要「竞技场排名」来解锁，但竞技场需要「战力」
          → 死循环（两个系统互相锁死）
```

**系统策划的核心能力**：一眼看出**数据流环是否自洽**。

### Step 6：逐个系统出「设计文档」

一份好的系统设计文档有**固定的结构**：

```
1. 设计目的（一句话）
   → 例：让玩家在单局外有可感知的成长目标

2. 核心规则（3-5 条，先写最重要的）
   → 例：
     (a) 武器分 4 个稀有度（N/R/SR/SSR）
     (b) 每把武器可升 5 级（Lv1→Lv5 解锁词条）
     (c) 重复武器自动转化为碎片（10 碎片=升级 1 级）
     (d) 武器满级后溢出碎片可兑换为金币

3. 功能清单（要做什么、不要做什么——边界感）
   → 要做的：武器升级/武器分解/武器锁定/武器筛选
   → 不做的：武器交易（海外合规风险）/武器外观（V2）

4. 界面设计（线框图 + 交互说明）
   → 画个草稿就行，但必须画

5. 配置表字段（见下方）
   → 策划配表的所有字段

6. 与系统的交互（数据流入/流出）
   → 流入：抽卡产出武器/战斗掉落武器/商店购买武器
   → 流出：武器战力影响战斗/武器收集影响成就/武器图鉴影响奖励

7. 版本迭代计划（MVP 做什么 / V1.1 加什么）
   → MVP：武器升级+分解
   → V1.1：武器锁定+筛选
   → V1.2：武器皮肤（商业化）
```

### Step 8：跟进 + 调优 + 复盘

系统策划不是写完文档就完事。上线后你要看：
- 武器升级率：多少玩家在升级武器？卡在哪一级？
- 货币消耗率：金币够不够用？玩家是不是攒着不花？
- 系统渗透率：多少玩家碰过天赋树？多少玩家完全忽略？
- 付费转化：养成系统对首次付费的拉动效果？

**复盘模板**：
```
系统：武器养成
上线 2 周数据：
  - 武器升级渗透率：78%（目标 60% ✅）
  - 平均升级等级：3.2 级（目标 3.5 ⚠️ 略低）
  - 金币消耗率：超预期 20%，玩家金币不够用 → 下版本：每日产金 +15%
  - 问题：SSR 武器升级太贵，F2P 玩家放弃 → 下版本：SSR 升级打折活动
```

## 四、系统设计注意事项（用户附加问题 2）

这是系统策划的血泪经验——**踩过的坑**。面试时能讲出这些，面试官会觉得"这家伙真做过"。

### 注意点 1：系统之间必须「单向依赖」

❌ 错误设计：
```
竞技场需要战力→战力需要武器→武器需要竞技场货币→死循环
```

✅ 正确设计：
```
竞技场产出荣誉币→荣誉币买皮肤（纯外观）
武器养成消耗金币→金币来自战斗和任务
→ 两个系统完全独立，产出和消耗各自闭环
```

**核心原则**：任何一个系统要能**独立上线**、**独立砍掉**，不影响其他系统。

### 注意点 2：配置表是「策划的代码」

**第一原则**：能配表解决的，不写死代码。
```
❌ 写死在代码里：if (weapon.level == 5) unlockSkin = true;
✅ 配表驱动：weapon_config 里加一列 unlock_skin_at_level = 5
```

**第二原则**：配置表要让人看得懂。
```
❌ 字段名叫 "val1", "val2", "flag"
✅ 字段名叫 "upgrade_cost_gold", "damage_bonus_percent", "is_legendary"
```

**第三原则**：条件格式 = 你的质检员。
```
用 Excel 条件格式标出：
- 升级费用 > 上一级的 3 倍（红色警告）
- 空白字段（黄色警告）
- 同一稀有度武器的基础攻击力偏差 > 20%（蓝色警告）
```

### 注意点 3：数值不能「凭感觉」

每个系统的数值都必须是**设计出来的**，不是拍出来的。

```
武器升级的消耗曲线设计：

等级  消耗金币    升级后基础攻击力    金币/攻击力比
Lv1   0（初始）   50                  -
Lv2   100        60                  100/10 = 10
Lv3   250        72                  150/12 = 12.5
Lv4   500        86                  250/14 = 17.9
Lv5   1000       100                 500/14 = 35.7

→ 金币/攻击力随着等级递增：前期性价比高（让玩家愿意升级）
                          后期性价比递减（制造稀缺感→可控广告/付费）
```

### 注意点 4：养成天花板 = 游戏寿命

肉鸽手游养成的最大陷阱：**无限养成 → 老玩家秒杀 BOSS → 失去挑战 → 退坑**。

设计原则：
- 基础养成（武器满级/角色满级）→ 2 个月内可达
- 边际养成（微小属性加成）→ 4 个月可达
- 极限养成（最后 5%）→ 6 个月+ 但不影响 95% 体验
- 横向养成（新武器/新角色/新词条）→ 持续更新，这是真·寿命

### 注意点 5：商业化不能卖构筑优势

肉鸽玩家最敏感的就是"充钱 = 更强"。

```
✅ 可以卖：
  - 皮肤/外观（纯视觉）
  - 通行证（加速养成，不是独占养成）
  - 体力购买（更多游玩次数）
  - 复活机会（降低挫败感）

❌ 不能卖：
  - 专属武器（F2P 永远拿不到）→ 会被海外玩家喷到飞起
  - P2W 属性（充钱直接 +50% 攻击力）
  - Gacha 独占 Meta 武器 → 破坏公平性
```

### 注意点 6：海外玩家的 UI/UX 偏好

| 维度 | 中国玩家 | 海外玩家（光汇目标） |
|---|---|---|
| UI 复杂度 | 接受满屏功能入口 | **极简**——3 个主 Tab 最多 |
| 红点 | 红点消不完 = 焦虑 | **红点太多 = 删除游戏** |
| 新手引导 | 接受 10 分钟教程 | **前 30 秒必须给爽感**，拒绝长篇教学 |
| 付费入口 | 放得越显眼越好 | **放几个小红点就好**，太 aggressive 会差评 |
| 社交 | 公会/世界频道/好友 | 排行榜 > 好友 > 公会 |

### 注意点 7：跨部门协作的「翻译」能力

系统策划 70% 的时间不是在写文档，是在**沟通**。

```
跟战斗策划沟通：养成给多少战力 → 会被战斗平衡吃掉
跟数值策划沟通：货币产耗曲线 → 拉到 6 个月看会不会崩
跟程序沟通：系统状态机 → 用伪代码说清楚
跟美术沟通：UI wireframe → 画清楚了再给
跟运营沟通：活动上线的风险点 → 提前列出来
跟老板沟通：做什么/不做什么 → 优先级排好后只汇报第一版
```

### 注意点 8：永远给自己留「回滚」方案

任何一个系统上线前，必须准备好：
- 数据回滚方案（万一数值崩了怎么回到上线前的状态）
- 玩家补偿方案（怎么补偿受影响的玩家）
- 紧急关闭开关（能不能一键关掉该系统而不影响其他系统）

## 五、各核心系统设计详解（肉鸽专项）

### 5.1 养成系统（Meta Progression）—— 系统策划的一号工程

**玩家看到什么**：
```
大厅 → 养成中心
  ├── 角色（可选英雄列表、升级、觉醒）
  ├── 武器（武器列表、升级、精炼、词条查看）
  ├── 天赋（全局天赋树：攻击/防御/收益/特殊）
  └── 图鉴（已收集的武器/角色/成就图鉴）
```

**你要设计什么**：
- 养成深度：有多少个养成维度？每个维度多少级？
- 养成节奏：玩家几天能升到顶？
- 养成产出：每个等级给多少属性？
- 养成消耗：每条养成线消耗什么？会不会互相抢资源？
- 养成解锁：什么条件解锁下一条养成线？

**肉鸽特有的设计**：
```
养成和单局的「张力」：
  养得太快 → 单局 3 天就速通 → 没意思
  养得太慢 → 单局永远通不了 → 挫败退坑

解决方案：
  - 基础养成（武器+角色升级）→ 2 周可达 70%
  - 深度养成（天赋树）→ 2 个月可达 90%
  - 极限养成（满天赋树）→ 6 个月（仅硬核玩家追求）
  - 横向扩展（每 2 周新武器/角色）→ 持续的「新东西」
```

### 5.2 任务系统 —— 留存的骨架

**设计原则**：任务 = 给玩家一个「今天做这个」的理由。

```
任务阶梯设计：

登录任务（D1）→ 「上线就有，养成习惯」
  └─ 每日任务（D1-D7）→ 「简单但需要付出 5 分钟」
      └─ 周常任务（D7+）→ 「需要一周才能完成」
          └─ 赛季任务（D30+）→ 「这个月的主线」
```

**反模式**：
```
❌ 每日任务：通关 20 层（太肝→流失）
✅ 每日任务：完成 3 局（不管输赢→轻松）
```

### 5.3 商业化系统 —— 海外三板斧

| 系统 | 简介 | 定价参考（海外） |
|---|---|---|
| **通行证 Battle Pass** | 免费 30 级 + 付费 50 级 | $4.99（小额）/$9.99（中额） |
| **月卡** | 30 天每天 50 钻 | $4.99/月 |
| **抽卡** | 武器/角色 Gacha | 单抽 $1-2 / 十连 $10-20 |
| **新手礼包** | 上线 3 天限时 | $0.99/$4.99/$9.99 |
| **等级礼包** | 到达 X 级触发 | $4.99-$19.99 梯度 |
| **限时礼包** | 周末/节日限定 | $9.99-$29.99 |
| **看广告** | 复活/双倍/加速 | eCPM $5-15（按地区不同） |

### 5.4 活动系统 —— 运营的武器库

作为系统策划，你有一个能力是**设计活动模板**——运营来填内容，你提供框架。

**活动模板要支持**：
- 任务型活动：完成 N 个任务 → 拿奖励
- 收集型活动：收集 N 个碎片 → 合成
- 冲榜型活动：排名前 N → 奖励
- 兑换型活动：打活动本掉代币 → 商店兑换
- 签到型活动：连续 N 天签到 → 奖励

## 六、系统策划的配置表设计

系统策划的 Excel 就是你的「设计文档第二稿」。

### 配置表设计原则
1. **一张表做一件事**——别把养成和商店塞一张表里
2. **字段要有业务含义**——别写 `param1/param2`
3. **关联关系用 ID 做外键**——`weapon_id` 关联武器表
4. **数值用公式**——升级费用 = 上一级 × 成长倍率，不是手填
5. **条件格式做质检**——一眼看出异常数据

### 系统策划最常用的 5 张配置表

**① 玩家等级表 `player_level`**
```
level | exp_required | max_stamina | stamina_recovery_rate | unlock_feature
    1 |            0 |         100 |                   300 | ""
    2 |          100 |         105 |                   300 | "每日任务"
    5 |          500 |         120 |                   280 | "排行榜"
   10 |         2000 |         150 |                   250 | "天赋树"
   20 |        10000 |         200 |                   200 | "公会"
```
公式：`exp_required(Lv) = exp_required(Lv-1) × 1.2`

**② 货币产出表 `currency_output`**
```
source            | currency_type | base_amount | level_multiplier | daily_cap
每日签到           | gold          |         500 |              0  |         0
普通战斗通关       | gold          |         200 |            0.1  |         0
看广告             | diamond       |           5 |              0  |        50

```

**③ 商店配置表 `shop_config`**
```

   9001 | weapon    | "新手武器箱" | diamond |  300 | false | daily | 1 | daily
   9002 | stamina   | "体力恢复"   | gold   | 1000 | false | daily | 3 | daily
   9003 | skin      | "圣诞皮肤"   | diamond | 1500 | true  | event | 1 | never
```

**④ 通行证配置表 `battlepass_config`**

## 七、面试高频 Q&A（系统策划版）

### Q1：「给你一个空项目，怎么搭系统框架？」
→ 这就是上面「第三部分」的 8 步走，背熟。面试官问这个问题你直接拿笔画全景图。

### Q2：「养成系统做到什么程度算成功？」
> 三个指标：
> 1. **渗透率**：70%+ 玩家碰过养成
> 2. **进步感**：D3 玩家战力比 D1 高 60%+——他能感知到「变强了」
> 3. **不崩坏**：最高养成的玩家通关第 10 层也不用超过 30 分钟

### Q3：「怎么跟战斗策划配合？」
> 养成 = 给战斗提供「变量」：攻击力、暴击率、移速、CD 缩减...
> 战斗 = 告诉我「养成的天花板是多少」——我说武器升到顶加 200% 攻击力，战斗策划说"不行，这会让我 BOSS 设计崩掉"→ 我降到 150%。
> **养成和战斗不是谁配合谁——是互相约束**。

### Q4：「任务系统怎么做才能让玩家愿意做？」
> 三个字：**不肝 + 值得 + 清晰**。
> - 不肝：每日任务 5 分钟能完成，周常 30 分钟
> - 值得：每日任务奖励 = 一局战斗的产出，周常 = 十局的产出
> - 清晰：玩家打开任务页面，3 秒就知道「我今天该干嘛」

### Q5：「商业化怎么做才不被骂？」
> 三原则：
> 1. **不卖构筑优势**：所有提升战力的养成，F2P 也有路径到顶
> 2. **买时间不买能力**：付费 = 加速养成，不是独占养成
> 3. **价格透明无陷阱**：没有隐藏收费、没有 auto-renew 暗坑（海外 Apple/Google 会严查）

### Q6：「你怎么看海外玩家的系统需求？」
> 三点跟国内不同：
> 1. **UI 极简**：3 个主 Tab 是上限，超过就砍
> 2. **红点克制**：海外玩家对 notification 非常敏感，太多红点→差评
> 3. **社交轻量化**：排行榜>好友>公会，不要世界频道
> 4. **尊重隐私**：GDPR 合规（欧洲）、COPPA 合规（美国）——不强制获取好友列表

### Q7：「你怎么排 MVP 和上线版本的系统优先级？」
> MVP（最小可玩） = 战斗核心 + 武器养成 + 金币钻石 + 抽卡 + 新手引导
> → 只有这 5 个系统，游戏也必须能玩、能收钱。
>
> 怎么看一个系统是不是 MVP？问自己：**没有这个系统，玩家会直接删游戏吗？**
> - 没有武器养成 → 删（因为没有目标感）→ MVP
> - 没有公会 → 可能会留（因为自己是核心循环）→ 非 MVP

### Q8：「最有成就感的系统？」
> 选你简历里 Zodiac 的**飞船系统** 或 **好友系统**。结构：
> - 背景：为什么做
> - 我的角色：完全独立 / 牵头
> - 做了什么：具体设计决策（不是形容词）
> - 结果：数据/反馈
> - 如果重做一次：改进一句话

### Q9：「你还有什么想问我们的？」
1. 这款产品当前的开发阶段？团队多少人？
2. 系统策划是独立负责模块，还是有主策牵头？
3. 你们用的是什么配置表工具？Excel + 转表工具？还是自研编辑器？
4. 商业化是纯 IAP，还是有广告变现（Rewarded Ads）？
5. 目标海外市场优先级？美国 > 日本 > 韩国？

## 八、面试前一页纸速记

### 系统策划面试 7 秒自我介绍
> 9 年经验，奕兆执行主策。做过养成（天赋/转职/装备）、社交（好友+时间线）、活动收集、竞技场外围、商业化红包。能从 0 搭系统框架，也懂得跨部门推需求。看光汇这个系统策划岗，是想把跨品类系统设计经验带到俯视角肉鸽出海这个方向上。

### 必须带去的 3 个东西
1. Excel 数值表截图（任一系统配表）
2. 系统全景图（手画也行，面试时画在白板上）
3. 一份你做过的系统设计文档（打印 + U盘）

### 必须会说的 5 个词
```
MVP（最小可玩版本）      | "第一版只有战斗+养成+新手教程"
Meta Progression（永久养成）| "跨局保留的武器/角色/天赋升级"
产耗平衡（产出vs消耗）    | "每天产出 5000 金币，消耗 4000，净余 1000"
留存漏斗（D1/D3/D7/D30） | "肉鸽品类标准是 40/20/10/5%"
付费不卖构筑              | "加速养成行，独占属性不行"
```

### 最容易踩的 3 个坑（面试时主动说，显得很懂）
1. 养成太快→游戏 3 天没内容→流失
2. 系统互相锁死→养成需要战力→战力需要养成→死循环
3. 货币膨胀→金币越产越多→经济崩→要设计金币消耗出口

## 九、最后一段

战斗策划让你拿到面试资格，系统策划让你拿到 offer。

比纯战斗策划的优势：
- 你 9 年经验里**系统覆盖面极广**（养成/社交/活动/收集/商业化），比只做战斗的广
- 执行主策的**管理经验**（版本计划/任务分配/文档规范）= 系统策划最需要的能力
- 计算机背景 = 配表建模强 + 跟程序沟通无障碍

**光汇是跨界公司**（石油+互联网）→ 他们没有老牌游戏厂的系统架构积淀 → 你来就是**搭系统框架的人**。面试时主动说这句话："我做过执行主策，理解整个团队的系统需求，能从 0 画全景图、排优先级、跟进上线。对你们这种开局团队，这个能力比单一系统的设计经验更有价值。"
