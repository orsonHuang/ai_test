### 1. AI 在游戏中的应用（你最擅长的领域）

**核心概念清单**（直接背）：

```
生成式 AI（Generative AI）
  - 文字生成：NPC 对话、剧情、任务文本（GPT/Claude）

  - 音频生成：背景音乐、音效、角色语音（Suno/网易云）

AI Agent（智能体）
  - ReAct / Chain-of-Thought：推理+行动循环
  - Tool Use：调用外部工具（搜索、计算、调接口）
  - Memory System：短期/长期记忆
  - RAG（检索增强生成）：外挂知识库

AI 游戏设计模式
  - AI NPC：自适应对话（State Machine + LLM）
  - AI 玩法生成：程序化关卡、动态难度
  - AI 教学引导：新手指南、NPC 助手
  - AI 内容审核：UGC 内容审查
  - AI 数值调优：自动战斗模拟器
```

**你 AI 经验的标准化表达**：

> "我做的 AI-NPC 系统采用了**混合回复引擎**：
> 1. **预烘焙响应库**（确定性回复，秒级响应）
> 2. **学习闭环**（玩家行为驱动状态切换）
> 3. **RAG**（检索 Top-3 知识片段注入 prompt）

### 2. UGC 平台设计（必须突击的领域）

**UGC = User Generated Content**，**用户生产内容**。

**UGC 三层模型**：

```
┌──────────────────────────────────────────────┐
│            内容消费层（玩家）                    │
│   浏览/搜索 → 进入空间 → 玩/收藏/分享/关注      │
├──────────────────────────────────────────────┤
│            内容生产层（创作者）                  │
│   创作工具 → 创作内容 → 提交审核 → 发布         │
├──────────────────────────────────────────────┤
│            平台基建层（运营/系统）              │
│   内容审核 / 内容分发 / 激励体系 / 数据分析       │
└──────────────────────────────────────────────┘
```

**UGC 平台成功的三大支柱**：

| 支柱 | 关键设计 | 举例 |
|---|---|---|
| **创作工具** | 门槛低 + 上限高 | Roblox Studio（专业级）/ 蛋仔编辑器（傻瓜级）|
| **激励机制** | 让创作者赚到钱/名/权 | 蛋仔的"巅峰大师"、Roblox 的开发者分成 |
| **内容分发** | 让好内容被看见 | 算法推荐 + 编辑推荐 + 搜索 |

**核心设计原则**：
1. **创作门槛低**：10 分钟能做出第一个内容
2. **创作上限高**：1% 的深度玩家能做出令人惊叹的作品
3. **反馈即时**：创作者发布后立刻看到曝光数据
4. **变现清晰**：每个内容的收益可追踪
5. **社区氛围**：保护创作者，不让搬运/抄袭泛滥

**必玩 + 必拆的产品**：

```
产品：Roblox ★★★
  - UGC 鼻祖，估值全球最高
  - 创作工具：Roblox Studio（Lua 脚本）
  - 商业模式：玩家充值→开发者分成（创作者拿走 25%）
  - 用户结构：日活 7000 万，60% 玩家 < 16 岁

产品：蛋仔派对（网易）★★★
  - 国内 UGC 最成功产品
  - 创作工具：蛋仔编辑器（可视化拖拽）
  - 激励：巅峰大师 + 粉丝打赏 + 官方签约
  - 用户：日活峰值 3000 万

产品：迷你世界 ★★
  - 早期国内 UGC 沙盒
  - 创作工具：低门槛可视化
  - 激励：开发者分成 + 广告分成

产品：我的世界（Minecraft）★★
  - 沙盒鼻祖
  - 创作工具：红石电路 + Modding
  - 激励：第三方分成

产品：VRChat ★
```

### 3. AI + UGC 的产品形态（最前沿）

**这是面试官最关心的话题**——AI 怎么改变 UGC 平台？

**当前的 AI + UGC 应用**：

| 维度 | AI 能做什么 | 例子 |
|---|---|---|
| **生成内容** | AI 生成 3D 场景/角色/剧情 | Midjourney + Roblox（Roblox 正在做）|
| **辅助创作** | AI 帮创作者补全/修整 | AI 帮你调材质、改贴图 |
| **降低门槛** | 用自然语言代替脚本 | Roblox 的 "Assistant" 功能（Beta） |
| **内容审核** | AI 自动识别违规内容 | 几乎所有 UGC 平台都在用 |
| **动态内容** | AI 根据玩家行为实时生成 | AI 生成的副本、NPC 对话 |
| **个性化推荐** | AI 推荐玩家可能喜欢的内容 | 算法推荐 |

**生量科技可能的产品形态推测**（基于 JD + AI + UGC）：

```
用户输入一句话："我想要一个赛博朋克风的酒吧"
     ↓
AI 生成 3D 空间 + 装饰 + 氛围 + NPC
     ↓
用户在这个空间里：
  - 跟 AI NPC 互动
  - 邀请朋友来玩
  - 玩 AI 生成的迷你游戏
  - 分享到 UGC 社区
     ↓
其他用户可以：
  - 进入空间游玩
  - 复制/改造空间（Remix）
  - 关注创作者
  - 打赏/购买创作者的资产
```

**这跟传统 UGC（Roblox）的最大区别**：
- Roblox：要会编程才能创作
- 生量（推测）：用自然语言就能创作
- 创作门槛：**数量级降低**

### 5. 大厅自定义系统设计（JD 第二条核心职责）

**大厅 = 玩家进入游戏后的主入口**。

```
典型大厅设计：
  ├─ 大厅 UI（按钮+背景+音乐+氛围）
  ├─ 角色显示（角色站位+动作+表情）
  ├─ 功能入口（任务/邮件/排行榜/商店）
  ├─ 活动入口（限时/赛季/节日）
  ├─ 背景层（动态背景+天气+日夜）
  └─ 玩家个性化元素（称号/勋章/装扮）

→ 大厅自定义 = 让玩家自己改大厅的某些元素
  - 角色站位（Roblox 的 avatar 站位）
  - 背景主题（蛋仔派对的大厅皮肤）
  - 装饰物摆放（我的世界的家园装饰）
  - 入口图标（装扮游戏常用）
```

**设计原则**：
1. **简单可改**：玩家能 30 秒改一个东西
2. **改完即爽**：立刻看到视觉效果
3. **有限选择**：不要给 1000 个选项让人选麻

### 6. 创作者激励机制设计（UGC 经济基础）

**创作者想要的四件事**：

```
1. 名 → 关注/粉丝/点赞/榜单/称号
2. 利 → 直接收入分成 / 月度奖励 / 比赛奖金
3. 权 → 高级工具 / 限定素材 / 优先曝光
4. 成长 → 数据反馈 / 用户洞察 / 创作进阶课程
```

**变现模式**：

```
模式 A：广告分成（YouTube）
  - 创作者内容的曝光量 × 千次展示单价
  - 适合：休闲内容/观赏性内容

模式 B：直接交易抽成（Roblox）
  - 玩家充值 → 开发者分成（25%）
  - 适合：付费内容/强工具内容

模式 C：打赏/礼物（Twitch/抖音）
  - 观众送给创作者虚拟礼物
  - 适合：直播/强社交内容

模式 D：签约费（网易蛋仔）
  - 官方签约 → 月度底薪+作品分成
  - 适合：顶级创作者

模式 E：创作等级（按作品数量/质量）
  - 等级越高，分成比例越高
  - 适合：长期生态培育
```

### 7. 轻叙事与世界体系设计

**"轻叙事" = 不做强叙事剧情，但有世界观**。

```
为什么要轻叙事？
  - 强叙事（主机游戏剧情）成本极高，UGC 平台无法承受
  - 但完全没有叙事，玩家没有情感寄托
  - 轻叙事 = 用世界规则+角色设定+碎片叙事 营造氛围

举例：
  - 《原神》有强叙事，但每个角色有自己的背景故事+角色 PV
  - 《动物森友会》几乎没有叙事，但有"无人岛"的世界观+角色（小狸猫、博物馆馆长）
  - 《蛋仔派对》有"蛋仔星"的设定，每个蛋仔有自己的个性
  - Roblox 几乎没有官方叙事，但有用户自定义的所有内容
```

**轻叙事设计 4 件套**：
1. **世界观设定**（一句话能讲清："这是一个被遗忘的无人岛/赛博朋克世界/卡通蛋仔星球"）
2. **角色体系**（3-5 个核心 NPC，每个有名字/性格/口头禅/功能）
3. **碎片叙事**（探索过程中解锁的背景故事+收集品）
4. **氛围细节**（BGM/UI 颜色/字号/插画风格统一）

> 1. **AI 游戏产品实战**：我做了一个独立的 AI-NPC 对话解谜游戏，从 0 搭了 AI-NPC 人格演化系统、混合回复引擎（预烘焙+学习闭环+RAG+AI 兜底）、意图识别系统。**这个独立游戏就是我最直接的 AI 空间创作经验。**
> 2. **从 0 到 1 搭过战斗/玩法框架**：Zodiac Heroes 战斗框架是我独立从 0 搭的，理解"从无到有推玩法"的全流程。
> 3. **计算机科班**：能写代码、能直接和 AI/程序团队用同一套语言对话。
>

### Q2：为什么离开奕兆？
> 奕兆是回合 RPG + 即时卡牌方向，主战场是传统品类。但我最近 1 年一直在做 AI-NPC 方向的独立游戏，**这个方向才是我真正想深耕的**。生量的 AI + UGC 方向和我个人兴趣、长期职业规划完全对齐。

### Q3：你没做过 UGC 平台，怎么办？
> 诚实地承认主战场不是 UGC，但说明三件事：
> 1. **我实玩 + 拆解过 Roblox / 蛋仔派对 / 迷你世界**——从创作者角度自己做了一两个 demo
> 2. **我的 AI 经验可以应用到 UGC 创作工具上**——AI 降低创作门槛是必然趋势
> 3. **我的计算机科班 + 写代码能力**，能在产品早期快速落地 AI 功能

### Q4：你怎么理解"AI + UGC"的产品形态？
> 这是核心问题。讲三件事：
>
> 1. **AI 降低创作门槛**：从会编程 → 用自然语言，UGC 才能真正 UGC
> 2. **AI 辅助创作过程**：实时补全、修整、风格化
> 3. **AI 改变消费体验**：每个用户进入同一个空间，看到的是不同的 AI 适应性内容
>
> 形态举例：「用户输入『赛博朋克酒吧』→ AI 生成 3D 空间 + NPC → 用户游玩/分享/Remix → 形成 UGC 飞轮」

### Q5：怎么设计一个 AI-NPC？
> 按 5 层架构讲（用你独立游戏的实战经验）：
> 1. **状态机**（剧情阶段 → 触发不同人格）
> 2. **响应库**（确定性回复+检索匹配）
> 3. **RAG**（知识库检索 Top-K）
> 4. **LLM 兜底**（未匹配才用，且限流）
> 5. **记忆系统**（短期/长期记忆）
>
> 金句：「AI 不是越多越好——只用在必要的地方，否则成本爆炸、回复变傻。」

### Q6：UGC 内容生态怎么冷启动？
> 三个杠杆：
> 1. **官方带头做内容**（PGC 填充量+做示范）
> 2. **小部分头部创作者重金激励**（签约+独家分成）
> 3. **长尾创作者低门槛工具**（让他们也参与进来）
>
> 「冷启动不是算法问题，是社区氛围问题——平台早期先有 100 个种子创作者比 1000 个潜水玩家重要。」

### Q7：AI + UGC 内容审核怎么做？
> 双层审核：
> 1. **AI 自动审核**（敏感词+违规内容+AI 生成内容标识）
> 2. **人工抽审**（高曝光/被举报内容）
>
> 但更核心的是**创作源头引导**：
> - 提供清晰的创作指南
> - 训练 AI 时内置合规规则
> - 给创作者明确的合规反馈

### Q8：最有成就感的项目？
