**"选品操盘手 + 付费策划 + CP 对接 PM"** 三合一，对产品收益结果直接负责：

## 四、面试准备

### 必讲案例（STAR 演练）

1. **次日 ROI≥1**（满天星）：收购产品 + 买量压力 → ROI 反向驱动"玩法留存×关卡数值×红包投放"三线调优 → ROI≥1 跑通正向循环 → 升华：商业化设计本质是留存-变现-成本的三角平衡
2. **《动物餐厅》4880w**（广点通）：投放数据反推产品优化、评测报告推动 CP 调优 → 证明选品与诊断能力
3. **弹珠机活动 5 倍收益**（奕兆）：活动机制 + 动态奖励/debuff 设计
4. **《点消》操盘 + 广告 SDK 中台**：对齐"平台上线全流程"与产品矩阵思路

### 高概率面试题

1. "你会怎么给一款小游戏做选品评估？看什么指标？" → 准备选品框架：品类大盘/买量成本、次留/7留基准线、广告 eCPM 与 IAP 付费率、玩法-场景适配度（含直播场景）、CP 团队交付能力
2. "直播互动场景的游戏怎么做适配？" → 补课后答：玩法节奏切成短循环、弹幕/礼物作为输入源、单局时长与直播间留存节奏匹配
3. "产品上线后数据不达标，你的复盘流程？" → 漏斗定位（曝光-点击-次留-付费）→ 假设 → 小步迭代 → 验证，用点消案例
4. "怎么推动 CP 改需求？" → 广点通诊断报告经验：数据说话 + 优化建议附带可执行方案
5. "IAA 与 IAP 混合变现怎么设计？" → 点消广告变现 + 奕兆礼包/抽卡双经验
6. "你做过 RPG 主策，为什么来做小游戏商业化？" → 回归优势区：本质都是数据驱动的商业化设计，且这是我最早（运营/增长）的起点，闭环回归
7. 反问环节建议：产品矩阵规模与在跑产品数量、直播场景业务的具体形态、KPI 定义（流水/ROI/留存）、与 Cocos 引擎侧的协同方式
