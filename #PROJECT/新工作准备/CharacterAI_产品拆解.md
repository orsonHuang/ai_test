# Character.AI 产品拆解 · AIGC 经典案例

> 产品：Character.AI（c.ai）· 全球 #1 AI 角色互动平台
> 数据：日活 2000 万+ · 月活 1 亿+ · 用户创建角色 1 亿+ · 2024 估值 50 亿美元
> 创始人：Noam Shazeer & Daniel De Freitas（前 Google Brain，Transformer 论文作者）
> 面试适用：生量科技（AI 空间创作 + UGC）岗位，可直接引出你的 AI-NPC 经验

---

## 一、产品定位：一句话讲清

> "让任何人 30 秒创建一个 AI 角色，然后跟它对话。"

```
Character.AI = 角色创建工具 + 角色互动平台 + 角色社区

用户身份双重：
  ┌─ 创作者：创建角色、设定人设、管理角色热度
  └─ 消费者：搜索/发现角色、跟 AI 聊天、收藏/分享
```

## 二、核心逻辑：四层架构

```
┌──────────────────────────────────────────────┐
│            第 1 层：角色定义层                  │
│  名字 + 头像 + 开场白 + 人设 Prompt            │
│  （用户输入，决定 AI 人格的边界）               │
├──────────────────────────────────────────────┤
│            第 2 层：对话引擎层                  │
│  用户输入 → LLM 推理 → 角色人设注入 → 回复     │
│  （GPT/Claude/自研模型）                       │
├──────────────────────────────────────────────┤
│            第 3 层：记忆与上下文层               │
│  短期记忆（当前对话） + 长期记忆（历史对话总结）  │
│  + 用户偏好（点赞/踩/删回复）                   │
├──────────────────────────────────────────────┤
│            第 4 层：分发与社区层                 │
│  分类浏览 / 搜索 / 推荐算法 / 热度榜 / 收藏     │
└──────────────────────────────────────────────┘
```

### 逐层拆解

### 第 1 层：角色定义层（用户能控制的）

创作者填 4 个字段，决定 AI 的角色：

| 字段 | 含义 | 举例（爱因斯坦角色） |
|---|---|---|
| **Name** | 角色名字 | "Albert Einstein" |
| **Greeting** | 开场白（第一印象） | "Hello, I'm Albert. What physics question keeps you up at night?" |
| **Short Description** | 一句话简介（搜索用） | "Friendly physicist who loves explaining relativity in simple terms." |
| **Definition（核心）** | 人设 Prompt（角色底层人格，最长 32000 字符） | `{personality: "curious, patient, loves metaphors", knowledge: "physics, philosophy, violin", speech_style: "uses simple analogies, never condescending"}` |
| **Voice**（新功能） | 声音（TTS） | 用户上传或选择语音风格 |
| **Visibility** | 可见性 | 公开 / 私密 |

**关键设计原则**：
- 创作者不需要会编程——填几句话就行
- 但高级创作者可以写 32000 字符的精细 Prompt → **低门槛 + 高天花板**
- 这就是 **UGC 创作工具的黄金公式**

### 第 2 层：对话引擎层（技术核心）

```
用户输入"相对论是什么？"
     ↓
系统 Prompt 模板组装：
  [角色定义: 爱因斯坦]
  [对话历史: 最近 10 轮]
  [用户输入: "相对论是什么？"]
  [系统指令: 用简单的比喻解释，保持友好]
     ↓
LLM 推理（GPT/Claude/自研）
     ↓
AI 回复："Imagine you're on a train moving very fast..."
     ↓
用户看到回复 → 可以点赞/踩/重新生成/继续聊
```

**核心设计决策**：

| 决策 | Character.AI 的选择 | 为什么 |
|---|---|---|
| 模型 | **自研模型**（不是套壳 GPT） | 成本可控、延迟可控、不被 OpenAI 绑架 |
| 人设注入方式 | **System Prompt 前置注入** | 每次对话都重新注入，不需要微调 |
| 记忆长度 | **滑动窗口（最近 N 轮）** | 太长成本爆炸、太短遗忘严重 |
| 多轮连贯性 | **对话历史摘要 + 关键信息提取** | 用小型模型做摘要，注入主 prompt |
| 安全阀 | **敏感话题拦截 + 角色人设约束** | 防止角色"跑偏"到不安全话题 |

### 第 3 层：记忆与上下文层

**短期记忆**：最近 10-20 轮对话直接附在 prompt 里

```
[System] You are Albert Einstein. Be curious and use simple analogies.
[User] What's relativity?
[AI] Imagine you're on a train...
[User] What about gravity?
[AI] Now imagine the train going up a hill...
[User] So spacetime curves?
→ 最近 3 轮对话都在上下文里 → AI 知道在聊什么
```

**长期记忆**：超长对话时，用摘要技术压缩：
```
→ 前 50 轮对话 → 小型模型摘要 → "用户在问引力相关的内容"
→ 注入下 20 轮的主 prompt
```

**用户偏好学习**：
- 点赞（👍）→ 强化这类回复风格
- 踩（👎）→ 下次避免
- 删除 → 视为强烈负面信号
- 但这些信号**不跨对话**，只影响当前对话

### 第 4 层：分发与社区层

**角色分发机制**：

```
角色被创建 → 发布到平台
  ↓
分发渠道：
  ├─ 分类浏览（名人 / 动漫 / 游戏 / 助手 / 原创...）
  ├─ 搜索（按名字/分类/简介匹配）
  ├─ 推荐算法（个性化推荐）
  ├─ 热度榜（Top Creator / Trending）
  ├─ 社交分享（用户分享角色链接）
  └─ 外部搜索（Google 搜索落页）
```

**推荐算法的核心指标**（推测）：

| 指标 | 含义 | 权重 |
|---|---|---|
| 互动率 | 对话消息数 / 进入角色页的人数 | 最高 |
| 留存率 | 多少用户第二次回来跟同一个角色聊 | 高 |
| 点赞率 | 回复被点赞的比例 | 中 |
| 分享率 | 角色被分享的次数 | 中 |
| 创建时间 | 新角色被算法优待 | 中 |
| 创作者历史 | 稳定输出好角色的创作者权重高 | 低 |

## 三、UGC 飞轮：Character.AI 的增长引擎

```
    ┌──────────────────────────────────────────┐
    │                                            │
    ▼                                            │
┌─────────┐ 创建角色  ┌─────────┐ 互动  ┌─────────┐

│         │          │  （内容） │       │         │

    ▲                     │                 │
    │                     ▼                 │
    │              ┌───────────┐            │
    │              │  内容分发   │            │
    │              │ 推荐/搜索  │            │
    │              └───────────┘            │
```

## 六、关键设计决策（为什么做对了）

### 决策 1：不强制注册

```
Character.AI 的首屏 = 直接可以跟精选角色聊天
→ 第一句话不用注册
→ 聊完想保存对话 → 才需要注册

结果：注册转化率极高，因为用户已经"投入"了（聊了好几句）
```

**面试迁移**：生量产品同理——先让用户玩 3 分钟，爽了再注册。

### 决策 2：角色人设用 Prompt 而不是微调

```
❌ 方式 A：每个角色微调一个模型（成本高、维护难、不实时）
✅ 方式 B：一个通用模型 + 每个角色一个 System Prompt（成本低、实时生效）

System Prompt 例子：
  "You are Albert Einstein. You speak with a German accent..."
  
  模型推理时，这个 prompt 被前置注入 → AI 立刻变成爱因斯坦
```

**面试迁移**：你独立游戏的混合回复引擎也是同理——预烘焙响应库 + RAG + AI 兜底，不用每次微调。

### 决策 3：自研模型，不套壳

Character.AI 没有用 GPT API，自己训了模型。原因：
- 成本：GPT API 按 token 收费，一天 2000 万用户 × 平均 20 条消息 → 每天几百万美元
- 延迟：API 调用有网络延迟，自研可以做到 < 1 秒回复
- 可控：可以针对"角色扮演"场景专门优化模型

**面试迁移**：成本是 AI 产品的第一约束——你做的混合回复引擎里，LLM 只在兜底时触发并限流，就是成本控制。

### 决策 4：不做 AI 生成角色

```
全部角色由用户创建 → 100% UGC

为什么不自己做角色？
  → 1 亿个角色 = 1 亿个用户数据点
  → 每一个角色背后是一个愿意"投资"的用户
  → User-generated 角色 = 用户的情感绑定（"这是我的角色"）
  → AI 生成的角色 = 没有情感绑定
```

## 七、存在的问题（面试时批评 = 有深度）

| 问题 | 具体表现 | 如果我来改 |
|---|---|---|
| **角色破防** | 用户用特定 prompt 可以"攻破"角色限制，让 AI 说不想说的话 | 增加角色安全性测试（红队测试），发布前自动跑一遍破防数据集 |
| **记忆天花板** | 聊超过 50 轮后，AI 开始忘记之前的对话 | 引入结构化记忆（用向量数据库存储关键信息），而不是纯滑动窗口 |
| **创作者激励机制弱** | 创作者没有任何收入，全靠"热度"驱动 | 引入创作者经济：热度分 = 广告分成 / 打赏 / 订阅 |
| **内容过载** | 1 亿+ 角色，用户不知道怎么选 | 更智能的个性化推荐 + "角色匹配"引导（问用户 3 个问题推荐角色） |
| **同质化** | 大量角色人设雷同（"霸道总裁 AI" x 1000）| 角色质量分 + 查重机制 + 独特角色额外曝光 |

## 八、跟生量科技产品的对标（面试时直接说）

| 维度 | Character.AI | 生量科技（推测） | 可迁移 |
|---|---|---|---|
| 创作内容 | AI 角色的"人格" | AI 生成的 **3D 空间** | 创作工具的低门槛+高天花板设计 |
| 互动方式 | 文字对话 | **3D 空间探索+社交+游戏** | 多模态输入/输出 |
| 分发方式 | 推荐+搜索+热度榜 | 推荐+搜索+分类+社交分享 | 分发算法可直接迁移 |
| 商业模型 | 订阅制 C.AI+ | 订阅+抽成+皮肤（推测） | 不做内容独占，卖体验优化 |
| 记忆系统 | 文字对话摘要 | **空间状态+对话+交互记录** | 记忆系统结构迁移，表达层换 3D |

**面试话术**：

> "Character.AI 证明了一条公式：**低门槛创作 × 高效分发 × 数据激励 = UGC 飞轮**。
>
> 但我注意到它有两个遗憾：
> 1. 创作者没有任何收入（只能靠热度自我感动）
> 2. 互动形态扁平（纯文字——用户创建的是角色人格，但角色没有一个[空间]来承载）
>
> 生量的产品如果能在这两点上突破——**给创作者经济回报 + 给角色一个 3D 空间的[家]**——就能在 AI+UGC 赛道里打出一条新路。这也是为什么我对这个岗位感兴趣。"

## 九、面试必背速记

### 一句话讲清 Character.AI
> 让任何人 30 秒创建一个 AI 角色，然后跟它聊天。日活 2000 万，1 亿+角色，全是用户创建的。

### 四层架构（画在纸上的 4 层）
```
角色定义层（Prompt + 人设）
   ↓
对话引擎层（LLM 推理 + System Prompt 注入）
   ↓
记忆与上下文层（短期窗口 + 长期摘要 + 用户偏好）
   ↓
分发与社区层（推荐 + 搜索 + 热榜 + 分享）
```

### UGC 飞轮公式
> 低门槛创作 × 高效分发 × 数据激励 = UGC 飞轮

### 金句
> "CharacterAI 证明了 UGC 的核心不是技术，是让创作者感觉自己的内容被看到、被认可、有价值。AI 把创作门槛降低了 10 倍，但分发机制和激励体系才是飞轮转起来的原因。"

> "CharacterAI 不做 AI 生成角色，100% UGC——因为一个用户创建的角色背后，是情感绑定。AI 生成的角色没有这种绑定。"

> "如果让我升级 CharacterAI，我会给每个角色一个[3D 空间]——不只是文字对话，而是角色住在自己的世界里，用户走进来。这就是生量产品要解决的核心命题。"
