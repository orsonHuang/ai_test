## 工作规则
- 运行时使用原生 HTML/CSS/JavaScript，`dist/` 可直接部署至现有 Nginx 子目录。内容导出使用锁定依赖的 Node 构建工具；服务器无需安装 Node。
- 所有资源使用相对路径；不依赖远程字体、脚本、图片或在线模型。
- 用户资料与项目记录只存浏览器 localStorage；提供 JSON 备份及合并恢复。
- 本地挖掘是关键词匹配和设计模板重组，不宣称 AI 分析、真实市场需求或爆款预测。生成结果保留原始资料引用与待验证项。
- 用户已明确授权发布 `orson.games/game-ideas/`；部署仅限此子目录，保留站点首页与其他应用。Sites旧预览身份保留，本轮不更新该域名。
- 修改后运行核心逻辑测试与桌面/移动端浏览器流程验收；只提交本项目和本轮状态记录。

## 目录结构
- `reader.json`（位于对应游戏目录）：指定公开文章、地图分组、原创封面和 UI 说明；构建时覆盖默认正文，原系统规格保留在折叠附录。
- `scripts/build-library.mjs`：从 `../../#Game-TearDown` 导出内容与公开图片，研究图片转为提示，不复制源图；只允许HTTP来源链接和本库文档跳转，原始HTML转义。
- `dist/library*`：案例数据、界面、样式；`dist/media/`：48原创图；`dist/mermaid.js`：离线流程图渲染包。
- `tests/library.cjs`：筛选、证据边界、收藏/笔记/备份、56文档流程图及多屏验收；`BASE_URL`可指向线上子路径。
- `dist/index.html`：应用入口。
- `dist/styles.css`：响应式页面样式。
- `dist/engine.js`：资料分类、候选生成、数据校验与导出逻辑。
- `dist/app.js`：页面交互与浏览器存储。
- `tests/`：逻辑测试和浏览器验收。
- `.openai/hosting.json`：Sites 身份与部署清单（注册成功后生成）。
- `DEPLOY.md`：部署到现有网页的说明。
- `validation/`：浏览器验收记录。

## 注意事项
- 尚不包含联网抓取、模型调用、登录、云端同步。备份文件用于跨浏览器迁移。
- 关键词命中只是线索，无法判断否定、讽刺或真实市场规模；必须人工核查原文。
- 不在前端存放 API 密钥。后续联网采集/模型分析应通过后端适配器接入。
- 验证预算是用户设定的范围，不是工期承诺。
