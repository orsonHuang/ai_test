# Brainstorm-GodotGame · 脑暴项目

> **一句话定位**：基于 Godot 引擎 + Godot MCP + AI 协作的独立游戏脑暴工作区。
> **当前阶段**：01-方向探索（发散阶段）
> **创建日期**：2026-08-04

---

## 项目目标

探索用 **Godot MCP 结合 AI** 开发独立游戏的可行性，产出：
1. 一个经过充分论证的游戏设计方向
2. 一套 Godot MCP + AI 协作的可行工作流
3. 一份可移交正式开发的 GDD 骨架

## 技术栈

- **引擎**：Godot 4.x（GDScript）
- **AI 工具链**：Godot MCP（AI 直接操控 Godot 编辑器）
- **AI 协作**：AI 辅助设计 + 代码生成 + 资源管理
