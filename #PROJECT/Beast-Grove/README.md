# 兽境小憩 · Beast Grove

## 项目描述
面向微信小游戏的休闲斗兽棋原型。用户指定最终使用 Cocos，已授权先通过浏览器验证玩法。本版本不是 Cocos 工程。

## 工作规则
- 零依赖 HTML/CSS/JavaScript 原型，规则独立于 DOM；后续迁移 Cocos 时复用规则模块并补 TypeScript 类型。
- 运行：本目录执行 `node server.cjs`，访问 http://127.0.0.1:4178 。也可直接打开 index.html。
- 验证：`node --test rules.test.cjs`。
- 先验证休闲体验，再决定技能、联网、商业化；不在当前范围内发布微信小游戏。

## 目录结构
- `DESIGN-V2.md`：用户反馈后的“亮将暗走＋轮换热点”设计提案，尚未实现。
- `index.html` / `style.css`：响应式试玩界面。
- `rules.js`：独立棋盘规则、胜负、轻量 AI。
- `app.js`：交互、悔棋、音效、本地恢复。
- `rules.test.cjs`：规则与完整对局回归。
- `server.cjs`：仅本机可访问的静态预览服务。

## 注意事项
这是精简变体：5×7 棋盘，每方象虎猫鼠各一只，无陷阱。象8＞虎6＞猫2＞鼠1，同级可吃；鼠可吃象、象不能吃鼠。只有鼠可下水，水陆之间不能吃子；虎可跳过连续河格，河中有鼠时不能跳。己方兽穴不能进入。

两处营地：在己方回合开始时，每占一处获得一星；达到5星、进入敌方兽穴、吃光敌方或让敌方无路可走即胜。100步后按星数决胜，同分和局。营地不增强战力。

默认玩家先手、轻松 AI；可切换认真 AI 或同屏双人。AI 为两层搜索启发式，无隐藏信息、无额外行动。布局与数值未做大样本平衡。当前使用系统动物 emoji，跨设备外观会有差异。无联网、账号、付费和正式美术资产。
