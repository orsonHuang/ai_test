# 三国：谋定天下 — 核心玩法循环

## 一、宏观循环

```
选职落地 → 资源发育 → 武将招募/养成 → 同盟协作 → 沙盘征战 → 赛季结算/重置
```

整个游戏围绕「赛季制」运转，每个赛季约 7 周，赛季结束后进入新剧本，玩家保留核心养成（武将、战法等），部分进度重置，形成「成长 + 重启」的循环。

## 二、各阶段拆解

### 1. 选职落地（开局身份选择）

- 玩家从 **六大职业** 中选择一个作为赛季主职业：
  - **镇军**：前排/防御向，擅长守点、承伤、攻城。
  - **青囊**：治疗/辅助向，为友军恢复、降低战损。
  - **神行**：机动/侦查向，行军速度快，适合骚扰、抢资源、探情报。
  - **天工**：建造/工程向，修建箭塔、拒马、攻城器械等战场设施。
  - **司仓**：资源/后勤向，提升资源产出与运输效率。
  - **奇佐**：谋略/控制向，擅长计策、陷阱、战场控场。

- **设计意图**：
  - 把 SLG 中原本单一的玩家角色，拆成类似 MMO 的职业分工。
  - 迫使玩家在同盟中找到自己的位置，强化社交与协作。
  - 降低「只有高战才重要」的单一价值观，让非付费玩家也能靠职业贡献获得存在感。

### 2. 资源发育（内政 + 地块）

- **地块占领**：玩家通过铺路占领资源地（木材、铁矿、石料、粮食等）。
- **城建系统**：升级主城、资源建筑、军事建筑，解锁更高兵种与科技。
- **自动铺路/自动攻城**：降低手动操作负担，减少「肝」的痛点。

- **设计意图**：
  - 保留 SLG 经典的「占地盘 → 涨资源 → 升科技」的成长感。
  - 通过自动化功能降低重复劳动，吸引对传统 SLG 肝度望而却步的用户。

### 3. 武将招募与养成

- **武将获取**：抽卡招募三国名将，卡牌有稀有度、战法差异。
- **队伍构建**：武将 + 战法 + 兵种搭配，形成不同阵容（如蜀枪、魏盾、吴弓等）。
- **赛季继承**：核心武将、战法等跨赛季保留，玩家有长期积累感。

- **设计意图**：
  - 武将养成是长线付费与留存的核心锚点。
  - 阵容搭配提供策略深度，也支撑赛季间的持续内容消耗。

### 4. 同盟协作（GVG 的核心组织）

- 玩家加入同盟，职业分工在团体战中放大价值：
  - 镇军扛线、青囊续航、神行骚扰、天工筑城、司仓供血、奇佐控场。
- 同盟共同目标：占领城池、争夺州府、进军洛阳、完成赛季霸业。

- **设计意图**：
  - 把「个人养成」转化为「团体战力」。
  - 职业协作创造社交粘性，同盟是玩家留存和付费的重要载体。

### 5. 沙盘征战（核心战斗体验）

- **兵种克制**：盾、弓、枪、骑等兵种形成克制链，影响配队与战场决策。
- **即时/半即时大地图战斗**：部队在大地图上移动、交战、攻城。
- **战场设施**：天工可修建箭塔、拒马、投石车等，改变局部战场形态。
- **计策与谋略**：奇佐等职业释放计策，增加战场变量。

- **设计意图**：
  - 保留 SLG 沙盘战争的张力。
  - 通过职业技与战场设施，让「策略」不止于数值，增加可操作空间。

### 6. 赛季结算与重置

- 赛季末根据同盟/个人表现结算奖励。
- 新赛季进入新剧本，地图、规则、玩法主题可能变化。
- 核心养成继承，部分进度（如占领地块、赛季专属内容）重置。

- **设计意图**：
  - 降低后进玩家追赶成本，保持公平重启。
  - 每个赛季提供新内容，延长游戏生命周期。

## 三、循环张力与目标

| 阶段 | 核心体验 | 关键驱动 |
|------|----------|----------|
| 选职落地 | 身份认同 | 职业差异化 + 团队定位 |
| 资源发育 | 成长感 | 占地、城建、自动化减负 |
| 武将养成 | 收集与策略 | 抽卡、配队、赛季继承 |
| 同盟协作 | 社交归属 | 职业互补 + 共同目标 |
| 沙盘征战 | 策略对抗 | 兵种克制 + 职业技 + 战场设施 |
| 赛季重置 | 新鲜感 | 新剧本 + 公平重启 + 核心保留 |

## 四、核心设计亮点

1. **职业即社交**：六大职业不是单纯的角色 BUFF，而是把玩家按功能分组，天然产生协作需求。
2. **自动化降低门槛**：铺路、攻城等重复操作自动化，让轻度玩家也能参与核心玩法。
3. **赛季制保鲜**：短赛季 + 新剧本，持续提供目标与变化，避免传统 SLG 后期 boredom。
4. **保留核心继承**：武将/战法跨赛季保留，让玩家投入有长期价值。

## 五、潜在风险/待验证点

- 职业平衡：某个职业过强或过弱会影响同盟生态。
- 赛季节奏：7 周是否足够让玩家完成从发育到争霸的全过程？
- 中后期目标：赛季后期是否会出现「定局后无聊」的问题？
- 商业化与降氪的张力：如何在保证收入的同时不破坏「降氪」口碑？
