# 三国：谋定天下 — 游戏基本信息

| 项目 | 内容 |
|------|------|
| **游戏名** | 三国：谋定天下 |
| **开发商** | 杭州鸿钧网络（东风工作室） |
| **发行商** | 哔哩哔哩游戏 |
| **公测时间** | 2024 年 6 月 13 日 |
| **平台** | 移动端（iOS / Android） |
| **类型** | 多职业战争策略 SLG 手游 |
| **题材** | 三国历史 |
| **核心卖点** | 六大职业协作、降肝降氪、快节奏赛季制、拟真动态沙盘 |

## 市场定位

- **目标用户**：传统 SLG 玩家、三国题材爱好者、希望降低肝度与氪度的策略手游用户。
- **竞争差异**：相比《三国志·战略版》《率土之滨》等传统 SLG，强调「多职业分工协作」和「降肝降氪」体验，赛季节奏更快（约 7 周一赛季）。

## 核心差异点

1. **六大职业体系**：镇军、青囊、神行、天工、司仓、奇佐，每个职业在资源、战斗、辅助、建造等维度有明确分工。
2. **职业协作驱动同盟**：不再是单一「高战为王」的逻辑，职业互补成为同盟作战的基础。
3. **快节奏赛季制**：约 7 周一赛季，快速重启 + 赛季剧本更新，降低新手追赶门槛，提升内容新鲜感。
4. **降肝降氪设计**：通过自动铺路、自动攻城、减少熬夜等机制降低时间成本；抽卡与养成设计相对克制。

## 一句话总结

《三国：谋定天下》是一款以「多职业协作 + 快节奏赛季」为核心差异的三国 SLG 手游，目标是在传统 SLG 赛道中用降肝降氪和职业分工吸引并留住策略玩家。
