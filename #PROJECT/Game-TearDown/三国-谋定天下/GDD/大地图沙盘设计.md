# 三国：谋定天下 — GDD：大地图沙盘设计

> 文档类型：游戏设计文档（GDD）
> 主题：大地图沙盘系统
> 适用范围：SLG 战争策略手游，以《三国：谋定天下》为分析对象

---

## 一、设计目标

大地图沙盘是 SLG 的底层舞台，承载资源争夺、行军作战、同盟扩张、赛季叙事等核心玩法。其设计目标包括：

1. **支撑赛季叙事**：地图需要为每个赛季的剧本提供舞台，承载历史事件与战略目标。
2. **制造地缘冲突**：通过资源分布、地形关卡、城池位置，推动玩家/同盟产生争夺。
3. **支持多层次战略**：从个人占地、同盟攻城，到跨州争夺洛阳，地图需要在不同尺度上都有意义。
4. **降低操作负担**：通过自动铺路、快速行军等设计，减少玩家在地图上的重复操作。
5. **与职业系统联动**：让天工、神行、奇佐等职业在大地图上有独特的战略价值。

---

## 二、地图分层结构

### 2.1 宏观分层

```
全服地图
├── 十三州（或赛季剧本自定义大州）
│   ├── 州府（核心城市，如洛阳、长安）
│   ├── 郡城（区域中心城市）
│   ├── 县城（小型据点）
│   ├── 关隘/渡口（战略通道）
│   └── 野外地块（资源地、空地、特殊地形）
```

### 2.2 各层级作用

| 层级 | 数量级 | 功能 |
|------|--------|------|
| **州** | 10+ | 玩家出生地、赛季中期争夺单元、资源与文化主题差异化 |
| **州府/郡城/县城** | 数十至数百 | 同盟扩张节点、资源加成来源、战略目标 |
| **关隘/渡口** | 数十 |  choke points（咽喉要道），制造地缘冲突与防守价值 |
| **地块** | 数万至数十万 | 资源产出、行军路径、个人发育基础 |

## 三、地块系统

### 3.1 地块类型

| 类型 | 作用 | 示例 |
|------|------|------|
| **资源地** | 产出木材/石料/铁矿/粮食 | 林场、石矿、铁矿、农田 |
| **空地** | 可铺路、可建营帐、无资源产出 | 平原、荒地 |
| **城池地块** | 同盟占领后提供资源加成与军事据点 | 县城、郡城、州府 |
| **关隘地块** | 连接州/区域的关键通道 | 虎牢关、潼关等历史关隘 |
| **特殊地形** | 影响行军速度或战斗属性 | 河流、山地、森林、沼泽 |

### 3.2 地块等级

- 资源地按等级区分产出效率与守军强度。
- 高等级地块集中在地图边缘或中心区域，制造玩家向外扩张的动力。
- 新手出生区域周围多为低等级地块，降低初期难度。

### 3.3 地块占领规则

- 玩家只能占领与自己已有领地相邻的地块（连城机制）。
- 高级地块需要更高战力才能攻克。
- 地块有耐久度，被攻打后需要恢复或重新占领。

---

## 四、行军与铺路机制

### 4.1 行军基础规则

- 部队从主城或营帐出发，沿已占领/同盟地块移动。
- 不同兵种/职业行军速度不同（如神行职业机动性更高）。
- 行军消耗体力，体力限制玩家连续作战次数。

### 4.2 自动铺路

- 玩家选择目标地块后，系统自动规划路径并依次占领沿途地块。
- 大幅减少手动铺路的重复操作。
- 保留战略决策：玩家决定「去哪里」，系统处理「怎么去」。

### 4.3 营帐与补给

- 玩家可在前线建造营帐，作为临时据点和征兵点。
- 营帐缩短前线往返时间，是长期作战的基础设施。
- 营帐需要消耗资源建造，且有数量限制。

## 五、城池与关卡设计

### 5.1 城池设计

| 要素 | 设计要点 |
|------|----------|
| **等级** | 县城 < 郡城 < 州府 < 洛阳，等级越高守军越强、奖励越丰厚 |
| **耐久度** | 城池有耐久度，需要同盟成员持续攻打才能占领 |
| **攻城器械** | 天工职业可建造投石车等器械，加速攻城 |
| **首占奖励** | 激励同盟积极参与首次占领 |
| **资源加成** | 占领后全体成员获得资源产出加成 |

### 5.2 关卡设计

- 关隘、渡口是连接不同区域的必经之路。
- 关卡通常具有高耐久度和窄通道特性，易守难攻。
- 控制关卡可以封锁敌方行军路线，形成战略优势。

### 5.3 攻城流程

```
宣战 → 倒计时准备 → 集结部队 → 攻城战 → 占领/失败 → 分配奖励
```

- 宣战机制给防守方反应时间，也便于同盟组织。
- 自动攻城功能让无法实时在线的玩家也能贡献力量。

## 六、地形与战略要地

### 6.1 地形类型

| 地形 | 效果 |
|------|------|
| **河流** | 无法直接通行，需通过渡口或桥梁 |
| **山地** | 行军速度降低，部分区域不可通行 |
| **森林** | 可能提供隐蔽或伏击加成 |
| **平原** | 默认地形，无特殊效果 |

### 6.2 战略要地

- **洛阳**：赛季终极目标，通常位于地图中心，全服最强同盟争夺。
- **州府**：各州核心，控制州府意味着控制该州主要资源。
- **关键关隘**：如通往洛阳的必经之路，控制后可扼守要道。

---

## 七、视野与信息博弈

### 7.1 视野机制

- 玩家/同盟只能看到己方领地及周围一定范围内的敌军动态。
- 神行职业可能具有更远的侦查范围或隐身能力。
- 敌方部队进入视野后显示在地图上。

### 7.2 信息战

- 侦查、埋伏、佯攻是常见战术。
- 奇佐职业的计策可以制造视野干扰或陷阱。
- 同盟需要共享情报，形成统一战场认知。

---

## 八、赛季剧本与地图变化

### 8.1 地图复用与变化

- 基础地图结构（十三州、洛阳、关隘）保持相对稳定。
- 每个赛季剧本可调整：资源分布、城池等级、特殊事件区域、胜利条件。

### 8.2 赛季剧本示例

| 剧本类型 | 地图变化 |
|----------|----------|
| **群雄割据** | 各州出生，争夺洛阳 |
| **南北对峙** | 地图分为南北两大阵营，争夺中部要地 |
| **逐鹿中原** | 多个势力围绕中原展开混战 |

### 8.3 动态事件

- 赛季中可能出现随机事件：贼寇入侵、资源丰收、限时据点等。
- 事件为地图注入不确定性，打破僵局。

## 九、与职业系统的联动

| 职业 | 大地图价值 |
|------|------------|
| **镇军** | 攻城战前排承伤、守城核心 |
| **青囊** | 前线治疗、降低部队战损 |
| **神行** | 快速侦查、骚扰、断粮道、抢先机 |
| **天工** | 建造营帐、攻城器械、战场设施 |
| **司仓** | 资源运输、后勤补给、维持长期作战 |
| **奇佐** | 设置陷阱、火攻、视野干扰、控场 |

## 十、技术实现考虑

### 10.1 地图数据

- 地图采用网格化或六边形地块系统。
- 每个地块记录：类型、等级、占领者、耐久度、资源产出等状态。
- 赛季重置时，地块占领状态清零，但地形与基础结构保留。

### 10.2 行军同步

- 部队行军需要实时或准实时同步给同盟成员。
- 大规模 GVG 时需要优化性能，避免同屏过多部队导致卡顿。

### 10.3 自动寻路与铺路

- 自动铺路需要基于相邻关系计算最短/最优路径。
- 需要考虑敌方地块阻隔、地形限制、体力消耗等因素。

## 十一、设计验证指标

| 指标 | 验证目标 |
|------|----------|
| 新手 48 小时占地数 | 验证地图早期体验是否顺畅 |
| 首次攻城参与率 | 验证地图目标对玩家的吸引力 |
| 州战/洛阳争夺活跃度 | 验证中后期地图战略价值 |
| 自动铺路使用率 | 验证减负设计是否被接受 |
| 不同职业的大地图书写贡献 | 验证职业系统与地图的联动效果 |

---

## 十二、潜在风险与应对

| 风险 | 应对思路 |
|------|----------|
 地块过多导致操作繁琐 | 自动铺路、自动攻城、一键出征 |
| 大地图后期无聊 | 赛季事件、限时据点、剧本变化 |
| 大盟垄断地图 | 跨州加盟、小盟奖励、个人功勋系统 |
| 行军卡顿/同步问题 | 性能优化、分层显示、LOD 技术 |
| 地形设计失衡 | A/B 测试、赛季数据复盘、动态调整 |

---

## 十三、总结

《三国：谋定天下》的大地图沙盘设计，核心在于**用分层结构支撑从个人到集体的多种玩法尺度**，用**地形与关卡制造地缘冲突**，用**自动功能降低操作负担**，并**与职业系统深度联动**。地图不仅是背景，而是 SLG 核心循环的物理承载和战略博弈的棋盘。
