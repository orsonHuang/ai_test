# 三国：谋定天下 — 职业系统

## 一、系统定位

职业系统是《三国：谋定天下》最核心的差异化设计。它将传统 SLG 中单一的玩家角色，拆分为六个具有明确分工的「职业」，让同盟内的协作更像 MMO 中的团队作战。

## 二、六大职业

| 职业 | 定位 | 核心作用 | 典型场景 |
|------|------|----------|----------|
| **镇军** | 战斗专精 | 攻城、承伤、正面战场 | 攻城战前排、守点、拆城 |
| **青囊** | 治疗辅助 | 恢复兵力、降低战损 | 团战续航、友军支援 |
| **神行** | 机动侦查 | 急行军、骚扰、探情报 | 抢资源、断粮道、侦查 |
| **天工** | 建造工程 | 修建战场设施、攻城器械 | 建箭塔/拒马/投石车、铺桥开路 |
| **司仓** | 资源后勤 | 提升资源产出与运输 | 同盟后勤、资源供给、种田发育 |
| **奇佐** | 谋略控制 | 计策、陷阱、控场 | 火攻/埋伏、战场节奏控制 |

## 三、设计意图

1. **瓦解「高战独尊」**：传统 SLG 中，付费高战玩家主导一切；三谋让平民玩家通过职业贡献获得同盟地位。
2. **强制社交协作**：单一职业无法覆盖所有场景，玩家必须依赖同盟完成大型目标。
3. **丰富战场维度**：职业技与战场设施让战争不止于数值碰撞，增加策略纵深。
4. **降低入门门槛**：玩家可以按自己喜欢的风格选职（种田、打架、辅助），不必所有人都拼战力。

## 四、职业与同盟配比

根据赛季经验，接战时同盟职业配比通常建议：
- 司仓、青囊、天工：每个职业最少 35 人左右
- 奇佐、神行、镇军：根据战术需求灵活配置

这体现了三谋「后勤与工程职业是战争基础」的设计思路。

## 五、潜在问题

- **职业平衡**：部分职业（如青囊、司仓）可能在特定赛季/剧本中显得「混子感」强，成就感不如镇军/神行直观。
- **选职锁定**：赛季内主职业切换成本高，一旦选错可能影响整个赛季体验。
- **指挥复杂度**：职业协作需要更精细的同盟指挥，对中小盟不友好。
