# 三国：谋定天下 — 战斗系统

## 一、战斗类型

游戏战斗分为两个层面：

1. **大地图沙盘战斗**：部队在真实地图上移动、交战、攻城，是 SLG 的核心对抗形式。
2. **回合制/自动战斗结算**：部队相遇后进入战斗，由武将、战法、兵种等数值自动结算。

## 二、兵种与克制

### 兵种体系

- **盾兵**：防御高，适合前排承伤。
- **弓兵**：远程输出，克制枪兵。
- **枪兵**：中距离输出，克制骑兵。
- **骑兵**：高机动，冲锋爆发，克制弓兵。

> 部分赛季/版本可能加入更多兵种或特殊兵种。

### 克制循环

```
骑兵 → 弓兵 → 枪兵 → 骑兵
盾兵：偏防御，克制关系相对独立
```

### 设计意图

- 兵种克制让配队与战场决策有明确策略维度。
- 鼓励玩家根据敌方阵容调整自己的队伍配置。
- 为「多队共存」「针对不同敌人出不同队」提供基础。

## 三、武将、战法与配队

### 武将

- 三国名将按稀有度划分，核心获取途径为抽卡。
- 武将拥有自带战法、属性成长、兵种适性。
- 武将等级支持**无损置换**，降低新手试错成本。

### 战法

- 战法分为主动、被动、指挥、突击等多种类型。
- 战法可通过铜币升级，也可重置，养成成本相对可控。
- 核心策略点：战法与武将的联动、队伍内的战法配合。

### 配队流派

常见流派包括：
- **反击流**：夏侯惇、典韦类武将，靠受击反击输出。
- **主动流**：依赖主动战法爆发，如许褚、张辽。
- **追击流**：依靠普攻后追击，如马超、孙尚香。
- **治疗续航流**：刘备、华佗等提供持续恢复。
- **控制流**：诸葛亮、周瑜等提供技穷、震慑等控制。

## 四、战斗节奏与体验

- **自动铺路/自动攻城**：降低大地图操作负担，让玩家更关注策略决策。
- **营帐征兵**：部队可在城外营帐快速补充兵力，缩短来回时间。
- **战场设施**：天工的箭塔、拒马、投石车等改变局部地形与战斗节奏。
- **职业技介入**：奇佐火攻、青囊治疗、神行骚扰等让战场局势动态变化。

## 五、设计亮点

1. **策略 > 纯数值**：兵种克制 + 战法搭配 + 职业技让战力相近时策略能左右胜负。
2. **降低战损焦虑**：青囊治疗、营帐征兵、自动攻城减少玩家因战损而停滞的挫败感。
3. **多队共存需求**：一个玩家通常需要培养 3-5 支队伍，支撑长线养成目标。

## 六、潜在问题

- **阵容固化**：赛季 T0 阵容传播快，后期容易同质化。
- **平衡性挑战**：新武将/战法可能打破既有克制关系，引发玩家争议。
- **战报可读性**：自动战斗结算对新手不够直观，理解成本较高。
