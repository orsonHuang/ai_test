## 一句话定位

《三国：谋定天下》是 B 站发行、东风工作室研发的 SLG 手游，以「多职业战争策略」为核心差异点，通过镇军、青囊、神行、天工、司仓、奇佐六大职业重构同盟协作体验，并以快节奏赛季制和降肝降氪设计冲击传统 SLG 市场。
