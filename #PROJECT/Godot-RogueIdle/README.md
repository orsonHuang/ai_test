# Godot-RogueIdle

放置肉鸽·战斗即构筑 的游戏设计文档目录。

## 项目定位

一款以 Godot 开发的放置 + 肉鸽（Rogue-lite）游戏，核心体验为「战斗即构筑」：通过战斗掉落装备、词条、技能，逐步构建角色流派。

## 配置表设计原则

- **效果原子表（EffectResource）**：技能、词条、套装共用
- **词条表（AffixResource）**：引用效果原子，定义适用部位/数值范围/累计规则
- **技能表（SkillResource）**：引用效果原子，定义 CD/AI 条件
- **套装表（SetResource）**：引用效果原子，定义激活条件
- **装备表（EquipmentResource）**：引用词条 ID 池，不直接绑定具体词条
