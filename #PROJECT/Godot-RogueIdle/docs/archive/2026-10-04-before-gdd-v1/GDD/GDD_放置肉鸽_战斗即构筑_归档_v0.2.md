# 游戏设计文档（GDD）— 放置肉鸽·战斗即构筑

> 版本：v0.2 草案  
> 引擎：Godot 4.x  
> 日期：2026-08-04  
> 状态：装备系统迭代——稀有度/词条/强化重铸/套装

---

## 1. 游戏概述

### 1.1 一句话描述

一款融合杀戮尖塔关卡结构、放置挂机战斗、暗黑式装备系统的 Roguelite 单机游戏。

### 1.2 核心体验

- **构筑爽感**：战前搭配技能与装备，战中观察 Build 自动运转，战后收获新装备深化流派
- **轻量操作**：战斗全自动进行，玩家战前搭配技能与装备，战中观察 Build 自动运转，零手动操作
- **短局快节奏**：单局约 20 分钟，3 层地图，每层 6-8 节点，适合碎片化时间
- **渐进解锁**：局外养成解锁新技能、新职业，保持长线探索欲

### 1.3 核心循环

```
[局外] 选择职业 → 配置技能 → 进入战斗
[局内] 选路线 → 战斗/商店/篝火/事件 → 获取装备/强化/重铸 → BOSS
[局后] 结算奖励 → 解锁新技能/职业 → 再次挑战
```

## 2. 关卡结构

### 2.1 地图设计

- **3 层地图**：每层为一个独立章节，主题风格不同（如森林→城堡→深渊）
- **每层 6-8 个节点**，节点之间 2-3 条分叉路线，玩家自选前进方向
- **每层末尾为 BOSS 节点**，击败后进入下一层
- 节点类型：

| 节点类型 | 图标 | 说明 |
|----------|------|------|
| 普通战斗 | ⚔️ | 掉落金币 + 低级装备（1-2 件自选） |
| 精英战斗 | 💀 | 掉落高品质装备 + 技能替换机会（三选一） |
| BOSS | 👹 | 掉落稀有品质装备 + 大量金币 + 套装装备 |
| 商店 | 🛒 | 金币购买装备/强化石/重铸石 |
| 篝火 | 🔥 | 回复生命 / 强化一件装备 |
| 随机事件 | ❓ | 文本抉择事件，可能获得装备/金币/诅咒等 |

### 2.2 路线选择策略

玩家在每层起点看到完整地图，路线选择的权衡点：
- "走精英拿好装备 vs 绕路去商店消费"
- "血量充裕时直奔 BOSS 路线 vs 血量不足时找篝火"
- "赌随机事件搏收益 vs 走确定收益的战斗路线"

## 3. 战斗系统

### 3.1 战斗模式

**全自动放置战斗**（方案 B 修订版）

- 进入战斗后，角色自动进行普通攻击，主动/被动技能均按各自 CD 与触发条件自动释放
- 玩家拥有 **1 个主动职业技能**，由 AI 在合适时机自动释放（如敌人蓄力时开护盾、BOSS 破防窗口开爆发）
- 战内取消所有手动操作，构筑策略完全前置到战前与路线选择中

### 3.2 战斗流程

一场普通战斗约 30-60 秒，精英战 60-90 秒，BOSS 战 90-120 秒：

1. **开局**：双方登场，自动战斗开始
2. **自动循环**：角色按照攻速/技能 CD 自动释放已装备的被动技能
3. **技能自动释放**：主动技能由系统自动判断最佳时机释放，释放后进入 CD
4. **波次**（可选）：精英/BOSS 战可能存在 2-3 个波次，波次间有短暂间隙
5. **结算**：击败所有敌人后显示掉落奖励

### 3.3 伤害与属性体系

| 属性 | 说明 |
|------|------|
| 攻击力 | 基础伤害值 |
| 攻击速度 | 每秒攻击次数 |
| 暴击率 / 暴击伤害 | 暴击系统 |
| 生命值 / 护盾 | 生存属性 |
| 防御力 | 减伤百分比 |
| 冷却缩减 | 降低主动技能 CD |
| 吸血率 | 造成伤害的百分比回复生命 |
| 反击率 / 反击伤害 | 被击中时触发反击 |
| 召唤物强度 | 提升召唤随从的属性 |

## 4. 装备系统

> **v0.2 迭代说明**：移除"圣物/神器"系统（与装备重叠，demo 后再考虑加回），移除一次性道具；装备系统重写为稀有度+词条+强化重铸+套装体系。

### 4.1 装备槽位

| 槽位 | 类型 | 说明 |
|------|------|------|
| 主手武器 | 武器 | 决定攻击力/攻速的基础来源 |
| 头盔 | 防具 | 偏防御/生命 |
| 身体 | 防具 | 主防御属性 |
| 鞋子 | 防具 | 偏移速/闪避/冷却 |
| 手套 | 防具 | 偏攻击属性 |
| 耳环 | 饰品 | 偏暴击/冷却 |
| 项链 | 饰品 | 偏特殊效果 |
| 戒指1 | 饰品 | 偏攻击属性 |
| 戒指2 | 饰品 | 偏攻击属性 |

共 **9 个装备槽位**，全为可掉落/可强化/可重铸的装备。

### 4.2 稀有度体系

参考《暖雪》的稀有度分级，装备分为 6 级：

| 稀有度 | 颜色 | 自带词条数 | 属性倍率 | 说明 |
|--------|------|-----------|----------|------|
| 凡品 | 灰 | 0 | ×1.0 | 基础属性，无词条 |
| 良品 | 绿 | 0-1 | ×1.2 | 概率自带 1 条词条 |
| 上品 | 蓝 | 1 | ×1.5 | 固定 1 条词条 |
| 极品 | 紫 | 1-2 | ×2.0 | 概率自带 2 条词条 |
| 神品 | 橙 | 2 | ×2.5 | 固定 2 条词条 |
| 绝品 | 红 | 2-3 | ×3.0 | 概率自带 3 条词条，极品属性 |

**稀有度获取途径**：
- 掉落：普通战斗掉落凡品/良品，精英掉落上品/极品，BOSS 掉落极品/神品
- 强化：通过强化系统可提升稀有度（见 4.4）

**稀有度与词条上限**：
- 每件装备的词条上限取决于其稀有度
- 凡品上限 2 条，良品上限 3 条，上品上限 3 条，极品上限 4 条，神品上限 4 条，绝品上限 5 条
- 通过强化提升稀有度时，词条上限同步提升

### 4.3 词条系统

装备词条是装备上的被动效果，参考《暖雪》《卡尔斯梦境》的设计。

#### 4.3.1 词条类型

| 词条分类 | 示例效果 | 说明 |
|----------|----------|------|
| 基础属性 | 攻击力+N%、生命值+N%、防御力+N% | 直接提升面板属性 |
| 战斗机制 | 暴击率+N%、暴击伤害+N%、攻速+N%、冷却缩减+N% | 影响战斗循环 |
| 特殊效果 | 吸血+N%、反击率+N%、击杀回复+N% | 提供特殊战斗能力 |
| 元素伤害 | 火焰伤害+N%、冰霜伤害+N%、闪电伤害+N% | 元素流派核心 |
| 条件触发 | 满血时伤害+N%、低血时防御+N%、每击杀+N%攻击（本局） | 条件型增益 |
| 召唤强化 | 召唤物生命+N%、召唤物伤害+N% | 召唤流派核心 |

#### 4.3.2 词条获取途径

| 途径 | 说明 |
|------|------|
| 装备掉落自带 | 装备生成时根据稀有度概率附带词条 |
| 强化获得 | 强化成功时概率获得新词条（不超过当前稀有度的词条上限） |
| 重铸替换 | 重铸系统可替换已有词条为新随机词条 |

#### 4.3.3 词条数值规则

- 词条数值在设定范围内随机波动（如"攻击力+8%~15%"）
- 词条稀有度越高，数值范围越优
- **同名词条数值累计**：若玩家装备了多条相同词条（如3件装备都有"攻击力+10%"），则在属性区显示为"攻击力+10% (×3) = 30%"，实际效果累计计算
- 词条效果在战斗外即生效（面板实时反映）

#### 4.3.4 示例词条库

| 词条名 | 类型 | 效果范围 | 适用部位 |
|--------|------|----------|----------|
| 攻击强化 | 基础属性 | 攻击力+8%~15% | 武器、手套、戒指 |
| 生命增幅 | 基础属性 | 生命值+10%~20% | 头盔、身体 |
| 防御强化 | 基础属性 | 防御力+8%~15% | 头盔、身体、鞋子 |
| 精准 | 战斗机制 | 暴击率+3%~8% | 耳环、戒指、手套 |
| 致命 | 战斗机制 | 暴击伤害+15%~30% | 武器、耳环 |
| 疾风 | 战斗机制 | 攻速+5%~12% | 武器、鞋子、手套 |
| 冷静 | 战斗机制 | 冷却缩减+5%~10% | 耳环、项链 |
| 嗜血 | 特殊效果 | 吸血+3%~8% | 武器、项链 |
| 荆棘 | 特殊效果 | 反击率+5%~15% | 身体、头盔 |
| 贪婪 | 特殊效果 | 金币掉落+10%~25% | 戒指、项链 |
| 烈焰 | 元素伤害 | 火焰伤害+10%~20% | 武器、手套 |
| 冰霜 | 元素伤害 | 冰霜伤害+10%~20% | 武器、手套 |
| 雷击 | 元素伤害 | 闪电伤害+10%~20% | 武器、手套 |
| 召唤大师 | 召唤强化 | 召唤物伤害+15%~30% | 项链、戒指 |
| 绝境 | 条件触发 | 生命低于30%时，防御+30%~50% | 身体 |

### 4.4 强化系统

**目的**：消耗资源提升装备稀有度，提升基础数值，并概率获得新词条。

#### 4.4.1 强化规则

| 规则项 | 说明 |
|--------|------|
| 消耗材料 | **强化石**（商店购买/精英掉落/事件奖励） |
| 强化效果 | 稀有度提升 1 级（如良品→上品），基础属性按新稀有度倍率重算 |
| 词条获得 | 强化成功时，概率获得 1 条新随机词条（不超过当前稀有度词条上限） |
| 强化上限 | 最高可强化至 **绝品（红）** |
| 失败惩罚 | 强化不失败，100% 成功（避免负面体验） |
| 成本递增 | 每次强化消耗的强化石递增：良品→上品 1 颗，上品→极品 2 颗，极品→神品 4 颗，神品→绝品 8 颗 |

#### 4.4.2 强化词条概率

| 稀有度提升 | 获得新词条概率 |
|------------|---------------|
| 凡品 → 良品 | 50% |
| 良品 → 上品 | 60% |
| 上品 → 极品 | 70% |
| 极品 → 神品 | 80% |
| 神品 → 绝品 | 90% |

- 若当前词条数已达目标稀有度上限，则不再获得新词条，改为随机提升一条已有词条的数值（+5%~10%）

#### 4.4.3 强化入口

- **篝火节点**：可免费强化 1 件装备（不消耗强化石）
- **商店节点**：可消耗强化石强化任意件装备
- **战斗中不可强化**

### 4.5 重铸系统

**目的**：消耗资源替换指定词条，优化 Build 方向。

#### 4.5.1 重铸规则

| 规则项 | 说明 |
|--------|------|
| 消耗材料 | **重铸石**（商店购买/精英掉落/事件奖励） |
| 重铸方式 | 选择一件装备 → 选择一条已有词条 → 消耗重铸石将其替换为一条新随机词条 |
| 新词条来源 | 从该装备部位可出现的词条池中随机抽取（不会重铸出已存在于该装备的词条） |
| 消耗数量 | 每次重铸消耗 1 颗重铸石 |
| 无次数限制 | 同一件装备可反复重铸，消耗逐次递增（第1次1颗，第2次2颗，第3次3颗...） |

#### 4.5.2 重铸策略

- 重铸是定向优化工具，玩家可以"洗掉"不需要的词条来追求理想 Build
- 风险：新词条随机，可能洗出更差的词条
- 套装词条不可被重铸（见 4.6）

#### 4.5.3 重铸入口

- **商店节点**：消耗重铸石重铸词条
- **战斗中不可重铸**

### 4.6 套装系统

套装是特殊的词条类型，区别于普通词条。

#### 4.6.1 套装规则

| 规则项 | 说明 |
|--------|------|
| 定义 | 套装词条是特殊词条，每件装备**最多有且仅有 1 条**套装词条 |
| 生成 | 装备掉落时概率附带套装词条（稀有度越高概率越大），神品/绝品必定附带套装词条 |
| 激活条件 | 需要**指定数量**的同名套装词条（分布在多件装备上）才会生效 |
| 不占词条上限 | 套装词条不计入普通词条数量上限 |
| 不可重铸 | 套装词条无法被重铸系统替换，永久绑定在该装备上 |
| 状态区分 | 套装词条有 [生效] 和 [未生效] 两种状态，在属性区分别以绿色高亮和灰色展示 |

#### 4.6.2 套装激活数量

| 套装类型 | 所需件数 | 说明 |
|----------|----------|------|
| 小型套装 | 2 件 | 效果适中，容易凑齐 |
| 中型套装 | 3 件 | 效果较强，需要一定运气/策略 |
| 大型套装 | 5 件 | 效果强力，需要全身过半部位统一 |

#### 4.6.3 示例套装设计

| 套装名 | 类型 | 所需件数 | 效果 |
|--------|------|----------|------|
| 烈焰之心 | 小型 (2件) | 2 | 火焰伤害+30%，击杀燃烧敌人时爆炸造成 80% 攻击力 AOE |
| 冰霜之触 | 小型 (2件) | 2 | 冰霜伤害+30%，减速效果翻倍 |
| 不屈意志 | 中型 (3件) | 3 | 生命低于 50% 时减伤 25%，低于 25% 时减伤提升至 50% |
| 狂风之怒 | 中型 (3件) | 3 | 攻速+25%，每第 5 次攻击造成 200% 伤害 |
| 召唤主宰 | 中型 (3件) | 3 | 召唤物数量上限+1，召唤物继承主角 50% 暴击属性 |
| 暗夜刺客 | 大型 (5件) | 5 | 暴击伤害+100%，暴击时回复 5% 最大生命，每 3 次暴击触发一次隐身（2秒无敌） |

#### 4.6.4 套装词条概率

| 稀有度 | 附带套装词条概率 |
|--------|-----------------|
| 凡品 | 0% |
| 良品 | 5% |
| 上品 | 10% |
| 极品 | 20% |
| 神品 | 100%（必定附带） |
| 绝品 | 100%（必定附带） |

### 4.7 装备配置表设计

装备数据采用三表分离的 `.tres` Resource 设计，便于策划配置和维护。

#### 4.7.1 装备表 (EquipmentResource)

```gdscript
# equipment_base.tres 的 Resource 定义
class_name EquipmentResource
extends Resource

@export var id: String = ""                    # 唯一ID，如 "sword_common_01"
@export var equipment_name: String = ""        # 显示名称
@export var slot: int = 0                      # 槽位类型（枚举：武器/头盔/身体/鞋子/手套/耳环/项链/戒指）
@export var rarity: int = 0                    # 稀有度（0=凡品~5=绝品）
@export var base_stats: Dictionary = {}        # 基础属性 {"atk": 10, "hp": 50}
@export var possible_affixes: Array[String] = []  # 该装备可能出现的词条ID池
@export var possible_set_affixes: Array[String] = []  # 该装备可能出现的套装词条ID池
@export var icon_path: String = ""             # 图标资源路径
@export var description: String = ""           # 描述文本
```

**配置表示例**：
| id | name | slot | rarity | base_stats | possible_affixes | possible_set_affixes |
|----|------|------|--------|------------|-----------------|---------------------|
| sword_common_01 | 铁剑 | 武器 | 凡品 | {atk: 10} | [atk_up, crit_dmg] | [] |
| sword_rare_01 | 秘银长剑 | 武器 | 极品 | {atk: 40} | [atk_up, crit_dmg, fire_dmg, atk_speed] | [set_fire_heart, set_ice_touch] |
| helm_legend_01 | 龙鳞盔 | 头盔 | 神品 | {hp: 120, def: 25} | [hp_up, def_up, thorn, desperate] | [set_unyielding] |

#### 4.7.2 词条表 (AffixResource)

```gdscript
# affix_base.tres 的 Resource 定义
class_name AffixResource
extends Resource

@export var id: String = ""                    # 唯一ID，如 "atk_up"
@export var affix_name: String = ""            # 显示名称，如 "攻击强化"
@export var affix_type: int = 0                # 词条类型（枚举：基础属性/战斗机制/特殊效果/元素伤害/条件触发/召唤强化）
@export var effect_target: String = ""         # 影响的属性名，如 "atk"
@export var effect_type: int = 0               # 效果类型（0=百分比加成, 1=固定值加成）
@export var min_value: float = 0.0             # 数值最小值
@export var max_value: float = 0.0             # 数值最大值
@export var applicable_slots: Array[int] = []  # 适用装备槽位
@export var weight: int = 100                  # 随机抽取权重（越高越常见）
@export var is_set_affix: bool = false         # 是否为套装词条
@export var description_template: String = ""  # 描述模板，如 "{target}+{value}%"
```

**配置表示例**：
| id | name | type | effect_target | min | max | applicable_slots | weight | is_set |
|----|------|------|---------------|-----|-----|-----------------|--------|--------|
| atk_up | 攻击强化 | 基础属性 | atk | 8% | 15% | [武器,手套,戒指] | 100 | false |
| hp_up | 生命增幅 | 基础属性 | hp | 10% | 20% | [头盔,身体] | 100 | false |
| crit_rate | 精准 | 战斗机制 | crit_rate | 3% | 8% | [耳环,戒指,手套] | 80 | false |
| fire_dmg | 烈焰 | 元素伤害 | fire_dmg | 10% | 20% | [武器,手套] | 60 | false |
| summon_master | 召唤大师 | 召唤强化 | summon_dmg | 15% | 30% | [项链,戒指] | 40 | false |
| set_fire_heart | 烈焰之心 | - | - | - | - | [全部位] | - | true |
| set_ice_touch | 冰霜之触 | - | - | - | - | [全部位] | - | true |
| set_unyielding | 不屈意志 | - | - | - | - | [全部位] | - | true |

#### 4.7.3 套装表 (SetResource)

```gdscript
# set_base.tres 的 Resource 定义
class_name SetResource
extends Resource

@export var id: String = ""                    # 唯一ID，如 "set_fire_heart"
@export var set_name: String = ""              # 套装名称，如 "烈焰之心"
@export var required_pieces: int = 2           # 激活所需件数
@export var set_bonus: Dictionary = {}         # 套装效果 {"fire_dmg": 30, "on_kill_explode": 80}
@export var description: String = ""           # 套装效果描述
@export var icon_color: Color = Color.GREEN    # 套装图标/文字颜色
```

**配置表示例**：
| id | name | required | bonus | description |
|----|------|----------|-------|-------------|
| set_fire_heart | 烈焰之心 | 2 | {fire_dmg_pct: 30, kill_explode_pct: 80} | 火焰伤害+30%，击杀燃烧敌人爆炸造成80%攻击AOE |
| set_ice_touch | 冰霜之触 | 2 | {ice_dmg_pct: 30, slow_double: true} | 冰霜伤害+30%，减速效果翻倍 |
| set_unyielding | 不屈意志 | 3 | {low_hp_def_pct: 25, crit_hp_def_pct: 50} | 生命<50%时减伤25%，<25%时减伤50% |
| set_wind_fury | 狂风之怒 | 3 | {atk_speed_pct: 25, every_5th_hit_pct: 200} | 攻速+25%，每第5次攻击造成200%伤害 |
| set_summon_lord | 召唤主宰 | 3 | {summon_limit_plus: 1, summon_crit_inherit: 50} | 召唤物上限+1，召唤物继承50%暴击属性 |
| set_shadow_assassin | 暗夜刺客 | 5 | {crit_dmg_pct: 100, crit_heal_pct: 5, stealth_every_3_crit: true} | 暴击伤害+100%，暴击回复5%生命，每3次暴击隐身2秒 |

#### 4.7.4 三表关系

```
装备表 (EquipmentResource)
  ├── possible_affixes → 引用词条表 (AffixResource) 中的 ID
  ├── possible_set_affixes → 引用词条表 (AffixResource) 中 is_set_affix=true 的 ID
  └── 套装效果计算 → 引用套装表 (SetResource) 中的 set_bonus

词条表 (AffixResource)
  ├── 普通词条 (is_set_affix=false)：装备掉落/强化/重铸时随机
  └── 套装词条 (is_set_affix=true)：装备掉落时概率附带，不可重铸

套装表 (SetResource)
  └── 定义激活条件与套装效果，运行时由 GameManager 检查同名套装词条数量
```

#### 4.7.5 运行时装备实例数据

```gdscript
# 运行时装备实例（存储在存档/内存中，非 .tres 文件）
class_name EquipmentInstance
extends Resource

@export var base_id: String = ""               # 引用 EquipmentResource.id
@export var instance_id: String = ""           # 运行时唯一ID
@export var rarity: int = 0                    # 当前稀有度（强化后会变化）
@export var current_stats: Dictionary = {}     # 当前基础属性（强化后重新计算）
@export var affixes: Array[String] = []        # 当前拥有的词条ID列表
@export var set_affix_id: String = ""          # 套装词条ID（有且仅有0或1个）
@export var enhancement_level: int = 0         # 已强化次数
@export var reroll_count: int = 0              # 已重铸次数（用于递增消耗计算）
```

## 5. 技能系统

### 5.1 技能类型

| 类型 | 说明 | 携带上限 |
|------|------|----------|
| 主动技能 | 自动释放，长 CD，由 AI 判断最佳时机，战局翻盘点 | 1 个 |
| 被动技能 | 自动触发或被动机理，构成 Build 核心 | 1 个 |

- 入场前从已解锁的技能池中选择 **1 主动 + 1 被动**
- 精英/BOSS 战后可在 **3 个随机技能中替换** 当前携带中的一个

### 5.2 首发职业：战士

**定位**：攻守兼备、前排、物理伤害

**流派方向**：

| 流派 | 核心机制 | 初始技能示例 |
|------|----------|-------------|
| 属性增幅 | 战斗中叠加攻击力/攻速 Buff | 主动「战斗怒吼」：8 秒内攻击力+40%；被动「愈战愈勇」：每击杀一个敌人，永久+3% 攻击力（本局） |
| 反击 | 被击中时触发高额反击 | 主动「盾反」：2 秒内格挡所有伤害并反击 200%；被动「荆棘甲」：受到伤害时 30% 概率反击 80% |
| 吸血 | 造成伤害回复生命 | 主动「血之狂暴」：6 秒内吸血率+30%、攻速+25%；被动「嗜血」：暴击时回复 5% 最大生命 |

**初始技能池**（首发 3-4 个，局外可解锁到 8-10 个）：

| 类型 | 技能名 | 效果 |
|------|--------|------|
| 主动 | 战斗怒吼 | 8 秒内攻击力+40%，CD 25s |
| 主动 | 盾反 | 2 秒内格挡并反击 200%，CD 30s |
| 被动 | 愈战愈勇 | 每击杀+3% 攻击力（本局） |
| 被动 | 荆棘甲 | 受击 30% 概率反击 80% |

### 5.3 首发职业：法师

**定位**：爆发、后排、法术伤害

**流派方向**：

| 流派 | 核心机制 | 初始技能示例 |
|------|----------|-------------|
| 长 CD 爆发 | 积累能量后一次性大伤害 | 主动「陨石术」：3 秒吟唱后造成 500% 范围伤害；被动「奥术积蓄」：每 10 秒获得一层充能，主动技能伤害+15%/层 |
| 灼烧+引爆 | 叠加灼烧层数后引爆 | 主动「烈焰爆破」：引爆目标所有灼烧层数，每层造成 80% 伤害；被动「火焰亲和」：攻击附加灼烧，每秒造成 5% 攻击力伤害，可叠 10 层 |
| 冰冻控制 | 减速/冻结控制敌人 | 主动「冰封领域」：冻结所有敌人 3 秒，解冻时造成 120% 伤害；被动「寒冰之触」：攻击减速敌人 30%，持续 2 秒 |

### 5.4 后续解锁职业（设计预留）

| 职业 | 解锁顺序 | 定位 | 流派方向 |
|------|----------|------|----------|
| 骑士 | 自由选择 | 坦克、光环、团队 Buff | 待设计 |
| 射手 | 自由选择 | 远程物理、攻速、风筝 | 待设计 |
| 刺客 | 自由选择 | 近战爆发、潜行、一击脱离 | 待设计 |
| 道士 | 自由选择 | 中国风、召唤僵尸、雷击、毒 | 雷击流 / 毒流 / 召唤僵尸流 |

### 5.5 召唤物规则

- 所有职业均可能通过装备词条/套装效果获得召唤能力
- **玩家角色最多同时存在 2 个随从**
- 召唤流职业（如道士）可突破此上限或给召唤物额外强化

## 6. 局外养成（Meta-Progression）

### 6.1 职业技能解锁

- 每个职业初始 3-4 个技能可使用
- 通过局数累计 / 特定成就解锁新技能，最终池为 8-10 个
- 解锁方式示例：
  - 「用战士通关一次」→ 解锁反击流被动
  - 「用法师累计造成 10000 点火焰伤害」→ 解锁灼烧主动技
  - 「击败第 3 层 BOSS」→ 解锁战士吸血主动技

### 6.2 职业解锁

- 首发：战士、法师
- 后续 4 个职业（骑士/射手/刺客/道士）由玩家自由选择解锁顺序
- 解锁条件：使用已拥有职业累计通关 N 次 / 消耗局内获取的"灵魂货币"

### 6.3 局外永久升级（可选扩展）

- 考虑加入类似 Hades 镜子的"全局天赋树"，所有职业共享
- 方向示例：初始金币+50、初始生命+10%、装备掉落品质概率提升

## 7. 一局完整流程

```
[战前]
  选择职业（战士/法师/已解锁的其他职业）
  从技能池中选择 1 主动 + 1 被动
  确认后进入地图

[第一层 - 森林]
  ┌─ 起点 ─→ 普通战 ─→ 商店 ─→ 精英战 ─→ BOSS
  │              ↘ 随机事件 ↗
  │
  └─ 击败 BOSS → 高品质装备掉落 → 进入第二层

[第二层 - 城堡]
  （同上结构，难度提升）

[第三层 - 深渊]
  （同上结构，最终 BOSS 为本局最终战）

[局后结算]
  展示本局数据（伤害统计、装备收集、通关时间）
  结算灵魂货币 / 成就进度
  可能解锁新技能或新职业
  回到主菜单
```

### 8.2 数据驱动设计

所有装备、词条、套装、技能、敌人使用 Godot 的 `.tres` 资源文件定义。**装备体系采用三表分离**（详见 4.7）：

- **装备表 (EquipmentResource)**：定义装备基础数据、槽位、稀有度、可出现的词条池
- **词条表 (AffixResource)**：定义所有词条（含普通词条和套装词条）的效果、数值范围、适用部位
- **套装表 (SetResource)**：定义套装激活条件与效果

```gdscript
# 技能资源示例 — skill_battlecry.tres
class_name SkillResource

@export var skill_name: String = "战斗怒吼"
@export var skill_type: int = 0  # 0=主动, 1=被动
@export var cooldown: float = 25.0
@export var class_name: String = "warrior"
@export var effects: Array[EffectData]
@export var description: String = "8秒内攻击力+40%"
```

### 8.3 开发优先级建议
