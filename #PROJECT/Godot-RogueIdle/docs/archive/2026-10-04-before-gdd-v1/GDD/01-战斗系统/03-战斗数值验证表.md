**目标**：单层地图战斗时长控制在 1.5-2 分钟，节奏紧凑。

### 4.2 伤害公式验证

```
实际伤害 = max(1, 攻击力 × 技能倍率 - 防御力)

验证案例：
- 战士攻击20，普攻倍率1.0，防御5
- 实际伤害 = 20 - 5 = 15 ✓

- 战士攻击50，暴击触发，防御10
- 实际伤害 = (50 - 10) × 1.5 = 60 ✓
```

### 6.2 伤害计算伪代码

```gdscript
func calculate_damage(attacker, defender, skill_multiplier = 1.0) -> int:
    var base_damage = attacker.attack * skill_multiplier
    var actual_damage = max(1, base_damage - defender.defense)
    
    # 暴击判定
    if randf() < attacker.crit_rate:
        actual_damage *= attacker.crit_damage
    
    return int(actual_damage)

func calculate_dps(character) -> float:
    var avg_damage = character.attack * (1 + character.crit_rate * (character.crit_damage - 1))
    return avg_damage * character.attack_speed
```

## 附录：TTK 计算公式

```
TTK（击杀时间）= 目标HP / DPS

其中：
- DPS = 平均伤害 × 攻击频率
- 平均伤害 = 攻击力 × (1 + 暴击率 × (暴击伤害 - 1)) - 目标防御
- 攻击频率 = 攻速值（或 1/攻击间隔）

示例：
战士 DPS = (20 - 5) × 1.0 × (1 + 0.05 × 0.5) = 15.375
哥布林 TTK = 60 / 15.375 ≈ 3.9秒
```
