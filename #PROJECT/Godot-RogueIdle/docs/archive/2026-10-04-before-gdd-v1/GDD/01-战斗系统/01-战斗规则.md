# 战斗系统 — 战斗规则

## 1. 战斗模式

**全自动放置回合制战斗**

- 进入战斗后，系统按**速度属性**排序形成行动队列，角色依次自动行动
- 每个角色在自己的回合自动执行：普攻或技能（按优先级和CD判断）
- 玩家拥有 **1 个主动职业技能**，由 AI 在合适时机自动释放
- 战内取消所有手动操作，构筑策略完全前置到战前与路线选择中

## 2. 回合制行动机制

### 2.1 行动队列

```
回合开始 → 收集所有存活单位速度 → 按速度降序排序 → 依次行动 → 回合结束 → 下一回合
```

- **速度决定行动顺序**：速度高的单位先行动
- **同速度处理**：随机决定先后顺序（或按玩家/敌方优先级）
- **回合制非实时**：单位行动时有短暂动画，非ARPG实时碰撞

### 2.2 行动流程

每个单位的回合：
1. **判定可用技能**：检查主动技能CD、触发条件
2. **技能优先级**：
   - 若主动技能可用且满足AI条件（如敌人蓄力/BOSS破防）→ 释放主动技能
   - 否则 → 执行普通攻击
3. **执行动作**：播放动画、计算伤害、应用效果
4. **结算状态**：更新BUFF/DEBUFF、检查死亡

### 2.3 战斗时长估算

| 战斗类型 | 预估回合数 | 预估时间 |
|----------|-----------|----------|
| 普通战斗 | 8-15 回合 | 20-40 秒 |
| 精英战斗 | 15-25 回合 | 40-70 秒 |
| BOSS 战 | 25-40 回合 | 70-120 秒 |

## 3. 属性体系

### 3.1 基础属性

| 属性 | 说明 |
|------|------|
| **速度** | **决定行动顺序**，核心属性 |
| 攻击力 | 基础伤害值 |
| 攻击速度 | 影响普攻动画速度（视觉）和少量伤害加成 |
| 暴击率 / 暴击伤害 | 暴击系统 |
| 生命值 / 护盾 | 生存属性 |
| 防御力 | 减伤百分比 |

### 3.2 进阶属性

| 属性 | 说明 |
|------|------|
| 冷却缩减 | 降低主动技能 CD |
| 吸血率 | 造成伤害的百分比回复生命 |
| 反击率 / 反击伤害 | 被击中时触发反击 |
| 召唤物强度 | 提升召唤随从的属性 |

## 4. 伤害公式

```
最终伤害 = 攻击力 × 技能倍率 × (1 + 元素加成) × 暴击倍率 × (1 - 敌方防御减伤)

防御减伤 = 防御力 / (防御力 + 100)  [示例公式，后续调优]

暴击倍率 = 1 + 暴击率 × (暴击伤害 - 1)  [暴击时，否则为1]
```

## 5. 召唤物规则

- 所有职业均可能通过装备词条/套装效果获得召唤能力
- **玩家角色最多同时存在 2 个随从**
- 召唤物**独立参与行动队列**，拥有各自的速度属性
- 召唤流职业（如道士）可突破此上限或给召唤物额外强化

## 6. 技能释放AI逻辑

### 6.1 主动技能判断优先级

| 优先级 | 条件 | 行为 |
|--------|------|------|
| 1 | 敌人正在蓄力大招 | 释放护盾/减伤技能 |
| 2 | BOSS处于破防窗口期 | 释放爆发技能 |
| 3 | 自身生命值<30% | 释放治疗/护盾技能 |
| 4 | 多个敌人聚集（AOE收益高） | 释放AOE技能 |
| 5 | 技能CD已好 | 释放主动技能 |
| 6 | 无特殊条件 | 普通攻击 |

### 6.2 被动技能触发

- 按词条/装备描述的触发条件自动生效
- 如："每次攻击有20%概率触发XX"、"生命值低于50%时获得XX"
