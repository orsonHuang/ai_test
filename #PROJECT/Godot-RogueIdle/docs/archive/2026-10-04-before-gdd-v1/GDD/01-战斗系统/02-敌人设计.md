# 敌人设计文档

> 版本：v1.0（原型阶段）  
> 对应阶段：原型阶段 → Demo 阶段

---

## 1. 设计原则

### 1.1 核心定位
- **自动战斗适配**：敌人行为简单可预测，不依赖复杂 AI
- **数值驱动体验**：通过攻防数值差异制造挑战感
- **装备掉落来源**：不同敌人类型对应不同稀有度掉落期望

### 1.2 难度曲线
```
普通战（2-3场）→ 精英战（1场）→ BOSS战（1场）
  掉落：凡品~良品    掉落：上品~极品    掉落：极品~绝品
  威胁：低           威胁：中           威胁：高
```

## 3. 敌人配置表结构

### 3.1 EnemyResource 定义

```gdscript
# enemy_resource.gd
class_name EnemyResource
extends Resource

@export var enemy_id: String          # 唯一标识
@export var enemy_name: String        # 显示名称
@export var enemy_type: int           # 0=普通, 1=精英, 2=BOSS
@export var description: String     # 描述文本

# 战斗属性
@export var base_hp: int
@export var base_attack: int
@export var attack_interval: float    # 秒
@export var defense: int
@export var crit_rate: float          # 0.0-1.0
@export var crit_damage: float        # 1.5 = 150%

# 掉落配置
@export var gold_min: int
@export var gold_max: int
@export var drop_table: Array[DropEntry]  # 见下

# 特殊机制（BOSS）
@export var has_phase_change: bool = false
@export var phase_hp_threshold: float = 0.5  # 血量阈值
@export var phase_attack_speed_bonus: float = 0.2
```

### 3.2 DropEntry 定义

```gdscript
# drop_entry.gd
class_name DropEntry
extends Resource

@export var item_type: int    # 0=装备, 1=强化石, 2=重铸石
@export var rarity: int       # 装备稀有度（仅装备）
@export var weight: int       # 掉落权重
@export var min_count: int = 1
@export var max_count: int = 1
```

## 4. 数值基准与验证

### 4.1 战士 vs 敌人 TTK 预期

| 战斗场景 | 战士 DPS | 敌人 HP | 预期 TTK | 设计目的 |
|----------|----------|---------|----------|----------|
| 普通战（哥布林） | ~25 | 60 | ~2.5秒 | 快速清理 |
| 普通战（史莱姆） | ~25 | 90 | ~3.5秒 | 略慢但稳 |
| 精英战 | ~40 | 150 | ~4秒 | 有挑战感 |
| BOSS战 | ~50 | 400 | ~8秒 | 需要装备支撑 |

> TTK = Time To Kill，击杀所需时间

### 4.2 敌人 vs 战士 TTK 预期

以战士初始属性为基准（HP=100，防御=5）：

| 敌人 | 敌人 DPS | 有效伤害 | 预期 TTK | 威胁评估 |
|------|----------|----------|----------|----------|
| 哥布林 | 8 | 3 | ~33秒 | 极低 |
| 史莱姆 | 4 | 0（被防御） | ~∞ | 无威胁 |
| 哥布林队长 | 13.3 | 8.3 | ~12秒 | 中等 |
| 哥布林王 | 20 | 15 | ~7秒 | 高（需装备） |

### 4.3 层数缩放公式（Demo阶段）

```
第N层敌人属性 = 基础属性 × (1 + (N-1) × 0.3)

示例：
- 第1层：基础值 × 1.0
- 第2层：基础值 × 1.3
- 第3层：基础值 × 1.6
```
