:# 技能系统 — 技能基础与效果原子

## 1. 技能类型

| 类型 | 说明 | 携带上限 |
|------|------|----------|
| 主动技能 | 自动释放，长 CD，由 AI 判断最佳时机，战局翻盘点 | 1 个 |
| 被动技能 | 自动触发或被动机理，构成 Build 核心 | 1 个 |

- 入场前从已解锁的技能池中选择 **1 主动 + 1 被动**
- 精英/BOSS 战后可在 **3 个随机技能中替换** 当前携带中的一个

## 2. 技能与效果原子的关系

技能本身不直接定义数值，而是引用**效果原子表（EffectResource）**中的效果ID。效果原子表与装备词条共用同一套底层效果定义。

```
SkillResource
  └── effects: Array[String] → 引用 EffectResource.id

EffectResource
  └── 定义具体效果：目标、类型、数值、持续时间、扩展参数
```

## 3. 技能表 (SkillResource)

```gdscript
class_name SkillResource
extends Resource

@export var id: String = ""                    # 唯一ID，如 "skill_battlecry"
@export var skill_name: String = ""            # 显示名称
@export var skill_type: int = 0                # 0=主动, 1=被动
@export var class_id: String = ""              # 适用职业
@export var cooldown: float = 0.0              # CD（主动技能有效）
@export var effects: Array[String] = []        # 引用的 EffectResource.id 列表
@export var ai_condition: int = 0              # AI释放条件
@export var animation: String = ""             # 动画资源路径
@export var icon_path: String = ""             # 图标资源路径
@export var description: String = ""           # 描述文本
```

### AI 释放条件枚举（草案）

| 条件 | 说明 |
|------|------|
| 0 | 无特殊条件，CD 好了就释放 |
| 1 | BOSS 战时释放 |
| 2 | 敌人蓄力时释放（打断/护盾） |
| 3 | 我方生命低于 30% 时释放 |
| 4 | 多个敌人聚集时释放（AOE） |

## 4. 效果原子表（与装备系统共用）

详见 `03-装备系统/06-装备配置表.md` 中的 EffectResource 定义。

## 5. 示例技能

### 5.1 主动技能：战斗怒吼

```gdscript
id: "skill_battlecry"
skill_name: "战斗怒吼"
skill_type: 0                    # 主动
class_id: "warrior"
cooldown: 25.0
effects: ["add_atk_pct_40_8s"]   # 引用效果原子：攻击力+40%，持续8秒
ai_condition: 1                  # BOSS 战释放
animation: "res://anim/battlecry.anim"
description: "8秒内攻击力+40%"
```

对应效果原子：

```gdscript
id: "add_atk_pct_40_8s"
effect_name: "战斗怒吼：攻击力加成"
effect_category: 0               # 属性修改
target_type: 0                   # 自身
stat_key: "atk"
value_type: 0                    # 百分比
base_value: 40.0
duration: 8.0
```

### 5.2 被动技能：愈战愈勇

```gdscript
id: "skill_warrior_spirit"
skill_name: "愈战愈勇"
skill_type: 1                    # 被动
class_id: "warrior"
cooldown: 0.0
effects: ["atk_on_kill_3"]       # 每击杀一个敌人，攻击力+3%（本局）
ai_condition: 0
animation: ""
description: "每击杀一个敌人，永久+3%攻击力（本局）"
```

对应效果原子：

```gdscript
id: "atk_on_kill_3"
effect_name: "击杀加攻"
effect_category: 0               # 属性修改
target_type: 0                   # 自身
stat_key: "atk"
value_type: 0                    # 百分比
base_value: 3.0
duration: 0                      # 永久（本局内）
params: {trigger: "on_kill", scope: "run"}
```
