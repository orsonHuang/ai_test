# 装备系统 — 强化系统

**目的**：消耗资源提升装备稀有度，提升基础数值，并概率获得新词条。

## 1. 强化规则

| 规则项 | 说明 |
|--------|------|
| 消耗材料 | **强化石**（商店购买/精英掉落/事件奖励） |
| 强化效果 | 稀有度提升 1 级（如良品→上品），基础属性按新稀有度倍率重算 |
| 词条获得 | 强化成功时，概率获得 1 条新随机词条（不超过当前稀有度词条上限） |
| 强化上限 | 最高可强化至 **绝品（红）** |
| 失败惩罚 | 强化不失败，100% 成功（避免负面体验） |
| 成本递增 | 每次强化消耗的强化石递增：良品→上品 1 颗，上品→极品 2 颗，极品→神品 4 颗，神品→绝品 8 颗 |

## 2. 强化词条概率

| 稀有度提升 | 获得新词条概率 |
|------------|---------------|
| 凡品 → 良品 | 50% |
| 良品 → 上品 | 60% |
| 上品 → 极品 | 70% |
| 极品 → 神品 | 80% |
| 神品 → 绝品 | 90% |

- 若当前词条数已达目标稀有度上限，则不再获得新词条，改为随机提升一条已有词条的数值（+5%~10%）

## 3. 强化入口

- **篝火节点**：可免费强化 1 件装备（不消耗强化石）
- **商店节点**：可消耗强化石强化任意件装备
- **战斗中不可强化**
