:# 装备系统 — 装备配置表

装备数据采用多表分离的 `.tres` Resource 设计，便于策划配置和维护。

## 1. 核心配置表关系

```
效果原子表 (EffectResource)
  ├── 被技能表引用
  ├── 被词条表引用
  └── 被套装表引用

词条表 (AffixResource)
  ├── 普通词条：装备掉落/强化/重铸时随机
  ├── 套装词条：装备掉落时概率附带，不可重铸
  └── 效果通过 effects 数组引用 EffectResource

套装表 (SetResource)
  └── 定义激活条件与套装效果，通过 effects 数组引用 EffectResource

装备表 (EquipmentResource)
  ├── possible_affixes → 引用 AffixResource 中的普通词条ID
  ├── possible_set_affixes → 引用 AffixResource 中的套装词条ID
  └── 运行时通过 SetResource 计算套装效果
```

## 2. 效果原子表 (EffectResource)

技能和词条的"效果"共用此表定义。

```gdscript
class_name EffectResource
extends Resource

@export var id: String = ""                    # 唯一ID，如 "add_atk_pct"
@export var effect_name: String = ""           # 显示名称
@export var effect_category: int = 0           # 0=属性修改, 1=造成伤害, 2=治疗, 3=施加状态, 4=召唤...

# 目标相关
@export var target_type: int = 0               # 0=自身, 1=单个敌人, 2=全体敌人, 3=召唤物

# 数值相关
@export var stat_key: String = ""              # 影响的属性名，如 "atk"
@export var value_type: int = 0                # 0=百分比加成, 1=固定值加成, 2=直接伤害倍率
@export var base_value: float = 0.0            # 基础数值
@export var value_per_level: float = 0.0       # 每级成长（可选）

# 状态相关
@export var status_id: String = ""             # 施加的状态ID，如 "burn"
@export var duration: float = 0.0              # 持续时间（秒），0=永久/常驻

# 特殊参数
@export var params: Dictionary = {}            # 扩展参数，如 {aoe_radius: 100, trigger_condition: "on_crit"}
```

### 示例效果原子

| id | name | category | target | stat_key | value_type | base_value | duration | params |
|----|------|----------|--------|----------|------------|------------|----------|--------|
| add_atk_pct | 攻击力百分比加成 | 属性修改 | 自身 | atk | 百分比 | 15 | 0 | {} |
| add_crit_rate_pct | 暴击率加成 | 属性修改 | 自身 | crit_rate | 百分比 | 5 | 0 | {} |
| deal_fire_damage | 火焰伤害 | 造成伤害 | 单个敌人 | - | 倍率 | 2.0 | 0 | {element: fire} |
| apply_burn | 施加灼烧 | 施加状态 | 单个敌人 | - | - | 0 | 5.0 | {dot_dmg_pct: 5, stack_max: 10} |
| summon_skeleton | 召唤骷髅 | 召唤 | - | - | - | 0 | 0 | {unit_id: skeleton, count: 1} |
| heal_on_kill | 击杀回血 | 治疗 | 自身 | hp | 固定值 | 50 | 0 | {trigger: on_kill} |

## 3. 词条表 (AffixResource)

```gdscript
class_name AffixResource
extends Resource

@export var id: String = ""                    # 唯一ID，如 "affix_atk_up"
@export var affix_name: String = ""            # 显示名称
@export var affix_type: int = 0                # 词条分类枚举
@export var effects: Array[String] = []        # 引用的 EffectResource.id 列表
@export var min_value: float = 0.0             # 数值最小值
@export var max_value: float = 0.0             # 数值最大值
@export var applicable_slots: Array[int] = []  # 适用装备槽位
@export var weight: int = 100                  # 随机抽取权重
@export var is_set_affix: bool = false         # 是否为套装词条
@export var stack_rule: int = 0                # 0=数值相加, 1=效果独立, 2=取最高
@export var description_template: String = ""  # 描述模板
```

### 示例词条

| id | name | type | effects | min | max | applicable_slots | weight | is_set | stack_rule |
|----|------|------|---------|-----|-----|-----------------|--------|--------|------------|
| affix_atk_up | 攻击强化 | 基础属性 | [add_atk_pct] | 8% | 15% | [武器,手套,戒指] | 100 | false | 0 |
| affix_hp_up | 生命增幅 | 基础属性 | [add_hp_pct] | 10% | 20% | [头盔,身体] | 100 | false | 0 |
| affix_crit_rate | 精准 | 战斗机制 | [add_crit_rate_pct] | 3% | 8% | [耳环,戒指,手套] | 80 | false | 0 |
| affix_fire_dmg | 烈焰 | 元素伤害 | [add_fire_dmg_pct] | 10% | 20% | [武器,手套] | 60 | false | 0 |
| set_fire_heart | 烈焰之心 | - | [set_fire_bonus] | - | - | [全部位] | - | true | 0 |
| set_unyielding | 不屈意志 | - | [set_unyielding_bonus] | - | - | [全部位] | - | true | 0 |

## 4. 套装表 (SetResource)

```gdscript
class_name SetResource
extends Resource

@export var id: String = ""                    # 唯一ID，如 "set_fire_heart"
@export var set_name: String = ""              # 套装名称
@export var required_pieces: int = 2           # 激活所需件数
@export var effects: Array[String] = []        # 激活后触发的效果原子ID
@export var description: String = ""           # 套装效果描述
@export var icon_color: Color = Color.GREEN    # 套装图标/文字颜色
```

## 5. 装备表 (EquipmentResource)

```gdscript
class_name EquipmentResource
extends Resource

@export var id: String = ""                    # 唯一ID，如 "sword_common_01"
@export var equipment_name: String = ""        # 显示名称
@export var slot: int = 0                      # 槽位类型枚举
@export var rarity: int = 0                    # 稀有度（0=凡品~5=绝品）
@export var base_stats: Dictionary = {}        # 基础属性 {"atk": 10, "hp": 50}
@export var possible_affixes: Array[String] = []      # 普通词条ID池
@export var possible_set_affixes: Array[String] = []  # 套装词条ID池
@export var icon_path: String = ""             # 图标资源路径
@export var description: String = ""           # 描述文本
```

### 示例装备

| id | name | slot | rarity | base_stats | possible_affixes | possible_set_affixes |
|----|------|------|--------|------------|-----------------|---------------------|
| sword_common_01 | 铁剑 | 武器 | 凡品 | {atk: 10} | [affix_atk_up, affix_crit_dmg] | [] |
| sword_rare_01 | 秘银长剑 | 武器 | 极品 | {atk: 40} | [affix_atk_up, affix_crit_dmg, affix_fire_dmg, affix_atk_speed] | [set_fire_heart, set_ice_touch] |
| helm_legend_01 | 龙鳞盔 | 头盔 | 神品 | {hp: 120, def: 25} | [affix_hp_up, affix_def_up, affix_thorn, affix_desperate] | [set_unyielding] |

## 6. 运行时装备实例

```gdscript
class_name EquipmentInstance
extends Resource

@export var base_id: String = ""               # 引用 EquipmentResource.id
@export var instance_id: String = ""           # 运行时唯一ID
@export var rarity: int = 0                    # 当前稀有度（强化后会变化）
@export var current_stats: Dictionary = {}     # 当前基础属性（强化后重新计算）
@export var affixes: Array[AffixInstance] = [] # 当前拥有的词条实例
@export var set_affix_id: String = ""          # 套装词条ID（0或1个）
@export var enhancement_level: int = 0         # 已强化次数
@export var reroll_count: int = 0              # 已重铸次数
```

```gdscript
class_name AffixInstance
extends Resource

@export var affix_id: String = ""              # 引用 AffixResource.id
@export var roll_value: float = 0.0            # 随机出的数值
@export var effect_instances: Array[EffectInstance] = []  # 展开后的效果实例
```

## 7. 词条随机生成流程

```
装备掉落/强化时：
1. 从 EquipmentResource.possible_affixes 中按权重随机抽取 N 个词条ID
2. 对每个词条ID，找到 AffixResource
3. 在 AffixResource.min_value ~ max_value 之间随机 roll 数值
4. 根据 roll 值生成 EffectInstance（引用 EffectResource，填入实际数值）
5. 写入 EquipmentInstance.affixes
```
