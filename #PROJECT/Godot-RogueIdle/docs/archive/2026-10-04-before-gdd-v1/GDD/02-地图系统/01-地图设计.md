# 地图系统 — 地图设计

## 1. 地图结构

- **3 层地图**：每层为一个独立章节，主题风格不同（森林→城堡→深渊）
- **每层 6-8 个节点**，节点之间 2-3 条分叉路线，玩家自选前进方向
- **每层末尾为 BOSS 节点**，击败后进入下一层

## 2. 节点类型

| 节点类型 | 图标 | 说明 |
|----------|------|------|
| 普通战斗 | ⚔️ | 掉落金币 + 低级装备（1-2 件自选） |
| 精英战斗 | 💀 | 掉落高品质装备 + 技能替换机会（三选一） |
| BOSS | 👹 | 掉落稀有品质装备 + 大量金币 + 套装装备 |
| 商店 | 🛒 | 金币购买装备/强化石/重铸石 |
| 篝火 | 🔥 | 回复生命 / 强化一件装备 |
| 随机事件 | ❓ | 文本抉择事件，可能获得装备/金币/诅咒等 |

## 3. 路线选择策略

玩家在每层起点看到完整地图，路线选择的权衡点：
- "走精英拿好装备 vs 绕路去商店消费"
- "血量充裕时直奔 BOSS 路线 vs 血量不足时找篝火"
- "赌随机事件搏收益 vs 走确定收益的战斗路线"

## 4. 一局完整流程

```
[战前]
  选择职业（战士/法师/已解锁的其他职业）
  从技能池中选择 1 主动 + 1 被动
  确认后进入地图

[第一层 - 森林]
  ┌─ 起点 ─→ 普通战 ─→ 商店 ─→ 精英战 ─→ BOSS
  │              ↘ 随机事件 ↗
  │
  └─ 击败 BOSS → 高品质装备掉落 → 进入第二层

[第二层 - 城堡]
  （同上结构，难度提升）

[第三层 - 深渊]
  （同上结构，最终 BOSS 为本局最终战）

[局后结算]
  展示本局数据（伤害统计、装备收集、通关时间）
  结算灵魂货币 / 成就进度
  可能解锁新技能或新职业
  回到主菜单
```
