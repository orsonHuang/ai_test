# 随机事件库

> 版本：v1.0（Demo阶段）  
> 原型阶段：不包含事件节点，Demo阶段启用

---

## 1. 事件设计原则

### 1.1 核心定位
- **抉择感**：提供有意义的选择，影响后续战斗
- **风险与收益**：高风险高回报，低风险稳收益
- **主题契合**：与当前地图层主题相关
- **可预测性**：结果范围可控，不出现极端情况

### 1.2 事件触发

| 触发条件 | 说明 |
|----------|------|
| 节点类型 | 事件节点（Demo阶段新增） |
| 出现概率 | 每层 1-2 个事件节点 |
| 不可重复 | 同一次冒险中相同事件只触发一次 |

## 2. 事件结构定义

### 2.1 EventResource 配置

```gdscript
class_name EventResource
extends Resource

@export var event_id: String
@export var event_name: String
@export var description: String        # 事件描述文本
@export var theme: String              # 适用主题（森林/城堡/深渊/通用）
@export var min_layer: int = 1        # 最低出现层数
@export var options: Array[EventOption]

class EventOption:
    @export var text: String           # 选项文本
    @export var requirement: Dictionary # 需求条件（如金币≥X）
    @export var success_outcome: EventOutcome
    @export var fail_outcome: EventOutcome  # 可选，失败结果
    @export var success_chance: float = 1.0  # 成功概率（默认100%）

class EventOutcome:
    @export var type: String           # "gold"/"hp"/"equipment"/"buff"/"curse"
    @export var value: int             # 数值
    @export var rarity: int = 0       # 装备稀有度（仅装备）
    @export var buff_id: String = ""   # Buff ID
    @export var description: String    # 结果描述
```

## 4. 事件平衡参数

### 4.1 收益基准

| 事件类型 | 预期金币收益 | 预期装备稀有度 | 风险等级 |
|----------|--------------|----------------|----------|
| 低风险 | 10-20 | 凡品~良品 | 低 |
| 中风险 | 20-40 | 良品~上品 | 中 |
| 高风险 | 40-80 | 上品~绝品 | 高 |

### 4.2 诅咒平衡

| 诅咒类型 | 效果 | 持续时间 |
|----------|------|----------|
| 轻度诅咒 | 单一属性-10% | 2-3场战斗 |
| 中度诅咒 | 单一属性-20% 或 双属性-10% | 3-5场战斗 |
| 重度诅咒 | 单一属性-30% 或 命中率-30% | 至本层结束 |
| 永久诅咒 | 仅深渊事件，至冒险结束 | 整局 |

## 5. 实现注意事项

### 5.1 事件触发控制

```gdscript
# 确保事件不重复触发
var triggered_events: Array[String] = []

func can_trigger_event(event_id: String) -> bool:
    return not triggered_events.has(event_id)

func trigger_event(event_id: String):
    triggered_events.append(event_id)
    # 执行事件逻辑
```

### 5.2 Buff/Debuff 系统预留

事件中的 buff 和 curse 需要配合 BuffSystem 实现：
- Buff：临时增益，有明确持续时间
- Curse：临时减益，可被特定道具解除
