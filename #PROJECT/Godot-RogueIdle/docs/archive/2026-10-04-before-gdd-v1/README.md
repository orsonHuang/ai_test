# Godot-RogueIdle

放置肉鸽·战斗即构筑 的设计文档、Godot 工程与玩法原型目录。

## 编辑前必读 · 项目文件夹规范

**后续对 `Godot-RogueIdle/` 文件夹内的任何文件进行新增、编辑、整理或开发，都必须遵循 [AGENTS.md · 项目文件夹编辑规范](./AGENTS.md)。** 覆盖本目录内的文档、GDD、素材、HTML 原型、Godot 子工程和工具；每次开始工作先读本 README、AGENTS.md 与目标内容说明。该规范只在本项目目录内生效。

通用要求包括先读后改、明确目录归属、保留已有改动、同步本项目索引、检查引用和限定提交范围。涉及 Godot 开发时，还须满足原生场景与节点可编辑、参数可配置、MCP 核对及保存重开验收。用户最新明确指令优先，具体规则统一维护在 AGENTS.md。

当前目录同时存在 `cat-idle/`、`rogue-idle-gd/` 和 `html-mvp/`。它们的存在不代表已完成迁移或指定了唯一开发入口；每次根据任务与工程说明确认目标，避免跨工程覆盖。

## 项目定位

一款以 Godot 开发的放置 + 肉鸽（Rogue-lite）游戏，核心体验为「战斗即构筑」：通过战斗掉落装备、词条、技能，逐步构建角色流派。

- [HTML MVP 入口](./html-mvp/index.html)：2026-10-04，单文件离线可玩；鹿鸣村 → 三个探索区域 → 魔王城，完整选路、行动预算、自动回合战斗、招募、套装与存档闭环。

## 配置表设计原则

- **效果原子表（EffectResource）**：技能、词条、套装共用
- **词条表（AffixResource）**：引用效果原子，定义适用部位/数值范围/累计规则
- **技能表（SkillResource）**：引用效果原子，定义 CD/AI 条件
- **套装表（SetResource）**：引用效果原子，定义激活条件
- **装备表（EquipmentResource）**：引用词条 ID 池，不直接绑定具体词条
