# GDD v1 改版依据与迁移边界

2026-10-05。用户授权依据MVP重写整个GDD。旧稿已按原始字节归档，见 [归档说明](../archive/2026-10-04-before-gdd-v1/ARCHIVE_NOTES.md)。这次改的是设计、数据起点与计划，不是可执行游戏规则。

## 1. 为什么重写

旧稿同时存在按秒技能、按速度回合、九槽装备、六品质、全图节点、六职业、永久属性养成和延后Steam的不同方向。HTML已经验证的是另一条完整流程：地区选择、6时段、三人自动回合、目标副本、2/3件套、魔王城。

继续往旧系统叠加区域预算会扩大维护面，并掩盖最值得验证的玩法。新版以“有目的地刷装＋有限时间取舍＋可读的小队配合”为主轴。是否足以支撑独立游戏，需要重复真人试玩，不能仅凭一个可通关原型判断。

## 2. 逐项对照

| 主题 | 旧GDD | 当前HTML MVP | v1目标 / 理由 |
|---|---|---|---|
| 产品形态 | 放置与多职业刷装，发布路线分散 | 单人短远征 | Godot / Steam；Idle限定为自动战斗，减少时间等待 |
| 地图 | 多层一次性节点 | 9块固定地图，每局3区 | 沿用；地理相邻与前进边分开定义 |
| 迷雾 | 全图信息与随机节点混用 | 直接邻区揭雾，部分首领先可见 | 保留，明确地标情报不等于完整活动揭示 |
| 区域活动 | 节点触发一次内容 | 每区完整活动菜单 | 副本＋营地固定，3随机活动，首区保招募 |
| 预算 | 缺少地区预算闭环 | 每区6，副本2，其他1 | 沿用，不结转、无真实倒计时、可提前走 |
| 副本重复 | 无统一定义 | 可重复，正常掉装与战斗成长 | 重复仅求装备；公开轻度加压，保留贪心的风险 |
| 等级 | 职业/成长体系分散 | 每2胜升级，最高5，补14生命 | 每区首胜升级，最高4，不补生命；避免刷装同时刷等级 |
| 战斗时间 | 秒与回合混用 | 明确回合，但首领共骨架 | 全部用回合/行动/跳数，动画与结算分开 |
| 首领 | 行为与数值草案混合 | 区域首领蓄力横扫同构 | 三种机制家族＋最终组合，优先解决策略对象同质化 |
| 战前策略 | 职业/词条为主 | 技能被动、随从、阵位 | 增加有限目标优先级与释放条件，避免复杂条件编程 |
| 装备 | 9槽、6品质、大词条池 | 3槽、2品质、3词条 | 保留小规模；2件＋高档散件与3件形成选择 |
| 套装 | 3/5件等多个版本，概率套装词条 | 2/3件，首次3件补齐部位 | 固定模板身份＋跨区域获得账本；保底只保部位 |
| 词条/品质 | 高倍率稀有度驱动 | 小范围随机 | 固定词条值，精良仅放大基础属性15%，减少重复随机 |
| 行商 | 装备材料等 | 1时段＋25金币回血80%，可重复 | 每区一次交易：补给或散件，让金币有不同用途 |
| 恢复 | 多种来源定义分散 | 营地50%、商店80% | 保留高效率时段换血，移除升级补血，堵换装/招募补满漏洞 |
| 强化重铸 | 核心系统＋两种材料 | 未实现 | M1/M2移除；收益先来自新掉落与路线取舍 |
| 局外 | 永久属性、货币、多职业 | 本地战绩 | 图鉴/复盘/挑战，无永久属性树，不用局外数值掩盖局内问题 |
| 技术验收 | 文件创建、连接报告、设计混在一起 | HTML实际测试有独立记录 | 区分设计/已实现/已验证，Godot要求场景可编辑、保存重开 |
| 发布 | Steam被列为后续 | HTML非发行版本 | Steam是正式目标；平台集成进入M3验收 |

## 3. 取舍与风险

- **缩小系统面**能更快查明核心是否有趣，代价是初看内容少。用真实组合差异证明深度，再量产。
- **定向保底**减少构筑迟迟不成型的挫败，代价是毕业快。靠区域机会成本、3件与散件、敌方机制产生后续决策。
- **确定性战斗**便于理解与调试，代价是可能被解成固定最优。先用路线/活动变化和队伍克制处理，不随意加入暴击随机。
- **不做永久加点**能保持战术价值，代价是失败外在奖励较少。必须让复盘和下一种组合有吸引力；测试不成立时重审产品定位。
- **轻度副本加压**防止重复收益碾压其它行动，但可能变成惩罚玩家追套装。公开预览并单独做对照测试，可调整或撤销。
- **余烬中段成型**保留路线性格，但可能在三套公平性上吃亏，需统计成型时点与生存压力。

## 4. 实施顺序与禁止误读

先做M1规则和可编辑场景，验证“愿意为两件套选路、愿意少刷一次来休整、能解释战斗结果”。未验证前不扩职业/强化/大量美术。

HTML保留作为上一版对照，本次不改。两份Godot工程均不动；之后实施必须确定目标工程。旧报告不再作为当前MCP或Godot完成证据。新版数量、时长与胜率目标都不是已经通过的事实。
