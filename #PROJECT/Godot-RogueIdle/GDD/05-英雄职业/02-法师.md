# 英雄职业 — 法师

## 1. 基础信息

| 项目 | 内容 |
|------|------|
| 职业名 | 法师 |
| 定位 | 爆发、后排、法术伤害 |
| 初始生命 | 低 |
| 初始攻击 | 高 |
| 初始防御 | 低 |
| 初始攻速 | 低 |
| 推荐流派 | 长 CD 爆发 / 灼烧+引爆 / 冰冻控制 |

## 2. 基础属性（草案）

| 属性 | 初始值 | 成长 |
|------|--------|------|
| 生命值 | 100 | +10/级 |
| 攻击力 | 30 | +3/级 |
| 防御力 | 8 | +0.8/级 |
| 攻击速度 | 0.8 | - |
| 暴击率 | 8% | - |
| 暴击伤害 | 160% | - |
| 冷却缩减 | 5% | - |

## 3. 流派方向

### 3.1 长 CD 爆发流

| 类型 | 技能 | 效果 |
|------|------|------|
| 主动 | 陨石术 | 3 秒吟唱后造成 500% 范围伤害 |
| 被动 | 奥术积蓄 | 每 10 秒获得一层充能，主动技能伤害+15%/层 |
| 核心装备词条 | 冷却缩减、暴击伤害、元素伤害 | |
| 核心套装 | 狂风之怒（减 CD） | |

### 3.2 灼烧+引爆流

| 类型 | 技能 | 效果 |
|------|------|------|
| 主动 | 烈焰爆破 | 引爆目标所有灼烧层数，每层造成 80% 伤害 |
| 被动 | 火焰亲和 | 攻击附加灼烧，每秒造成 5% 攻击力伤害，可叠 10 层 |
| 核心装备词条 | 火焰伤害、攻速、暴击率 | |
| 核心套装 | 烈焰之心 | |

### 3.3 冰冻控制流

| 类型 | 技能 | 效果 |
|------|------|------|
| 主动 | 冰封领域 | 冻结所有敌人 3 秒，解冻时造成 120% 伤害 |
| 被动 | 寒冰之触 | 攻击减速敌人 30%，持续 2 秒 |
| 核心装备词条 | 冰霜伤害、冷却缩减 | |
| 核心套装 | 冰霜之触 | |

## 4. 专属机制

- 法师普通攻击为法术伤害，可享受元素加成
- 技能多为 AOE/控制型，适合清理多敌人场景
- 生命值较低，需要依赖控制或爆发快速清场
