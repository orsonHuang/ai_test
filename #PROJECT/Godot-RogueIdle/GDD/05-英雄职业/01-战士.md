# 英雄职业 — 战士

## 1. 基础信息

| 项目 | 内容 |
|------|------|
| 职业名 | 战士 |
| 定位 | 攻守兼备、前排、物理伤害 |
| 初始生命 | 高 |
| 初始攻击 | 中 |
| 初始防御 | 高 |
| 初始攻速 | 中 |
| 推荐流派 | 属性增幅 / 反击 / 吸血 |

## 2. 基础属性（草案）

| 属性 | 初始值 | 成长 |
|------|--------|------|
| 生命值 | 150 | +15/级 |
| 攻击力 | 20 | +2/级 |
| 防御力 | 15 | +1.5/级 |
| 攻击速度 | 1.0 | - |
| 暴击率 | 5% | - |
| 暴击伤害 | 150% | - |
| 冷却缩减 | 0% | - |

## 3. 流派方向

### 3.1 属性增幅流

| 类型 | 技能 | 效果 |
|------|------|------|
| 主动 | 战斗怒吼 | 8 秒内攻击力+40% |
| 被动 | 愈战愈勇 | 每击杀一个敌人，永久+3% 攻击力（本局） |
| 核心装备词条 | 攻击强化、攻速、暴击伤害 | |
| 核心套装 | 狂风之怒、不屈意志 | |

### 3.2 反击流

| 类型 | 技能 | 效果 |
|------|------|------|
| 主动 | 盾反 | 2 秒内格挡并反击 200% |
| 被动 | 荆棘甲 | 受击 30% 概率反击 80% |
| 核心装备词条 | 防御强化、荆棘、生命值 | |
| 核心套装 | 不屈意志 | |

### 3.3 吸血流

| 类型 | 技能 | 效果 |
|------|------|------|
| 主动 | 血之狂暴 | 6 秒内吸血率+30%、攻速+25% |
| 被动 | 嗜血 | 暴击时回复 5% 最大生命 |
| 核心装备词条 | 攻击强化、暴击率、嗜血 | |
| 核心套装 | 暗夜刺客 | |

## 4. 专属机制

- 战士拥有基础较高的生命值和防御力，容错率高
- 主动技能多为 Buff/防御型，适合自动战斗 AI 判断释放时机
