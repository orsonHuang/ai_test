# 自动回合战斗规则

状态：v1 目标；保留 MVP 回合制，替代旧稿秒制攻速与冷却。数值见 [参数表](../data/rules.csv)、[单位表](../data/units.csv)。

## 1. 输入与胜负

战前可配置主角主动/被动各1、目标优先级、技能策略、全队前中后阵位与装备。确认后锁定战斗快照。战中只有暂停、倍速、跳过动画；不允许换装、改阵、手动放技能或喝药。

每轮每个存活单位行动一次，速度只决定顺序。全体敌人倒下为胜，全体友方倒下为负；主角倒下不立即失败。一次原子伤害与其反应链结算完成后检查胜负；双方同时无存活者算败。胜后倒地成员以1生命恢复，其余保留实际生命；状态、护盾、技能冷却清除，生命跨区域延续。

最终战胜利结束本局；其他胜利回到原地区。战败结束远征；没有默认逃跑、付费复活或读档重抽。异常回合上限达到时判败，必须在战前规则和战报中可见。

## 2. 回合结算顺序

1. 回合开始，重置“每回合一次”触发计数，生成公开敌人意图。
2. 按速度降序建立行动快照。同速以固定战斗单位ID升序，界面显示最终顺序；同一存档重放一致。
3. 轮到单位时先结算灼烧，再检查死亡；死亡则跳过。
4. 存活单位处理回合开始被动（如再生），检查技能冷却与条件，选定目标、执行技能或普攻。
5. 每次伤害处理护盾、生命、允许的触发反应；死亡立即移出可选目标。一个范围攻击内按目标ID逐一结算，不在目标间重新选择敌人意图。
6. 行动结束时减少本单位已有标记的剩余行动次数；灼烧在步骤3计次。进入下一单位。
7. 全队都处理后进入下一轮。速度变化仅在下轮建队列生效，M1无额外行动机制。

目标失效时按本次战术优先级重新选择。日志显示改选原因。敌人的蓄力也占用一次行动，不额外普攻。

## 3. 数学和属性

```text
有效护甲 = max(0, 面板护甲 - 标记减甲)
直接伤害 = max(1, floor(攻击 × 技能系数 × 伤害增幅 - 有效护甲 + 0.5))
护盾吸收 = min(现有护盾, 本次伤害)
生命损失 = min(现有生命, 本次伤害 - 护盾吸收)
恢复 = min(缺失生命, floor(最大生命 × 恢复比例) 或 固定恢复值)
```

伤害增幅内的不同百分比加算，不把每个词条逐项乘起来；技能系数单独乘。属性加算完成后应用百分比，最终取最近整数（正数0.5向上）。M1无命中、闪避、暴击、元素抗性和攻击间隔；不引入没有玩法对应的属性。

| 状态 | 规则 |
|---|---|
| 护盾 | 吸收直接伤害；叠加上限为自身最大生命50%，战斗结束清零；灼烧绕过护盾和护甲 |
| 标记 | 同时降低4护甲；持续目标3次行动，在目标行动结束计次；重新施加刷新为3，不能叠层 |
| 灼烧 | 每层7伤害，上限3层；施加/刷新后在目标接下来3次行动开始结算；重新施加刷新全组计次 |
| 倒地 | 生命0，不行动、不被治疗、不触发装备；只在战后胜利恢复 |
| 冷却C | 施放后接下来C次自身行动不能施放；每次经过一格后减1，不能减到0就当次立刻释放 |

冷却2例：第1次自身行动放技能，第2、3次只能普攻，第4次再次可用。施加灼烧后敌人同轮尚未行动，便会在这次行动开始受到第一跳；UI必须显示“剩余跳数”，不能含糊显示“3秒”。

护盾先吸收不等于没受击：荆棘触发条件为主角受到敌人直接命中且结算后仍存活，护盾完全吸收也可触发。持续伤害不触发反击；反击、追击不能再次触发反击/追击或攻击附灼烧，避免无限链。

## 4. 战斗长度与反拖延

| 参数 | 目标/规则 |
|---|---|
| 普通战斗 | 常态3–5回合，目标不是保证 |
| 区域首领 | 常态4–8回合 |
| 最终战 | 常态6–10回合 |
| 压力上升 | 第9回合起，敌方攻击相对本场基础攻击每回合额外＋15%，累计；回合8提示下一回合开始 |
| 硬上限 | 30回合完成仍无结果，远征失败并注明“战线崩溃” |
| 播放 | 1/2/4倍、暂停与快速结算；均产生同样最终状态 |

敌方本场基础攻击已经包含区域和重复挑战倍率；压力上升在其后应用。没有“拖住最后一只怪无限治疗”策略；若再生和修女仍让残血队伍可低成本刷满，应调恢复或敌方压力，不额外增加一套疲劳税。

## 5. 属性成长和换装

每区首次战斗胜利，小队等级＋1，最多4级；新加入随从直接取小队等级。各级成长见 [单位表](../data/units.csv)。生命上限增加不补当前生命；换装升上限同理，降上限时当前生命截断至新上限。卸下再穿不能凭空治疗。

战斗只读取一份配置快照，结算只应用一次。存档、行动费、奖励事务见 [存档与验证](../07-技术架构/03-存档与验证.md)。
