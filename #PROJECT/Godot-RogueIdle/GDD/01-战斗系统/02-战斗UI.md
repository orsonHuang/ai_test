# 战斗体验与战报

状态：v1 目标。重要信息为“接下来谁做什么、我的配置如何生效”，不是把整份属性表铺满战场。

## 1. 战前整备

同一屏内完成：左侧敌人列表与循环预告，中间我方三人阵位，右侧主角装备和主动/被动，下方目标优先级与技能策略。默认提供坚守反击、猎风集火、余烬消耗三个预设，可以修改，不额外设计职业锁。

显示敌方本轮主要威胁和重复副本加压；使用实际属性和可解释预警，例如“后排修女会被潜袭者攻击”。不生成未经验证的胜率百分比。按下“开始，消耗2时段”才扣费。

## 2. 战中信息层级

| 层级 | 内容 | 表现 |
|---|---|---|
| 常驻 | 队伍生命/护盾、敌人生命、回合、行动条、当前意图 | 明确数值与目标指示 |
| 触发 | 反击、追击、灼烧、技能保留/释放 | 短文字＋对应单位动效；同一因果链顺序播放 |
| 深入 | 完整属性、状态来源、详细日志 | 点击或悬停查看，不遮住主要战场 |
| 控制 | 暂停、1/2/4倍、快速结算 | 不改变战斗计算，跳过前可查看战斗规则 |

主角倒地时显示“小队仍在战斗”，不要立即弹失败窗。第8轮预告敌方压力即将上涨，后续在敌人攻击详情展示倍率来源。

## 3. 结算要回答三个问题

1. **为什么赢/输？** 时间线列出第一个倒地单位、致命来源、关键首领技能。
2. **我的构筑做了什么？** 单列主动直接伤害、反击、追击、灼烧、有效治疗、实际吸收护盾；过量治疗与未消耗护盾不算贡献。
3. **下次可以改什么？** 给基于本场事实的提示，例如“后排承受了影卫攻击”，不伪造改阵就必胜的因果推断。

展示套装首次生效事件和三件套新效果，允许点击跳转到规则；完整战报可折叠。无套装结算同样正常。结算中可领取并装备新物品，战斗快照不被倒改。

## 4. 验收

相同战斗分别正常播放、4倍、直接跳过、保存恢复，应得到相同HP、掉落、金币、活动状态。玩家应能在不读开发日志的前提下指出本场一种首领机制和一种自己的应对；这项需要真人测试，截图或模拟不能替代。
