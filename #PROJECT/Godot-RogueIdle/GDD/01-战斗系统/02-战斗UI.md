# 战斗系统 — 战斗 UI

## 1. 分辨率

- **1920 × 1080**，固定横向布局
- 窗口模式：全屏 / 窗口化可选，默认窗口化 1920×1080
- 目标帧率：60 FPS

## 2. 整体结构

左侧玩家信息栏 + 中部我方角色区 + 右侧敌方区域（类似杀戮尖塔的左右对峙布局）。

## 3. 区域宽度分配（1920px 基准）

| 区域 | 宽度 | 说明 |
|------|------|------|
| 玩家信息栏 | ~300px | 头像、HP、装备槽、属性区、词条效果 |
| 我方角色区 | ~560px | 主角 + 召唤物，居中偏左站立 |
| VS 分隔线 | ~100px | 视觉分隔，可展示技能释放特效 |
| 敌方区域 | ~560px | 最多 4 个敌人，阶梯式排列 |
| 剩余边距 | ~400px | 左右留白 |

## 4. 布局要点

- **左侧玩家信息栏**（~300px）：头像、职业名、HP 条、装备槽位网格、属性区（可上下滑动）、装备词条效果区
- **我方角色区**（中部偏左）：主角大尺寸站立 + 最多 2 个召唤位，面向右侧敌人。召唤物使用紧凑型小血条
- **敌方区域**（右侧）：最多 4 个敌人，按前后排阶梯排列（参考杀戮尖塔敌人布局），面向左侧我方
- **VS 分隔线**：我方与敌方之间的视觉分界，可展示技能释放特效、伤害数字飘动
- **属性区支持上下滑动**：上方展示基础属性，下滑可见更多属性和装备词条效果汇总
- **装备词条效果区**：同名词条数值自动合并（如"攻击力+15% (×2)"），套装词条[生效]绿色高亮、[未生效]灰色
- **顶部功能条**：关卡信息、通用/技能/ACTION 信息展示、倍速按钮（X1/X2）、货币、设置
- **底部 Tab 切换**：基础信息 | 装备信息 | 词条详情 | 整体属性
- 战内无主动技能释放按钮，无一次性道具手动使用入口
