# 数值起点与验证方法

状态：v1 初始假设，**未进行新版战斗模拟或真人平衡验证**。本轮只检查文档、数据和规则一致性；MVP 的90局可达性测试不能推导新版通关率。

## 1. 表与公式

参数见 [rules.csv](../data/rules.csv)、[units.csv](../data/units.csv)、[equipment.csv](../data/equipment.csv)。单位成长：基础＋每级成长×(等级−1)；护甲另用 floor((等级−1)/2)。敌人不升级，只应用区域生命/攻击倍率与副本加压；魔王及影卫使用独立最终战数值。

| 手算情境 | 输入 | 期望 |
|---|---|---|
| 普攻 | 攻击24，系数1，护甲5 | 19 |
| 爆发 | 攻击24，系数1.85，护甲5 | 39 |
| 标记后的猎风2件普攻 | 攻击24，系数1，增幅1.30，原护甲5，标记减4 | 30 |
| 护盾 | 19直接伤害，护盾12 | 护盾归0，生命损失7 |
| 灼烧 | 3层、护盾100、护甲20 | 21真实伤害，护盾不变 |
| 营地 | 最大生命160，当前35 | 恢复80，变为115 |
| 区域二第2次荆棘副本 | 基础HP240/攻击21；区域1.25/1.15；加压1.15/1.10 | HP345，攻击27（最终一次四舍五入） |

不同来源的属性百分比按 [战斗规则](01-战斗规则.md) 处理。敌方区域倍率、重复挑战倍率是独立难度系数相乘；不能把玩家的词条加算规则误套到难度档位。

## 2. 必做边界

- 相同速度、倒地跳过、目标失效、双方同时倒下、主角倒地同伴获胜。
- 冷却2在自身第1/4/7次行动可用；灼烧恰好3跳；新标记刷新不重复减甲。
- 反击/追击不得递归；每轮上限正确；完全被盾吸收仍可反击，致死命中不能反击。
- 主角再生先于本次攻击但晚于灼烧；灼烧致死不能先治疗救回。
- 三级加压、9轮压力和30轮失败都明确记录；快进和跳过不改变结果。
- 升级、换装、招募不会绕过生命资源；重复副本不再升级。

## 3. 对比实验，而不是只跑“所有构筑都通关”

| 假设 | 对照方法 | 初步观察标准，非统计证明 |
|---|---|---|
| 2件套足以影响打法 | 同等级同属性，关闭/开启套装效果 | 战报出现对应效果；至少改变承伤或击杀节奏 |
| 3件并非所有情况下唯一正确 | 2件＋高阶散件 vs 3件；固定三个首领情境 | 存在可解释的各自优势；若全部被3件支配，先调效果/散件 |
| 修女不是强制位 | 卫士＋游侠 vs 含修女队伍；同种子、相近花费 | 无修女队伍有多条可通关路线，而非仅极端装备 |
| 重复挑战仍值得 | 第2/3刷与休整/事件机会成本对比 | 至少部分局面愿意第3刷，部分局面明确放弃 |
| 路线不锁单一流派 | 三预设 × 各可达路线 × 多种活动种子 | 无因生成导致必败或无法成型的组合承诺 |
| 目标和技能策略有用 | 同装备换目标/释放策略 | 改变首个击杀对象或关键技能覆盖，不要求每次都更强 |

先保留确定性战斗和种子回放，发现异常能重现。工具模拟验证可达性、无限循环和资源上限；真人验证理解、动机、压力和重复兴趣，两类结果分别记录。
