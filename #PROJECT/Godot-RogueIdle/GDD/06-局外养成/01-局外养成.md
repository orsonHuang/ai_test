# 局外养成（Meta-Progression）

## 1. 职业技能解锁

- 每个职业初始 3-4 个技能可使用
- 通过局数累计 / 特定成就解锁新技能，最终池为 8-10 个

### 1.1 解锁方式示例

| 条件 | 解锁内容 |
|------|----------|
| 用战士通关一次 | 解锁反击流被动「荆棘甲」 |
| 用法师累计造成 10000 点火焰伤害 | 解锁灼烧主动技「烈焰爆破」 |
| 击败第 3 层 BOSS | 解锁战士吸血主动技「血之狂暴」 |
| 单局累计反击 50 次 | 解锁战士主动「盾反」 |

## 2. 职业解锁

- 首发：战士、法师
- 后续 4 个职业（骑士/射手/刺客/道士）由玩家自由选择解锁顺序
- 解锁条件：使用已拥有职业累计通关 N 次 / 消耗局内获取的"灵魂货币"

### 2.1 职业解锁消耗（草案）

| 职业 | 解锁消耗 |
|------|----------|
| 骑士 | 灵魂货币 × 500 或 战士通关 3 次 |
| 射手 | 灵魂货币 × 500 或 法师通关 3 次 |
| 刺客 | 灵魂货币 × 800 或 任意职业通关 5 次 |
| 道士 | 灵魂货币 × 1000 或 完成召唤相关成就 |

## 3. 局外永久升级（可选扩展）

考虑加入类似 Hades 镜子的"全局天赋树"，所有职业共享。

### 3.1 天赋方向示例

| 天赋 | 效果 |
|------|------|
| 初始金币 +50 | 每局开始时额外获得 50 金币 |
| 初始生命 +10% | 每局开始时最大生命值 +10% |
| 装备掉落品质提升 | 良品/上品掉落概率小幅提升 |
| 强化石携带上限 +1 | 每局可额外携带 1 颗强化石 |
| 复活一次 | 每局首次死亡时回复 30% 生命并继续 |

## 4. 灵魂货币

- 通过每局战斗、通关、成就获得
- 用于职业解锁、天赋升级、商店刷新（可选）
- 局外永久保留
