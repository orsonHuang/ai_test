# 技能与效果原子

状态：v1 目标。所有持续时间采用回合/自身行动/跳数；界面播放秒数只属于表现配置。

## 1. 技能规则

主角携带主动1＋被动1，村庄全部初始技能开放，战外免费调整。自动战斗里的“主动”指有冷却的自动释放技能，不表示手动操作。随从各有一个固定技能和普通攻击，先以身份产生差异。

技能配置包含：ID、目标选择、效果列表、冷却自身行动数、释放条件、回退普攻、说明文本。冷却、状态层数、触发次数写在战斗运行态，不写回共享 Resource。

## 2. M1 仅实现需要的原子

| 原子 | 核心参数 | 边界 |
|---|---|---|
| damage | 系数、目标集合、来源标签 | 普攻/主动/反击/追击/持续伤害必须区分 |
| shield | 固定值、目标 | 上限规则统一；记录实际吸收而不是全部授予值 |
| heal | 固定值或最大生命比例 | 不复活、不过量计入统计 |
| apply_mark | 减甲、目标剩余行动数 | 同名刷新，不叠减甲 |
| apply_burn | 加层数、最大层数、剩余跳数 | 本版只有主角和敌人施加；记录归属 |
| modify_stat | 属性、固定值/比例、持续范围 | 装备/被动持续至换装或本场结束，事件只定义明确的下一战 |
| triggered_effect | 触发事件、来源过滤、每轮次数 | 条件在配置中可读；反应不能自行递归 |

不预先开发通用编程语言或任意脚本表达式编辑器。先满足当前三套装、三主动、三被动与三随从；新机制必须说明复用哪些原子和新增测试。

## 3. 触发时序

直接攻击 → 伤害与倒地 → 若主角仍存活则处理其受击反击 → 主角普通/主动攻击命中时处理套装追击或附灼烧 → 检查胜负。范围攻击是同一技能中的多个目标事件，套装“每轮一次”仍只触发一次。

灼烧按“施加阵营＋来源单位”保存；同阵营在同一目标上的层数合并，M1友方施加者仅主角。敌人各自的灼烧来源记录可合并伤害但须保留战报归属。余烬治疗只认主角施加的灼烧，且主角活着才触发。

完整公式、冷却例子和死亡优先级见 [战斗规则](../01-战斗系统/01-战斗规则.md)，具体技能见 [配置](02-技能与战术配置.md)。
