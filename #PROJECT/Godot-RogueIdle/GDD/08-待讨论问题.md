## 2. 真人试玩方案

先邀请5–8名符合目标画像的新玩家做定性测试，再至少记录20局完整过程看趋势。小样本只定位问题，不宣称代表市场或具有统计显著性。使用本地记录和观察即可，不需要提前接入云分析服务。

| 问题 | 记录 | 暂定通过线/行动 |
|---|---|---|
| 是否理解预算 | 第一区离开前能否解释副本和休整的取舍 | 至少4/5无需提示说清；否则改UI/引导 |
| 是否为构筑规划路线 | 首次看掉落、第一次两件套时间、选择路径理由 | 多数主动提到目标装备；否则改情报/奖励 |
| 是否有不同可行计划 | 副本/休整/活动支出、第三次刷取比例 | 不出现所有人同一固定支出；若出现查是否严格支配 |
| 修女是否必选 | 同水平含修女/无修女的承伤、休整与结果 | 无修女有稳定可达路线；否则先调护盾/敌压 |
| 战斗是否可解释 | 结算后问第一位倒地原因和可改一项配置 | 至少4/5能描述事实与合理应对 |
| 成型是否过早结束乐趣 | 两件/三件后还有哪些决策 | 第二区后仍有阵位/装备/路线取舍 |
| 时长与重玩 | 阅读、决策、动画分别用时；愿意再试的理由 | 熟悉后15–25分钟目标；若只想跳过等待，压缩表现 |
| 是否有商业内容基础 | 同一玩家连续3局后的兴趣和重复抱怨 | 决定内容扩展方向，不凭一次通关判断可售 |

## 3. 停止扩内容的条件

若玩家无法区分路线价值、每区只想无脑三刷、三套装打法相同，暂停做新职业/美术量产，修核心。若试玩者理解且愿意主动尝试第二种队伍，再进入M2。

关键风险：
- 固定地理很快被解出：用活动/敌人组合验证重玩性，不立即做无限随机地图。
- 加压使第三刷不值得：先降低倍率，保留明确告知。
- 护盾/治疗拖延获利：检查9轮压力、实际治疗量和战斗长度。
- 余烬中段成型被误读成弱开局：改善情报，必要时改副本分布。
- 三槽毕业太快：先测试两件＋散件、随从与战术，不回到九槽堆管理量。
