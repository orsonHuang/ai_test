# Godot-RogueIdle · GDD v1.0 设计基线

更新：2026-10-05。本文是新版设计入口；“v1.0”指文档版本，不代表游戏已经达到正式版。

**一句话定位：带着三人小队，在有限远征时段内选路刷装，构筑队伍并攻破魔王城。**

## 状态与阅读顺序

| 标记 | 含义 |
|---|---|
| 用户确认 | Godot / Steam、回合制 Idle、主角＋最多两随从、向前相邻选区、迷雾、区域行动预算、副本套装、预先可见的首领情报 |
| MVP 已实现 | 以 [HTML 规则](../html-mvp/README.md)和原型代码为准 |
| v1 目标 | 本轮整合后的默认开发设计，包含新的改进建议；尚未实现和验证的数值不得称为平衡结论 |
| 后续候选 | 不进入当前制作排期，满足验证条件后再评估 |

除明确说明为历史或 MVP 的段落外，本目录规则均属于 **v1 目标**。所有数值是首轮调参起点。用户的新决定优先；项目编辑与 Godot 可视化交付遵循 [AGENTS.md](../AGENTS.md)。

3. [主角与随从](05-英雄职业/01-主角与随从.md)、[技能与战术](04-技能系统/02-技能与战术配置.md)：战前策略。
