# 装备与定向掉落

状态：v1 目标。继承 MVP 三槽与套装保底；替代九槽、六稀有度和强化材料经济。

## 1. 装备结构

主角仅武器、护甲、护符三槽；随从不穿装备。初始无装备，基础属性保证首区可以开始。背包M1不设容量博弈、不出售装备，局末清空；界面可按套装/部位/获得顺序筛选。

| 维度 | 规则 |
|---|---|
| 部位 | 每件固定一种，只能占一个槽 |
| 区域档次 | 1/2/3；影响基础属性，不改变套装机制 |
| 品质 | 普通、精良；精良基础属性乘1.15，正数四舍五入 |
| 词条 | 每件恰好1条：坚韧/锋利/迅捷等权抽取 |
| 套装身份 | 模板固定 set_id；不是随机额外套装词条 |
| 独立实例 | instance_id、模板ID、档次、品质、词条、获得来源持久化 |

对应数值以 [equipment.csv](../data/equipment.csv)、[affixes.csv](../data/affixes.csv) 为准。属性没有隐式职业系数；不要仅用“更高级”覆盖套装阈值判断。

## 2. 副本掉落保护

每次区域首领胜利必得所属套装1件，区域档次随当前地区。普通70%、精良30%；三个词条等权。魔王仅做通关结算与图鉴记录，不给本局已结束后无用途的装备操作。

部位优先从**本局该套装从未获得的部位**等权抽取；三部位全获得后，三个部位等权。取得即写入获得账本，穿戴、卸下、以后可能加入的出售/分解都不能清空账本。

同套装前三次副本掉落覆盖三槽，跨地区累计。保底只保障部位，不保证品质和词条。两次首领耗4时段便可获得两件效果；第三次收益是完整套装，代价是另2时段及生命风险。拒绝或收进背包也视为已经获得，不能取消领奖刷部位。

## 3. 非副本产出

| 来源 | 结果 |
|---|---|
| 宝箱 | 当前档次普通散件1件＋15金币，部位等权 |
| 行商 | 当前档次精良散件1件，预先可见部位与词条；30金币＋1时段，与补给互斥 |
| 事件 | 只按事件表发明示物品，默认不发套装 |
| 巡游敌人 | 12金币；不掉装备 |
| 起始/升级 | 不赠送装备 |

宝箱散件固定普通，副本外精良主要来自付费行商/指定事件，避免随机箱子淹没首领定位。所有奖励在事务内确定，刷新或选择“稍后装备”不重抽。

## 4. 两件与三件之间的选择

M1先通过区域档次差异测试“两件＋高阶散件”的价值。M2再加入三种明确散件特效：
- 斩将武器：对生命低于50%的目标，主角普通/主动直接伤害＋20%。
- 护心护甲：战斗开始自身获得30护盾。
- 共鸣护符：主角施放主动后给最低生命比例存活友方恢复10生命，每轮最多一次。

M2特效替代该件随机词条，不与词条多层叠加；只通过对应行商/事件模板产出。如果M1三件过强，先调三件效果，不依赖新增散件补救。

## 5. 明确移除

M1/M2无强化、重铸、宝石、耐久、装备等级经验、六色稀有度。金币用于区域事件和行商取舍；新玩法没有缺口前不增加强化石、重铸石或局外灵魂货币。旧稿详情仅留在归档。
