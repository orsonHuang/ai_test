# 词条与属性边界

状态：v1 目标。[affixes.csv](../data/affixes.csv) 是M1完整词条表。

每件普通或精良装备各带1条词条。三个词条可作用于全部三部位，等权抽取，不再抽上下限。坚韧＋10最大生命，锋利＋2攻击，迅捷＋2速度；不同装备同名词条相加。精良品质只放大基础属性，不放大词条或套装效果。

迅捷影响标记、护盾和攻击顺序，不额外增加行动次数。装备对比须显示队伍速度排序变化，不默认速度提升总是好事。

不加入暴击率、冷却缩减、闪避、移速、召唤伤害等当前规则不支持的属性。每新增词条，必须回答：改变什么决策、如何观察、如何叠加、是否引入触发循环。

文本由配置生成，显示基础、装备、被动和最终属性。HP上限变化不补血。M2机制散件替代该件随机词条，见 [装备基础](01-装备基础.md)。
