# 美术、音频与交互体验方向

状态：v1 建议，尚未最终美术定稿；先做可读的垂直切片，再决定资产预算。

## 1. 视觉方向

采用绘本式奇幻区域地图＋清晰的单位卡/小幅角色动画。地图是“想去冒险”的主要展示面；战斗表达强调阵位、目标、意图和构筑触发。原型SVG仅用于验证，不等于正式角色资产规格。

背景低对比，当前区域/可前进方向突出；荆棘、猎风、余烬用轮廓/图标＋色彩双重编码。迷雾像地图上未调查的纸面区域，不把已知首领图标一起盖掉。套装首次激活有一次短反馈，重复掉落缩短动画。

## 2. M1最小资产预算

| 类型 | 数量目标 | 复用策略 |
|---|---:|---|
| 主角/随从 | 1＋3 | 通用待机、攻击、受击、倒地表现，先用位移与特效辅助 |
| 普通敌人 | 3 | 与影卫共用基础动画，影卫有辨识外观 |
| 首领 | 3家族＋1魔王 | 区域名字可复用家族资产，不重复制作七整套 |
| 地图 | 1张、9分区 | 每区可编辑图形与标志，统一迷雾和通路材质 |
| 装备图标 | 12基础模板 | 3套×3槽＋3散件，品质用外框表达 |
| 技能/状态 | 6主角技能图标＋核心状态 | 反击/追击/燃烧独立可识别反馈 |
| 界面 | 地图、整备、战斗、活动、结算 | 共享Theme、按钮与卡片 |
| 音频 | 地图/普通战/首领战3段循环；约12类短音效 | 控制同时播放数量，倍速不堆叠尖锐音效 |

占位阶段不需要逐帧精细动作。先保证三个构筑能从视觉上分辨，再扩动画数量。参考图和素材原件留在原目录，实际采用的资产记录来源与许可，不把“素材包存在”视为已可商用。

## 3. 显示与操作目标

| 项目 | 目标 |
|---|---|
| 设计参考 | 1600×900逻辑画布 |
| 最低验收窗口 | 1280×720，文字/按钮不遮挡，不依赖强制全屏 |
| 高分屏 | 1920×1080及缩放检查；UI文字用动态字体 |
| 性能 | 普通开发PC目标60FPS；M1建立基线机器与指标，未测前不承诺最低配置 |
| 文本 | 简体中文优先；用文本ID便于英文扩展，不把文字烘进图 |
| 设置 | 主音量/音乐/音效、字号档位、减少闪烁/震屏、倍速记忆 |

界面主题支持不同文字长度；不为HTML的手机窄屏兼容承诺正式移动版。安装包和内存上限待首批资产导入后测量再冻结，初期避免引入大型3D场景与高清视频。

## 4. 感官反馈的优先级

必须：行动已扣费、套装激活、下一步可去哪里、首领重击意图、护盾吸收、倒地与胜败。

其次：揭雾、装备品质、反击/追击/灼烧的差异声画。

后续：复杂镜头、长演出、全程配音。长掉落动画不能遮挡玩家比较装备；跳过表现仍保留结果和战报入口。
