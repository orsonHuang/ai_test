# 技术架构（Godot 引擎）

## 1. 项目基础配置

| 配置项 | 值 | 说明 |
|--------|-----|------|
| 分辨率 | 1920 × 1080 | 固定横向，不自动缩放 |
| 窗口模式 | 全屏 / 窗口化可选 | 默认窗口化 1920×1080 |
| 渲染引擎 | Godot 4.x Compatible | 2D 为主（像素/手绘风格） |
| 目标帧率 | 60 FPS | 战斗动画流畅 |

## 3. 数据驱动设计

所有装备、词条、套装、效果原子、技能、敌人使用 Godot 的 `.tres` 资源文件定义。

### 3.1 核心 Resource 类

| 类名 | 职责 | 所在目录 |
|------|------|----------|
| EffectResource | 定义效果原子 | Resources/Effects/ |
| SkillResource | 定义技能，引用 EffectResource | Resources/Skills/ |
| AffixResource | 定义词条，引用 EffectResource | Resources/Affixes/ |
| SetResource | 定义套装，引用 EffectResource | Resources/Sets/ |
| EquipmentResource | 定义装备基础，引用 AffixResource | Resources/Equipment/ |
| ClassResource | 定义职业基础属性 | Resources/Classes/ |

### 3.2 配置表工作流

1. 策划在 `Resources/Effects/` 中定义所有效果原子
2. 在 `Resources/Affixes/` 中定义词条，引用效果原子
3. 在 `Resources/Sets/` 中定义套装，引用效果原子
4. 在 `Resources/Skills/` 中定义技能，引用效果原子
5. 在 `Resources/Equipment/` 中定义装备，引用可能出现的词条
6. DataManager 运行时加载所有 .tres 文件
7. 掉落/强化/重铸时，按配置表规则生成 EquipmentInstance
