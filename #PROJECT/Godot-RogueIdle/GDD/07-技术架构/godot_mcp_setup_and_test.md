## 5. MCP 使用指南

### 5.1 场景创建命令示例
```
请帮我创建一个名为 Battle.tscn 的场景，包含以下节点：
- Control (根节点)
- VBoxContainer (UI容器)
- HBoxContainer (战斗区域)
- TextureProgressBar (玩家血条)
- TextureProgressBar (敌人血条)
- Label (伤害数字预制体)
```

### 5.2 脚本创建命令示例
```
请帮我创建 BattleManager.gd 脚本，实现 turn-based 战斗逻辑，包括：
- 行动队列管理
- 战斗单位管理
- 战斗状态管理
- 战斗结果判定
```

### 5.3 资源配置命令示例
```
请帮我创建玩家和敌人的基础属性资源，使用 .tres 文件格式，包含 HP、Attack、Defense、Speed 属性
```

## 6. 故障排除

### 6.1 MCP 连接问题
- 如果无法连接 MCP 服务，请检查：
  1. Godot 编辑器是否正在运行
  2. MCP 插件是否已启用
  3. 网络连接是否正常

### 6.2 代码生成问题
- 如果生成的代码不符合预期：
  1. 检查提示的明确性
  2. 提供更详细的代码结构要求
  3. 分步请求复杂功能

### 6.3 项目运行问题
- 如果项目无法正常运行：
  1. 检查场景结构是否正确
  2. 验证脚本路径是否正确
  3. 确认资源引用是否有效
