# 地图生成算法

> 版本：v1.0（原型阶段）  
> 对应阶段：原型阶段 → Demo 阶段

---

## 1. 生成目标

### 1.1 设计原则
- **线性推进感**：玩家从左向右推进，有明确的进度感
- **路线选择**：提供 2-3 条可选路径，增加策略性
- **难度递增**：越靠右的节点敌人越强
- **必达终点**：确保玩家能到达 BOSS 节点

### 1.2 原型阶段地图规格

```yaml
单层地图:
  节点总数: 6-8个
  列数: 4列（从左到右推进）
  起始列: 1个节点（起点）
  中间列: 2-3列，每列1-2个节点
  终点列: 1个节点（BOSS）
  
节点类型分布:
  普通战斗: 3-4个
  精英战斗: 1个
  BOSS: 1个
  商店: 0-1个
  篝火: 1个
  
路线规则:
  每个节点必须有至少1个入边（起点除外）
  每个节点必须有至少1个出边（BOSS除外）
  不允许回头边（只能从左向右）
```

---

## 2. 生成算法详解

### 2.1 算法流程

```
Step 1: 初始化网格
  - 创建 4 列的网格结构
  - 第0列：1个节点（起点）
  - 第1-2列：随机1-2个节点
  - 第3列：1个节点（BOSS）

Step 2: 分配节点类型
  - 起点：固定为普通战斗（教学战）
  - 终点：固定为 BOSS
  - 中间列：按权重随机分配类型

Step 3: 生成连接边
  - 确保每个中间节点有入边和出边
  - 允许跨列连接（如第0列→第2列）
  - 避免边交叉（简化版可允许）

Step 4: 验证连通性
  - 确保起点可达 BOSS
  - 确保无孤立节点
```

### 2.2 伪代码实现

```gdscript
class_name MapGenerator

const COLUMNS = 4
const NODE_TYPES = {
    "normal": {"weight": 60, "max_per_map": 4},
    "elite": {"weight": 15, "max_per_map": 1},
    "shop": {"weight": 10, "max_per_map": 1},
    "campfire": {"weight": 15, "max_per_map": 1}
}

func generate_map() -> MapData:
    var map_data = MapData.new()
    
    # Step 1: 创建节点网格
    var grid = create_grid()
    
    # Step 2: 分配节点类型
    assign_node_types(grid)
    
    # Step 3: 生成连接
    generate_connections(grid)
    
    # Step 4: 验证并修复
    validate_and_fix(grid)
    
    map_data.nodes = flatten_grid(grid)
    return map_data

func create_grid() -> Array[Array]:
    var grid = []
    
    # 第0列：起点
    grid.append([create_node(0, 0, "start")])
    
    # 第1-2列：中间节点（随机1-2个）
    for col in range(1, COLUMNS - 1):
        var node_count = randi() % 2 + 1  # 1或2个
        var column_nodes = []
        for row in range(node_count):
            column_nodes.append(create_node(col, row, "unset"))
        grid.append(column_nodes)
    
    # 最后一列：BOSS
    grid.append([create_node(COLUMNS - 1, 0, "boss")])
    
    return grid

func assign_node_types(grid: Array[Array]):
    var available_types = ["normal", "normal", "normal", "elite", "shop", "campfire"]
    
    # 打乱并分配给中间节点
    available_types.shuffle()
    var type_index = 0
    
    for col in range(1, COLUMNS - 1):
        for node in grid[col]:
            if type_index < available_types.size():
                node.type = available_types[type_index]
                type_index += 1
            else:
                node.type = "normal"  # 默认填充

func generate_connections(grid: Array[Array]):
    for col in range(COLUMNS - 1):
        for from_node in grid[col]:
            # 连接到下一列的节点
            var next_col = col + 1
            var next_nodes = grid[next_col]
            
            # 至少连接1个
            var target = next_nodes[randi() % next_nodes.size()]
            from_node.connections.append(target)
            
            # 50%概率连接第2个（如果有）
            if next_nodes.size() > 1 and randf() > 0.5:
                var target2 = next_nodes[1 - next_nodes.find(target)]
                if not from_node.connections.has(target2):
                    from_node.connections.append(target2)
```

class_name MapNode
extends Resource

@export var node_id: String
@export var node_type: int  # 见 NodeType 枚举
@export var position: Vector2  # 在地图上的坐标（列, 行）

## 4. 难度曲线控制

### 4.1 敌人强度与节点位置关联

```gdscript
func get_enemy_multiplier(node_column: int, total_columns: int) -> float:
    # 线性递增：从 1.0 到 1.5
    var progress = float(node_column) / float(total_columns - 1)
    return 1.0 + progress * 0.5

# 应用示例：
# 第0列（起点）：×1.0
# 第1列：×1.17
# 第2列：×1.33
# 第3列（BOSS）：×1.5
```

### 4.2 掉落质量与节点类型关联

| 节点类型 | 装备稀有度加成 | 金币加成 |
|----------|----------------|----------|
| 普通战斗 | 基准 | 基准 |
| 精英战斗 | +1级 | ×1.5 |
| BOSS | +2级 | ×3.0 |
| 商店 | 固定价格 | - |
