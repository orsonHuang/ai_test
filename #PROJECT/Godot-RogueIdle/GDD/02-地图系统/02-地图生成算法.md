# 地图生成与揭雾

状态：v1 目标。M1 固定地理、随机区域内容；先把路线读懂，不做任意多边形生成算法。

## 1. 三种关系必须分开

| 字段 | 用途 | 规则 |
|---|---|---|
| polygon_points / label_anchor | 多边形绘制和标签布局 | 在资源中可编辑，绘制不改变通行关系 |
| adjacent_ids | 揭雾的物理邻接 | 互相对称；同层可邻接；只有接触点不自动算邻接 |
| next_ids | 可以前往的方向 | 必须同时物理相邻且推进层级＋1；无环 |

[regions.csv](../data/regions.csv) 给出 M1 的全部节点、邻接、通路、地标与内容家族。九块地图可以有七个地区名字，但只需三套副本行为资产，不能把同一机制换名字算成七种机制。

## 2. 可见性状态

1. **迷雾**：轮廓、公共通路存在；如果是初始地标，额外显示首领/掉落信息。
2. **已揭示**：区域活动类型、首领及候选情报可查看；不代表可移动。
3. **当前位置**：可消费本区活动。
4. **已离开**：保留看过的信息，所有行动不可用。
5. **被放弃分支**：仍可查看已知内容，但从当前位置不可达；明确灰显。

进入村庄或探索区时，只揭示自身与 adjacent_ids 中直接邻居。新揭示的邻居不会继续揭邻居。进入一个区不会消耗它邻居的预算，预算只在真正入区时初始化。

## 3. 内容生成步骤

```text
开局：
  校验地图模板 → 固定首领及公开地标 → 建立各区独立随机子种子
首次揭示区域：
  如果已生成则返回既有结果
  固定副本与营地
  抽3种可选活动（首区强制招募）
  按区域标签选择事件、敌人、两名候选与行商商品
  生成活动ID与内容快照 → 保存 → 标为已揭示
进入区域：
  校验当前位置的 next_ids → 封存上一区 → AP置6 → 揭示直接邻居
```

随机通道分开：区域活动、事件结果、装备掉落、表现特效。看菜单、播放动画、选择倍速不得推进玩法随机数。装备在战斗开始的事务中锁定奖励种子，在胜利后生成/展示唯一奖励。

事件同一局优先不重复；池耗尽时允许重复并保留状态独立，不能无限重抽卡死。M1六事件全区域可用；M2主题事件通过标签进入池；无合法候选退回通用事件。

## 4. 不可违反的校验

- 所有探索区 AP=6，村庄/城堡AP=0；每条终点路径均经过3探索区。
- 所有探索区有至少一个前进出口；任何选项都能到达城堡。
- next_ids 全在 adjacent_ids 中，邻接对称；区域ID和活动ID唯一。
- 首区必有招募；各区恰好2固定＋3可选活动，无重复类别。
- 起始地标包括至少一种可在前两区到达的目标套装；现版荆棘/猎风从首区可刷，余烬从第二区可刷。
- 余烬开局依靠引火术工作，明确属于中段成型；不宣传每个流派首区都能拿两件套。
- 生成失败使用已验证的固定模板并记录种子与错误，不能静默丢区或断路。

## 5. 后续扩展的准入

只有连续重复游玩表明“路线已经没有选择”时，才增加第二张同规模地图模板、改变副本分布或区域主题权重。先复用合法拓扑，不做随机连线后大量修补。任何新增模板必须重新通过路径和掉落可达性验证。
