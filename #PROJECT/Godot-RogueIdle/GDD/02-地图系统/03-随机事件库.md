# 随机事件库：让资源改变计划

状态：v1 目标。M1实现前6个；M2扩展至12个。清单见 [events.csv](../data/events.csv)。

## 1. 统一规则

标题与选项代价可预览；确认进入花1时段。两分支选一，不额外耗时。金币为分支增减，HP费用必须保留至少1生命，否则禁用；始终有无需金币/生命的分支。

事件不随机判成功/失败、不增加时段、不赠套装、不触发额外战斗。先验证确定取舍是否有趣。后续概率选项须显示概率、最坏结果与保护条件。

下一战修正槽最多1个，后取得的替换旧修正，替换前明示；可改选另一分支。仅在下一场真实开始的战斗消耗，预览不消耗。敌方修正作用该场全体敌人，与区域倍率相乘；主角攻击修正归入玩家属性百分比加算。恢复按最大生命比例向下取整。

## 4. 数据和验收

events.csv的 outcome 为受限命令：party_heal_pct、hero_heal_pct、gold、hero_hp_cost、gear_choice_fine、gear_random_normal、next_hero_atk_pct、next_enemy_hp_pct、next_enemy_atk_pct、next_hero_shield、next_enemy_armor_flat。分号分隔、冒号后是参数，百分比按0–100表示，不是可执行脚本。

每事件必须验证：条件不足有原因；保守分支可完成；双击只发一次；不合法分支不扣金币/生命，已支付的入场时段不退，仍可选择合法分支完成；读档保留候选；装备档次正确；替换修正可理解。不能只验“文本显示了”。
