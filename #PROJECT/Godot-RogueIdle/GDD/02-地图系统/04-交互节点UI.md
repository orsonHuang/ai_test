# 区域交互与完整操作流程

状态：v1 目标。视图入口遵循“世界地图 → 区域面板 → 活动预览 → 确认执行 → 结算 → 整备”。

## 1. 地图与区域主屏

顶部持续展示：当前位置、推进阶段、剩余时段、金币、存档状态。中央保留不规则区域地图，当前区描边；可去区用方向箭头；已知但不可去的区明确灰显。右侧为当前区活动卡，底部为三人状态与整备入口。

点击任何地块只预览，不立即移动。移动卡显示“进入后不能返回；剩余X时段将放弃”，有剩余时段时确认一次，零时段无需多余警告。不会因为鼠标掠过地图而扣费或存新状态。

副本卡同时显示：时段成本、首领意图概览、套装2/3件效果、已获部位、下一件保底范围、当前重复挑战加压。不要只显示一个不可解释的“战力建议”。

## 2. 统一事务

| 阶段 | 可取消 | 扣费/存档 |
|---|---|---|
| 浏览活动 | 是 | 不扣费 |
| 选择具体方案 | 是 | 不扣费 |
| 确认合法行动 | 否 | 原子写入扣费、活动ID、锁定结果或种子 |
| 播放/选择已进入事件的分支 | 可关闭后恢复，不可退费重抽 | 进度持久化；未完成时禁止移动和开启别的活动 |
| 领取结果 | 完成后返回区域 | 唯一结果ID，只可应用一次 |

普通事件可以先看事件标题和两条分支的条件、代价；确认进入消耗1时段，再选其中一条。保守分支一定合法。关闭事件只暂存，不把已经付费的事件变成免费情报反复重抽。

## 3. 特殊活动

- **招募**：先看候选，再选替换对象（如满员），最后确认1时段。旧成员离队不可回购；新成员使用当前小队等级，入队生命比例取全队当前最低生命比例，至少1生命。招募用来改变功能，避免变成免费满血包。
- **休整**：显示每人“当前 → 恢复后”生命，确认才花时段；全员满血时禁用。
- **行商**：一次交易二选一，花1时段加明示金币；不能先扣入场费再发现无钱。补给全满时不可买，装备可正常购买。
- **宝箱**：直接确认开箱，然后有“装备/收入背包”按钮；装备并不消耗另一时段。
- **结算装备**：新旧基础属性、有效属性差、套装阈值变化并排显示。若会失去两/三件效果，显示具体效果，不用数值总分代替判断。

## 4. 引导与无障碍

首局四个短提示：看目的地掉落、认识6格预算、预览两件套、看敌方意图。只有首次遇见机制时出现，能关闭/回看；不锁定用户去唯一正确路线。

状态同时用文字、图标与颜色表达。关键按钮键鼠可达，中文长文本不截核心代价。返回关闭预览，不能撤销已执行行动；快捷键不得在弹窗背后触发移动。

具体分辨率与资产标准见 [美术音频](../09-美术音频与体验.md)，存档边界见 [持久化验收](../07-技术架构/03-存档与验证.md)。
