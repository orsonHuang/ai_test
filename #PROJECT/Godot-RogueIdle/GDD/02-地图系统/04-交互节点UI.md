# 交互节点 UI 设计

> 版本：v1.0  
> 包含：商店、篝火、事件的界面流程与交互设计

---

## 1. 通用设计原则

### 1.1 界面风格
- **沉浸式**：不离开地图场景，使用弹窗/面板形式
- **简洁高效**：核心信息突出，操作步骤 ≤ 3 步
- **视觉反馈**：操作后有明确的确认动画
- **一键返回**：随时可关闭界面回到地图

### 1.2 交互模式

```
地图节点 → 点击 → 节点详情弹窗 → 选择行动 → 执行 → 返回地图
                    ↓
              可直接关闭返回
```

### 2.4 商品生成规则

```gdscript
func generate_shop_items(layer: int, shop_type: int) -> Array[ShopItem]:
    var items = []
    
    # 装备生成
    var equipment_count = 3 if shop_type == 0 else 5
    for i in range(equipment_count):
        var rarity = calculate_shop_rarity(layer)
        var equipment = EquipmentGenerator.generate(rarity)
        equipment.price = calculate_price(equipment, layer)
        items.append(equipment)
    
    # 材料生成
    items.append(create_material_item("强化石", 30, layer))
    items.append(create_material_item("重铸石", 50, layer))
    
    return items

func calculate_shop_rarity(layer: int) -> int:
    var roll = randf()
    match layer:
        1: # 第1层
            if roll < 0.5: return 1  # 良品
            if roll < 0.9: return 2  # 上品
            return 3  # 极品
        2: # 第2层
            if roll < 0.3: return 1
            if roll < 0.7: return 2
            return 3
        3: # 第3层
            if roll < 0.2: return 2
            if roll < 0.7: return 3
            return 4  # 神品
```

## 7. 实现建议

### 7.1 节点基类设计

```gdscript
class_name InteractiveNode
extends Node2D

@export var node_type: NodeType
@export var ui_scene: PackedScene  # 对应的UI场景

signal node_interacted(result: Dictionary)

func on_player_enter():
    # 显示可交互提示
    show_interact_hint()

func on_player_interact():
    # 打开对应UI
    var ui = ui_scene.instantiate()
    ui.node_data = self
    ui.result.connect(on_ui_result)
    get_tree().current_scene.add_child(ui)

func on_ui_result(result: Dictionary):
    # 处理UI返回结果
    node_interacted.emit(result)
    mark_as_cleared()
```

### 7.2 UI 管理器

```gdscript
class_name UIManager
extends Node

var active_ui: Control = null

func open_ui(ui_scene: PackedScene, data: Dictionary) -> void:
    if active_ui != null:
        close_active_ui()
    
    active_ui = ui_scene.instantiate()
    active_ui.setup(data)
    active_ui.close_requested.connect(close_active_ui)
    add_child(active_ui)

func close_active_ui() -> void:
    if active_ui != null:
        active_ui.queue_free()
        active_ui = null
```
