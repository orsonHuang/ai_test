# 地图、远征时段与行动经济

状态：v1 目标。地图骨架与每区6时段继承 MVP；活动组合、区域成长和商店规则是本轮改进。

## 1. 地图不是一连串一次性遭遇

地图块代表一个地区；进入后在同一地区做数次活动。地图下方是鹿鸣村，上方是魔王城。多边形只表现地理，移动按显式有向通路，不能用屏幕纵坐标猜是否可以走。

路线清单与地标见 [regions.csv](../data/regions.csv)。每条合法路线经过3个探索区，最多获得18时段。村庄和魔王城没有可刷的区域预算。村庄免费选好初始配置，魔王城免费整备但不赠送回血或额外商店。

开局看见地形轮廓、前进通路、古树守卫、熔火祭司、白狼领主和魔王地标的套装/威胁概览；地标情报不自动揭开其活动。其余副本随附近揭雾被发现。最终战的两种主要威胁从开局即可查看，不临到门前宣布“某流派免疫”。

## 2. 行动点包装：远征时段

世界观：魔王的封锁逐步收紧，小队在每个地区只有有限的安全活动窗口。离开后通路封闭；只做一次简短世界观说明，不在每次行动制造剧情弹窗。

| 规则 | 数值/行为 |
|---|---|
| 入区预算 | 6时段，显示六格进度 |
| 副本 | 2时段；可重复，战斗前预览掉落与重复挑战加压 |
| 营地休整 | 1时段；全队各恢复最大生命50%，可重复 |
| 抽选活动 | 宝箱、事件、巡游敌人、招募、行商各1时段，各区域限一次 |
| 移动、查看、换装、排阵、技能调整 | 免费；生命不重置 |
| 离开 | 可随时在非结算状态选择；剩余时段弃置，不兑换金币或加成 |
| 不足以副本 | 剩1点时只可做1点活动或离开；没有强制消费要求 |
| 0时段 | 仍可免费整备、看情报，然后选下一地区；不自动替玩家选路 |

“时段”没有现实倒计时；阅读、暂停和动画长短完全不影响消耗。进入付费行动的确认才扣费，预览不扣；行动进行中不能取消来退款。不可用的选项显示具体原因，不用笼统“条件不足”。

## 3. 每区内容配方

固定2项：所属首领副本、营地。再从5类活动抽3个不同类别。首区固定含招募，另抽2类；后两区按权重不放回抽3类。具体候选只在首次揭雾时生成一次。

| 类别 | 价值 | 限制与反馈 |
|---|---|---|
| 宝箱 | 当前区域档次的1件普通散件＋15金币 | 部位按种子确定；打开前显示“散件＋金币”，不假称保底套装 |
| 事件 | 明示代价的两项选择，提供局部变化 | 进入时段消费不因选保守分支而退还 |
| 巡游敌人 | 较低战斗风险，12金币，能触发本区首次战斗升级 | 不掉套装；必须与副本形成机会成本 |
| 招募 | 补足第三人，或换队伍功能 | 两候选取一；不能带重复职业；未确认可退出不扣费 |
| 行商 | 1时段进入一次交易：25金币全队恢复80%，或30金币买一件预览散件 | 只能二选一，商品生成后固定；无无限售卖/买回循环 |

类型权重：宝箱3、事件3、巡游敌人3、招募2、行商2。M1 使用统一权重，区域差别先来自首领与事件主题；M2 再验证是否需要生物群系偏好。行商至少一种交易可承担时才允许确认，否则免费离开。金币初始15，无跨局继承；除明确事件外，副本不发金币。

## 4. 成长和刷装的分离

每个探索区第一次战斗胜利使小队等级＋1；满级4。无论首次击败巡游敌人还是副本都只发一次。重复副本不能额外升级，金币也不重复产出，主要动机是目标套装和更合适的部位。

副本第2/3次挑战的首领生命分别为首轮的115%/130%，攻击为110%/120%；仅按**本区已胜利次数**计算，不跨区累计，不提高掉落品质。随从小怪不额外加压。M1 暂不超过2次加压；6时段已限制每区最多3次挑战。进入前明确显示强度变化。这个机制需要测试，若使第三件形同陷阱，先降低加压而不是隐藏惩罚。

营地恢复50%很强，目的在于把选择压缩为“战斗机会换生存”，而非让玩家反复点小药。不会额外施加一个同义的饥饿/疲劳资源。

## 5. 三种合法预算方案

| 方案 | 支出 | 留下的遗憾 |
|---|---|---|
| 首区招人与成型 | 招募1＋副本2＋副本2＋休整1＝6 | 放弃宝箱、事件和第三件 |
| 极端刷装 | 副本2×3＝6 | 无招募/休整；要承受加压；只能已有完整队伍再考虑 |
| 稳健探索 | 巡游1＋副本2＋事件1＋休整1＝5，余1可离开 | 只有一件指定套装，换来资源与生存 |

这些是可选计划，不是攻略保证。地图生成不得强制玩家刚好按某个方案才不会死。随机活动不能产出额外时段，避免破坏18点总预算与反复刷装上限。

## 6. 一条18时段的完整体验样例

路线：鹿鸣村 → 荆棘林地 → 苔石矿谷 → 霜落高地 → 魔王城。示例种子的第二区含巡游/事件/宝箱，第三区含事件/行商/宝箱。

| 地区 | 顺序 | 总支出 | 关键结果 |
|---|---|---:|---|
| 荆棘 | 招募1 → 副本2 → 休整1 → 副本2 | 6 | 三人队；两件荆棘；只升一次级 |
| 矿谷 | 巡游1 → 副本2 → 事件1 → 休整1 → 宝箱1 | 6 | 升级、补第三件；也可考虑宝箱散件替换 |
| 霜落 | 副本2 → 事件1 → 休整1 → 行商1 → 宝箱1 | 6 | 用生命与金币为最终战做准备，不保证猎风成套 |

行商选择需金币足够；示例事件都选不花金币的分支，此前巡游＋宝箱已有27金币，加初始15可以补给。伤害和胜败需真实模拟，表只证明资源与流程合法，不能据此声称能通关。
