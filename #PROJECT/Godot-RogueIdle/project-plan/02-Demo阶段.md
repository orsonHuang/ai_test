## 1. 阶段目标

在原型基础上补齐所有核心系统，达到可对外演示的 Demo 品质。

---

## 2. 任务分解

### 2.1 法师职业

| 任务 | 说明 | 优先级 |
|------|------|--------|
| 法师基础属性 | 攻击力偏低、技能伤害倍率高 | P0 |
| 6 个技能 | 陨石术/烈焰爆破/冰封领域（主动）+ 奥术积蓄/火焰亲和/寒冰之触（被动） | P0 |
| 灼烧机制 | 层数叠加、引爆计算 | P0 |
| 冰冻机制 | 减速/冻结效果实现 | P0 |
| 职业选择 UI | 主菜单战前选职业 | P0 |

### 2.2 完整稀有度体系

| 任务 | 说明 | 优先级 |
|------|------|--------|
| 神品（橙） | 固定 2 词条、属性倍率 ×2.5 | P0 |
| 绝品（红） | 2-3 词条、属性倍率 ×3.0、必定带套装词条 | P0 |
| BOSS 掉落调整 | BOSS 掉落极品~绝品 | P0 |
| 稀有度颜色/特效 | 不同稀有度装备 UI 颜色区分 | P1 |

### 2.3 词条系统完善

| 任务 | 说明 | 优先级 |
|------|------|--------|
| 完整词条库 20+ 条 | 含基础属性/战斗机制/特殊效果/元素伤害/条件触发/召唤强化 | P0 |
| 词条随机抽取 | 按权重从 applicable_slots 池中随机 | P0 |
| 同名词条累计 | 属性区合并显示"攻击力+10% (×3)"，效果叠加 | P0 |
| 词条数值波动 | 在 min~max 范围内随机 | P0 |

### 2.4 重铸系统

| 任务 | 说明 | 优先级 |
|------|------|--------|
| 重铸逻辑 | 指定词条→随机替换为新词条（不重复） | P0 |
| 重铸石系统 | 物品定义、掉落、消耗递增 | P0 |
| 商店重铸入口 | 商店界面可重铸任意件装备 | P0 |
| 套装词条保护 | 套装词条不可被重铸 | P0 |

### 2.5 套装系统

| 任务 | 说明 | 优先级 |
|------|------|--------|
| SetResource | 套装表 Resource 类定义 | P0 |
| 套装词条生成 | 装备掉落时概率附带套装词条 | P0 |
| 套装激活检测 | 运行时检查同名套装词条数量，判断生效/未生效 | P0 |
| 套装效果实现 | 6 个示例套装效果（烈焰之心/冰霜之触/不屈意志/狂风之怒/召唤主宰/暗夜刺客） | P0 |
| 套装状态 UI | [生效]绿色高亮 / [未生效]灰色 区分 | P0 |

### 2.6 完整地图系统

| 任务 | 说明 | 优先级 |
|------|------|--------|
| 3 层地图 | 森林→城堡→深渊，主题差异化 | P0 |
| 地图间过渡 | BOSS 击败后进入下一层，继承装备/状态 | P0 |
| 最终 BOSS | 第 3 层 BOSS 为通关目标 | P0 |

### 2.7 商店/篝火/事件

| 任务 | 说明 | 优先级 |
|------|------|--------|
| 商店界面 | 装备购买、强化石/重铸石购买 | P0 |
| 篝火界面 | 回复生命 + 免费强化 1 件 | P0 |
| 随机事件 | 5-8 个文本抉择事件，影响装备/金币/生命 | P1 |

### 2.8 UI 完善

| 任务 | 说明 | 优先级 |
|------|------|--------|
| 属性区滑动 | 左侧属性区域支持上下滑动 | P0 |
| 词条效果展示区 | 底部展示所有已生效词条的累计效果 | P0 |
| 套装状态展示 | [生效]/[未生效] 视觉区分 | P0 |
| Tab 切换 | 基础信息/装备信息/词条详情/整体属性 | P1 |
| 倍速按钮 | X1/X2 战斗倍速切换 | P1 |

### 2.9 强化系统完善

| 任务 | 说明 | 优先级 |
|------|------|--------|
| 商店强化入口 | 消耗强化石可强化任意件 | P0 |
| 神品→绝品强化 | 最高稀有度的强化路径 | P0 |
| 词条数值提升 | 强化时若词条已满，随机提升已有词条数值 | P1 |

---

## 3. 里程碑验收标准

- [ ] 战士、法师两个职业均可通关 3 层地图
- [ ] 装备稀有度体系完整（凡品→绝品），掉落分布合理
- [ ] 强化系统可用（篝火免费 + 商店消耗强化石）
- [ ] 重铸系统可用（消耗重铸石替换词条）
- [ ] 套装系统可激活（至少 3 套可凑齐）
- [ ] UI 属性区可滑动，词条效果正确累计展示
- [ ] 商店/篝火/随机事件均可正常交互
- [ ] 无重大 Bug，可流畅游玩 20 分钟一局
