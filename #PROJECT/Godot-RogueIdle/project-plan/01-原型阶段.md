# 阶段一：原型（0 → 可运行最小版本）

> 状态：待启动  
> 预估周期：3-4 周  
> 目标：实现战斗自动逻辑 + 1 职业 + 单层地图 + 基础装备掉落 + 基础词条 + 强化系统  
> GDD 参考：`Godot-RogueIdle/GDD/README.md`、`03-装备系统/`、`04-技能系统/`、`05-英雄职业/`

---

## 1. 阶段目标

搭建最小可玩原型，验证核心战斗循环和装备系统基础框架。

---

## 2. 任务分解

### 2.1 Godot 工程搭建

| 任务 | 说明 | 优先级 |
|------|------|--------|
| 创建 Godot 4.x 项目 | 初始化项目结构、配置 Autoload 单例 | P0 |
| 搭建核心场景框架 | MainMenu / Map / Battle / Result 场景骨架 | P0 |
| 资源目录结构 | 按 GDD 8.1 创建 Resources/ 和 Scripts/ 目录树 | P0 |
| 数据加载基础 | DataManager 读取 .tres 资源文件 | P0 |

### 2.2 战斗系统原型

| 任务 | 说明 | 优先级 |
|------|------|--------|
| 自动战斗逻辑 | 角色自动普攻，按攻速/间隔执行 | P0 |
| 敌方 AI | 敌方自动普攻主角，单敌人先行 | P0 |
| 伤害计算器 | 攻击力/防御力/暴击率/暴击伤害 公式实现 | P0 |
| HP/护盾系统 | 生命值显示、护盾机制 | P0 |
| 战斗 UI 基础版 | 左侧属性区 + 中部战斗区 + 顶部信息条（无滑动） | P0 |

### 2.3 战士职业 + 技能

| 任务 | 说明 | 优先级 |
|------|------|--------|
| 战士基础属性 | 攻击力、生命值、防御力等面板 | P0 |
| 3 个初始技能 | 战斗怒吼（主动）+ 愈战愈勇（被动）+ 荆棘甲（被动） | P0 |
| 技能系统 | SkillResource 定义、CD管理、自动释放判断 | P0 |
| 技能效果实现 | Buff/Debuff 系统、反击机制 | P0 |

### 2.4 基础装备系统

| 任务 | 说明 | 优先级 |
|------|------|--------|
| EquipmentResource | 装备表 Resource 类定义 | P0 |
| AffixResource | 词条表 Resource 类定义 | P0 |
| 装备实例化 | 掉落时根据 Resource 生成 EquipmentInstance | P0 |
| 装备槽位 UI | 9 槽位展示、拖拽装备/卸下 | P0 |
| 稀有度 0-3 级 | 凡品/良品/上品/极品（灰/绿/蓝/紫） | P0 |
| 基础词条 5-8 条 | 攻击力/生命值/防御力/暴击率/暴击伤害/攻速等 | P0 |
| 装备掉落 | 普通战掉落凡品/良品，精英掉落上品/极品 | P0 |

### 2.5 强化系统

| 任务 | 说明 | 优先级 |
|------|------|--------|
| 强化逻辑 | 提升稀有度、重算属性、概率获新词条 | P1 |
| 强化石系统 | 物品定义、掉落、消耗 | P1 |
| 篝火强化入口 | 篝火节点免费强化 1 件 | P1 |

### 2.6 单层地图

| 任务 | 说明 | 优先级 |
|------|------|--------|
| 地图生成 | 6-8 节点、分叉路线、随机布局 | P0 |
| 节点类型 | 普通战斗 / 精英战斗 / BOSS / 商店 / 篝火 | P0 |
| 地图 UI | 节点展示、路线选择、进度保存 | P0 |
| 1 个 BOSS | 简单 BOSS 战，掉落高品质装备 | P1 |
