## 必须 / 重要 / 后续

必须：上述完整闭环、敌人意图、关键战报、存档安全、场景在Inspector可调。

重要：装备比较质量、日志筛选、减少闪烁/震屏、长文本布局；若影响理解则提升为必须。

后续：12事件、机制散件、额外地图模板、挑战、随从专精。强化/重铸/六职业/永久属性树不在当前计划。

## M1 完成门槛

- [x] 功能：可从村庄选目的地，走过三个区后挑战魔王；有胜败复盘与重开。
- [x] 功能：同区刷两次形成两件套，与休整/招募竞争预算；已实际输入验证。
- [ ] 同档敌人有不同应对；玩家能解释至少一种配队或阵位的作用。
- [ ] 所有随机/费用/奖励边界与读档回归通过；不因倍速改变结果。
- [x] 代表性场景节点可选中修改，保存重开与运行效果一致，留有证据。
- [ ] 真人测试记录支持三大支柱，不把脚本通关当真人乐趣证明。

当前已完成 Godot 功能闭环、13 项规则回归、268 项场景结构检查、正常数值通关及战中续档。自动测试覆盖关键边界，尚未证明所有种子、所有构筑的平衡和真人理解；真人试玩门槛保留未完成，M1 不整体标记完成。先完成定性试玩，再决定是否进入 M2 内容量产。
