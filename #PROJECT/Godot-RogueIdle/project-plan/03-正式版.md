## 2. 任务分解

### 2.1 后续职业（4 个）

| 职业 | 核心机制 | 技能数量 | 优先级 |
|------|----------|----------|--------|
| 骑士 | 坦克、光环、团队 Buff | 6 技能 | P0 |
| 射手 | 远程物理、攻速、风筝 | 6 技能 | P0 |
| 刺客 | 近战爆发、潜行、一击脱离 | 6 技能 | P1 |
| 道士 | 中国风、召唤僵尸、雷击、毒 | 6 技能 | P1 |

每个职业包含：
- 3 个流派方向（各含 1 主动 + 1 被动初始技能）
- 完整技能池 8-10 个（初始 3-4 + 解锁 5-6）

### 2.2 局外养成系统

| 任务 | 说明 | 优先级 |
|------|------|--------|
| 技能解锁 | 局数累计/成就触发解锁新技能 | P0 |
| 职业解锁 | 灵魂货币消耗，自由选择解锁顺序 | P0 |
| 全局天赋树 | 类似 Hades 镜子，初始金币/生命/掉落概率 | P1 |
| 成就系统 | 战斗/收集/通关类成就 | P1 |
| 局外存档 | 解锁进度、成就持久化 | P0 |

### 2.3 词条库扩充

| 任务 | 说明 | 优先级 |
|------|------|--------|
| 词条总数 40+ | 覆盖所有职业流派的核心需求 | P0 |
| 职业专属词条 | 如"召唤物伤害+20%"仅限道士相关装备 | P1 |
| 传奇特效词条 | 稀有词条改变机制（类似暗黑传奇特效） | P1 |
| 负面词条 | 诅咒装备（高属性 + 负面效果） | P2 |

### 2.4 套装库扩充

| 任务 | 说明 | 优先级 |
|------|------|--------|
| 套装总数 12+ | 每个职业至少 1 套专属套装 | P0 |
| 职业专属套装 | 如道士"僵尸主宰"、刺客"暗影行者" | P1 |
| 通用套装 | 跨职业可用的通用效果套装 | P0 |
| 大型套装 5 件套 | 全身半数部位统一，强力效果 | P1 |

### 2.5 圣物系统评估

| 任务 | 说明 | 优先级 |
|------|------|--------|
| 可行性评估 | 与现有装备/套装体系是否重叠 | P1 |
| 设计方案 | 如需加回，设计独立的圣物槽位和效果 | P2 |
| 实现 | 如果决策加入 | P2 |

### 2.6 平衡调优

| 任务 | 说明 | 优先级 |
|------|------|--------|
| 数值曲线 | 3 层难度递进、稀有度属性倍率平衡 | P0 |
| 词条数值调整 | 根据测试数据调整 min/max 范围 | P0 |
| 职业平衡 | 6 职业通关率趋近、流派多样性 | P0 |
| 套装平衡 | 套装效果强度与激活难度的匹配 | P0 |
| 强化/重铸成本 | 强化石/重铸石消耗与产出的平衡 | P0 |
| 难度等级 | 普通/困难/噩梦 可自选 | P1 |

### 2.7 敌人设计完善

| 任务 | 说明 | 优先级 |
|------|------|--------|
| 敌人类型 15+ | 不同行为模式的敌人 | P0 |
| 精英词缀 | 随机词缀（如"快速""巨大""分裂"） | P1 |
| BOSS 机制 | 每个 BOSS 有独特机制（非纯数值） | P0 |
| 敌人 AI 完善 | 蓄力技、AOE 预警、阶段切换 | P1 |

### 2.8 美术与音效

| 任务 | 说明 | 优先级 |
|------|------|--------|
| 美术风格确定 | 像素/手绘/低多边形 最终选择 | P0 |
| 角色/敌人资源 | 6 职业 + 15+ 敌人 + BOSS 的美术资源 | P0 |
| 装备图标 | 9 槽位 × 多稀有度 的装备图标 | P0 |
| UI 美化 | 战斗 UI、地图 UI、商店/篝火/事件 UI 美化 | P0 |
| 动画效果 | 攻击/技能/受击/死亡动画 | P1 |
| 战斗 BGM | 3 层地图各 1 首 + BOSS 战专属 | P1 |
| 音效 | 攻击/技能/UI交互/掉落/升级 音效 | P1 |

### 2.9 随机事件库

| 任务 | 说明 | 优先级 |
