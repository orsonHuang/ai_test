# M3 打磨与Steam发布准备

状态：未启动。Steam是用户确认的正式目标，不再放到“不知何时做”的扩展列表。售价、首发内容规模、上线日期和其他系统支持尚未冻结。

## 1. 内容冻结门槛

根据M2重复游玩证据确定地图模板、敌人变体、事件与流派数量，形成资产预算和维护清单。每个新增内容要有独立决策价值；不以六职业/十二套装的数字自动代表深度。

正式版要求完成当前承诺范围的教程、复盘、图鉴、设置、本地存档恢复。扩展机制须补GDD、数值与测试，不把旧稿被取消的系统偷偷恢复为必做。

## 2. 发布工作包

| 项目 | 验收要求 |
|---|---|
| 构建 | 明确Windows导出预设；独立机器离线可启动、可玩和保存；无开发路径依赖 |
| 性能 | 冻结最低/推荐测试机，记录帧时间、内存、加载与安装体积，依据实测填写商店资料 |
| 稳定性 | 无阻断进度或损坏存档的已知问题；其它问题有分级与处置，不写“零Bug” |
| 存档 | 版本迁移、损坏恢复、覆盖提示；云存档如承诺则实测冲突与同步，不仅勾配置 |
| 平台功能 | 成就/云存档按产品决定接入，逐项核验；不把平台功能当作核心乐趣补丁 |
| 素材 | 原图/字体/音频/插件来源与使用许可可追溯，正式产物无未替换占位 |
| 页面素材 | 截图、短视频、介绍真实展示玩法和局内选择，不误导为联网MMO或离线挂机 |
| 体验 | 字体缩放、音量、色彩辅助、减少震屏；实际键鼠操作闭环 |
| 安全与工具 | 正式包关闭MCP、开发调试控制入口和测试资源，保留正常存档功能 |
| 发布流程 | 届时依据Steam官方现行要求核对商店、构建、审核与发售手续；本轮未执行 |

## 3. 发布与后续边界

上传、商店提交、对外宣传和正式发布在相应用户授权任务中执行。本次GDD更新不等于这些动作已经获准或完成。

首发不承诺联网、移动版、跨端存档、MOD、日常任务和无尽模式。只有当前产品通过留存兴趣与制作成本评估后再选扩展；不为未来扩展提前制造大量空系统。
