# 骰子战斗游戏概念

## 游戏概述
一个基于骰子的战斗游戏，灵感来源于《小丑牌》，玩家通过投掷骰子并与怪物战斗。

## 核心机制

### 骰子系统
- 玩家每次可以投掷6个骰子
- 投掷后可以选择使用1-5个骰子作为最终结果
- 未选择的骰子可以重新投掷

### 伤害计算
- 基础伤害：选中骰子的点数总和
- 根据骰子组合有额外的伤害倍率：

| 组合类型 | 伤害倍率 | 描述 |
|----------|----------|------|
| 散牌 | x1 | 没有特殊组合 |
| 对子 | x1.5 | 两个相同点数 |
| 两对 | x2 | 两组相同点数 |
| 三条 | x2.5 | 三个相同点数 |
| 葫芦 | x5 | 三带二（三条+对子） |
| 顺子 | x5 | 连续的点数 |
| 四条 | x5 | 四个相同点数 |
| 五条 | x10 | 五个相同点数 |

### 战斗系统
- 怪物拥有血量值
- 玩家每次投掷并选择骰子组合攻击怪物
- 总伤害值扣除怪物血量
- 目标是用最少的回合击败怪物

### 用户体验
- 简单直观的操作界面
- 类似《小丑牌》的策略选择体验
- 每次投掷都有策略考量（保留还是重投）
- 感官反馈（视觉、音效）增强骰子投掷和战斗效果

## 技术实现考虑
- 使用Godot开发
- 支持HTML5/WebAssembly导出
- UI设计要突出骰子的视觉效果
- 动画效果表现战斗过程
- 随机数生成和概率平衡调整

## 可扩展性
- 多种怪物类型（不同血量和特性）
- 骰子强化道具
- 特殊能力/技能系统
- 成就和排行榜系统
