# 参考游戏分析

> 分析玩过的游戏，提取可借鉴的设计元素。

---

## 分析模板

每个游戏记录：
- **游戏名称**
- **核心体验**（玩家为什么玩）
- **亮点设计**（值得借鉴的机制）
- **Godot 可实现性**
- **AI 协作切入点**

## Murdoku

- **游戏名称**：Murdoku（网页游戏，murdoku.com）
- **核心体验**：数独的排列约束 + 案件推理的叙事包装。每个案件有场景、嫌疑人、线索条件，玩家需要在网格中放置嫌疑人，满足行列唯一性 + 线索条件来破案
- **亮点设计**：
  - 数独骨架 + 叙事皮肤，让纯逻辑推理有了故事代入感
  - 线索条件作为额外约束层（"站在树边的人""穿红色衣服的人"），比纯数独更有层次
  - 网页即开即玩，零门槛
- **Godot 可实现性**：高——核心是 Grid + 约束求解 + UI 渲染，无物理/复杂动画
- **AI 协作切入点**：
  - **关卡自动生成**：AI 生成线索组合 + 验证唯一解（核心价值！）
  - 案件叙事包装（AI 写案件背景、嫌疑人描述）
  - 难度曲线设计（AI 分析约束数量 vs 难度关系）

## 喵喵消消乐

- **游戏名称**：喵喵消消乐
- **核心体验**：经典三消 + 猫咪主题的治愈感。消除反馈即时、爽快，关卡推进有成长感
- **亮点设计**：
  - 三消玩法极其成熟，玩家无需学习成本
  - 猫咪主题提供情感价值（可爱=留存）
  - 关卡式推进，短期目标清晰
- **Godot 可实现性**：高——Grid + 消除逻辑 + 简单动画，Godot 的 2D 和动画系统完全胜任
- **AI 协作切入点**：
  - **关卡设计**：AI 生成棋盘布局 + 目标条件
  - 道具/特殊块效果设计
  - 进度系统数值平衡

## 小丑牌（Balatro）

- **游戏名称**：小丑牌 Balatro
- **核心体验**：用扑克牌型得分，用小丑卡修改规则。每次出牌都是一次"我能不能打出更强的牌型"的期待感，小丑卡的组合产生化学反应
- **亮点设计**：
  - **牌型即得分**：扑克牌型（对子、顺子、同花等）天然有认知基础，零学习成本
  - **小丑卡改规则**：不是改数值，是改机制（"黑色花色算两次""可以跳过一张牌组顺子"），这才是爽感的来源
  - **肉鸽构筑**：每轮商店选小丑卡，Build 逐渐成型
  - 极简 UI，纯卡牌操作
- **Godot 可实现性**：高——卡牌数据结构 + UI + 计分逻辑，无物理需求
- **AI 协作切入点**：
  - **小丑卡效果设计**：AI 可以批量生成"修改规则"类效果，人类筛选
  - 牌型得分平衡
  - Boss Blind 设计（限制条件）

## 种呱得呱

- **游戏名称**：种呱得呱
- **核心体验**：卡牌肉鸽 + 农场经营。抽卡消耗资源，打牌免费——这个反直觉设计制造了独特的资源紧张感
- **亮点设计**：
  - **抽卡付费、打牌免费**：与传统 CCG 相反，改变了决策重心（什么时候抽 vs 抽什么）
  - 有限农场空间 + 植物成长，空间也是一种资源约束
  - 肉鸽式卡组构筑
- **Godot 可实现性**：高——卡牌系统 + 资源管理，UI 驱动
- **AI 协作切入点**：
  - 卡牌效果与资源消耗平衡
  - 植物/作物数据表生成

## 龟龟潜海记

- **游戏名称**：龟龟潜海记（Shelldiver）
- **核心体验**：放置增量 + 海洋探索。手动点击→自动化→数值爆炸，经典的 Idle 快感循环
- **亮点设计**：
  - 可爱的乌龟潜水主题，治愈感强
  - 增量游戏的标准范式：升级工具→自动化→新资源→再升级
  - 资源用于重建社区，有长期目标感
- **Godot 可实现性**：高——数值系统 + UI，Godot 的 Tween/动画可做升级特效
- **AI 协作切入点**：
  - 数值曲线设计（成本增长 vs 产出增长）
  - 升级树结构生成

## 七大奇迹（7 Wonders）

- **游戏名称**：七大奇迹
- **核心体验**：轮抽选牌 + 多路线得分。每轮从手牌中选一张打出，剩下的传给下家——你既要考虑自己，也要卡别人
- **亮点设计**：
  - **轮抽机制**：手牌在玩家间传递，选牌 = 构筑自己 + 阻断对手
  - **三时代递进**：时代 I→II→III，卡牌强度递增，节奏感清晰
  - **多路线得分**：军事/科技/文化/商业/奇迹，每条路线都能赢
  - 无 downtime，所有人同时选牌
- **Godot 可实现性**：高——卡牌 + 计分系统，单人模式更简单
- **AI 协作切入点**：
  - **卡牌设计**：AI 批量生成不同时代的卡牌效果
  - 多路线平衡验证
  - AI 对手的选牌策略

## 恶魔的谎言（Demon Bluff）⭐ 核心参考

- **游戏名称**：Demon Bluff / 恶魔的谎言
- **核心体验**：单人社交推理 × 肉鸽卡牌。村庄被恶魔渗透，每个角色是一张卡牌——村民提供真情报，恶魔伪装村民散布谎言。玩家翻牌收集信息、交叉验证，从真假混杂中揪出恶魔
- **亮点设计**：
  - **卡牌会说谎**：文字描述与实际效果可能不一致——这个设计从根本上颠覆了卡牌游戏的"信任"基础
  - **身份推理骨架**：借鉴血染钟楼，村民/恶魔/爪牙/外来者多身份，每个身份有独特的信息提供规则
  - **信息差驱动**：不是比谁手牌强，而是比谁从混乱信息中提取真相的能力强
  - **肉鸽构筑**：每局随机生成卡牌组合，耐玩度高
  - 单机解决了多人社交推理"凑人难"的问题
- **Godot 可实现性**：高——卡牌数据结构 + 信息逻辑系统 + UI，核心是数据模型设计
- **AI 协作切入点**：
  - **角色设计**：AI 批量生成不同身份角色的信息提供规则（核心价值！）
  - **场景/剧本生成**：AI 生成村庄背景、角色关系网、谎言模式
  - **难度调控**：AI 分析"真假信息比例"对推理难度的曲线
  - **AI 作为"说书人"**：动态调整信息投放，类似血染钟楼的 DM 角色

## 跨游戏模式识别（更新）

| 维度 | 小丑牌 | 种呱得呱 | 龟龟潜海记 | 七大奇迹 | Murdoku | Demon Bluff |
|------|--------|----------|------------|----------|---------|-------------|
| **核心操作** | 选牌打出 | 抽卡打牌 | 点击升级 | 轮抽选牌 | 排列推理 | 翻牌推理 |
| **爽感来源** | 组合爆炸 | 资源循环 | 数值爆炸 | 路线成型 | 推理突破 | **识破谎言** |
| **卡牌角色** | 改规则 | 改资源 | 无 | 改得分 | 无 | **改信息** |
| **AI 最大价值** | 效果设计 | 数值平衡 | 数值曲线 | 卡牌设计 | 关卡生成 | **角色+谎言生成** |

**核心洞察（更新）**：Demon Bluff 引入了一个全新维度——**信息可信度**。传统卡牌游戏中"卡牌效果"是确定的，但 Demon Bluff 让卡牌"会说谎"，这是一个可以迁移到其他品类中的强大设计模式。

### Demon Bluff 的设计精华提取

```
传统卡牌：  抽牌 → 看到效果 → 决定打出
Demon Bluff：抽牌 → 看到描述（可能假的）→ 需要推理验证 → 决定是否相信
```

这个"信任层"是核心创新。可以迁移到：
- 信息不对称的卡牌游戏
- 带有隐藏信息的策略游戏
- 任何需要"判断真假"的决策场景

## 阿瓦隆（Avalon）⭐ 核心机制参考

- **游戏名称**：阿瓦隆 / Avalon
- **核心体验**：阵营对抗 + 选人上车 + 任务投票。好人要完成三次任务并保护梅林，坏人要破坏任务或刺杀梅林。没有人中途出局，全程靠逻辑推理和话术博弈
- **核心循环**：
  ```
  选人上车 → 投票表决 → 任务执行（成功/失败）→ 分析结果推理身份 → 下一轮
  ```
- **亮点设计**：
  - **选人机制（组队）**：每轮由"队长"选人上车做任务——选谁、不选谁本身就是信息
  - **公开投票**：所有人对组队方案投票，投票模式暴露阵营倾向
  - **任务匿名投票**：车上的人秘密投成功/失败，只需要一张失败票任务就炸——但不知道是谁投的
  - **梅林困境**：梅林知道所有坏人身份，但必须隐藏自己（否则坏人刺杀梅林翻盘），只能在发言中微妙引导
  - **无淘汰**：所有人全程参与，不像狼人杀会"第一轮出局"
- **信息差层次**：
  - 梅林：知道所有人身份（信息最多，但最不能说话）
  - 派西维尔：知道梅林和莫甘娜是谁，但分不清哪个是哪个
  - 忠臣：什么都不知道，只能靠推理
  - 坏人：互相知道身份，可以配合演戏
- **Godot 可实现性**：高——核心是状态机 + 投票系统 + 身份逻辑，单人版更简化
- **AI 协作切入点**：
  - **AI 角色扮演**：每个角色用不同的"信息策略"发言（核心价值！）
  - **组队逻辑**：AI 模拟不同身份的选人策略
  - **结果生成**：AI 根据角色身份生成"任务执行后的对话/线索"

## 阿瓦隆 × Demon Bluff 融合分析

这是本次脑暴最关键的设计洞察——两个游戏的互补性极强：

| 维度 | Demon Bluff | 阿瓦隆 | 融合机会 |
|------|-------------|--------|----------|
| **核心操作** | 翻牌看信息 | 选人上车 | **选人 + 翻牌看该角色的"汇报"** |
| **信息来源** | 卡牌描述（可能假） | 任务结果（成功/失败） | 角色对话 + 任务结果双重信息 |
| **推理方式** | 交叉验证多条信息 | 分析投票模式 | 选谁→看他怎么说→和结果对比 |
| **节奏** | 回合制翻牌 | 轮次制选人-投票 | 每轮：选人→执行→看汇报→分析 |
| **角色深度** | 身份决定信息真假 | 身份决定行为策略 | 身份决定"汇报内容"和"任务行为" |

**融合后的核心循环草案**：
```
列车长选人上车 → 执行任务 → 车上角色各自"汇报" → 汇报可能为假 → 玩家分析 → 下一轮
```
