# Project-Card

一个参考《杀戮尖塔》战斗系统的卡牌 + 枪支回合制战斗项目。

## 项目定位

- 核心体验：回合制卡牌战斗，通过左轮、霰弹、狙击三种枪支上膛子弹并攻击怪物。
- 目标平台：待定
- 当前阶段：框架设计

## 关键机制

1. 回合分为 5 个阶段：回合开始、抽牌、打牌、攻击、回合结束。
2. 玩家携带 3 把枪支：左轮枪（6 仓）、霰弹枪（2 仓）、狙击枪（1 仓）。
3. 手牌分为功能牌与子弹牌，子弹牌用于上膛并在攻击阶段依次打出。
4. 怪物每回合显示行动意图，回合结束时执行。
5. 包含圣器系统（对标遗物）、Buff 系统、距离与攻击范围。
