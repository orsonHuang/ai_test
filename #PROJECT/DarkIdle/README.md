# DarkIdle · 燃爆法师体验版

## 项目描述
Godot / Steam 单机买断制、横版暗黑剪纸自动战斗。玩家战前安排法术与触发规则，观看燃烧叠层、扩散和引爆。

**当前：燃爆法师体验版可玩。** 打开 [Godot 工程](gd-dark-idle/project.godot)，按 F5，再点击“开始战斗”。默认一法师对三小怪，支持编排、条件、被动反应、暂停单步与战术保存。

## 工作规则
- 本项目独立于 Godot-RogueIdle；引擎工程实际目录为 `gd-dark-idle/`。
- Godot 4.x，使用类型明确的 GDScript、原生可编辑场景和可调资源；规则层与表现层分离。
- MCP 操作须验证目标会话路径；所有场景需保存并重新打开验证，不能把概念图当运行画面。
- 原始需求与实现假设分别记录。数值可调，试玩结论不能以测试通过替代。
