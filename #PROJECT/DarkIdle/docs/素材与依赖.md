# 素材与依赖

## v0.2 当前素材

| 内容 | 来源 / 用途 |
|---|---|
| `assets/v2/ground.png` | 本会话内置imagegen；2172×724，明确地表与土层 |
| `assets/v2/icons.png` | 内置imagegen透明图集，1619×971；5列3行，7主动、3反应、3敌招、燃烧及标记 |
| `assets/v2/{mage,soot,antler,straw}-grid.png` | 内置imagegen根据初稿修改，1280×1280透明四姿势；当前实际使用 |
| `resources/*_frames.tres` | 原生AtlasTexture与SpriteFrames；四独立姿势＋返回待机，9fps |
| `assets/v2/animation_metrics.json` | 读取透明度边界计算脚底偏移；没有通过脚本修改栅格图像 |
| `resources/tactical_theme.tres` | 原生UI主题，系统中文字体沿用v1 |

完整生成提示词：[首轮](v2-art-prompts.json) / [动作分格修订](v2-animation-refinement.json)。`assets/v2/{mage,soot,antler,straw}.png`为初始横条稿，因姿势跨格未用于运行；保留供追溯。当前Atlas左右分界采用720px，避免左侧伸出的法杖/爪子被裁切；高度分界640px。

`assets/units.png`仍用于行动轴头像，四个音效继续复用。当前四角色共16个真实姿势，未声称制作完整走路、受击和死亡动画。

## v0.1 素材与共用依赖

| 内容 | 来源 / 处理 |
|---|---|
| `assets/orchard.png` | 本会话内置 imagegen 生成的场景图，1672×941；原图保存进工程 |
| `assets/units.png` | 本会话内置 imagegen 生成的透明角色图集，2172×724；通过 AtlasTexture 区域使用，未依赖外部在线链接 |
| `assets/*.wav` | `tools/build_scenes.py` 数学合成的四段原创提示音 |
| `resources/paper_theme.tres` | 本项目原生主题；运行时使用系统 Microsoft YaHei / Noto Sans CJK SC 回退，不附带字体文件 |
| `addons/godot_ai/` | 复用本机已有 Godot AI 2.9.0，开发工具依赖；保留插件原 MIT LICENSE 与 copyright |
| `icon.svg` | Godot 建项目的默认图标，尚未制作游戏标识 |

完整美术提示词见 [art-prompts.json](art-prompts.json)。方向依据用户选中的暗黑剪纸；没有截取《圣兽之王》角色、UI 贴图或音频。

发布版还需制作正式图标、确定字体方案、完善音频，并评估是否从玩家构建移除开发插件和调试 helper。当前没有设置发行导出预设。
