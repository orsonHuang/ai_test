# DarkIdle｜战前策略体验版 v0.2

更新：2026-10-30。当前实现入口 `gd-dark-idle/scenes/tactical_main.tscn`。v0.1 设计留在 [GDD.md](GDD.md)，不作为本版运行规则。

## 1. 一句话定位
装备四个法术与两个反应，让剪纸法师按条件自动叠火、扩散和引爆。

## 2. 核心循环

| 层次 | 玩家动作 → 反馈 → 回报 |
|---|---|
| 行动 | 观察意图与行动轴 → 技能、燃烧与反应飘字 → 看懂一次结算 |
| 单场 | 看敌人 → 装备、排序、设条件和目标 → 自动战斗 → 与上场比较 → 再编排 |
| 多场（未实现） | 不同敌情 → 获得技能变体或遗物 → 改变构筑 → 挑战首领 |

当前是一场固定遭遇的战术实验台。Steam 买断版应通过敌情、技能组合和路线提供持续变化；离线收益、每日任务不在本版范围。

## 3. 用户、平台与参考
面向喜欢构筑和自动战斗的桌面玩家。Godot 4.7.2，当前实测 Windows；计划 Steam 单机买断，一人＋AI 制作。Auto Rogue 为战前编排方向参考，《圣兽之王》为主动、反应与固定触发时机参考；本作未照搬其完整战斗规则。

历史参考来源见 [v1 GDD](GDD.md) 与剪纸风格提案。当前截图均来自运行中的 Godot，不是效果图。

## 4. 核心机制

| 机制 | 规则 | 边界 |
|---|---|---|
| 行动装备 | 7 选 4，按左到右逐槽检查，每轮每槽最多一次 | 允许重复法术；空槽、禁用、条件失败或 AP 不足跳过 |
| 反应装备 | 3 选 2，各技能有固定触发时机，成功消耗 1 RP | 重复装备时交换两槽，避免重复技能占槽但不生效 |
| 条件 | 总是、目标已有燃烧、目标燃烧≥4、自身生命<50% | 先筛选目标；无合格目标不花 AP；范围法术存在合格目标即可影响全部存活敌人 |
| 目标 | 标记目标优先、燃烧最多、生命最低、最前方 | 标记不合格/死亡时回退到首个合格目标；最低生命取绝对值；平局从左到右 |
| 固定目标 | 爆燃取燃烧最多；火墙、火葬、炼狱取全体 | UI 固定显示，不能配置无效目标偏好 |
| 燃烧 | 每层 8 伤；回合末引爆并清空 | 炎爆、炼狱即时引爆保留层数，技能照常付 AP；用户已确认 |
| 炎爆转移 | 先加层，再直伤及引爆；击杀后将保留层数叠给下个存活目标 | 从后方找，末位绕回首位；没有后续目标则结束；转移不立即连爆 |
| 蓄能 | 本轮首次成功施法前检查；下一行动新增燃烧量×2 | 不翻倍直伤或伤害系数；原3层的翻倍技能受蓄能后为3+6=9层 |
| 行动轴 | 每轮每个存活单位一次行动机会；尚未行动者中位置最靠右者出手 | 到右端放大，AP耗尽且动作结算完后退出本轮行动轴；下一轮重新进入。英雄机会内执行整个装备序列 |
| 位置变更 | `shift_initiative(actor, position)` 直接改变0—1位置并产生事件 | 会改变尚未行动者顺序；已行动者不会凭位移获得额外回合。本版7法术不新增推拉轴效果 |
| 胜负 | 全敌死亡即胜；英雄死亡即败；最多8轮 | 英雄死亡后不补结算燃烧；伤害、死亡与反应按事件先后执行 |

用户2026-10-30补充：所有角色AP用完才结束本轮。实现为“全员退出行动轴 → 本轮结束/燃烧结算 → 第N回合/AP与RP恢复”。只有AP尚余但装备序列已无可执行技能时，显示“待机”和放弃剩余AP，避免条件失败造成死锁。头像在动作效果结算完后退出，保证出手者的动作能看完整；AP恢复的提示即使4倍速也至少保留0.7秒。

反应附加条件：总是、自身生命<50%、RP≥2，消耗前检查。AP用完退出行动轴不会取消剩余RP的反应资格。炎盾是受击前减伤并向攻击者挂火；它还不是独立的“受伤后反击”事件系统。

优先目标为战前配置；开战后锁定。战斗中点击人物只查阅。设置中的开关控制是否允许点击怪物改变标记，不会自动清除已有标记；另有“清除优先目标”。

## 5. 系统与界面

| 入口 | 行为 |
|---|---|
| 4行动＋2反应槽 | 点击打开装备库，悬停看效果，点击候选再装备；“设置”编辑当前槽；左右箭头换顺序 |
| 固定右下详情 | 人物、技能、头像、主动/被动意图、燃烧标牌共用；人物数值和燃烧层数随播放更新 |
| 技能预览 | 在隔离状态中试放完整效果；结束或中途返回后恢复战前配置与资源 |
| 敌人头顶 | 显示主动/AP和被动/RP；悬停查效果；阵亡隐藏意图 |
| 单位信息卡 | 生命、AP、RP集中在各单位下方；旧全局状态条移除 |
| 反馈 | 实际技能名、反应名、燃烧与转移分别在所属单位飘字；名字、层数、伤害分层避让；当前行动槽高亮 |
| 战斗复盘 | 生命、回合数、峰值燃烧、跳过原因；同一进程内比较上一场生命与回合差值 |
| 控制 | 预设、开始、暂停、单步、1/2/4倍速、返回、保存；音效和减弱闪震在设置里 |

`balance_v2.tres` → `combat_rules.gd` 确定性事件流 → `tactical_view.gd` 播放 → `tactical_unit.gd` / `tactical_fx.gd` / `action_track.gd` 表现。预览与倍速不影响战斗计算。

`tactics_store.gd` 写 `user://tactics_v2.json`，保存4＋2槽、条件、目标、启停和优先目标模式。校验失败使用默认值，保留v1存档。当前不保存战斗进度与复盘历史。

## 6. 数值与实测取舍

| 参数 | 当前值 |
|---|---:|
| 法师生命 / 每轮 AP / RP | 120 / 4 / 3 |
| 每层燃烧 / 炎盾减伤 | 8 / 50%（剩余伤害向上取整） |
| 最大轮数 | 8 |

| 行动 | AP | 效果 |
|---|---:|---|
| 点燃 | 1 | 单体4伤，+1层 |
| 火墙 | 1 | 全体3伤，各+1层 |
| 爆燃 | 1 | 燃烧最多者4伤，其层数翻倍 |
| 火星 | 1 | 单体2伤，攻击前记录的层数复制给其他敌人 |
| 火葬 | 2 | 全体3伤，各自层数翻倍 |
| 炎爆 | 1 | 单体+2层，4伤并保留层数引爆；击杀转移 |
| 炼狱 | 2 | 全体+1层，保留层数引爆 |

| 反应 | RP | 固定时机与效果 |
|---|---:|---|
| 蓄能 | 1 | 首次施法前；该行动新增燃烧量×2 |
| 魔力恢复 | 1 | AP不足时恢复1AP，每轮最多一次 |
| 炎盾 | 1 | 受击前减伤50%，攻击者+1层，可在RP允许时重复 |

| 敌人 | 生命 / 攻击 | AP / RP | 被动 |
|---|---|---|---|
| 灰烬刺球 | 95 / 12 | 1 / 0 | 无 |
| 鹿面巡守 | 125 / 16 | 1 / 1 | 枯木护身：每轮首次直接攻击减伤50% |
| 枯枝稻人 | 155 / 20 | 1 / 0 | 无 |

实伤统计扣除过量部分，飘字展示该次伤害数值。数值是原型调试值，尚不能视为商业平衡。

无指定标记时的确定性比较（[24组原始结果](verification/v2-build-comparison.json)）：

| 四个行动 | 反应 | 回合 / 剩余生命 | 含义 |
|---|---|---|---|
| 火墙→爆燃→火星→炎爆 | 蓄能、炎盾 | 3 / 68 | 默认扩散方案 |
| 火墙→爆燃→炎爆→火星 | 蓄能、炎盾 | 3 / 76 | 同技能换序，先给源目标加层再复制 |
| 点燃→爆燃→炎爆→炎爆 | 蓄能、炎盾 | 3 / 92 | 单点及转移更保血 |
| 火墙→火葬→炼狱→点燃 | 蓄能、回能 | 2 / 52 | 更快，但缺少炎盾；最后点燃因AP不足跳过 |
| 火墙→爆燃→火星→炎爆 | 回能、炎盾 | 4 / 68 | 少了蓄能，持续时间更长 |

默认方案标记鹿面时剩42生命、标记稻人时剩44生命，说明“优先目标”需与爆燃的固定目标配合。只有一场敌情，尚不能据此推导全局最优构筑。

## 7. 美术与声音
暗黑剪纸、暖纸背景、朱红火焰。新增明确水平地面、15格图标图集、四个单位各4个独立姿势；Godot `SpriteFrames` 播放待机→蓄势→攻击→收势→待机，每套四张不同姿势，脚底依据透明图的实际边界对齐。

1600×900设计画布，实测1440×810。系统中文字体、四个合成提示音。素材来源与废弃迭代见 [素材与依赖](素材与依赖.md)。正式发布前仍需字体与跨平台适配、完整音频及表现打磨。

## 9. 里程碑与本轮优化
M0规则与M1战术体验版已具备可验证基础；下一阶段先用不同敌情验证策略迁移，再扩量。当前没有 Steam 发行包，也不承诺正式版周期。

本轮根据实测落地：AP预算提示、隔离预览、反应重复装备交换、同名预设可重新应用、固定详情实时刷新、战后与上一场比较。它们让玩家能更快提出并验证战术假设。新增敌情与更复杂反击留待下一轮设计，避免在单人制作初期同时扩大角色、内容和规则规模。

真人试玩仍需验证：能否一分钟内区分条件和目标；能否解释一次RP消耗；修改顺序后是否愿意再打一场。自动测试不能替代这些结论。
