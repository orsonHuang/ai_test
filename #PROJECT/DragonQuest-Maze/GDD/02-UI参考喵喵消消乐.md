# UI 参考：喵喵消消乐

## 1. 参考目标

以「喵喵消消乐」为 UI 蓝本，借鉴其清爽可爱、信息层级清晰、操作符合微信小游戏习惯的界面设计，为我们的勇者斗恶龙迷宫游戏建立 UI 规范。

参考维度：

- 整体配色与质感
- 主界面布局
- 关卡选择界面
- 游戏中 HUD
- 弹窗与结算
- 按钮与图标风格
- 字体与动效

---

## 2. 喵喵消消乐 UI 特征总结

| 维度 | 特征 |
|------|------|
| **风格** | 萌系卡通、圆角为主、轻质感 |
| **配色** | 暖色调打底（米白/浅黄/天空蓝），高亮按钮用橙/粉强调 |
| **主界面** | 顶部头像/金币/体力，中间大标题，底部功能按钮一字排开 |
| **关卡地图** | 卷轴式关卡选择，每关一个圆形节点，当前关有呼吸动画 |
| **游戏 HUD** | 顶部悬浮信息条：关卡数、步数/目标、道具按钮 |
| **弹窗** | 半透明遮罩 + 圆角卡片 + 大按钮，减少文字阅读量 |
| **反馈** | 点击缩放、连击飘字、过关满屏星星 |
| **图标** | 猫咪主题图标，外形圆润，表情可爱 |

> 注：由于未拿到喵喵消消乐实际截图，本参考基于典型三消休闲游戏 UI 范式。实际制作时建议截取目标参考游戏界面替换到本文档。

## 3. 本项目 UI 设计规范

### 3.1 整体风格

- **基调**：勇者斗恶龙式的明亮奇幻卡通。
- **圆角**：所有按钮、卡片、面板使用 16-24px 圆角。
- **描边**：关键元素保留 2-4px 深色描边，增强 DQ 卡通感。
- **阴影**：轻投影（y: 4px, blur: 8px, 透明度 15%），避免厚重。

### 3.2 配色方案

| 用途 | 色值 | 说明 |
|------|------|------|
| 主背景 | `#FFF8E7` | 暖米色，像羊皮纸/营地 |
| 主按钮 | `#FF8C42` | 活力橙，用于开始/继续/确定 |
| 次要按钮 | `#4ECDC4` | 青绿色，用于返回/取消/设置 |
| 危险/失败 | `#FF6B6B` | 红色，用于重开/警告 |
| 成功/金币 | `#FFD93D` | 金黄，用于星星、金币、奖励 |
| 草地绿 | `#7CB342` | 关卡底板主色 |
| 石墙灰 | `#8D8D8D` | 石墙描边与阴影 |
| 文字主色 | `#4A4A4A` | 深灰，避免纯黑刺眼 |

### 3.3 字体规范

- **标题**：圆润卡通字体（如站酷快乐体、优设标题黑）。
- **正文**：系统黑体 / PingFang SC / HarmonyOS Sans。
- **数字**：等宽或粗圆数字字体，用于步数、分数、金币。
- **字号**：
  - 大标题 48-64px
  - 关卡标题 36px
  - 按钮文字 32-36px
  - HUD 数字 40px
  - 提示文字 24px

## 4. 界面拆解

### 4.1 启动页 / Logo 页

- 中央：游戏 Logo + 勇者剪影 + 魔王剪影。
- 底部：版本号 + 版号信息（微信小游戏需要）。
- 动效：Logo 弹跳进入，背景有轻微云朵飘动。

### 4.2 主界面

```
┌─────────────────────────────────────┐
│  [头像]  勇者 Lv.3      [金币]  999  │
│                                     │
│          勇者斗恶龙迷宫              │
│         （大标题 + 魔王剪影）         │
│                                     │
│        [开始冒险] 大按钮             │
│                                     │
│  [关卡] [排行榜] [设置] [商店]       │
└─────────────────────────────────────┘
```

**元素说明**：

- 顶部左侧：玩家头像 + 等级，点击进个人中心。
- 顶部右侧：金币数量，点击进商店。
- 中央大标题：使用描边卡通字体，配合动态小怪物装饰。
- 底部按钮：横向一字排开，图标 + 文字，等分宽度。

### 4.3 关卡选择界面

```
┌─────────────────────────────────────┐
│  < 返回          选择关卡            │
├─────────────────────────────────────┤
│                                     │
│   ① → ② → ③ → ④ → ⑤            │
│        ↓                            │
│  ⑩ ← ⑨ ← ⑧ ← ⑦ ← ⑥            │
│        ↓                            │
│  ⑪ → ⑫ → ⑬ → ⑭ → ⑮            │
│                                     │
└─────────────────────────────────────┘
```

**元素说明**：

- 关卡节点：圆形按钮，内部显示关卡数字。
- 已通关：金色星星标记（1-3 星根据步数评级）。
- 当前关：节点放大 + 呼吸光效 + 勇者小图标站在上面。
- 未解锁：灰色锁图标。
- 横向滚动地图，模拟冒险路线。

### 4.4 游戏主界面（HUD）

```
┌─────────────────────────────────────┐
│  < 返回   关卡 12   [步数]  14/20   │
│                                     │
│                                     │
│          (迷宫棋盘区域)              │
│                                     │
│                                     │
│  [撤销]    [提示]    [道具]          │
└─────────────────────────────────────┘
```

**元素说明**：

- 顶部信息条：半透明悬浮，显示关卡数、当前步数 / 限制步数。
- 步数低于 5 时数字变红并闪烁。
- 底部工具栏：
  - 撤回：撤销上一步。
  - 提示：显示下一步推荐路径（看广告或消耗金币）。
  - 道具：打开道具面板（炸弹、隐身斗篷等）。

### 4.5 守卫视野提示

- 守卫正面视野格显示**红色半透明扇形/直线**。
- 背后一格显示**绿色脚印图标**，提示玩家可以绕后击晕。
- 长按守卫 0.5 秒：视野范围高亮，便于规划。

### 4.6 胜利结算界面

```
┌─────────────────────────────────────┐
│          通关成功！                  │
│         ⭐ ⭐ ⭐                    │
│                                     │
│      用时：  00:32                   │
│      步数：  18/20                   │
│      奖励：  +50 金币                │
│                                     │
│   [下一关]        [重玩]             │
│   (双倍奖励 看广告)                  │
└─────────────────────────────────────┘
```

**元素说明**：

- 大标题 + 满屏星星动画。
- 根据步数评级：
  - 最优步数内：3 星
  - 中等步数：2 星
  - 勉强通关：1 星
- 底部主按钮「下一关」，次按钮「重玩」。
- 可选「看广告双倍金币」悬浮标签。

### 4.7 失败界面

```
┌─────────────────────────────────────┐
│          被发现了！                  │
│       （守卫抓住勇者动画）            │
│                                     │
│      失败原因：闯入龙守卫视野         │
│                                     │
│   [再看一次提示]  [重新开始]         │
│   (分享复活  继续本关)               │
└─────────────────────────────────────┘
```

**元素说明**：

- 显示具体失败原因，帮助玩家理解规则。
- 提供「分享复活」或「看广告复活」选项。
- 动画：守卫扑向勇者，屏幕震动。

### 4.8 设置 / 暂停弹窗

```
┌─────────────────────────────────────┐
│           暂停                       │
│                                     │
│    [音乐] 开 / 关                    │
│    [音效] 开 / 关                    │
│    [震动] 开 / 关                    │
│                                     │
│   [继续]    [重开]    [返回主菜单]   │
└─────────────────────────────────────┘
```

## 5. 图标规范

所有图标统一风格：

- 尺寸：64×64px（标准）、128×128px（高清屏）。
- 描边：2-3px 深色描边。
- 圆角：图标外形圆润，无尖锐棱角。
- 配色：2-3 个主色，不超过 4 色。

**图标清单**：

| 图标 | 用途 |
|------|------|
| 勇者头像 | 玩家头像、个人中心 |
| 金币袋 | 货币显示、商店 |
| 星星 | 通关评级 |
| 锁 | 未解锁关卡 |
| 撤回箭头 | 撤销操作 |
| 灯泡 | 提示 |
| 宝箱 | 奖励、商店 |
| 齿轮 | 设置 |
| 盾牌 | 防御/道具 |
| 闪电 | 能量/体力 |

## 6. 动效规范

| 场景 | 动效 |
|------|------|
| 按钮点击 | 缩放 0.95 → 1.0，时长 100ms |
| 角色移动 | 平滑位移 200ms，带轻微弹跳 |
| 击晕守卫 | 守卫摇晃 → 倒地 → 星星旋转 |
| 传送 | 角色缩小消失 → 出口放大出现 |
| 击杀魔王 | 冲刺 + 闪白 + 魔王倒下 + 宝箱弹出 |
| 胜利结算 | 星星依次点亮，金币飞入顶部栏 |
| 失败 | 屏幕震动 300ms，红色渐变覆盖 |

---

## 7. 微信小游戏特殊适配

- 顶部保留微信胶囊按钮安全区，HUD 下移 88px。
- 分享按钮使用微信标准分享图标。
- 激励视频按钮统一文案：「看视频获取奖励」。
- 排行榜使用微信开放数据域绘制，不遮挡主界面。
