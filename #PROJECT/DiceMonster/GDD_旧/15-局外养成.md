# 15 · 局外养成

> 模块定位：定义技能树永久升级系统。
> 玩家通过挑战获得骰子碎片（meta 货币），在技能树中购买永久属性加成。
> 参考 Rocket Rats 的局外养成循环：跑图获得货币 → 技能树购买永久属性加成。

## 1. 核心循环

```
挑战（尖塔地图）
  │
  ├─→ 战斗获得 骰子碎片（局内）
  ├─→ Boss 获得 大量骰子碎片
  └─→ 通关/放弃 → 结算
        │
        ▼
骰子碎片（meta）存入玩家账户
        │
        ▼
玩家大厅 → [养成] → 技能树
        │
        ▼
消耗骰子碎片 → 解锁/升级技能节点 → 永久生效
```

## 2. 货币：骰子碎片

### 2.1 获取途径

| 来源 | 数量 | 条件 |
|------|------|------|
| 普通怪物战斗 | 3~5 | 每次击败 |
| 精英怪物战斗 | 8~12 | 每次击败 |
| Boss 战斗 | 20~30 | 每次击败 |
| 通关最终 Boss | 50（额外奖励） | 通关 |

### 2.2 转换规则

- 局内获得的骰子碎片在挑战结束（通关或放弃）时 **1:1 转入** 局外 meta 货币。
- 中途放弃挑战：已获得的骰子碎片 **保留 50%**（惩罚机制，鼓励通关）。

### 2.3 用途

| 用途 | 详见 |
|------|------|
| 技能树升级 | 本文件 §4 |
| 商店购买 | `16-商店系统.md` |

## 3. 技能树结构

### 3.1 树形布局

技能树分为 **3 大分支**，从中心向外扩展：

| 分支 | 方向 | 主题 |
|------|------|------|
| 生存分支 | 左 | HP、回复、防御 |
| 策略分支 | 中 | 重摇次数、骰子面数、骰子池 |
| 输出分支 | 右 | 伤害加成、暴击、牌型加成 |

```
                    [起点]
                   ╱      ╲
            [HP+10]      [伤害+5%]
              │    ╲    ╱    │
           [HP+20]  [重摇+1]  [伤害+10%]
              │    ╱    ╲    │
           [HP+30]  [面数+1]  [伤害+15%]
              │    ╲    ╱    │
           [全回复]  [骰子+1]  [暴击]
```

### 3.2 节点规则

| 属性 | 说明 |
|------|------|
| 解锁条件 | 前置节点已解锁 + 足够骰子碎片 |
| 最大等级 | 每个节点可升级 1~5 级（视节点而定） |
| 升级费用 | 每级递增（如 10/20/40/80/160） |
| 生效方式 | 立即永久生效，所有后续挑战都享受加成 |
| 重置 | 不支持重置（避免频繁调整破坏平衡） |

## 4. 技能节点详细列表

### 4.1 生存分支

|----|------|------|----------|----------|

## 5. 加成生效时机

| 类型 | 生效时机 | 计算方式 |
|------|----------|----------|
| 最大 HP | 挑战开始时 | `base_hp + skill_hp_bonus` |
| 伤害加成 | 每次伤害结算 | 作为额外乘区（独立于装备和能力） |
| 重摇次数 | 每回合开始时 | `base_rerolls + skill_reroll_bonus` |
| 初始骰子 | 挑战开始时 | 加入初始骰子池 |
| 暴击 | 伤害结算时 | 独立判定，在最终伤害上 ×2 |

### 5.1 伤害公式整合

```gdscript
# 完整伤害公式（含局外养成）
skill_mult = 1.0
for skill in unlocked_skills:
    if skill.type == "dmg_percent":
        skill_mult += skill.value

# 暴击判定
crit_mult = 1.0
if crit_enabled and rng.randf() < crit_chance:
    crit_mult = 2.0

final_damage = floor(dice_sum * hand_base_mult * ability_mult * equip_mult * skill_mult * crit_mult)
```

## 6. 技能树界面

### 6.1 布局

```
┌─────────────────────────────────────────┐
│  [骰子碎片: 💎 500]       [返回]         │
│                                         │
│  ┌─────────────────────────────────┐    │
│  │  生存 │  策略  │  输出           │    │
│  │  (左) │ (中)  │  (右)           │    │
│  │                                 │    │
│  │     ● ← 已解锁 (亮色)           │    │
│  │     ○ ← 可解锁 (白色边框)       │    │
│  │     ✕ ← 未解锁 (灰色)           │    │
│  └─────────────────────────────────┘    │
│                                         │
│  [选中节点详情]                          │
│  名称: 生命强化 I                        │
│  等级: 3/5                              │
│  效果: 最大 HP +30                      │
│  升级费用: 💎 80                         │
│  [升级]                                  │
└─────────────────────────────────────────┘
```

### 6.2 交互

| 操作 | 行为 |
|------|------|
| 点击已解锁节点 | 显示当前等级和效果 |
| 点击可解锁节点 | 显示升级费用和效果，出现"升级"按钮 |
| 点击未解锁节点 | 显示"需要先解锁前置节点" |
| 点击"升级" | 消耗骰子碎片，升级节点，播放动画 |

## 7. 数值平衡原则

| 原则 | 说明 |
|------|------|
| 早期快速成长 | 前几个技能费用低（10~30），让玩家快速感受到成长 |
| 后期递减 | 高等级技能费用指数增长，避免过早满级 |
| 分支独立 | 3 个分支可以独立推进，不需要全部点满才能推进另一条 |
| 总投入 | 全部技能满级约需 2000~3000 骰子碎片 |
| 单次挑战收益 | 一次完整通关约获得 150~250 骰子碎片 |
| 预计满级次数 | 约 10~20 次完整通关 |
