# 02 · 骰子系统

> 模块定位：定义骰子类型、**词条属性**、骰子池管理、投掷/选子/重摇行为，以及骰子作为**掉落奖励**（类杀戮尖塔遗物）的获取与替换机制。
> 玩家默认持有 **5 颗无词条 d6**，通过击败怪物可在奖励选择中获得带词条的骰子替换池中已有骰子。

## 1. 骰子类型

| 骰子 | 面数 | 点数范围 | 单颗期望 | 特点 |
|------|------|----------|----------|------|
| d4 | 4 | 1~4 | 2.5 | 低方差，利于凑顺子（低段） |
| d6 | 6 | 1~6 | 3.5 | 均衡，默认骰 |
| d8 | 8 | 1~8 | 4.5 | 中高方差，伤害与顺子兼顾 |
| d12 | 12 | 1~12 | 6.5 | 高方差，纯伤害向 |

> 所有骰子点数均为均匀分布，各面等概率。

## 2. 词条系统

### 2.1 概述

每颗骰子除面数外，可附带 **1 条词条**（Affix）。词条赋予骰子特殊能力，是构筑策略的核心维度。

- **默认骰子**：无词条（`affix: null`）
- **掉落骰子**：带 1 条词条
- 骰子 = **面数** + **词条**，两者共同决定骰子的价值

### 2.2 词条类型总览

| 词条 id | 名称 | 效果 | 适用场景 | 稀有度 |
|---------|------|------|----------|--------|
| `straight_boost` | 顺子之力 | 参与顺子结算时，该骰子点数 **+10** | 顺子流 | common |
| `pair_mult` | 对子加成 | 参与对子结算时，该骰子点数 **×1.5** | 对子流 | rare |
| `reroll_trigger` | 重摇触发 | 投掷出 1 时，自动重投该骰子 **1 次** | 通用 | common |
| `flat_bonus` | 固定增伤 | 被选中时，额外 **+3** 伤害（不计入牌型） | 通用 | common |
| `straight_mult` | 顺子倍率 | 参与顺子结算时，该骰子点数 **×2** | 顺子流 | epic |
| `high_card_boost` | 散牌强化 | 作为散牌最大骰子时，点数 **+5** | 散牌流 | rare |
| `three_boost` | 三条强化 | 参与三条结算时，该骰子点数 **+5** | 三条流 | rare |
| `max_face_reroll` | 满值重投 | 投出非最大面时，可消耗 1 次重摇次数强制重投该骰子 | 通用 | epic |

> 词条持续生效，不需要额外激活。词条效果在伤害计算阶段应用（见 `03-牌型判定.md`）。

### 2.3 词条叠加规则

- 每颗骰子最多 **1 条词条**（无论来源：掉落或商店升级）。
- 新骰子替换旧骰子时，旧骰子的词条**随旧骰子消失**。
- 不同骰子的词条**各自独立生效**（如 2 颗骰子都有 `straight_boost`，则两颗都 +10）。
- **不存在双词条骰子**：无论掉落还是商店升级，每颗骰子只能拥有 0 或 1 条词条。
- 商店升级只能给**无词条**骰子赋予词条，已有词条的骰子不可再次升级。

## 3. 数据结构

```gdscript
class Die:
    faces: int              # 面数：4 / 6 / 8 / 12
    value: int              # 当前点数：1~faces
    is_selected: bool       # 是否被选为本次出牌
    affix: StringName       # 词条 id，无词条时为 &""
    affix_data: Dictionary  # 词条参数（如 { "bonus": 10 }）

class DicePool:
    dice: Array[Die]        # 固定 5 颗，初始全为无词条 d6
```

## 4. 基础规则

| 行为 | 规则 | 备注 |
|------|------|------|
| 骰子池大小 | 固定 **5 颗** | 不随关卡变化 |
| 初始骰子池 | 5 × d6（**无词条**） | 游戏开始时 |
| 投掷 | **全部 5 颗**同时投掷 | 每颗按各自面数独立随机 |
| 选子数量 | **固定 3 颗** | 必须选满 3 颗才能确定 |
| 重摇对象 | 仅未选中的骰子（2 颗） | 选中的锁住，不参与重摇 |
| 重摇随机 | 按各自面数独立随机 | d8 重摇仍为 1~8 |
| 重摇次数 | 从 `levels.json` 读取基础值，再由肉鸽能力修正 | 见 `11-肉鸽能力.md` §3 |

### 4.1 重摇次数计算
```gdscript
rerolls_left = base_rerolls(level_index) + bonus_from_abilities("reroll")
```
- 每次进入新的"投掷"时刷新（普通模式：同一回合内重摇消耗后不再恢复；无尽模式：每次投掷都恢复）。

### 4.2 词条触发时机

| 词条 | 触发阶段 | 说明 |
|------|----------|------|
| `reroll_trigger` | 投掷阶段（投掷后立即判定） | 出 1 自动重投，不消耗重摇次数 |
| `max_face_reroll` | 决策阶段（玩家主动操作） | 消耗 1 次重摇次数，重投该骰子 |
| 其余词条 | 伤害计算阶段（确定出牌后） | 根据牌型应用词条效果 |

## 5. 骰子作为掉落奖励（类遗物系统）

### 5.1 设计理念

骰子掉落**类似杀戮尖塔的遗物系统**：
- 击败怪物后，骰子**可能出现在奖励选择界面**中
- 骰子与肉鸽能力**共享选择界面**，玩家统一选择
- 每颗掉落骰子都有**面数 + 词条**，玩家需评估是否值得替换现有骰子

### 5.2 奖励选择界面

击败怪物后进入 REWARD 阶段：

```
┌─────────────────────────────────────────┐
│           选择一项奖励                    │
│                                         │
│  ┌───────┐  ┌───────┐  ┌───────┐       │
│  │ 能力A │  │ 骰子  │  │ 能力C │       │
│  │对子+30%│  │ d8    │  │重摇+1 │       │
│  │       │  │顺子之力│  │       │       │
│  │(common)│  │(rare) │  │(common)│      │
│  └───────┘  └───────┘  └───────┘       │
└─────────────────────────────────────────┘
```

- 3 个选项中，**0~1 个是骰子**，其余为肉鸽能力
- 骰子出现概率由掉落权重控制（见 §5.4）
- 玩家选择骰子后，进入**替换界面**选择要替换的已有骰子

### 5.3 替换流程

1. 玩家在奖励界面选择了一颗骰子
2. 进入替换界面：
   - 上方显示新骰子（面数 + 词条 + 期望评估）
   - 下方显示当前 5 颗骰子（可点击选择要替换的 1 颗）
   - **确认替换** / **放弃**（放弃则新骰子消失，奖励选择作废）
3. 新骰子替换被选中的旧骰子，骰子池仍保持 5 颗

> 放弃选项存在的原因：可能新骰子不如现有骰子（如已有 d12 满值铠甲，掉落 d4 顺子之力价值较低）。

### 5.4 掉落规则

| 项目 | 规则 |
|------|------|
| 骰子出现概率 | 每次奖励选择中，骰子出现的概率为 **40%**（可配置） |
| 面数权重 | d6: 40% / d8: 40% / d12: 20%（随关卡递进调整） |
| 词条权重 | 按词条稀有度权重抽取（见 §2.2） |
| 数量 | 每次奖励界面最多 **1 颗骰子** |

#### 面数权相关说明
- d4 不作为掉落奖励（面数太低），但保留类型定义供特殊能力/事件使用
- 关卡后期可逐步提高 d12 概率（通过 `levels.json` 配置）

#### 词条掉落权重

| 稀有度 | 权重 | 说明 |
|--------|------|------|
| common | 55% | `straight_boost`, `reroll_trigger`, `flat_bonus` |
| rare | 35% | `pair_mult`, `high_card_boost`, `three_boost` |
| epic | 10% | `straight_mult`, `max_face_reroll` |

### 5.5 骰子池演进示例

```
初始：[d6(无), d6(无), d6(无), d6(无), d6(无)]

击败 m_02 后奖励出现 d8[顺子之力] → 选择替换第 3 颗
→ [d6(无), d6(无), d8(顺子之力), d6(无), d6(无)]

击败 m_05 后奖励出现 d6[对子加成] → 选择替换第 1 颗
→ [d6(对子加成), d6(无), d8(顺子之力), d6(无), d6(无)]

击败 m_07 后奖励出现 d12[固定增伤] → 选择替换第 4 颗
→ [d6(对子加成), d6(无), d8(顺子之力), d12(固定增伤), d6(无)]
```

## 6. 商店升级骰子词条

### 6.1 概述

玩家可在**商店**中为骰子**赋予词条**，使无词条骰子获得 1 条词条。

- 每颗骰子最多 **1 条词条**（不可叠加双词条）
- 升级操作：选择 1 颗无词条骰子 → 随机获得 1 条词条 → 支付金币
- 已有词条的骰子**不可再次升级**

### 6.2 规则

| 项目 | 规则 |
|------|------|
| 触发时机 | 奖励选择后 / 特定商店关卡 |
| 升级对象 | 骰子池中**无词条**的骰子 |
| 词条获取 | 从词条池中**随机**抽取 1 条（权重见 §5.4 词条掉落权重） |
| 费用 | 按词条稀有度定价（见 `08-数值与平衡.md` §9.2） |
| 限制 | 每颗骰子只能升级 1 次（获得 1 条词条后不可再升级） |
| 不可逆 | 升级后词条不可移除或替换 |

### 6.3 设计意图

- 为玩家提供**主动构筑**路径（不完全依赖掉落随机性）
- 金币消耗的重要出口，与装备系统共享经济体系
- 无词条骰子（如默认 d6）可通过升级获得战略价值

## 7. 策略维度

### 7.1 面数策略（保留）

| 骰子 | 策略价值 |
|------|----------|
| d4 | 低点数利于凑顺子（1-2-3-4 连续段），但伤害天花板低 |
| d6 | 均衡，万金油 |
| d8 | 伤害提升 + 保留一定顺子能力 |
| d12 | 纯伤害向，对子/三条伤害极高，但难凑顺子 |

### 7.2 词条策略（新增）

| 词条 | 构筑方向 | 搭配建议 |
|------|----------|----------|
| `straight_boost` | 顺子流核心 | 搭配 d4/d6 凑低段顺子，+10 使顺子伤害飞跃 |
| `pair_mult` | 对子流核心 | 搭配 d8/d12 高点数骰，×1.5 收益更大 |
| `reroll_trigger` | 通用稳定 | 任何骰子均可，出 1 自动重投提升下限 |
| `flat_bonus` | 通用万金油 | 任何骰子均可，+3 稳定增伤 |
| `straight_mult` | 顺子流终极 | 搭配 d8 高点数顺子，×2 爆发极高 |
| `high_card_boost` | 散牌兜底 | 搭配 d12，散牌时也能有可观伤害 |
| `three_boost` | 三条流核心 | 搭配 d12，三条时点数+5 伤害爆炸 |
| `max_face_reroll` | 通用高阶 | 搭配 d12，追求满值的玩家可主动重投 |

### 7.3 面数 × 词条的决策空间

有趣的决策示例：
- 掉落 `d8[顺子之力]` vs 已有 `d12(无词条)` → 顺子流选 d8，纯伤害流留 d12
- 掉落 `d6[对子加成]` vs 已有 `d8(无词条)` → 对子流选 d6，其他留 d8
- 掉落 `d12[重摇触发]` vs 已有 `d6(顺子之力)` → 看当前构筑方向

> 面数 × 词条 = 大量有意义的决策，这是构筑深度的核心来源。

## 8. 顺子定义（多面骰适配）
- 3 颗点数连续即可，**不要求同面数骰子**。
- 例：d6 出 2、d8 出 3、d12 出 4 → 顺子 `2-3-4`。
- 词条效果在顺子判定后应用：如 `straight_boost` 在顺子确认后才 +10。
- 顺子的点数和取决于具体骰面值 + 词条效果。

## 9. 交互行为

### 8.1 选中/取消
- 玩家点击某颗骰子 → 在 `selected` / `unselected` 之间切换。
- 选中状态：视觉上"浮起 + 高亮边框 + 上方挂点数牌"。
- 取消选中：恢复原位。
- **词条标识**：有词条的骰子在角落显示词条图标。

### 8.2 重摇
- 玩家点击"重摇"按钮 → **未选中的骰子** 重新投掷。
- 选中的骰子保持不动（视觉上明确锁定）。
- 重摇次数 -1；归 0 时按钮置灰。
- `reroll_trigger` 词条骰子出 1 时自动重投，不消耗重摇次数。
- `max_face_reroll` 词条骰子可在决策阶段由玩家点击触发重投，消耗 1 次重摇次数。

### 8.3 确定
- 玩家点击"确定"按钮 → 进入 RESULT 阶段。
- 前置条件：`selected_count == 3`（必须选满 3 颗）。
- 未选满 3 颗时，"确定"按钮置灰 + 提示"请选择 3 颗骰子"。

## 10. 无尽模式下的特殊规则
- 每次点击"投掷"按钮时，**重摇次数完全重置**为无尽模式配置值。
- 不存在"怪物反击"或"回合失败"，只计算 10 次投掷内的总伤害。
- 骰子池（含词条）在普通模式 → 无尽模式之间保持不变。

## 11. 与肉鸽能力的联动
- **增加重摇次数**：直接 `+N` 到 `rerolls_left` 上限。
- **最大面伤害翻倍**（`dice_max_face`）：见 `11-肉鸽能力.md`，与词条效果独立计算。
- 能力与词条效果**乘法叠加**（能力提供全局倍率，词条提供骰子级倍率）。

## 12. 视觉规范（占位）

| 元素 | 状态 | 表现 |
|------|------|------|
| d4 骰子 | 始终 | 三角形轮廓 / 绿色底 |
| d6 骰子 | 始终 | 正方形轮廓 / 蓝色底 |
| d8 骰子 | 始终 | 菱形轮廓 / 紫色底 |
| d12 骰子 | 始终 | 五边形轮廓 / 金色底 |
| 词条标识 | 有词条时 | 骰子右下角小图标（如⚡=顺子之力，×=对子加成） |
| 无词条标识 | 无词条时 | 右下角无图标 / 灰色边框 |
| 骰子本体 | 未选 | 放在底部一排，缩略图样式 |
| 骰子本体 | 选中 | 浮起到怪物半身像区域周围，半透明叠放 |
| 骰子点数 | 始终 | 居中显示点数数字 |
| 面数标识 | 始终 | 骰子角落小字显示"d4"/"d6"等 |

## 13. 边界与异常
- 玩家连续点击同一颗骰子：在选中↔未选中间切换。
- 玩家在重摇动画过程中点击骰子：忽略输入（锁定）。
- 重摇次数耗尽但仍想重摇：UI 禁用 + 震动反馈（见 07）。
- 替换界面：未选择替换目标时确认按钮置灰。
- 放弃替换：新骰子消失，本次奖励作废（需二次确认弹窗）。
- `reroll_trigger` 在一回合内可触发多次（每颗骰子独立判定）。
- 骰子池已满 5 颗且全为高点数带词条骰子：掉落低价值骰子时玩家可选择放弃。
- 商店升级：已有词条的骰子不可再次升级（按钮置灰）。
- 商店升级：金币不足时确认按钮置灰。
