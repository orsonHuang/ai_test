# 07 · 音效与反馈

> 模块定位：所有"看得见 + 听得见"的反馈层，让操作有"打击感"。

## 1. 反馈类型总览

| 反馈层 | 通道 | 触发 | 强度 |
|--------|------|------|------|
| 视觉 | 飘字、闪红、震屏 | 命中、牌型达成、状态切换 | 强 |
| 听觉 | 音效 | 投掷、命中、牌型达成、怪物死亡 | 中 |
| 触觉 | 震动 | 投掷、命中、按钮禁用 | 弱 |

## 2. 音效清单

| 名称 | 时长 | 触发点 | 备注 |
|------|------|--------|------|
| `dice_roll.mp3` | 0.5~1 s | 投掷/重摇开始 | 骰子在桌面上滚动 |
| `dice_stop.mp3` | 0.2 s | 投掷结果揭晓 | "啪"落地声 |
| `select.mp3` | 0.1 s | 选中/取消骰子 | 短促"嗒" |
| `reroll.mp3` | 0.3 s | 点击"重摇" | UI 反馈 |
| `hit_small.mp3` | 0.4 s | 散/对子命中 | 轻击 |
| `hit_big.mp3` | 0.6 s | 顺子/葫芦/四条/五条 | 重击 + 低频 |
| `monster_die.mp3` | 1.0 s | 怪物 HP=0 | 碎裂 + 渐隐 |
| `combo_five.mp3` | 1.2 s | 五条达成 | 特殊音效 |
| `bgm_combat.ogg` | 循环 | 战斗中 | 可分层（低紧张 / 高紧张） |

## 3. 牌型触发的强化反馈
| 牌型 | 视觉强化 | 听觉强化 |
|------|----------|----------|
| 散牌 | 普通飘字 | hit_small |
| 对子 | 飘字放大 1.2× | hit_small |
| 两对 | 飘字 + 数字抖动 | hit_small ×2 |
| 三条 | 飘字 + 怪物闪红 2 次 | hit_big |
| 葫芦 | 飘字 + 屏幕轻微震 | hit_big + 短和弦 |
| 顺子 | 飘字 + 屏幕震 + 慢镜 0.3s | hit_big + 顺子专属音 |
| 四条 | 飘字 + 屏幕震 + 粒子爆裂 | hit_big + 低频 |
| 五条 | 全屏闪光 + 慢镜 0.5s + 大量粒子 | combo_five |

## 4. 震动（仅移动端）
| 事件 | 强度 | 时长 |
|------|------|------|
| 投掷 | 弱 | 30 ms |
| 命中 | 中 | 80 ms |
| 五条达成 | 强 | 200 ms |
| 按钮禁用 | 弱 | 20 ms |

> iOS/Android 通过 `Input.vibrate_handheld()` 触发；微信小游戏走 `wx.vibrateShort`。

## 5. 屏幕震动（视觉）
- 仅 RESULT 阶段，葫芦及以上触发。
- 实现：UI 节点 `position` 短促抖动 ±4 px，0.2 s 内衰减。
- 关闭选项：设置里可关"屏幕震动"。

## 6. 资源来源
