# 05 · 关卡与节奏

> 模块定位：定义关卡结构、难度曲线和节奏控制。
> 主线模式改为尖塔地图（3 层树状结构）；无尽模式保留为独立模式。
> 旧版线性 10 怪结构已废弃，详见 `10-扩展与待定.md`。

## 1. 模式总览

| 模式 | 结构 | 目标 | 解锁条件 |
|------|------|------|----------|
| **尖塔挑战**（主线） | 3 层尖塔地图 + 树状路线 | 击败最终 Boss 通关 | 默认解锁 |
| **无尽模式** | 连续战斗，难度递增 | 追求最高分数 | 首次通关尖塔挑战 |

## 2. 尖塔挑战（主线）

### 2.1 三层结构

| 层 | 名称 | 节点数 | 终点 | 难度 |
|----|------|--------|------|------|
| 第 1 层 | 普通层 | ~12 中间节点 | 层 Boss | 入门 |
| 第 2 层 | 普通层 | ~12 中间节点 | 层 Boss | 中等 |
| 第 3 层 | 最终层 | ~12 中间节点 | 最终 Boss | 高难 |

> 地图详细结构见 `14-尖塔地图.md`。

### 2.2 节点类型分布（每层）

| 节点类型 | 数量 | 说明 |
|----------|------|------|
| 怪物 | 4~6 | 普通战斗 |
| 精英 | 2~3 | 强化战斗，高奖励 |
| 商店 | 2~3 | 购买骰子/消耗品 |
| 休息 | 2~3 | 回复/强化 |
| 事件 | 1~2 | 随机事件 |
| 随机 | 0~1 | 随机类型 |
| Boss | 1 | 层终点 |

### 2.3 玩家路径长度

| 属性 | 值 |
|------|------|
| 每层经过节点数 | 8~10 个（含起点到 Boss） |
| 三层总节点数 | 24~30 个 |
| 其中战斗节点 | 12~18 个（怪物 + 精英 + Boss） |
| 预计单局时长 | 30~60 分钟 |

## 3. 难度曲线

### 3.1 怪物数值递增

| 层 | 怪物 HP 范围 | 怪物伤害范围 | 精英 HP | 精英伤害 |
|----|-------------|-------------|---------|---------|
| 第 1 层 | 30~60 | 5~10 | 80~120 | 8~15 |
| 第 2 层 | 60~100 | 10~18 | 120~180 | 15~25 |
| 第 3 层 | 100~160 | 18~28 | 180~260 | 25~35 |

### 3.2 Boss 数值

| Boss | HP | 伤害 | 特殊机制 |
|------|------|------|----------|
| 第 1 层 Boss | 150 | 12~18 | 每 3 回合投骰子攻击 |
| 第 2 层 Boss | 220 | 18~28 | 每回合改变牌型倍率 |
| 第 3 层最终 Boss | 350 | 25~35 | 阶段制（P1 → P2 增强） |

> 具体数值见 `08-数值与平衡.md`。

### 3.3 玩家成长曲线

| 阶段 | 骰子池 | 预期单次伤害 | 累计 HP 压力 |
|------|--------|-------------|-------------|
| 第 1 层开始 | 5 颗 d6 | 15~25 | 低 |
| 第 1 层结束 | 6~8 颗混合 | 30~50 | 中（Boss 前需休息） |
| 第 2 层开始 | 继承 + 新获取 | 35~55 | 中 |
| 第 2 层结束 | 8~10 颗混合 | 50~80 | 高 |
| 第 3 层开始 | 继承 | 55~85 | 高 |
| 第 3 层结束 | 10~12 颗混合 | 80~120 | 极高（最终 Boss） |

## 4. 节奏控制

### 4.1 张弛节奏

```
第 1 层:
  怪物 → 怪物/事件 → 休息 → 精英 → 商店 → 怪物 → 休息 → Boss
  (松)    (中)       (松)   (紧)   (松)   (中)   (松)   (紧)

第 2 层:
  怪物 → 精英 → 事件 → 怪物 → 休息 → 商店 → 精英 → 休息 → Boss
  (中)   (紧)   (松)   (中)   (松)   (松)   (紧)   (松)   (紧)

第 3 层:
  精英 → 怪物 → 商店 → 怪物 → 休息 → 精英 → 怪物 → 休息 → 最终 Boss
  (紧)   (中)   (松)   (中)   (松)   (紧)   (中)   (松)   (极紧)
```

### 4.2 休息节点分布原则

- Boss 前至少 1 个休息节点（给玩家回复机会）。
- 连续 2 个战斗节点后应有 1 个非战斗节点。
- 精英节点前后各 1 个休息/商店节点。

### 4.3 HP 压力管理

| 参数 | 值 | 说明 |
|------|------|------|
| 玩家基础 HP | 100 | 含技能树加成 |
| 层间回复 | 20% 最大 HP | 击败 Boss 后 |
| 休息节点回复 | 30% 最大 HP | 二选一 |
| 治疗药水 | 25 HP | 局内商店购买 |

## 5. 无尽模式

> 独立模式，不使用尖塔地图。

### 5.1 规则

| 项目 | 规则 |
|------|------|
| 结构 | 连续战斗，无地图，无路线选择 |
| 怪物生成 | 按 `04-战斗与怪物.md` §3 难度递增规则 |
| 难度 | 无上限，每 10 只怪物大幅提升 |
| 结束条件 | 玩家 HP ≤ 0 |
| 奖励 | 无骰子碎片（仅统计分数） |
| 排名 | 按击杀怪物数 / 存活回合数排名 |

### 5.2 无尽模式独有规则

| 项目 | 规则 |
|------|------|
| 骰子池 | 使用尖塔挑战中的骰子池（继承上次挑战配置）或默认池 |
| 能力 | 不保留局内能力，每次重新开始 |
| 局外养成 | 技能树加成生效 |
| 装备 | 装备加成生效 |

### 5.3 无尽模式入口

- 玩家大厅 → 挑战 → 选择"无尽模式"标签页 → 开始。
- 仅在首次通关尖塔挑战后解锁。
