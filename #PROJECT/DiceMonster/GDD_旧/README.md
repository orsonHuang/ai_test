## 核心设计概要

### 游戏类型
骰子 + 牌型 + 肉鸽 + 杀戮尖塔式地图

### 核心循环
掷骰 → 选骰 → 出牌 → 奖励 → 选择路径 → 下一节点

### 模式
- **尖塔挑战**（主线）：3 层尖塔地图，树状路线选择，击败最终 Boss 通关
- **无尽模式**：连续战斗，难度递增，追求最高分

### 成长系统
- **局内**：肉鸽能力（3选1）+ 骰子获取
- **局外**：技能树永久升级 + 装备（商店购买）

### 页面流
```
开始页面 → 玩家大厅 → 尖塔地图 → 战斗/事件/商店/休息
                ↓
          养成(技能树) / 商店(局外) / 装备
```
