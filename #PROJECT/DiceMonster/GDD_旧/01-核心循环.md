# 01 · 核心循环

> 模块定位：定义游戏最核心的玩法闭环与整体流程。
> 本文件是其他所有模块的纲领，其他模块必须与本文件一致。

## 1. 单回合循环（战斗内）

```
回合开始
  │
  ▼
投掷所有骰子（5 颗，可配置）
  │
  ▼
玩家观察结果
  │
  ├─→ 选择重摇（消耗重摇次数）→ 重新投掷选中骰子 → 循环直到满意
  │
  ▼
从所有骰子中选择 3 颗（可配置）
  │
  ▼
系统判定牌型（对子 / 顺子 / 三条 / 散牌 / 其他）
  │
  ▼
根据牌型 + 骰面点数计算伤害
  │
  ▼
对怪物造成伤害
  │
  ▼
怪物反击（固定伤害 / 按回合递增）
  │
  ▼
判断：怪物死亡？玩家 HP ≤ 0？
  │
  ├─→ 怪物死亡 → 胜利 → 奖励（见 §3）
  ├─→ 玩家 HP ≤ 0 → 失败 → 挑战结束
  └─→ 继续 → 下一回合
```

## 2. 整体流程（外层 → 战斗 → 地图）

```
游戏启动
  │
  ▼
开始页面
  ├─ [进入游戏] → 玩家大厅
  ├─ [设置] → 设置页面
  ├─ [玩法说明] → 玩法说明（预留）
  ├─ [反馈建议] → 反馈弹窗
  └─ [退出游戏] → 确认 → 关闭
  │
  ▼
玩家大厅
  ├─ [挑战] → 检查存档 → 新游戏/继续 → 尖塔地图
  ├─ [养成] → 技能树（局外永久升级）
  ├─ [商店] → 局外商店（购买一次性加强）
  └─ [返回] → 开始页面
  │
  ▼
尖塔地图（3 层树状结构）
  │
  ├─ 选择路径节点 → 进入对应事件
  │    ├─ 怪物节点 → 战斗
  │    ├─ 精英节点 → 强化战斗
  │    ├─ Boss 节点 → Boss 战
  │    ├─ 商店节点 → 局内商店
  │    ├─ 事件节点 → 随机事件
  │    ├─ 休息节点 → 回复/强化
  │    └─ 随机节点 → 随机分配
  │
  ├─ 击败怪物/精英 → 获得奖励（金币 + 骰子碎片 + 3选1）
  │
  ├─ 击败层 Boss → 进入下一层
  │
  └─ 击败最终 Boss → 通关
       │
       ▼
结算画面
  ├─ 骰子碎片 → 转入局外货币
  ├─ 局内金币 → 转入局外金币
  └─ [返回大厅]
```

## 3. 奖励循环

### 3.1 战斗胜利后（怪物/精英节点）

| 奖励 | 数量 | 说明 |
|------|------|------|
| 局内金币 | 10~30（普通）/ 30~60（精英） | 用于局内商店 |
| 骰子碎片 | 3~5（普通）/ 8~12（精英） | 用于技能树升级 |
| 3 选 1 | 能力或骰子 | 见 `11-肉鸽能力.md` |

### 3.2 Boss 战后

| 奖励 | 数量 |
|------|------|
| 局内金币 | 50~100 |
| 骰子碎片 | 20~30 |
| 3 选 1 | 全部 rare 以上品质 |

### 3.3 通关最终 Boss

| 奖励 | 说明 |
|------|------|
| 骰子碎片 | 全部转入局外 + 额外 50 奖励 |
| 局内金币 | 全部转入局外 |

| 系统 | 类型 | 持续时间 | 详见 |

## 5. 模式说明

| 模式 | 说明 | 详见 |
|------|------|------|
| **尖塔挑战**（主线） | 3 层尖塔地图，树状路线选择，击败最终 Boss 通关 | `14-尖塔地图.md` |
| **无尽模式** | 连续战斗，怪物难度持续递增，无地图，追求最高分数 | `05-关卡与节奏.md` §5 |

## 6. 存档规则

| 项目 | 规则 |
|------|------|
| 自动保存时机 | 每次完成节点后自动保存 |
| 存档内容 | 当前层数、节点位置、HP、骰子池、能力、金币、地图状态 |
| 存档数量 | 仅 1 个挑战存档（覆盖式） |
| 通关/失败后 | 挑战存档清除，meta 数据保留 |
