# 04 · 战斗与怪物

> 模块定位：定义战斗规则细节和怪物生成系统。
> 战斗发生在尖塔地图的怪物/精英/Boss 节点，以及无尽模式中。
> 单回合核心循环见 `01-核心循环.md`。

## 1. 战斗规则

### 1.1 基础参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 初始骰子数 | 5 | 每回合投掷的骰子数量 |
| 选择骰子数 | 3 | 每次出牌选择的骰子数 |
| 初始 HP | 100 | 玩家最大 HP（含技能树加成） |
| 初始重摇次数 | 2 | 每回合可重摇的次数 |

### 1.2 HP 规则

| 规则 | 说明 |
|------|------|
| 节点间 HP 保留 | 战斗结束后 HP 保留，不自动回满 |
| 层间回复 | 击败 Boss 后回复 20% 最大 HP |
| 休息节点 | 回复 30% 最大 HP（二选一） |
| 治疗药水 | 回复 25 HP（局内商店购买） |
| 死亡 | HP ≤ 0 时挑战结束 |

### 1.3 重摇规则

| 规则 | 说明 |
|------|------|
| 每回合重置 | 每回合开始时重摇次数重置为初始值 |
| 未选中骰子 | 重摇时只重新投掷未被选中的骰子 |
| 叠加 | 肉鸽能力/技能树/装备可增加重摇次数 |

## 2. 怪物生成

### 2.1 普通怪物

| 层 | HP 范围 | 伤害范围 | 特殊机制 |
|----|---------|---------|----------|
| 第 1 层 | 30~60 | 5~10 | 无或简单（如每 3 回合攻击一次） |
| 第 2 层 | 60~100 | 10~18 | 中等（如护甲、反击） |
| 第 3 层 | 100~160 | 18~28 | 复杂（如连击、增伤 buff） |

### 2.2 精英怪物

| 层 | HP 范围 | 伤害范围 | 特殊机制 |
|----|---------|---------|----------|
| 第 1 层 | 80~120 | 8~15 | 护甲 + 反击 |
| 第 2 层 | 120~180 | 15~25 | 连击 + 增伤 |
| 第 3 层 | 180~260 | 25~35 | 多机制组合 |

### 2.3 Boss

| Boss | HP | 伤害 | 机制 |
|------|------|------|------|
| 第 1 层 Boss（骰子守卫） | 150 | 12~18 | 每 3 回合投骰子攻击 |
| 第 2 层 Boss（骰子法师） | 220 | 18~28 | 每回合改变牌型倍率 |
| 第 3 层最终 Boss（骰子之王） | 350 | 25~35 | 阶段制 P1→P2 |

## 3. 怪物反击规则

| 模式 | 说明 |
|------|------|
| 固定伤害 | 怪物每回合对玩家造成固定伤害 |
| 意图显示 | 战斗界面显示怪物下回合意图（攻击/防御/Buff） |
| 递增伤害 | 部分怪物伤害随回合递增 |

## 4. 伤害计算

### 4.1 基础公式

```
骰子基础值 = 所选 3 颗骰子的点数之和
牌型基础倍率 = 根据牌型查表（见 03-牌型判定.md）
牌型基础伤害 = 骰子基础值 × 牌型基础倍率

肉鸽能力加成 → 能力倍率
装备加成 → 装备倍率
技能树加成 → 技能倍率
暴击判定 → 暴击倍率

最终伤害 = floor(牌型基础伤害 × 能力倍率 × 装备倍率 × 技能倍率 × 暴击倍率)
```

### 4.2 完整公式

```gdscript
# DamageCalc.gd
dice_sum = sum(selected_dice_values)
hand_base_mult = get_hand_type_mult(hand_type)  # 从牌型判定获取
base_damage = dice_sum * hand_base_mult

# 肉鸽能力加成
ability_mult = calculate_ability_mult(abilities, hand_type, selected_dice)

# 装备加成
equip_mult = calculate_equip_mult(equipment, hand_type, selected_dice)

# 技能树加成
skill_mult = calculate_skill_mult(unlocked_skills)

# 暴击
crit_mult = 1.0
if crit_enabled and rng.randf() < crit_chance:
    crit_mult = 2.0

final_damage = floor(base_damage * ability_mult * equip_mult * skill_mult * crit_mult)
```

## 5. 无尽模式特殊规则

| 规则 | 说明 |
|------|------|
| 怪物生成 | 不使用地图，连续生成，难度递增 |
| 难度递增 | 每 10 只怪物 HP 和伤害 +20% |
| 结束条件 | 玩家 HP ≤ 0 |
| 排名 | 按击杀数排名 |
