## 使用方式
- 改任何模块前，先看它的「相关依赖」段落。
- 改完核心规则（01/02/03/04/11/12）务必同步检查 08 数值表与 `data/*.json`。
- 数值类改动优先改 `data/*.json` 配置表，GDD 只保留说明与示例。
