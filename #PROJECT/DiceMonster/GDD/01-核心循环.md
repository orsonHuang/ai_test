# 01 · 核心循环

> 模块定位：定义一局游戏从开始到结束的**完整流程**，包括普通模式 10 只怪物 + 肉鸽能力选择 + 无尽正计条模式。
> 一切设计（骰子、怪物、能力、UI）都围绕这个循环服务。

## 1. 整体流程
```
[开始游戏]
   ↓
[普通模式 · 第 1 只怪]
   ↓ 击败
[能力选择 · 3 选 1（无成本）]
   ↓
[普通模式 · 第 2 只怪]
   ↓
   ...（重复 10 次）
   ↓
[普通模式 · 第 10 只怪]
   ↓ 击败
[进入无尽模式]
   ↓
[无尽模式 · 10 次投掷]
   ↓ 投掷次数用完
[结算：展示本局总伤害]
   ↓
[返回主菜单 / 再玩一次]
```

## 2. 普通模式单回合三阶段

| 阶段 | 中文名 | 玩家操作 | 系统响应 | 退出条件 |
|------|--------|----------|----------|----------|
| ① | 准备阶段 | 点击底部"投掷"按钮 | 6 颗骰子随机摇出点数 | 首次投掷完成 → 进入② |
| ② | 决策阶段 | 1) 点击骰子选/取消作为结果<br>2) 点击"重摇"指定部分骰子重投<br>3) 点击"确定" | 选中的骰子高亮；剩余重摇次数-1 | 选子数 ∈ [1,5] 且点击"确定" → 进入③ |
| ③ | 结果阶段 | 纯观看 | 牌型判定 → 伤害计算 → 怪物扣血 → 动画/飘字 | 动画结束 → 怪物死亡? 否 → 回到①；是 → 进入能力选择 |

> 重摇次数上限由配置表 `levels.json` 决定，并受肉鸽能力影响（见 `11-肉鸽能力.md`）。

## 3. 普通模式状态机（伪代码）
```gdscript
enum Phase { READY, DECIDE, RESULT, REWARD, WIN }

state Phase.current = READY
state monster_index = 0           # 0..9
state abilities: Array[Ability]   # 已获得能力

on button_投掷:   roll_all_6_dice(); current = DECIDE
on 选子变化:       selected_count = ...
on button_重摇:
    if rerolls_left > 0:
        reroll_unselected()
        rerolls_left -= 1
on button_确定:
    if selected_count in 1..5:
        damage = calc(selected, abilities)
        monster.hp -= damage
        current = RESULT
on RESULT结束:
    if monster.hp <= 0:
        if monster_index == 9:
            current = WIN          # 进入无尽模式
        else:
            current = REWARD       # 能力选择
    else:
        current = READY
on 能力选择完成:
    abilities.append(chosen)
    monster_index += 1
    load_next_monster()
    current = READY
```

## 4. 能力选择阶段（REWARD）
- **触发**：每击败 1 只怪物后（第 1~9 只怪后都触发；第 10 只后进入无尽）。
- **机制**：从配置表 `abilities.json` 中随机抽取 3 个能力，玩家**无成本**选择 1 个。
- **效果**：能力立即生效，持续到本局游戏结束。
- **UI**：三卡牌横向展示，玩家点击其一后进入下一只怪物。
- **去重规则**：同一能力可重复获得？建议允许叠加或互斥，见 `11-肉鸽能力.md` §4。

## 5. 无尽模式（Endless Mode）

### 5.1 触发条件
- 击败第 10 只怪物后自动进入。

### 5.2 规则
- **无怪物血条**：怪物的"血量"改为**正计条**，从 0 开始累计玩家造成的伤害。
- **投掷次数有限**：玩家拥有固定 `10` 次投掷机会。
- **每次投掷后重置重摇次数**：每次新的投掷都恢复为无尽模式配置的重摇次数（见 `balance.json`）。
- **选子/重摇/确定机制与普通模式一致**。
- **倒计时或次数显示**：顶部显示 `投掷 3/10`，提示剩余次数。

### 5.3 结束与结算
- 10 次投掷全部用完 → 进入结算画面。
- 结算展示：
  - 本局**总伤害**
  - 普通模式 10 只怪各自的伤害贡献
  - 无尽模式累计伤害
  - 达成过的最高倍率牌型
  - 获得的能力列表
- 最终伤害总量即为玩家的"通关成绩"，可用于排行榜或自我挑战。

## 6. 胜负条件
- **普通模式**：不存在玩家死亡失败；只要持续投掷，总能击败怪物。
- **无尽模式**：不存在失败；10 次投掷后按总伤害结算。
- 核心目标：**最大化本局总伤害**。

## 7. 边界与异常
- 6 颗全部未选 → "确定"按钮置灰。
- 6 颗全部选中 → 不允许（上限 5），第 6 颗自动置为"重摇候选"。
- 重摇次数为 0 → "重摇"按钮置灰。
- 无尽模式第 10 次投掷用完后，自动进入结算，不允许再点击投掷。
- 能力选择阶段倒计时？——否，玩家不选则卡住，需主动选择。
