# 13 · 外层系统

> 模块定位：定义游戏启动后、进入挑战前的所有外层页面与功能。
> 包括开始页面、玩家大厅（主菜单）、设置、玩法说明、反馈建议。
> 挑战入口、局外养成、商店分别在 `14-尖塔地图.md`、`15-局外养成.md`、`16-商店系统.md`。

## 1. 页面总览与跳转

```
游戏启动
  │
  ▼
┌─────────────────────────────────────┐
│          开始页面 (StartScreen)       │
│  [进入游戏]  [设置]  [玩法说明]        │
│  [反馈建议]  [退出游戏]               │
└─────────────────────────────────────┘
  │                    │           │
  ▼                    ▼           ▼
玩家大厅            设置页面     玩法说明 / 反馈弹窗
(HubScreen)
  │
  ├─→ [挑战] → 尖塔地图 → 战斗 / 事件 / 商店 ...
  ├─→ [养成] → 技能树页面
  ├─→ [商店] → 商店页面
  └─→ [返回] → 开始页面
```

- 背景：主视觉插画或动态效果。

## 3. 玩家大厅（HubScreen）

> 所有"继续/新游戏"决策集中在此页面。开始页面仅负责导航到此处。

### 3.1 功能入口

| 按钮 | 行为 | 详见 |
|------|------|------|
| **挑战** | 进入挑战入口 | §3.2 |
| **养成** | 打开技能树页面 | `15-局外养成.md` |
| **商店** | 打开商店页面 | `16-商店系统.md` |
| **返回** | 回到开始页面 | — |

### 3.2 挑战入口

点击"挑战"后，系统检查存档：

| 条件 | 行为 |
|------|------|
| **无存档** | 直接进入尖塔地图第 1 层起点 |
| **有存档** | 弹出对话框："检测到上次未完成的挑战，是否放弃进度重新开始？" |

对话框选项：

| 按钮 | 行为 |
|------|------|
| **继续上次** | 加载存档，进入尖塔地图当前节点 |
| **重新开始** | 清除存档，进入尖塔地图第 1 层起点 |
| **取消** | 返回玩家大厅 |

### 3.3 大厅布局建议

- 左侧：勇者立绘 + 基础信息（金币、骰子碎片数量）。
- 右侧：三个功能按钮（挑战 / 养成 / 商店）。
- 底部：返回按钮。

### 3.4 存档数据结构（参考）

```gdscript
# SaveData
{
    "version": 1,
    "run": {                          # 当前挑战存档（null = 无存档）
        "floor": 1,                   # 当前层数 1~3
        "current_node_id": "n_3_2",   # 当前节点 ID
        "visited_nodes": ["n_1_0", "n_1_1", "n_2_0"],
        "player_hp": 85,
        "player_max_hp": 100,
        "gold": 120,
        "dice_pool": [...],           # 当前骰子池
        "abilities": [...],           # 当前已获得能力
        "map_state": {...}            # 地图生成种子 + 节点状态
    },
    "meta": {
        "gold": 500,                  # 局外金币
        "dice_shards": 120,           # 骰子碎片（技能树货币）
        "skill_tree": {...},          # 已解锁技能
        "equipment": {...},           # 已拥有装备 + 当前穿戴
        "shop_inventory": [...]       # 商店已购物品（一次性）
    },
    "settings": {
        "fullscreen_mode": "fullscreen",
        "resolution": "1920x1080",
        "master_volume": 1.0,
        "music_enabled": true,
        "sfx_enabled": true,
        "music_volume": 0.8,
        "sfx_volume": 0.8
    }
}
```

## 4. 设置页面（SettingsScreen）

### 4.1 显示模式

| 选项 | 值 | 默认 |
|------|------|------|
| 全屏 | `fullscreen` | ✅ **默认** |
| 无边框窗口 | `borderless` | |
| 窗口化 | `windowed` | |

切换后立即生效，无需重启。

### 4.2 分辨率

| 可选值 |
|--------|
| 1280×720 |
| 1600×900 |
| 1920×1080（默认） |
| 2560×1440 |
| 3840×2160 |

- 仅在全屏 / 无边框模式下可选（窗口化时使用窗口尺寸）。
- 切换后弹出"是否保留此分辨率？"5 秒倒计时确认。

### 4.3 声音设置

| 控件 | 类型 | 范围 | 默认 |
|------|------|------|------|
| 总开关 | Toggle | ON / OFF | ON |
| 音乐子开关 | Toggle | ON / OFF | ON |
| 音效子开关 | Toggle | ON / OFF | ON |
| 音乐音量 | Slider | 0~100 | 80 |
| 音效音量 | Slider | 0~100 | 80 |

**联动规则**：
- 总开关 OFF → 所有声音静音，子开关变灰不可操作。
- 总开关 ON → 子开关独立控制；音乐子开关 OFF 时音乐静音但音效正常。
- 音量滑条仅在对应子开关 ON 时生效。

### 4.4 布局建议

- 分组显示：显示设置 / 声音设置。
- 底部：返回按钮（自动保存设置）。

## 6. 反馈建议（FeedbackDialog）

> 弹窗形式，不跳转页面。

### 6.1 内容

```
┌───────────────────────────────────────┐
│            反馈与建议                    │
│                                       │
│  感谢您提供的建议，可以发到以下邮箱：      │
│                                       │
│  📧 dice.monster@example.com          │
│                                       │
│  [复制邮箱]          [关闭]            │
└───────────────────────────────────────┘
```

### 6.2 交互

| 操作 | 行为 |
|------|------|
| 点击邮箱地址 | 自动复制到剪贴板，显示"已复制"提示 |
| 点击"复制邮箱" | 同上 |
| 点击"关闭" / 点击遮罩 | 关闭弹窗 |

## 7. 退出游戏

### 7.1 确认对话框

```
┌───────────────────────────┐
│     确定要退出游戏吗？       │
│                           │
│   [确定退出]    [取消]     │
└───────────────────────────┘
```

### 7.2 行为

| 按钮 | 行为 |
|------|------|
| 确定退出 | 自动保存当前进度（如有存档）→ 关闭游戏进程 |
| 取消 | 关闭对话框，返回开始页面 |

## 8. 页面流总览

```
StartScreen
  ├─→ [进入游戏] → HubScreen
  │     ├─→ [挑战] → 检查存档 → SpireMap（尖塔地图）
  │     ├─→ [养成] → SkillTreeScreen
  │     ├─→ [商店] → ShopScreen
  │     └─→ [返回] → StartScreen
  ├─→ [设置] → SettingsScreen
  ├─→ [玩法说明] → HowToPlayScreen
  ├─→ [反馈建议] → FeedbackDialog（弹窗）
  └─→ [退出游戏] → ExitDialog → 关闭游戏
```
