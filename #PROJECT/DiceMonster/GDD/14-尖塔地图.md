# 14 · 尖塔地图

> 模块定位：定义杀戮尖塔式的主线挑战地图结构。
> 3 层，每层有 BOSS，树状分支路线选择，节点类型包括怪物、精英、最终 Boss、随机、商店、事件、休息。
> 完全替代旧版线性 10 怪结构；无尽模式见 `05-关卡与节奏.md` §5。

## 1. 总体结构

```
第 1 层（普通层）
  起点 → 分支路线（~12 个节点）→ 第 1 层 BOSS
  │
  ▼
第 2 层（普通层）
  起点 → 分支路线（~12 个节点）→ 第 2 层 BOSS
  │
  ▼
第 3 层（最终层）
  起点 → 分支路线（~12 个节点）→ 最终 BOSS → 通关
```

### 1.1 三层概要

| 层 | 名称 | 节点数 | 终点 | 难度特征 |
|----|------|--------|------|----------|
| 第 1 层 | 普通层 | 12 | 层 Boss | 入门，怪物 HP 低，引导玩家熟悉机制 |
| 第 2 层 | 普通层 | 12 | 层 Boss | 中等，精英出现频率增加 |
| 第 3 层 | 最终层 | 12 | 最终 Boss | 高难度，精英密集，怪物数值大幅提升 |

## 2. 节点类型

| 类型 | 图标 | 英文 ID | 触发内容 | 备注 |
|------|------|---------|----------|------|
| 怪物 | 💀 | `monster` | 普通战斗 | 最常见的节点 |
| 精英 | ⚔️ | `elite` | 强化战斗 | 怪物更强，奖励更好 |
| 最终 Boss | 👹 | `final_boss` | 最终 Boss 战 | 仅第 3 层终点，1 个 |
| Boss | 🏰 | `boss` | 层 Boss 战 | 第 1、2 层终点 |
| 商店 | 🛒 | `shop` | 购买骰子/消耗品 | 见 `16-商店系统.md` |
| 事件 | ❓ | `event` | 随机事件 | 文本选择，有得有失 |
| 休息 | 🔥 | `rest` | 回复 / 强化 | 二选一 |
| 随机 | 🎲 | `random` | 随机分配 | 进入后随机变为上述之一 |

## 3. 层内地图结构

### 3.1 节点布局

每层采用**固定列数 × 多路线**的树状结构：

```
起点    第1列    第2列    第3列    第4列    第5列    终点
 ● ──→  ●  ──→  ●  ──→  ●  ──→  ●  ──→  ●  ──→  ● (Boss)
 │      │ ╲     │ ╱│    │ ╲     │ ╱│    │ ╲     │
 ● ──→  ●  ──→  ●  ──→  ●  ──→  ●  ──→  ●  ──→  ● (Boss)
 │      │ ╱╲    │ ╱╲    │ ╱╲    │ ╱╲    │ ╱╲    │
 ● ──→  ●  ──→  ●  ──→  ●  ──→  ●  ──→  ●  ──→  ● (Boss)
 │      │ ╲╱    │ ╲╱    │ ╲╱    │ ╲╱    │ ╲╱    │
 ● ──→  ●  ──→  ●  ──→  ●  ──→  ●  ──→  ●  ──→  ● (Boss)
```

| 属性 | 值 |
|------|------|
| 列数（中间节点列） | 6 列 |
| 每列节点数 | 3~4 个 |
| 总节点数（含起点和终点） | ~25~30 个 |
| 玩家经过节点数 | 起点 → 约 8~10 个中间节点 → Boss |
| 连接规则 | 每个节点连接到下一列的 1~2 个节点（上下相邻） |

### 3.2 节点分配规则

| 规则 | 说明 |
|------|------|
| 起点 | 固定为"怪物"节点（引导战斗） |
| 第 1 列 | 至少 1 个怪物节点 |
| 第 2~4 列 | 混合分配：怪物、精英、事件、休息、商店 |
| 第 5 列 | 至少 1 个休息节点（Boss 前准备） |
| 商店 | 每层固定 2~3 个商店节点 |
| 休息 | 每层固定 2~3 个休息节点 |
| 精英 | 每层固定 2~3 个精英节点 |
| 事件 | 每层固定 1~2 个事件节点 |
| 随机 | 每层 0~1 个随机节点 |
| Boss | 终点固定为 Boss（第 3 层为最终 Boss） |

### 3.3 路线连通规则

- 每个节点至少连接下一列的 1 个节点，最多连接 2 个。
- 保证从起点到 Boss 至少有 3 条不同路线。
- 相邻节点之间可以交叉（形成菱形 / 树状）。
- 地图生成时使用种子确保可复现。

## 4. 各节点详细规则

### 4.1 怪物节点（`monster`）

| 项目 | 规则 |
|------|------|
| 触发 | 进入节点后开始普通战斗 |
| 怪物生成 | 按 `04-战斗与怪物.md` §2 规则，根据当前层数选择难度池 |
| 胜利奖励 | 金币 + 骰子碎片（见 §5）+ 3 选 1 能力/骰子 |
| HP 保留 | 战斗结束后 HP 保留（不自动回满） |

### 4.2 精英节点（`elite`）

| 项目 | 规则 |
|------|------|
| 触发 | 进入节点后开始强化战斗 |
| 怪物生成 | 使用精英怪物池，HP 和伤害更高 |
| 胜利奖励 | 金币 ×2 + 骰子碎片 ×2 + 3 选 1（骰子出现概率提高到 60%） |
| 风险 | 精英可能附带特殊机制（护甲、连击等） |

### 4.3 Boss 节点（`boss` / `final_boss`）

| 项目 | 规则 |
|------|------|
| 触发 | 进入节点后开始 Boss 战 |
| Boss 生成 | 按层数从 Boss 池中选取（见 §6） |
| 胜利奖励 | 大量金币 + 骰子碎片 + 稀有能力选择（3 选 1 全部 rare 以上） |
| 后续 | 第 1/2 层 Boss → 进入下一层；第 3 层最终 Boss → 通关 |
| HP | Boss 战后 HP 保留，进入下一层前可选择是否调整 |

### 4.4 商店节点（`shop`）

| 项目 | 规则 |
|------|------|
| 触发 | 进入节点后打开商店界面 |
| 商品 | 见 `16-商店系统.md` |
| 货币 | 使用局内金币（`run.gold`） |
| 离开 | 玩家可随时点击"离开"退出商店，继续地图 |

### 4.5 事件节点（`event`）

| 项目 | 规则 |
|------|------|
| 触发 | 进入节点后播放事件文本 |
| 结构 | 文本描述 + 2~3 个选项 |
| 结果 | 每个选项有不同的正面/负面效果 |
| 事件池 | 从 `data/events.json` 中随机抽取，不重复 |

**事件示例**：

```json
{
  "id": "mysterious_dice",
  "title": "神秘的骰子",
  "text": "你在路边发现一颗发光的骰子，它似乎在呼唤你...",
  "choices": [
    {
      "text": "拿起骰子",
      "effect": { "type": "add_dice", "dice": {"faces": 8, "modifier": "+1"} },
      "result_text": "你获得了 d8+1！但它似乎有诅咒..."
    },
    {
      "text": "谨慎离开",
      "effect": { "type": "heal", "value": 10 },
      "result_text": "你离开了，感到一阵安心。回复 10 HP。"
    }
  ]
}
```

### 4.6 休息节点（`rest`）

| 项目 | 规则 |
|------|------|
| 触发 | 进入节点后弹出二选一 |
| 选项 A | **篝火休息**：回复 30% 最大 HP |
| 选项 B | **强化骰子**：选择一颗骰子，永久 +1 面（如 d6 → d6+1，仅本局有效） |

```
┌─────────────────────────────┐
│         篝火                   │
│  温暖的火焰让你感到安心。        │
│  选择一个行动：                 │
│                             │
│  [休息] 回复 30% 最大 HP      │
│  [强化] 选择一颗骰子 +1 面    │
└─────────────────────────────┘
```

### 4.7 随机节点（`random`）

| 项目 | 规则 |
|------|------|
| 触发 | 进入节点后，随机变为以下之一 |
| 可能结果 | 怪物（50%）/ 事件（20%）/ 休息（15%）/ 商店（10%）/ 精英（5%） |
| 揭晓 | 先显示"???"动画，再揭晓实际节点类型并进入 |

## 5. 通关奖励

### 5.1 每场战斗后（怪物 / 精英）

| 奖励 | 数量 |
|------|------|
| 局内金币 | 按怪物难度（`04-战斗与怪物.md`） |
| 骰子碎片 | 普通 3~5 / 精英 8~12 |
| 3 选 1 | 能力或骰子（`11-肉鸽能力.md`） |

### 5.2 Boss 战后

| 奖励 | 数量 |
|------|------|
| 局内金币 | 50~100 |
| 骰子碎片 | 20~30 |
| 3 选 1 | 全部 rare 以上品质 |

### 5.3 通关最终 Boss 后

| 奖励 | 数量 |
|------|------|
| 局内金币 → 局外金币 | 全部转换（1:1） |
| 骰子碎片 | 50（通关奖励） |
| 装备 | 不掉落（装备改为商店购买，见 `16-商店系统.md`） |

> 旧版"通关后掉落装备"机制已移除，改为通过商店系统获取。

## 6. Boss 池

| 层 | Boss | HP | 特殊机制 |
|----|------|------|----------|
| 第 1 层 | 骰子守卫 | 150 | 每 3 回合投骰子攻击，玩家需在其高点时防御 |
| 第 2 层 | 骰子法师 | 220 | 每回合改变一种牌型的伤害倍率（随机增强/削弱） |
| 第 3 层 | 骰子之王（最终 Boss） | 350 | 阶段制：P1 正常 → P2(50%HP) 每回合额外投 2 颗暗骰加入玩家池 |

> Boss 具体数值见 `08-数值与平衡.md`。

## 7. 层间过渡

```
击败层 Boss
  │
  ▼
┌─────────────────────────────┐
│      层间休息                  │
│  "你击败了 Boss，继续前进..."  │
│                             │
│  HP 回复 20%（可选）          │
│  [继续前进] → 进入下一层地图   │
└─────────────────────────────┘
```

| 项目 | 规则 |
|------|------|
| HP 回复 | 层间自动回复 20% 最大 HP |
| 能力保留 | 本局获得的所有能力保留 |
| 骰子池保留 | 当前骰子池保留 |
| 金币保留 | 局内金币保留（可在下一层商店使用） |
| 地图 | 使用新种子生成下一层地图 |

│                                         │

### 8.2 节点状态

| 状态 | 视觉 |
|------|------|
| 未探索（不可达） | 灰色，无连线高亮 |
| 可选（当前可达） | 白色边框 + 脉冲动画 |
| 已通过 | 绿色标记 + 半透明 |
| 当前节点 | 高亮 + 玩家图标 |
| Boss（未到达） | 红色骷髅 + 锁链图标 |

### 8.3 交互

| 操作 | 行为 |
|------|------|
| 点击可选节点 | 移动到该节点，触发对应事件 |
| 点击已通过节点 | 无反应（不可回退） |
| 点击不可达节点 | 无反应 |
| 点击菜单按钮 | 弹出暂停菜单（继续 / 设置 / 放弃挑战） |

## 9. 地图生成算法

```gdscript
# SpireMapGenerator.gd
func generate_floor(floor_index: int, seed: int) -> Dictionary:
    var rng = RandomNumberGenerator.new()
    rng.seed = seed
    
    var columns = 6          # 中间列数
    var rows = 4             # 每列节点数
    var nodes = []
    
    # 1. 生成节点网格
    for col in range(columns):
        var column_nodes = []
        for row in range(rows):
            var node_type = _assign_node_type(col, row, floor_index, rng)
            column_nodes.append({
                "id": "n_%d_%d" % [col, row],
                "col": col, "row": row,
                "type": node_type,
                "connections": [],
                "visited": false
            })
        nodes.append(column_nodes)
    
    # 2. 生成连接（每个节点连到下一列 1~2 个相邻节点）
    for col in range(columns - 1):
        for node in nodes[col]:
            var targets = _get_valid_targets(node, nodes[col + 1], rng)
            for target in targets:
                node.connections.append(target.id)
    
    # 3. 添加起点和终点（Boss）
    var start_node = {"id": "start", "type": "start", "col": -1, "row": 1}
    var boss_node = {"id": "boss", "type": "boss" if floor_index < 3 else "final_boss"}
    
    return {"nodes": nodes, "start": start_node, "boss": boss_node, "seed": seed}
```
