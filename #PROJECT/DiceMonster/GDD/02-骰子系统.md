# 02 · 骰子系统

> 模块定位：定义"6 颗骰子"的所有行为，包括投掷、选子、重摇，以及与能力、无尽模式的联动。

## 1. 数据结构
```gdscript
class Die:
    value: int        # 1~6，点数
    is_selected: bool # 是否被选为本次出牌
    is_locked: bool   # 锁定则不参与重摇（v1 不一定用）
```

## 2. 基础规则

| 行为 | 规则 | 备注 |
|------|------|------|
| 投掷数量 | 固定 6 颗 | 不随关卡变化（v1） |
| 点数范围 | 1~6 均匀分布 | 1/6 概率，可配置加权骰（v2） |
| 选子上限 | **最多 5 颗** | 第 6 颗不允许选 |
| 选子下限 | **至少 1 颗** | 不允许 0 颗出牌 |
| 重摇次数来源 | 从 `levels.json` 读取基础值，再由肉鸽能力修正 | 见 `11-肉鸽能力.md` §3 |
| 重摇对象 | 仅未选中的骰子 | 选中的锁住，不参与重摇 |
| 重摇随机 | 标准 1/6 均匀 | 可配置不同权重（v2） |

### 2.1 重摇次数计算
```gdscript
rerolls_left = base_rerolls(level_index) + bonus_from_abilities("reroll")
```
- 每次进入新的"投掷"时刷新（普通模式：同一回合内重摇消耗后不再恢复；无尽模式：每次投掷都恢复）。

## 3. 交互行为

### 3.1 选中/取消
- 玩家点击某颗骰子 → 在 `selected` / `unselected` 之间切换。
- 选中状态：视觉上"浮起 + 高亮边框 + 上方挂点数牌"（参考图 ③）。
- 取消选中：恢复原位。

### 3.2 重摇
- 玩家点击"重摇"按钮 → **未选中的骰子** 重新投掷。
- 选中的骰子保持不动（视觉上明确锁定）。
- 重摇次数 -1；归 0 时按钮置灰。

### 3.3 确定
- 玩家点击"确定"按钮 → 进入 RESULT 阶段。
- 前置条件：`1 ≤ selected_count ≤ 5`。

## 4. 无尽模式下的特殊规则
- 每次点击"投掷"按钮时，**重摇次数完全重置**为无尽模式配置值（不受之前消耗影响）。
- 不存在"怪物反击"或"回合失败"，只计算 10 次投掷内的总伤害。

## 5. 与肉鸽能力的联动
- **增加重摇次数**：直接 `+N` 到 `rerolls_left` 上限。
- **骰子 x 伤害翻 x 倍**：见 `04-战斗与怪物.md` §5。
- 能力不影响骰子点数分布本身（v2 可扩展"加权骰"）。

## 6. 视觉规范（占位）
| 元素 | 状态 | 表现 |
|------|------|------|
| 骰子本体 | 未选 | 放在底部一排，缩略图样式（参考图 ②） |
| 骰子本体 | 选中 | 浮起到怪物半身像区域周围，半透明叠放（参考图 ③） |
| 骰子点数 | 始终 | 居中显示点数数字 |

## 7. 边界与异常
- 玩家连续点击同一颗骰子：在选中↔未选中间切换。
- 玩家在重摇动画过程中点击骰子：忽略输入（锁定）。
- 重摇次数耗尽但仍想重摇：UI 禁用 + 震动反馈（见 07）。
