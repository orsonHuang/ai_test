# 11 · 肉鸽能力

> 模块定位：定义每击败一只怪物后的 3 选 1 能力系统。
> 所有能力数据来自 `data/abilities.json`；本文件只描述设计规则和配置示例。

## 1. 能力选择规则

| 项目 | 规则 |
|------|------|
| 触发时机 | 击败第 1~9 只怪物后，共 **9 次选择** |
| 选择成本 | **无成本** |
| 选项数量 | 每次 **3 选 1** |
| 来源 | 从 `data/abilities.json` 的能力池中随机抽取 |
| 生效时长 | 获得后立即生效，持续到本局游戏结束 |
| 叠加规则 | 同 id 能力可重复获得，效果**加法叠加**（默认） |
| 去重规则 | 同一选择界面内不重复出现同 id |

## 2. 能力类型总览

| 类型 | 名称 | 作用对象 | 示例 |
|------|------|----------|------|
| `hand_type` | 牌型伤害加成 | 特定牌型（对子/顺子/三条等） | 对子伤害 +30% |
| `dice_face` | 骰子点数伤害加成 | 特定点数（1~6） | 骰子 6 伤害翻倍 |
| `streak` | 连续相同骰子加成 | 连续同点数长度 ≥ N | 3 颗连相同伤害 +50% |
| `reroll` | 增加重摇次数 | 全局 | 每回合重摇次数 +1 |
| `mult_global` | 全局伤害加成 | 所有伤害 | 所有伤害 +10% |

> 用户提到的 6 类元素已分别归入上表 5 种类型 + 扩展的 `mult_global`。

## 3. 各类型详细规则

### 3.1 牌型伤害加成（`hand_type`）
- 配置字段：`{ "type": "hand_type", "target": "pair", "mult": 1.30 }`
- 生效条件：本次出牌判定为 `target` 牌型。
- 叠加方式：加法。获得两个 +30% → 总加成 1 + 0.3 + 0.3 = 1.6。
- 支持目标：`high_card`, `pair`, `two_pair`, `three_of_a_kind`, `full_house`, `straight`, `four_of_a_kind`, `five_of_a_kind`。

### 3.2 骰子点数伤害加成（`dice_face`）
- 配置字段：`{ "type": "dice_face", "target": 6, "mult": 2.00 }`
- 生效条件：所选骰子中**包含** `target` 点数。
- 叠加方式：乘法。多个不同目标可叠加；相同目标重复获得则乘法叠加或加法叠加，可配置。
- 示例：选了 `[2, 5, 6]`，拥有"骰子 5 伤害 ×1.5"和"骰子 6 伤害 ×2" → 总乘 3。

### 3.3 连续相同骰子加成（`streak`）
- 配置字段：`{ "type": "streak", "threshold": 3, "mult": 1.50 }`
- 生效条件：所选骰子中，最长连续相同点数长度 ≥ `threshold`。
- 连续定义：相同点数连续出现，如 `[2, 2, 2, 5, 6]` 中 2 的连续长度为 3。
- 示例阈值：3 / 4 / 5。

### 3.4 增加重摇次数（`reroll`）
- 配置字段：`{ "type": "reroll", "value": 1 }`
- 生效方式：全局 `base_rerolls += value`。
- 在无尽模式下同样生效（每次投掷后重置的上限增加）。

### 3.5 全局伤害加成（`mult_global`）
- 配置字段：`{ "type": "mult_global", "mult": 1.10 }`
- 生效条件：任何伤害结算时。
- 叠加方式：加法（与 hand_type 分开计算后再合并）。

## 4. 叠加规则设计（默认方案）

```gdscript
# DamageCalc.gd
var mult_total = hand_base_mult

# 1. 牌型类加成（加法）
for ability in abilities where type == "hand_type" and target == hand_type:
    mult_total += (ability.mult - 1.0)

# 2. 骰子点数加成（乘法）
for ability in abilities where type == "dice_face":
    if ability.target in selected_dice:
        mult_total *= ability.mult

# 3. 连续相同加成（乘法）
for ability in abilities where type == "streak":
    if max_streak >= ability.threshold:
        mult_total *= ability.mult

# 4. 全局加成（加法）
for ability in abilities where type == "mult_global":
    mult_total += (ability.mult - 1.0)

final_damage = floor(sum(selected_dice) * mult_total)
```

> 该公式为默认实现；可在 `data/balance.json` 中切换为纯乘法或纯加法。

## 6. 稀有度与出现权重

| 稀有度 | 颜色（建议） | 基础权重 |
|--------|--------------|----------|
| common | 白/灰 | 60% |
| rare | 蓝 | 30% |
| epic | 紫 | 10% |

> 权重可在 `data/balance.json` 中配置；关卡后期可逐步提高 epic 概率。

## 7. 能力选择算法

```gdscript
# AbilityManager.gd
func roll_abilities(level_index: int) -> Array[Ability]:
    var pool_tags = levels[level_index].ability_pool_tags
    var pool = abilities.filter(func(a): return a.tags.any(func(t): t in pool_tags))
    # 按稀有度权重抽 3 个不重复的 id
    var result = []
    while result.size() < 3:
        var candidate = weighted_random(pool)
        if not result.any(func(a): a.id == candidate.id):
            result.append(candidate)
    return result
```
