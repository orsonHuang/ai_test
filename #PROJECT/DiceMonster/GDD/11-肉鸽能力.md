# 11 · 肉鸽能力

> 模块定位：定义每击败一只怪物后的奖励选择系统（能力 + 骰子共享界面）。
> 所有能力数据来自 `data/abilities.json`；本文件只描述设计规则和配置示例。
> 骰子掉落规则见 `02-骰子系统.md` §5。
> 触发时机已更新：在尖塔地图中，击败怪物/精英/Boss 节点后触发。

## 1. 奖励选择规则

| 项目 | 规则 |
|------|------|
| 触发时机 | 击败怪物/精英节点后（Boss 节点有特殊奖励） |
| 选择成本 | **无成本** |
| 选项数量 | 每次 **3 选 1** |
| 选项构成 | 3 能力 **或** 2 能力 + 1 骰子（骰子出现概率 40%，精英节点 60%） |
| 能力来源 | 从 `data/abilities.json` 的能力池中随机抽取 |
| 骰子来源 | 按掉落配置生成（面数 + 词条），见 `02-骰子系统.md` §5 |
| 生效时长 | 能力：获得后立即生效，持续到本局结束；骰子：替换池中已有骰子 |
| 叠加规则 | 同 id 能力可重复获得，效果**加法叠加**（默认） |
| 去重规则 | 同一选择界面内不重复出现同 id |

## 2. 能力类型总览

| 类型 | 名称 | 作用对象 | 示例 |
|------|------|----------|------|
| `hand_type` | 牌型伤害加成 | 特定牌型（对子/顺子/三条等） | 对子伤害 +30% |
| `dice_max_face` | 最大面伤害翻倍 | 掷出骰子最大面时 | 最大面伤害翻倍 |
| `streak` | 连续相同骰子加成 | 连续同点数长度 ≥ N | 3 颗连相同伤害 +50% |
| `reroll` | 增加重摇次数 | 全局 | 每回合重摇次数 +1 |
| `mult_global` | 全局伤害加成 | 所有伤害 | 所有伤害 +10% |

## 3. 各类型详细规则

### 3.1 牌型伤害加成（`hand_type`）
- 配置字段：`{ "type": "hand_type", "target": "pair", "mult": 1.30 }`
- 生效条件：本次出牌判定为 `target` 牌型。
- 叠加方式：加法。获得两个 +30% → 总加成 1 + 0.3 + 0.3 = 1.6。
- 支持目标：`high_card`, `pair`, `straight`, `three_of_a_kind`（v1 共 4 种牌型）。

### 3.2 最大面伤害翻倍（`dice_max_face`）
- 配置字段：`{ "type": "dice_max_face", "mult": 2.00 }`
- 生效条件：所选骰子中**任意一颗**掷出该骰子最大面（d6 出 6、d8 出 8、d12 出 12）。
- 叠加方式：乘法。多个满值骰子可叠加；重复获得同类能力则乘法叠加。
- 示例：选了 `[d6(6), d8(8), d12(5)]`，拥有"满值暴击 ×2" → d6 和 d8 都满值，总乘 4。

### 3.3 连续相同骰子加成（`streak`）
- 配置字段：`{ "type": "streak", "threshold": 3, "mult": 1.50 }`
- 生效条件：所选骰子中，最长连续相同点数长度 ≥ `threshold`。
- 连续定义：相同点数连续出现，如 `[2, 2, 2, 5, 6]` 中 2 的连续长度为 3。

### 3.4 增加重摇次数（`reroll`）
- 配置字段：`{ "type": "reroll", "value": 1 }`
- 生效方式：全局 `base_rerolls += value`。

### 3.5 全局伤害加成（`mult_global`）
- 配置字段：`{ "type": "mult_global", "mult": 1.10 }`
- 生效条件：任何伤害结算时。
- 叠加方式：加法。

## 4. 叠加规则设计（默认方案）

```gdscript
# DamageCalc.gd
var mult_total = hand_base_mult

# 1. 牌型类加成（加法）
for ability in abilities where type == "hand_type" and target == hand_type:
    mult_total += (ability.mult - 1.0)

# 2. 最大面加成（乘法）
for ability in abilities where type == "dice_max_face":
    for die in selected_dice:
        if die.value == die.faces:
            mult_total *= ability.mult

# 3. 连续相同加成（乘法）
for ability in abilities where type == "streak":
    if max_streak >= ability.threshold:
        mult_total *= ability.mult

# 4. 全局加成（加法）
for ability in abilities where type == "mult_global":
    mult_total += (ability.mult - 1.0)

final_damage = floor(sum(selected_dice) * mult_total)
```

## 6. 稀有度与出现权重

| 稀有度 | 颜色（建议） | 基础权重 |
|--------|--------------|----------|
| common | 白/灰 | 60% |
| rare | 蓝 | 30% |
| epic | 紫 | 10% |

> Boss 战后 3 选 1 全部 rare 以上品质。

## 7. 能力选择算法

```gdscript
# AbilityManager.gd
func roll_abilities(node_type: String, floor_index: int) -> Array[Ability]:
    var pool = abilities.filter(func(a): return a.tags.any(func(t): t in get_pool_tags(floor_index)))
    var result = []
    while result.size() < 3:
        var candidate = weighted_random(pool)
        if not result.any(func(a): a.id == candidate.id):
            result.append(candidate)
    return result
```
