# 04 · 战斗与怪物

> 模块定位：定义伤害如何作用到怪物上，怪物属性，以及肉鸽能力、装备、无尽正计条对伤害公式的影响。

## 1. 两种模式下的"血条"

| 模式 | 血条类型 | 初始值 | 玩家动作影响 |
|------|----------|--------|--------------|
| 普通模式 | 扣血条 | `monster.max_hp` | 伤害扣减，归零即击败 |
| 无尽模式 | 正计条 | 0 | 伤害累加，无上限 |

## 2. 伤害公式（v1 最终版）

```gdscript
base_value   = hand_base_value[hand_type]          # 牌型基础值，见 03
dice_sum     = sum(selected_dice)                  # 所选骰子点数之和
ability_mult = ability_multiplier(hand_type, selected_dice, abilities)  # 见 11
equip_mult   = equipment_multiplier(hand_type, selected_dice, equipment) # 见 12
final_damage = floor((base_value + dice_sum) * ability_mult * equip_mult)
```

- `floor` 避免小数点飘字显示。
- 所有加成均从配置表读取，代码只负责解析和相乘。
- **牌型基础值**和**骰子点数之和**是加法关系，确保点数永远有价值。
- **肉鸽加成**和**装备加成**是乘法关系，区分局内/局外成长。

## 3. 怪物属性（普通模式）

```gdscript
class Monster:
    id: String
    name: String
    max_hp: int
    current_hp: int
    portrait_path: String      # 半身像贴图
```

| 属性 | 作用 | 备注 |
|------|------|------|
| id | 配置表索引 | 如 "monster_01" |
| name | UI 显示 | "MONSTER NAME"（参考图） |
| max_hp | 战斗开始时的 HP | 见 `data/monsters.json` |

## 4. 普通模式战斗循环
1. 玩家在 RESULT 阶段造成伤害 → `monster.current_hp -= final_damage`。
2. 飘字显示 `-N` 红色大字（参考图 ③）。
3. 怪物血条按比例缩短。
4. `current_hp ≤ 0` → 怪物倒地动画 → 进入能力选择（REWARD）阶段。

## 5. 肉鸽能力加成细则

### 5.1 牌型类加成
```gdscript
# 例：对子伤害加成 +30%
if hand_type == "pair":
    ability_mult *= 1.30
```
- 同类型能力可叠加（乘法）：两个 +30% → 总 ×1.69。
- 配置表 `abilities.json` 中定义：`{ "type": "hand_type", "target": "pair", "mult": 1.30 }`。

### 5.2 骰子 x 伤害翻 x 倍
```gdscript
# 例：骰子 6 的伤害翻 2 倍
if 6 in selected_dice:
    ability_mult *= 2.0
```
- 多个目标骰子可叠加：骰子 5、6 都翻倍 → 同时存在则乘两次。
- 配置表：`{ "type": "dice_face", "target": 6, "mult": 2.0 }`。

### 5.3 连续相同骰子型伤害加成
```gdscript
# 例：3 颗及以上连续相同骰子，伤害 ×1.5
max_streak = max_consecutive_same(selected_dice)
if max_streak >= 3:
    ability_mult *= streak_bonus_table[max_streak]
```
- 配置表：`{ "type": "streak", "threshold": 3, "mult": 1.5 }`。

### 5.4 增加重摇次数
- 不直接修改伤害，见 `02-骰子系统.md` §5。

## 6. 装备加成细则

装备加成与肉鸽能力**独立计算**，最终相乘：

```gdscript
equip_mult = 1.0

# 武器：提升特定牌型基础值 或 全局伤害
for equip in equipment:
    if equip.slot == "weapon" and equip.bonus_type == "hand_type":
        if equip.target == hand_type:
            equip_mult *= equip.mult

# 衣服：全局伤害加成 或 特定骰子加成
for equip in equipment:
    if equip.slot == "armor" and equip.bonus_type == "dice_face":
        if equip.target in selected_dice:
            equip_mult *= equip.mult

# 项链：特殊效果（如 streak 加成、全局加成）
for equip in equipment:
    if equip.slot == "necklace":
        equip_mult *= equip.mult
```

> 装备详细设计见 `12-装备系统.md`。

## 7. 无尽模式（正计条）
- 没有怪物 HP，只有 `endless_total_damage: int`，初始 0。
- 每次 RESULT 阶段：`endless_total_damage += final_damage`。
- UI 显示"累计伤害"进度条，从 0 向右增长。
- 10 次投掷用完后，结算展示 `endless_total_damage`。

## 8. 怪物受击反馈
| 事件 | 表现 |
|------|------|
| 受到伤害 | 半身像闪红 + 飘字 + 屏幕轻微震动 |
| 进入低血（普通模式 < 30%）| 半身像边缘泛红、出现裂痕 |
| 死亡 | 倒地 + 渐隐 + 碎裂音效 |
| 无尽模式累计伤害 | 正计条增长 + 大数字跳动 |

详见 `07-音效与反馈.md`。
