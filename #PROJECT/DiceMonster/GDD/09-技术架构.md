# 09 · 技术架构

> 模块定位：Godot 项目结构、数据驱动设计、配置表规范、导出到微信小游戏的考虑。
> **核心原则：数值、肉鸽元素、装备全部配置化，代码只负责读取与执行。**

## 1. 推荐 Godot 版本
- **Godot 4.2 LTS** 或更新 4.x
- 理由：生命周期稳定、对 HTML5/WebAssembly 导出支持成熟。

## 3. 数据驱动原则
- **怪物 / 关卡 / 能力 / 装备 / 全局数值**：全部放 `data/*.json`。
- **玩法逻辑**（牌型判定、状态机、伤害公式）：写 `*.gd` 脚本。
- **好处**：调数值、改能力、换装备都不用改代码；策划直接编辑 JSON 后重启游戏即可验证。

## 4. 核心模块（脚本）职责

| 脚本 | 职责 | 关键方法 |
|------|------|----------|
| `ConfigLoader.gd` | 加载并缓存 `data/*.json` | `load_json(path)`、`get_monster(id)`、`get_equipment(id)` |
| `Battle.gd` | 三阶段 + 能力选择 + 无尽模式状态机 | `_unhandled_input`、信号 `phase_changed` |
| `Dice.gd` | 单颗骰子行为 | `roll()`、`select()`、`deselect()` |
| `HandEvaluator.gd` | 牌型判定 | `evaluate(hand: Array[int]) -> {type, base_value}` |
| `Monster.gd` | 怪物属性 + 受击/累计伤害 | `take_damage(n)`、`add_endless_damage(n)` |
| `DamageCalc.gd` | 伤害公式 + 能力加成 + 装备加成 | `calc(hand, hand_type, abilities, equipment) -> int` |
| `AbilityManager.gd` | 随机抽 3 选 1 + 应用能力 | `roll_abilities(level_index)`、`apply(ability)` |
| `EquipmentManager.gd` | 装备加载 + 加成计算 + 掉落 | `get_equipment_bonus(hand_type, selected_dice)`、`roll_drop()` |
| `AudioManager.gd` | 音效/BGM 统一入口 | `play_sfx(name)`、`play_bgm(name)` |

## 5. 配置表加载方式（GDScript 示例）
```gdscript
# ConfigLoader.gd
const DATA_DIR = "res://data/"

var monsters: Dictionary
var levels: Array
var abilities: Array
var equipment: Array
var balance: Dictionary

func _init():
    monsters = _load_json("monsters.json")
    levels = _load_json("levels.json")
    abilities = _load_json("abilities.json")
    equipment = _load_json("equipment.json")
    balance = _load_json("balance.json")

func _load_json(file: String):
    var file_obj = FileAccess.open(DATA_DIR + file, FileAccess.READ)
    var text = file_obj.get_as_text()
    return JSON.parse_string(text)
```

## 7. 微信小游戏导出（参考 `Brainstorm/brainStorm-0807`）
1. Godot 项目设置 → Export → 添加 HTML5 模板。
2. 导出 `index.html` + `index.wasm` + `index.pck`。
3. 用微信开发者工具新建小游戏项目，关联上述文件。
4. 处理分辨率：微信小游戏默认 720×1280，按比例缩放。
5. 性能：避免大场景 + 大量 Tween；粒子系统用 GPUParticles2D。
6. 音频：使用 `.ogg` 或 `.mp3`，避免大文件。
7. 微信 API：分享成绩调用 `wx.shareAppMessage`；排行榜需要后端或微信云开发。

## 8. 性能预算（移动端）
- 帧率：稳定 60 FPS（中端机 30 FPS 兜底）。
- 内存：< 150 MB。
- 安装包：< 20 MB（v1）。

## 9. 调试工具
- `tools/simulate.gd`：蒙特卡洛概率/伤害模拟，直接读 `data/*.json`。
- `tools/validate_data.gd`：校验 JSON 字段是否完整、id 是否引用正确。
- Godot Remote：移动端实时调试。
