# 12 · 装备系统

> 模块定位：定义勇者的 3 部位装备（武器/衣服/项链），装备掉落规则，以及装备对伤害的加成方式。
> 所有装备数据来自 `data/equipment.json`；本文件只描述设计规则和配置示例。

## 1. 核心设计

- **勇者设定**：玩家扮演勇者，通关后获得随机装备奖励。
- **3 部位**：武器、衣服、项链，每个部位只能装备 1 件。
- **装备与肉鸽能力的区别**：
  - 装备 = **局外养成**，永久生效，可替换
  - 肉鸽能力 = **局内成长**，单局有效，不可保留

## 2. 装备部位

| 部位 | 英文 | 典型加成方向 | 示例 |
|------|------|-------------|------|
| 武器 | weapon | 特定牌型伤害加成 | 对子短剑：对子伤害+20% |
| 衣服 | armor | 特定骰子加成 / 全局加成 | 六面铠甲：含6的伤害+25% |
| 项链 | necklace | 特殊效果（streak/重摇/全局） | 连击戒指：连续相同骰子+30% |

## 3. 装备属性

```gdscript
class Equipment:
    id: String
    slot: String           # "weapon" | "armor" | "necklace"
    type: String           # "hand_type" | "dice_face" | "streak" | "reroll" | "mult_global"
    target: Variant        # 根据 type：牌型名 / 骰子点数 / streak阈值 / null
    mult: float = 1.0      # 伤害倍率加成
    value: int = 0         # 数值加成（如重摇次数）
    name: String
    desc: String
    rarity: String         # "common" | "rare" | "epic"
```

## 4. 装备加成规则

装备加成与肉鸽能力**独立计算**，最终与能力加成**相乘**：

```gdscript
equip_mult = 1.0

# 遍历 3 个装备槽
for equip in [weapon, armor, necklace]:
    if equip == null:
        continue
    
    match equip.type:
        "hand_type":
            if equip.target == hand_type:
                equip_mult *= equip.mult
        "dice_face":
            if equip.target in selected_dice:
                equip_mult *= equip.mult
        "streak":
            if max_streak >= equip.target:
                equip_mult *= equip.mult
        "mult_global":
            equip_mult *= equip.mult
        "reroll":
            # 重摇加成在 Battle.gd 中处理，不在伤害公式
            pass

final_damage = floor((base_value + dice_sum) * ability_mult * equip_mult)
```

## 5. 装备掉落规则

| 项目 | 规则 |
|------|------|
| 掉落时机 | **通关后**（击败第 10 只怪 + 完成无尽模式） |
| 掉落数量 | 固定 **1 件** 随机装备 |
| 来源 | 从 `data/equipment.json` 中按稀有度权重随机抽取 |
| 重复处理 | 已获得同 id 装备 → 转化为"强化材料"或自动升级（v2） |
| 保底机制 | 连续 N 次未出 epic → 下次必出 rare 以上（可配置） |

## 6. 稀有度与掉落权重

| 稀有度 | 颜色 | 基础掉落权重 | 属性强度 |
|--------|------|-------------|----------|
| common | 白/灰 | 60% | 加成 1.15~1.25 |
| rare | 蓝 | 30% | 加成 1.30~1.40 |
| epic | 紫/金 | 10% | 加成 1.50~2.00 |

## 8. 装备界面（局外）

- 主菜单或战斗前可进入装备界面。
- 3 个槽位横向排列：武器 | 衣服 | 项链。
- 点击槽位弹出已拥有装备列表，选择穿戴。
- 未解锁槽位显示"通关第 X 关解锁"（v2 扩展）。

## 9. 装备与肉鸽能力的协同

| 场景 | 装备 | 肉鸽能力 | 效果 |
|------|------|----------|------|
| 对子流 | 对子短剑 ×1.2 | 对子精通 ×1.3 | 总 ×1.56 |
| 顺子流 | 顺子长刀 ×1.35 | 顺子大师 ×1.5 | 总 ×2.025 |
| 六点流 | 六面铠甲 ×1.25 | 六点暴击 ×2.0 | 总 ×2.5 |

> 装备和能力是**乘法叠加**，鼓励玩家围绕同一流派同时堆叠装备和能力。
