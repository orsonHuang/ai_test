# 12 · 装备系统

> 模块定位：定义勇者的 3 部位装备（武器/衣服/项链），装备获取方式，以及装备对伤害的加成方式。
> 所有装备数据来自 `data/equipment.json`；本文件只描述设计规则和配置示例。
> **注意**：装备获取方式已从"通关掉落"改为"商店购买"（见 `16-商店系统.md`）。

## 1. 核心设计

- **勇者设定**：玩家扮演勇者，通过商店购买装备。
- **3 部位**：武器、衣服、项链，每个部位只能装备 1 件。
- **装备与肉鸽能力的区别**：
  - 装备 = **局外养成**，永久生效，可替换
  - 肉鸽能力 = **局内成长**，单局有效，不可保留

## 2. 装备获取

| 方式 | 说明 |
|------|------|
| 局外商店购买 | 使用局外金币在商店购买（见 `16-商店系统.md`） |
| 局内商店购买 | 使用局内金币在地图商店节点购买（v2 扩展） |

> 旧版"通关后掉落装备"机制已移除。

## 3. 装备部位

| 部位 | 英文 | 典型加成方向 | 示例 |
|------|------|-------------|------|
| 武器 | weapon | 特定牌型伤害加成 | 对子短剑：对子伤害+20% |
| 衣服 | armor | 最大面加成 / 全局加成 | 满值铠甲：掷出最大面时伤害+25% |
| 项链 | necklace | 特殊效果（streak/重摇/全局） | 连击戒指：连续相同骰子+30% |

## 4. 装备属性

```gdscript
class Equipment:
    id: String
    slot: String           # "weapon" | "armor" | "necklace"
    type: String           # "hand_type" | "dice_max_face" | "streak" | "reroll" | "mult_global"
    target: Variant        # 根据 type：牌型名 / streak阈值 / null
    mult: float = 1.0      # 伤害倍率加成
    value: int = 0         # 数值加成（如重摇次数）
    name: String
    desc: String
    rarity: String         # "common" | "rare" | "epic"
    price: int             # 商店价格（局外金币）
```

## 5. 装备加成规则

装备加成与肉鸽能力**独立计算**，最终与能力加成**相乘**：

```gdscript
equip_mult = 1.0

for equip in [weapon, armor, necklace]:
    if equip == null:
        continue
    
    match equip.type:
        "hand_type":
            if equip.target == hand_type:
                equip_mult *= equip.mult
        "dice_max_face":
            for die in selected_dice:
                if die.value == die.faces:
                    equip_mult *= equip.mult
        "streak":
            if max_streak >= equip.target:
                equip_mult *= equip.mult
        "mult_global":
            equip_mult *= equip.mult
        "reroll":
            pass  # 重摇加成在 Battle.gd 中处理

final_damage = floor((base_value + dice_sum) * ability_mult * equip_mult * skill_mult)
```

## 7. 装备界面（局外）

- 玩家大厅可进入装备界面。
- 3 个槽位横向排列：武器 | 衣服 | 项链。
- 点击槽位弹出已拥有装备列表，选择穿戴。

## 8. 装备与肉鸽能力的协同

| 场景 | 装备 | 肉鸽能力 | 效果 |
|------|------|----------|------|
| 对子流 | 对子短剑 ×1.2 | 对子精通 ×1.3 | 总 ×1.56 |
| 顺子流 | 顺子长刀 ×1.35 | 顺子大师 ×1.5 | 总 ×2.025 |
| 三条流 | 三条法杖 ×1.5 | 三条强化 ×1.4 | 总 ×2.1 |
| 满值流 | 满值铠甲 ×1.25 | 满值暴击 ×2.0 | 总 ×2.5 |

> 装备和能力是**乘法叠加**，鼓励玩家围绕同一流派同时堆叠装备和能力。
