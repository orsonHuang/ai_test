
### 2.2 交互流程

| 步骤 | 玩家操作 | 系统反馈 |
|------|----------|----------|
| 1 | 自动投骰 | 播放投骰动画，显示结果 |
| 2 | 点击骰子选中/取消 | 高亮选中骰子，更新牌型预览 |
| 3 | 点击"重摇" | 消耗重摇次数，重新投掷未选中骰子 |
| 4 | 确认选择后点击"出牌" | 计算伤害，播放攻击动画 |
| 5 | 怪物反击 | 播放受击动画，HP 减少 |

### 2.3 骰子选择规则

- 从所有骰子中选择 3 颗（可配置）。
- 未选中的骰子灰色显示。
- 选中后实时更新牌型预览和伤害预估。

## 4. 全局 UI 规范

### 4.1 分辨率适配

| 基准分辨率 | 1920×1080 |
|-----------|-----------|
| 适配方式 | 等比缩放 + 锚点布局 |
| 安全区域 | 上下左右各留 5% 边距 |

### 4.2 字体大小建议

| 元素 | 大小 |
|------|------|
| 页面标题 | 36px |
| 按钮文本 | 24px |
| 正文 | 18px |
| 数值（HP/金币） | 20px 加粗 |
| 提示文本 | 16px |

### 4.3 颜色规范

| 元素 | 颜色 |
|------|------|
| 主色调 | 暖色调（骰子/冒险主题） |
| HP 条 | 绿色(>50%) → 黄色(20~50%) → 红色(<20%) |
| 稀有度 common | 白/灰 |
| 稀有度 rare | 蓝色 |
| 稀有度 epic | 紫色 |
| 选中高亮 | 金色边框 |
| 不可用 | 灰色 + 半透明 |

### 4.4 动画规范

| 场景 | 动画 | 时长 |
|------|------|------|
| 骰子投掷 | 骰子旋转弹跳 | 0.5s |
| 重摇 | 选中骰子旋转 | 0.3s |
| 伤害数字 | 飘字上浮消失 | 0.8s |
| 怪物受击 | 抖动 + 闪红 | 0.3s |
| 玩家受击 | 屏幕边缘闪红 | 0.3s |
| 牌型判定 | 牌型名称弹出 | 0.5s |
| 节点选择 | 路径高亮流动 | 0.5s |

## 5. 暂停菜单

在战斗和地图中均可打开暂停菜单（ESC 键或菜单按钮）：

```
┌───────────────────────────┐
│         暂停                │
│                           │
│   [继续]                   │
│   [设置]                   │
│   [放弃挑战]  → 确认对话框  │
│   [返回主菜单] → 确认对话框 │
└───────────────────────────┘
```

| 按钮 | 行为 |
|------|------|
| 继续 | 关闭菜单，回到游戏 |
| 设置 | 打开设置页面（覆盖） |
| 放弃挑战 | 弹出确认 → 结算（骰子碎片 50%）→ 返回大厅 |
| 返回主菜单 | 弹出确认 → 自动保存 → 返回开始页面 |
