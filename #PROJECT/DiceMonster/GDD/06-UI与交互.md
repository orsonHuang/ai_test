# 06 · UI 与交互

> 模块定位：三阶段战斗 UI + 能力选择界面 + 无尽模式正计条 + 结算界面。

## 1. 整体布局（手机竖屏）
```
┌──────────────────────────┐
│  [返回]                  │
│    (3/10) · 投掷 2/10    │  ← 顶部：关卡进度 + 无尽次数
│   ┌────────────┐         │
│   │  Monster   │         │  ← 半身像
│   │  半身像     │         │
│   └────────────┘         │
│  ████░░░░░░░░ HP BAR     │  ← 普通：扣血条 / 无尽：正计条
│  MONSTER NAME            │
│                          │
│  [伤害飘字 -26]           │
│                          │
│  (① 准备)  投掷按钮        │
│  (② 决策)  [1][2][5][6][6][6] + [重摇] [确定]
│  (③ 结果)  骰子浮起 + 飘字  │
└──────────────────────────┘
```

## 2. 三阶段界面差异

| 阶段 | 顶部 | 中部 | 底部 | 状态指示 |
|------|------|------|------|----------|
| ① 准备 | 关卡进度 (N/10)，无尽模式显示投掷次数 | 怪物半身像 | 圆形"投掷"按钮 | 按钮轻微脉冲动画 |
| ② 决策 | 同上 | 怪物半身像 | 6 颗骰子 + [重摇] [确定] | 选中骰子浮起 + 高亮 |
| ③ 结果 | 同上 | 骰子浮到怪物周围 + 飘字 | 无 | `-N` 红色飘字 + 血条变化 |

## 3. 能力选择界面（REWARD 阶段）

### 3.1 布局
```
┌──────────────────────────┐
│  选择一项能力              │
│                          │
│  ┌────┐  ┌────┐  ┌────┐  │
│  │ 能力A │  │ 能力B │  │ 能力C │
│  │ 图标 │  │ 图标 │  │ 图标 │
│  │ 名称 │  │ 名称 │  │ 名称 │
│  │ 描述 │  │ 描述 │  │ 描述 │
│  └────┘  └────┘  └────┘  │
│                          │
└──────────────────────────┘
```

### 3.2 卡牌规范
- 3 张卡牌等宽横向排列，间距 16 px。
- 每张卡牌包含：图标、名称、简短描述、数值提示。
- 点击后高亮，再点击"确认"或再次点击即选中。
- 无成本，不需要显示货币。

## 4. 无尽模式正计条
- 视觉：从 0 开始的横向条，**从左向右增长**（与普通扣血条相反）。
- 颜色：建议金色/橙色，与普通血条粉色区分。
- 数字：显示 `累计伤害：XXXX`。
- 增长动画：每次 RESULT 阶段结束后，条平滑增长到最新值。

## 5. 结算界面
- 触发：无尽模式 10 次投掷用完。
- 展示内容：
  - 本局总伤害（大字）
  - 普通模式 10 只怪的伤害贡献（可选小字/柱状图）
  - 无尽模式累计伤害
  - 获得的能力列表
  - 最高倍率牌型
  - **装备掉落展示**：弹出 1 张装备卡牌，展示属性后自动存入装备库
  - [再玩一次] [返回主菜单] [分享]（微信小游戏）

## 6. 装备界面（局外）

### 6.1 布局
```
┌──────────────────────────┐
│  [返回]     装备          │
│                          │
│  勇者立绘（或头像）        │
│                          │
│  ┌────┐ ┌────┐ ┌────┐   │
│  │武器 │ │衣服 │ │项链 │   │  ← 3 个装备槽
│  │图标 │ │图标 │ │图标 │   │
│  │名称 │ │名称 │ │名称 │   │
│  └────┘ └────┘ └────┘   │
│                          │
│  已拥有装备列表：          │
│  ┌──────────────────┐    │
│  │ 装备A · 对子短剑   │    │
│  │ 装备B · 六面铠甲   │    │
│  │ 装备C · (空)      │    │
│  └──────────────────┘    │
└──────────────────────────┘
```

### 6.2 交互
- 点击槽位 → 弹出已拥有装备列表（按部位筛选）。
- 点击装备 → 穿戴到对应槽位。
- 已穿戴装备再次点击 → 卸下。
- 未解锁槽位 → 灰显 + "通关解锁"提示。

## 7. 关键交互规范

### 6.1 骰子
- 默认 96×96 px（占位），手机屏幕 9:16 适配。
- 触摸区域外扩。
- 选中状态：缩放 1.1 + Y 轴上移 20 px + 蓝色高亮边框。

### 6.2 按钮
- "投掷"：圆形，直径 ≈ 屏幕宽度的 1/4。
- "重摇" / "确定"：圆角矩形，高度 ≈ 骰子高度。
- 禁用态：灰度 50% + 不响应点击。

### 6.3 飘字
- 字体：粗体大号。
- 颜色：红色 `#E53935`。
- 动画：从怪物位置向上飘 60 px + 渐隐 0.6 s。
- 无尽模式下额外显示"+N"绿色飘字到正计条位置。

## 8. 状态文字
- 重摇次数：按钮旁 "重摇 (1/2)"。
- 牌型提示：决策阶段选中后，底部显示 "对子 ×1.5 + 能力加成 → 预估 45"。
- 关卡进度：`(当前/总数)`，如 `(3/10)`。
- 无尽次数：`投掷 3/10`。

## 9. 视觉资源清单（占位）
| 资源 | 用途 | 状态 |
|------|------|------|
| 怪物半身像 ×N | 怪物区 | 待准备 |
| 骰子贴图（1~6 面） | 骰子 | 待准备 |
| 投掷按钮图标 | 准备阶段 | 黑手图标占位 |
| 血条前景/背景 | 普通模式 | 粉/黑双色 |
| 正计条前景/背景 | 无尽模式 | 金/深色 |
| 能力卡牌背景 | 能力选择 | 待准备 |
| 背景图 | 全局 | 渐变占位 |

## 10. 适配与可访问性
- 屏幕方向：**仅竖屏**。
- 安全区：iOS 刘海 / Android 底部导航栏预留。
- 字号：基础 16 sp，最小不小于 14 sp。
- 色弱友好：伤害飘字不只用颜色，可加 `!` 符号或放大动画。
