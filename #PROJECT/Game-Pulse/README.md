# Game Pulse · 游戏团队项目情报台（暂定名）

## 项目描述

把 SVN 中的游戏项目更新转成可追溯的摘要、文档差异与时间线，并结合竞品、行业资讯和 AI 游戏开发方法，帮助团队快速建立共同认知。

当前阶段：产品与架构提案。已研究 AIHOT 官方页面及开源架构；尚未连接实际 SVN、实现采集器或部署网页。名称、技术选型和里程碑均为建议。

## 工作规则

- 每次工作先读本文件，再读相关设计文档；沿用工作区 AGENT.md。
- 产品优先级：项目更新可信可追溯 → 团队阅读与确认 → 外部情报 → 工作流沉淀。
- 默认只采集已提交内容，不改动个人 SVN 工作副本，不自动提交或更新其文件。
- 用户已允许公司批准的外部 AI API；原始文件留内网，按配置发送必要内容，密钥仅存服务端。演示数据必须明确标注。
- 提交记录、AI 推断、负责人确认、测试通过、上线状态分别保存，不能相互冒充。
- 服务端按项目和路径检查权限，适用于摘要、搜索、下载、推送及历史内容。
- 用户已确认本轮先完成架构；后续实施先核实 SVN 路径、样本文档、权限和部署环境。
