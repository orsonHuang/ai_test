# 核心玩法系统分析：日间农场

## 问题：怎样保留真实农场感，又不把白天变成杂活？

状态：agent_proposal

### 广度分析

- 纯菜单配置最省时间，但无法兑现“武器是种出来的”这一幻想。
- 除草、驱虫、修剪和复杂加工能增加拟真度，却会稀释出战准备。
- 真实地块配合少量关键操作，既能形成农庄记忆，也能控制节奏。

### 深度分析

白天真正影响下一次夜战的操作只有选地、播种、分配水、收获和主动铲除。玩家需要看见作物成长、成熟和战后变化，但不必持续处理与构筑无关的维护劳动。

地块承担空间取舍，作物状态承担跨天期待，战后集中反馈承担“这一晚推动了农庄”的因果感。成熟天数和停止生长原因应可查，但不需要常驻压屏。

### 综合判断

保留可辨认的真实地块和跨天成长，只实现五类关键操作；把复杂加工、嫁接、自动化和批量管理后置。白天段的目标是完成一组可解释的投资，而不是延长操作时间。

## 问题：水、地块和损耗怎样产生轻压力而不惩罚玩家？

状态：agent_proposal

### 广度分析

- 水无限会让分配失去意义。
- 缺水导致枯死能制造强压力，但会放大失败后的负反馈。
- 缺水只停止成长，能保留取舍而不摧毁积累。
- 铲除返还资源能提高容错，却容易成为套利手段。

### 深度分析

水应总体充足但不足以同时推进所有目标，玩家因此选择先让哪种武器作物成熟。未浇水只延迟成长，不枯萎、不毁档；主动铲除只释放地块，不返还材料，避免用重种刷收益。

堆肥箱和苗床适合提供早期容错：前者承接已经发生的损耗，后者缓解地块占用。灌溉和批量操作应在玩家理解手动分配价值后再解锁。

### 综合判断

用“有限但温和”的水和地块制造优先级：错误决策造成延迟，而不是不可逆损失。设施只用于改善容错与操作负担，不应消除白天的核心选择。
