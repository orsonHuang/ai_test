# 概念设计：刃种农庄

## 一句话概念

《刃种农庄》是一款黑色幽默武器作物 roguelite：玩家经营一座会长出荒诞武器作物的农庄，通过短局种植和局外资源投资准备下一次低输入夜战，战后推进下一天，等待更离谱的作物成熟、回收、变异和解锁。

## 设计锚点

- 核心幻想：作为刃种师，把荒诞作物种成武器并带进夜战。
- 目标体验：用少量有意义的农场投资塑造下一次低输入战斗，并持续期待更离谱的武器作物。
- 玩家动机：短期验证当天准备能走多远，长期解锁新的武器作物谱系和农场能力。
- 核心循环：经营农场并准备出战 → 推进或撤离夜战 → 带回资源并推进下一天 → 调整下一轮投资。
- 跑偏风险：膨胀成长线、生活模拟或生产线管理会掩盖“种武器去战斗”的核心承诺。
- 非目标：不做重动作战斗、硬核搜打撤、长期生活模拟或复杂农场生产线。

## 概念边界

Concept 阶段只定义游戏的核心幻想、目标用户、体验基调和排除方向。具体战斗时长、武器数量、资源流、系统清单和 MVP 内容，留到 Top Design 阶段决定。

## 核心幻想

玩家应该不断产生一个念头：

“这玩意居然能种出来，还真能拿去打怪。那下一种更抽象的作物会是什么？”

武器不是掉落装备，也不是商店商品，而是一种能播种、成熟、损耗、回收、变异并形成谱系的荒诞作物。农庄的价值不在于长期生产线效率，而在于让玩家为下一次夜战做投资，并期待新的武器作物谱系被永久解锁。

## 目标用户

目标用户与 Dave the Diver 的受众高度重合：

- 喜欢轻松双循环，而不是单一战斗或单一经营。
- 喜欢短段落推进，每一轮结束都获得清楚反馈。
- 喜欢怪点子和新奇内容，愿意为了“下一个会是什么”继续玩。
- 能接受轻量战斗压力，但不想被重动作门槛或硬核亏损惩罚劝退。

本项目也吸收 Vampire Survivors / Brotato 受众的一部分需求：低输入战斗、局外成长、反复挑战、解锁新构筑。但它不能变成纯幸存者换皮，因为农田视觉、作物成长和谱系解锁必须始终存在。

## 玩家身份

玩家是刃种师，经营一座不太正常的农庄。这里的作物不是为了卖钱，而是为了长成能咬、能砍、能爆、能挡、能拖着怪物一起烂在地里的活体武器。

白天，玩家把有限资源投入到种子、农田、保鲜、改造和谱系成长里。夜晚，玩家带着这些作物出战。战后，下一天被推进，部分作物成熟，部分作物损耗，部分东西变成堆肥、种核、材料或永久解锁。

## 体验目标

玩家应该感到：

1. 我不是在照顾一个长期慢慢运转的农场，而是在为下一次出战做局外投资。
2. 不进战斗就不会推进下一天，所以每次夜战都是农庄成长的节拍。
3. 打得好会赚到额外资源、谱系推进和新作物期待；打得不好主要是少赚，不会强烈劝退。
4. 作物会消耗，但消耗后的残渣、种核和材料仍然能回到农场。
5. 永久成长最重要的是解锁更多武器作物谱系，其次是农田设施，再其次才是角色数值。

## 情绪基调

黑色幽默，荒诞植物武器和怪物生态，现实感弱。可以有一点恶趣味，但边界是“有设计感的武器化农作物”，不是黏液、腐烂或器官感。

它不是可爱治愈农场，也不是严肃末日生存。压力可以有，但应是轻度的、带一点坏笑的压力：玩家会担心“这把能不能赚回来”，但不会害怕“一晚打差了整个存档完蛋”。

## 不是什么

| 不是 | 原因 |
|---|---|
| 不是 Stardew Valley 式生活模拟 | 不以长期生活、社交、日程和城镇关系为核心 |
| 不是开罗式长期经营 | 不以设施效率、员工、店铺优化或生产线排布为核心 |
| 不是重度农场生产线 | 农田保留视觉和跨天成长，但不做复杂布局优化 |
| 不是硬核搜打撤 | 有投入和回本感，但失败主要少拿额外奖励，不制造强亏本焦虑 |
| 不是纯 Vampire Survivors 换皮 | 战斗是农庄投资的验证，不是局内成长独立循环 |
| 不是武器店经营 | 种出来的武器主要拿去打怪，不是卖给顾客 |

## Concept 定稿

《刃种农庄》的核心不是“白天种田，晚上打怪”这么泛，而是：

> 用一座黑色幽默的武器农庄，管理下一次夜战的局外投资，并通过战斗推进下一天，解锁越来越抽象的武器作物谱系。

后续 Top Design 必须围绕这个概念展开：农场要短局化，战斗要低输入，损耗要可回收，长期成长要优先服务武器作物谱系期待。
