# 三款参考切片集成表 · P v1

本篇全部为P参考方案，作为27份文档的联调入口。各切片独立，不能把暖雪的局内币或蔚蓝的体力直接混入英雄没有闪。初始状态是演示夹具，不是任何原作新账号的真实初始资源。

## 共用覆盖顺序与生命计算

规则优先级为：明确的模式覆盖→模块专用规则→[公共契约](参考实现公共契约.md)。新模式若缺少必填覆盖则拒绝启动，不用猜测补齐。战斗基础、角色成长、装备、侍从、套装按独立来源汇总，重算从基础值开始。

直接伤害先算理论值，再取 `actualDamage=min(理论值,目标结算前剩余HP)`；吸血等按实际伤害，伤害飘字可以显示理论值但诊断日志同时保留两者。HP最终夹在0..maxHP。护盾先吸收，只有穿过护盾的部分是HP损失；模块指定“造成伤害”默认指HP实际损失，若需要包含护盾伤害须另设事件。最大HP增加不自动治疗，只有模块明确写明的创建、回营或奖励加血例外。

同tick事件收集后按固定序号结算，胜败以完整tick结束状态判定。出现互相致死按各模式规则处理；奖励只由模式/关卡域发放，伤害、装备和特效模块不能自行再次发奖。

### 开战快照与能力汇总

英雄攻击按基础×局内星级×永久等级系数×增伤池×暴击倍率计算后取整；增伤池包含装备attack、部位强化、披风、局内强化和当次符合条件的图腾/赛季效果。同类基点相加，条件在攻击时判断，不将前三波或首领增伤常驻化。暴击只作用于英雄直接攻击，上限5000基点。

国王是独立攻击源，普通攻击与剑气读取成长v2，不继承英雄星级和英雄暴击。共享城堡双方加成汇总后初始化满血，重连不重新加上限。公会靶场无城堡，护墙/装备baseHp无收益；靶为boss，boss图腾可生效。

### 经济边界与验收口径

本参考只有三名演示英雄及明确列出的内容集，不是原作全量可玩复刻。金币/材料产出与费用要在同一v2配置下模拟；章节中的单模块测试未声明的加成默认关闭。普通合作网页原型只演示房间准备，不实现双人战斗或赛季计分。

英雄5级首次召唤奖励与TD召唤事务同tick，合成不会再次给币。装备暴击逐次直接攻击独立抽，暴击先于敌HP扣除；多星级倍率与英雄系数相乘、攻击增益加法汇总。模式实例读固定配置，途中局外升级不影响任何进行中模式。

联调验收P：主线s1首通消耗1体力、发100金币；招募获得archer2碎片后，archer1→2消耗100金币2碎片。该角色1星攻击10×1.05取整10，界面应如实显示取整结果，不能虚构每级必有1点可见伤害提升。这个样例也用于发现低数值时的台阶效应，再由策划调参。

主线小怪装备处理完成计入本轮3怪进度；返回营地不清已完成进度。当前敌人退出保存HP与actionSeq，回营恢复主角HP，重新进入同敌人保留其HP会产生低风险磨血，这在参考方案中明确允许；若项目不接受，需同时修改恢复规则与失败成本，不能由开发自行改变。

联调验收P：普通掉落分解给结晶→祝福计时→领取升级→仅后续掉落用新权重；头衔扩大上限会消费累积XP；日常暗能奖励进入待领取时不触发普通装备分解提示。默认完整方案与单模块“基础攻击10”的隔离用例不同，联调时使用完整快照计算。
