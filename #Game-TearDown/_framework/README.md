## 工作规则

内容规范的单一来源在本目录。Skill 内保留可独立执行的精简规则；本库存在时优先遵循本库入口。新建游戏先写 README，再写系统案例；旧案例不自动升级为已验证。所有交付状态以文件和验证结果为准，不根据已有目录推断完成。

原始截图缺失不等于不能分析机制；可以用注明依据的原创关系图解释机制，但 UI 观察必须留待原图核实。公开展示只导出有明确公开状态的图片，研究引用材料默认保留来源链接。
