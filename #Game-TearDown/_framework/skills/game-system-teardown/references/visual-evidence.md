# 美术表现与视觉证据

先看原图再写观察。截图、宣传图、录屏各能证明不同事情：宣传图能说明视觉方向，不能证明实际战斗的信息可读性；静态画面不能证明动效节奏。

## 观察到解释

- 形状与轮廓：角色、敌人、可交互物的区分；缩小后哪些特征仍成立。
- 明暗与颜色职责：主目标、危险、奖励、禁用、背景分别如何处理；避免只写“色彩丰富”。
- 材质与细节：密度集中在哪里，是否干扰规则信息；战斗模型与角色展示的阅读任务不同。
- 镜头与布局：视线顺序、遮挡、安全区及操作距离；不要用审美标签替代功能分析。
- 动效与音频：有实际片段才分析预告、命中、结算和反馈时序；缺片段就写采证问题。

每项解释采用“具体画面 → 玩家如何识别/操作 → 收益与代价”。不推断原作制作成本、骨骼、Shader 或引擎实现。

## 图文交付

原作截图、依据截图重绘的线框、原创机制示意、补充设计使用不同图注。编号对应区域说明；说明置于图外，不挤进游戏 UI。重绘保留可证实的信息关系，删去无关装饰，注明不是像素复刻。未允许公开的素材仅保留来源入口，发布原创说明图。生成式美术只用于明确标注的概念示意，不制造实机证据。

在实际正文宽度与手机宽度查看；图中文字需要可读，必要时允许独立放大。原作图片缺失时不靠占位图宣称完成 UI 观察。
