# 分析分支与市场口径

在共同的产品介绍、循环、节奏、系统地图、数值和商业模式骨架上，按研究对象选择分支。游玩形态、收费方式、运营方式、发行地区相互独立；单机也可能销售 DLC，海外产品也可能长线内购。

## 完整体验与单机

沿学习、挑战、探索、叙事峰值及收束检查流程。解释玩家获得哪些新动作、为什么改变策略、失败付出什么、通关后为何重玩。把本体与 DLC 分开，不能将后续扩展规则归入基础版本。Steam 同类研究同时看成功与弱表现样本，记录标签、价格与评价窗口；评论数乘固定系数不当销量或收入事实。

## 长线商业化

按首日理解、形成稳定资源路线、多队伍/竞技/收藏目标区分阶段，不在没有体验记录时编造第几天解锁。分别画免费路径、付费改变的效率或能力、广告的触发位置；区分角色获取与培养可用。追踪日常、周常、活动、赛季，检查时间负担和资源回流。产消比、留存、LTV、概率及成长天数没有测量就不填经验常数。

## 地区与证据

- 先锁产品、平台、区服、语言、资料日期，再谈海内外；开发商国籍不等于发行市场。
- 同款跨区比较要逐项核对内容进度、价格币种、卡池、广告、活动和本地化。未查到海外规则就不补想象中的海外版。
- 每个计数保留渠道、地区、时间、单位、取整情况及官方/平台/估算身份。平台下载、关注、评价、活跃、收入不可混算；不从英语评论推断用户国籍。
- 界面出现、功能解锁、玩家首次使用是三个不同证据。截图记区域，视频记时间点，原作资料、作者推断与参考设计分层。
- 玩家评论用于发现问题，攻略用于核对操作；都须保留作者与样本背景，不能当总体玩家结论。公告中的计划不写成已上线。
