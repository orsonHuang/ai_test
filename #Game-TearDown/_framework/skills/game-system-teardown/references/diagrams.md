# 机制图与流程图

先写这张图回答的问题，再选图型。系统地图回答有哪些模块且可跳转；流程图回答步骤与判断；状态图回答状态如何变化；泳道/时序图回答多角色如何协作；资源图回答产出消耗与回流。

- 一张图保持同一层级。主图过密就拆分子流程，不靠缩小字体容纳。
- 箭头注明触发或关系；判断分支写清条件，避免只有“成功路径”。资源不足、取消、返回等仅在相关时添加。
- 原作未知分支不要补成事实。参考流程与观察流程分图，并在图旁说明。
- Mermaid/SVG 保留可编辑源。用统一主题和语义颜色，颜色之外还用文字或线型区分；窄屏优先纵向，复杂图提供放大。
- 图下用一句话解释结论；字段、状态名与正文、原型一致。
- 实际渲染检查标签裁切、重叠、箭头、对比度与手机字号；解析通过不代表可读。返回定位要等待图像和流程图稳定。

方法参考：[diagramming](https://github.com/arjunprabhulal/agent-skills/blob/main/skills/docs/diagramming/SKILL.md)。约九节点只是拆图提示，不是强制限制。
