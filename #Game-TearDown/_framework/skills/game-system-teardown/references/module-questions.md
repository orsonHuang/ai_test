# 模块专用问题

只加载本次相关模块。下表是采证问题，不代表目标游戏必然存在该机制。

| 模块 | 必须解释的决策与规则 | 图解优先 | 常见证据陷阱 |
|---|---|---|---|
| 背包／仓储 | 容量按格/重量/数量？物品堆叠、锁定、筛选、批量处理、溢出与扩容？ | 总览＋获得→比较→保留/处理前后 | 装备槽不等于背包；没看到扩容不等于免费无限 |
| 装备／圣物 | 品质、词条、槽位、套装、替换损失、强化继承、触发条件？ | 同物不同槽／换装对比／依赖图 | 战力上涨不代表当前构筑收益更高 |
| 养成 | 局内与永久如何分开？资源从哪来去哪里？重置、分支、上限与追赶？ | 两层循环＋解锁节点 | 长线成长不能直接套给局内肉鸽 |
| 竞技场 | 同步/异步？胜负、匹配、排名、赛季、奖励、次数、属性带入？ | 参赛→结算流程与榜单 | 有排名不能推定实时 PvP；看不见匹配算法就标未知 |
| 合作／社交 | 谁与谁协作？收益如何分配？失败、掉线、组队门槛？ | 角色分工＋资源流 | 自动匹配不代表真人；好友榜不等于公会 |
| 战斗 | 输入、资源、瞄准、距离、攻击窗口、受击、失败恢复？ | 动作循环与反馈时序 | 宣传视频不能测输入延迟、碰撞盒、伤害公式 |
| 构筑／技能 | 选项如何获得？哪些互斥/协同？决策可逆吗？随机有无补救？ | 选择树＋触发链 | 推荐配装不等于最优解；不要混 DLC 技能 |
| 关卡／挑战 | 目标、波次、分岔、敌人职责、难度、重复内容？ | 阶段图＋失败原因 | 商店承诺时长不等于实测通关时间 |
| 经济／商业化 | 各币种产消、库存、支付对应价值、免费路径与付费路径差异？ | 资源图；事实与假设分线 | 内部留存/流水未知；不以礼包存在证明强制付费 |
| 运营／任务 | 日周/赛季/开服时间、领奖、复位、补领、回流？ | 日历与状态转换 | 历史活动不是常驻系统；价格与概率必须有对应版本 |
| 叙事／收集 | 内容如何触发、查看、重访？是否影响结局或成长？ | 信息发现→拼接→反馈 | 有碎片叙事不等于所有结局条件已证实 |
| 引导／设置 | 教学顺序、跳过与重看、控制映射、可读性与反馈设置？ | 首次与再次进入对照 | 不因常见惯例而补出不存在的设置项 |

长线运营视角附问：重复频率、付费分层、追赶、版本通胀与维护负担。完整体验视角附问：学习、节奏、结束体验、重玩、操作摩擦与内容密度。两种视角都分析体验收益和玩家代价。
