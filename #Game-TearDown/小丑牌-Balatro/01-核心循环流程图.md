# 小丑牌（Balatro）核心循环流程图

> 用 Mermaid 绘制。可在支持 Mermaid 的编辑器（VS Code 插件、Typora、GitHub）中直接渲染。

## 1. 宏观循环（Run 层）

```mermaid
flowchart TD
    A[选择牌组与难度<br/>开始一局 Run] --> B[进入 Ante 底注 1/8]
    B --> C{当前 Ante 的<br/>三个盲注}
    C --> D[小盲注 Small Blind]
    D --> E[大盲注 Big Blind]
    E --> F[Boss 盲注 Boss Blind<br/>附带负面规则]
    F --> G{分数是否达标?}
    G -- 否 --> H[Run 结束<br/>Game Over]
    G -- 是 --> I{Ante &lt; 8?}
    I -- 是 --> J[底注要求翻倍<br/>Ante + 1]
    J --> C
    I -- 否 --> K[击败 Ante 8 Boss<br/>通关胜利<br/>可继续无尽模式]
```

## 2. 单盲注循环（回合层，核心中的核心）

```mermaid
flowchart TD
    A[开始盲注<br/>显示目标分数] --> B[发牌 8 张手牌<br/>拥有出牌/弃牌次数]
    B --> C[选牌形成扑克牌型<br/>同花/葫芦/顺子...]
    C --> D[打出 1~5 张牌]
    D --> E[基础计分<br/>牌型基础筹码 x 倍率]
    E --> F[牌面计分<br/>手牌中牌张逐张加分]
    F --> G[Joker 小丑牌从左到右<br/>依次触发效果]
    G --> H{最终分数<br/>&ge; 目标?}
    H -- 否 --> I{还有出牌次数?}
    I -- 是 --> C2[可先弃牌换手牌<br/>消耗弃牌次数] --> C
    I -- 否 --> J[盲注失败<br/>Run 结束]
    H -- 是 --> K[盲注通过<br/>结算金钱奖励]
    K --> L{是 Boss 盲注?}
    L -- 否 --> M[跳过可拿免税标签<br/>进入商店] --> N[商店阶段]
    L -- 是 --> O[进入下一 Ante] --> N2[商店阶段]
```

## 3. 商店 / 构筑循环（经济层）

```mermaid
flowchart TD
    A[进入商店] --> B[浏览商品<br/>小丑牌/塔罗牌/星球牌/补券]
    B --> C{花费金钱购买?}
    C -- 购买 --> D[加入构筑<br/>小丑牌上限 5 格可扩]
    C -- 刷新 Reroll --> B
    C -- 出售旧牌 --> B
    D --> E[构筑强度提升<br/>筹码/倍率/联动引擎]
    E --> F[回到下一个盲注<br/>分数要求持续指数增长]
    F --> G{构筑能跟上<br/>指数增长?}
    G -- 能 --> A
    G -- 不能 --> H[失败<br/>构筑螺旋跟不上底注]
```

## 核心张力总结

- **三条循环嵌套**：出牌计分（秒级）→ 盲注/商店（分钟级）→ Ante/整局（30~60 分钟）。
- **指数 vs 线性**：底注要求按指数增长，玩家分数只能靠构筑联动（Joker 之间乘法叠加）指数化提升，这是核心紧张感来源。
- **风险决策点**：弃牌次数分配、金钱 vs 立即战力、跳过盲注换标签、Boss 规则针对性调整构筑。
