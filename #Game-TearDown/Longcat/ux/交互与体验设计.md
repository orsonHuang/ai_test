# Longcat · 交互与体验设计

## 一、操作层：极简输入

| 维度 | 设计 |
|------|------|
| 输入方式 | WASD / 方向键 / 点击拖拽 |
| 输入空间 | **仅 4 个离散方向** |
| 单手可玩 | ✅ 是（拖拽即可，无需键盘） |
| 触屏适配 | ✅ 原生适配（滑动手势 = 方向输入） |
| 时间压力 | **零**（无计时器、无倒计时） |

### 关键设计：输入空间只有 4

这是整个体验的基石。对比：

| 游戏 | 输入粒度 | 失误可能 |
|------|---------|---------|
| 贪吃蛇 | 4 方向 × 实时时机 | 高（手速 + 判断） |
| 推箱子 | 4 方向 × 逐格 | 中 |
| **Longcat** | **4 方向 × 回合制** | **极低**（只有"选错"，没有"手滑"） |

**体验后果**：玩家的每次失败都归因于"我想错了"，而非"我没操作好"。
→ 玩家不会迁怒游戏 → 愿意重试 → 留存提升。

> 这是一条**可迁移的通用设计原则**：
> **想降低挫败感，就缩小输入空间，把失败归因从"执行"转移到"决策"。**

## 二、反馈设计：猫的长度就是一切

Longcat 几乎没有传统 HUD（无血条、无分数、无步数计数 `[推断]`），**所有的反馈都由"猫的身体"承载**：

| 传统 HUD 元素 | Longcat 的替代方案 |
|--------------|------------------|
| 进度条 | **猫的长度**（填得越多，猫越长） |
| 分数 | **通关时的长度展示** |
| 成就弹窗 | **猫绕成一团的视觉奇观** |
| 失败提示 | **困住时的视觉困局本身**（玩家一眼看懂自己死了） |

**这是"反馈即内容"的教科书案例**——不需要额外做 UI，游戏对象本身就是 UI。

### 三条可复用原则

1. **进度可视化优先于数字**：长条猫比 "87/100" 更有冲击力
2. **失败要"看得见"**：困死时玩家能一眼看到"哪里没填满"，理解失败原因 → 产生"我换个顺序就能过"的冲动
3. **奖励要有体积感**：通关时那条绕满全屏的长猫，是整个游戏的高光时刻

## 三、失败体验：零惩罚设计

```
困死 → 一键重开 → 立即回到关卡起点
```

| 设计 | 作用 |
|------|------|
| 无失败动画惩罚 | 不浪费玩家时间 |
| 无广告强制插入 `[推断]` | 不打断心流 |
| 无步数/生命限制 | 可无限试错 |
| 重开即回到初始状态 | 认知负担清零 |

**心理机制**：失败成本 ≈ 0 → 尝试次数 ↑ → 每次尝试都在深化对关卡的理解 → **学习发生在失败里**。

这是典型的「**Super Meat Boy 式设计**」——把重试的摩擦降到零，让"失败"变成"探索"而非"惩罚"。

## 四、可读性设计

解谜游戏的生命线是"玩家能看懂局面"。Longcat 的处理：

| 元素 | 处理 | 目的 |
|------|------|------|
| 墙体 | 体素方块，纯色无纹理 | 零视觉噪音 |
| 已填格 | 猫身，高对比色（黄色） | 一眼区分已填/未填 |
| 未填格 | 空白 / 深色 | 剩余空间可视化 |
| 视角 | 全局俯视/等距，一屏看完 | 支持脑内推演 |
| 特效 | 几乎无 | 不干扰空间判断 |

**反面警示**：
如果新项目加入粒子特效、动态光影、遮挡物、镜头跟随，**会直接摧毁这类谜题的核心体验**。
空间解谜的前提是**全图可读性**——任何干扰都是负分。

## 五、UX 缺陷（新项目可改进处）

| 缺陷 | 表现 | 改进建议 |
|------|------|---------|
| **无撤销** `[待确认]` | 走错一步只能整关重开 | 加"撤销 1 步"，大幅降低挫败感 |
| **无提示** | 卡关只能硬想或放弃 | 加提示（可用广告变现！） |
| **无跳过** | 卡死在某关就彻底流失 | 加"跳过"（广告解锁 / 每日 1 次免费） |
| **无进度感** | 1900 关看不到头 | 分章节 / 世界地图 |
| **无社交** | 无法分享、无对比 | 微信生态下必须补 |
| **无重玩动机** | 通关即结束 | 加"最短步数"星级 |

**注意**：这些"缺陷"在 Longcat 里可能是刻意的极简主义选择。
但对**微信小游戏**而言，其中至少 3 条（提示 / 跳过 / 社交）是**留存刚需**，不能照搬原作的克制。

## 六、可迁移 UX 清单

做新项目时，这些建议直接照搬：

- [x] 输入空间压缩到 4 个离散方向
- [x] 单指滑动 → 移动端原生适配
- [x] 零时间压力（无计时器）
- [x] 失败零惩罚，一键重开
- [x] 进度可视化 = 游戏对象本身（不另做 HUD）
- [x] 全局视角，一屏可读
- [x] 失败时"看得见原因"
- [ ] 补：撤销 / 提示 / 跳过（微信生态刚需）
- [ ] 补：章节化进度 + 社交对比（微信生态红利）
