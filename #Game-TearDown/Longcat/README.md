## 一句话定位

Longcat 是一款把「贪吃蛇的身体」和「冰面滑行的移动」缝在一起的空间解谜游戏：你只决定**往哪拐**，不决定**走多远**——猫头一路滑到撞墙或撞到自己尾巴才停，目标是用身体填满关卡里每一个空格。

**它的真正创新不是"贪吃蛇变体"，而是把移动的距离控制权从玩家手里拿走，交给关卡地形。** 这一条取舍，让关卡从"操作场"变成了"谜题本身"。
