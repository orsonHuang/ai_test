# 三国：谋定天下 — 商业化系统

## 一、商业定位

《三国：谋定天下》主打「降肝降氪」标签，目标是在传统 SLG 高氪高压的市场中，用更友好的付费曲线吸引并留住中轻氪玩家。

## 二、主要付费点

| 付费点 | 说明 |
|--------|------|
| **抽卡（武将/战法）** | 核心付费点，获取新武将、新战法。 |
| **月卡** | 稳定付费，提供每日资源/黄金。 |
| **战令/通行证** | 赛季内阶段性奖励，鼓励活跃。 |
| **限时礼包** | 开荒期、赛季初等关键节点推出。 |
| **资源/加速礼包** | 用于快速补充资源或缩短建造/征兵时间。 |

## 三、抽卡机制

### 核心参数

- 橙卡爆率约 **8%**。
- **20 抽保底** 橙将（新手卡池）。
- 存在大卡池、小卡包、赛季限定卡包等结构。

### 玩家策略

- 月卡党通常选择「囤金珠/黄金，只抽关键小卡包/赛季新武将」。
- 新手期优先抽新手卡池拿保底。
- 武将/战法可重置、置换，降低试错成本。

## 四、降氪设计

### 具体体现

1. **高爆率 + 低保底**：8% 橙卡 + 20 抽保底，相比传统 SLG 更友好。
2. **武将/战法可重置**：配错队可以直接换，避免重复投入。
3. **月卡党可玩**：玩家反馈显示，月卡党也能在赛季中取得不错成绩。
4. **取消部分高压机制**：例如取消「翻地」等让玩家焦虑的强 PVP 机制。
5. **自动功能降低时间成本**：自动铺路、自动攻城减少玩家必须在线的时间。

### 设计意图

- 用「性价比」吸引对传统 SLG 望而却步的用户。
- 扩大付费用户基数（薄利多销），而非只依赖 whales。
- 建立「良心」口碑，形成差异化传播。

## 五、商业化张力

| 矛盾点 | 说明 |
|--------|------|
| **降氪 vs 收入** | 降氪标签下，如何在新武将、新战法上设计吸引力，同时不破坏平民体验。 |
| **赛季制 vs 付费重置** | 每个赛季推出新内容，需要玩家持续投入；但过度付费压力会侵蚀降氪口碑。 |
| **职业系统 vs 战力付费** | 职业系统让平民有贡献空间，但高战 + 高氪 still 在战场上具有优势。 |

## 六、潜在风险

- **玩家预期管理**：一旦降氪口碑建立，后续提高付费压力容易被反噬。
- **内容消耗速度**：赛季制要求持续出新武将/战法/剧本，否则玩家容易流失。
- **同质化竞争**：其他 SLG 也在学习降肝降氪，三谋需要持续寻找新差异点。
