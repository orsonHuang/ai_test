# 三国：谋定天下 — 同盟与赛季系统

## 一、同盟系统

### 定位

同盟是《三国：谋定天下》中 GVG（公会 vs 公会）的核心组织。游戏的核心目标（攻城、争夺州府、完成霸业）几乎全部需要同盟协作完成。

### 核心功能

| 功能 | 说明 |
|------|------|
| **成员管理** | 盟主、副盟主、官员分级，管理成员与权限。 |
| **攻城宣战** | 对目标城池宣战，进入倒计时后组织集结。 |
| **连城机制** | 占领城池后可向相邻区域扩张，形成势力版图。 |
| **跨州加盟** | 赛季中后期允许跨州加入同盟，整合力量。 |
| **同盟科技/资源加成** | 同盟占领高级城池后，全体成员获得资源产出加成。 |

### 攻城玩法

- 对城池宣战，进入倒计时（让玩家有时间集结）。
- 攻城时，镇军扛线、青囊续航、天工修建攻城器械、神行骚扰敌方援军。
- 首占奖励与参与奖励结合，激励普通玩家参与。
- 自动攻城机制降低组织成本，盟主不需要熬夜一个个催上线。

### 设计意图

- 把「个人成长」转化为「集体战争叙事」。
- 职业协作在同盟层面被放大，强化社交粘性。
- 降低盟主管理负担，减少「SLG 盟主像上班」的痛点。

## 二、赛季系统

### 赛季节奏

- 一个赛季约 **7 周**。
- 赛季内分为不同阶段：开荒期、发育期、州战期、洛阳争夺战、赛季结算。

### 赛季类型

- **常规赛季（S1/S2/S3 等）**：每个赛季推出新武将、新战法、新机制。
- **问鼎赛季/剧本赛季**：进入特定剧本，地图、规则、玩法主题变化（如「王业之争」限时 GVG）。

### 赛季重置规则

- **保留**：核心武将、战法、装备、部分养成进度。
- **重置**：地块占领、城池归属、赛季专属进度、部分资源。
- **奖励**：根据同盟/个人赛季表现发放结算奖励。

### 设计意图

1. **降低追赶成本**：新玩家或后进玩家在赛季重启后更容易追赶。
2. **持续新鲜感**：短赛季 + 新剧本，避免游戏后期内容枯竭。
3. **制造目标感**：每个赛季都有明确的霸业目标，驱动玩家长期留存。

## 三、连城与跨州机制

- **连城**：占领城池后可解锁相邻区域的攻打权限，模拟真实地理扩张。
- **跨州加盟**：赛季中后期打破地域限制，让小散人/小盟有机会加入大盟，整合为最终洛阳争夺做准备。

## 四、潜在问题

- **赛季中后期定局无聊**：一旦洛阳/霸业大局已定，最后几周活跃度容易下滑。
- **大盟吞并小盟**：跨州加盟可能加速服务器 consolidation，散人体验下降。
- **赛季节奏与产能**：7 周一赛季对内容更新速度要求很高，需要持续产出新剧本。
