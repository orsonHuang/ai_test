# 三国：谋定天下 — 资源与经济系统

## 一、资源种类

游戏内资源分为两大类：

### 1. 基础资源（建筑材料 + 军队补给）

| 资源 | 主要用途 | 获取途径 |
|------|----------|----------|
| **木材** | 建筑升级、科技升级、交易置换 | 资源地块、城内建筑、任务、商店 |
| **石料** | 建筑升级、科技升级（消耗最大） | 资源地块、城内建筑、任务、商店 |
| **铁矿** | 建筑升级、科技升级、营帐征兵 | 资源地块、城内建筑、任务、商店 |
| **粮食** | 征兵恢复预备兵、快速征兵 | 资源地块、城内建筑、任务、商店 |

### 2. 货币/特殊资源

| 资源 | 主要用途 | 获取途径 |
|------|----------|----------|
| **铜币** | 升级战法、解锁韬略、打造装备、集市购买 | 民居产出、军演、任务、讨伐贼寇、寻访、商店 |
| **黄金/金珠** | 抽卡、购买礼包、加速 | 充值、月卡、战令、任务、活动 |

## 二、资源产出循环

```
占领资源地 → 城内资源建筑升级 → 同盟资源加成 → 支撑城建/科技/征兵 → 提升战力 → 占领更高级资源地
```

## 三、资源消耗结构

### 建筑与科技

- 升级内城建筑、研究所科技主要消耗 **木材、石料、铁矿**。
- 资源比例大致为：**铁 : 木 : 石 = 3 : 3 : 4**，石料消耗最高。

### 征兵与战斗

- **粮食** 主要用于征兵所恢复预备兵。
- 城外营帐征兵额外消耗木材、铁矿。
- 战斗损耗会转化为资源消耗压力，因此控制战损是开荒关键。

### 铜币消耗

- 战法升级、韬略解锁、装备打造是铜币主要去向。
- 铜币是「养成深度」的关键资源，决定了队伍最终强度。

## 四、资源调配机制

### 集市交易

- 玩家可在集市以 **10:7** 的比例互换木材、石料、铁矿。
- 用于缓解某种资源短期溢出的问题。

### 商店兑换

- 日常商店、同盟商店、功勋商店可用资源或代币兑换稀缺资源。
- 是资源补充和玩家活跃奖励的重要出口。

### 自动采集/自动铺路

- 降低玩家手动管理资源地的成本，让资源获取更平滑。

## 五、经济系统设计意图

1. **资源是战争的基础**：所有军事行动最终都依赖资源产出，形成「种田 → 打仗」的 SLG 经典循环。
2. **石料作为瓶颈资源**：石料消耗最高，制造玩家持续争夺高级石料地的动力。
3. **粮食限制战争频率**：征兵需要粮食，战损需要粮食恢复，天然约束玩家无节制开战。
4. **铜币支撑养成深度**：铜币用于战法、韬略、装备，是长期养成的隐性门槛。
5. **自动机制降低门槛**：自动铺路和采集让轻度玩家也能稳定获取资源，减少因操作不足而被甩开。

## 六、赛季经济重置

- 赛季结束后，地块占领、部分资源/进度重置。
- 核心养成（武将、战法）保留，让玩家既有积累感，又不会因旧资源差距过大而无法追赶。

## 七、潜在问题

- **资源失衡风险**：如果某种资源获取过易或过难，会导致策略选择单一化。
- **后期资源溢出**：赛季中后期，老玩家可能出现资源过剩，需要消耗出口（如赛季新养成）。
- **资源与付费的张力**：加速/资源礼包若设计过强，会侵蚀「降氪」口碑。
