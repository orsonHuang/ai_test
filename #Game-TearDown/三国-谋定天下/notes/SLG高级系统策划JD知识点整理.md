## 二、知识点一：SLG 用户分层需求

### 2.1 按付费能力分层

| 层级 | 月付费区间（参考） | 核心诉求 | 系统设计重点 |
|------|-------------------|----------|--------------|
| **大 R / 鲸鱼用户** | 万元以上 | 碾压快感、排名炫耀、同盟统治力、社交地位 | 高成长上限、VIP 特权、限定外观、盟主特权、赛季结算荣誉 |
| **中 R** | 千元至万元 | 性价比、战力成长、同盟中坚力量 | 月卡/战令、成长基金、抽卡保底、中坚职业定位 |
| **小 R / 微氪** | 百元至千元 | 跟得上大部队、有参与感 | 低门槛付费、自动功能、平民职业价值、参与奖励 |
| **零氪 / 平民** | 不付费 | 不花钱也能玩、有贡献空间、不被碾压 | 降肝降氪设计、职业系统贡献、自动铺路/攻城、赛季重启追赶 |

### 2.2 按活跃与社交角色分层

| 角色 | 核心诉求 | 系统设计重点 |
|------|----------|--------------|
| **盟主 / 管理** | 同盟凝聚力、管理效率、胜率 | 自动攻城、一键集结、战功统计、官员权限、同盟日志 |
| **高战 / 核心玩家** | 战斗爽感、战力验证、赛季荣誉 | 多队养成、兵种克制、战场设施、赛季排名 |
| **种田 / 休闲玩家** | 稳定发育、低压力、参与感 | 资源产出、自动功能、职业贡献、赛季保底奖励 |
| **社交型玩家** | 归属感、兄弟情义、语音指挥 | 同盟频道、联盟战、跨服社交、赛季兄弟会 |
| **回流 / 新手玩家** | 快速追上、不被碾压、明确目标 | 赛季重启、新手保护期、追赶机制、目标引导 |

### 2.3 用户分层设计原则（结合三谋）

1. **避免单一数值碾压**：三谋通过职业系统让平民玩家在同盟中有不可替代的价值。
2. **拉大横向价值维度**：除了战力，还可以有资源、后勤、工程、治疗、侦查等贡献维度。
3. **控制付费差距上限**：降低红度/星级带来的战力差距，避免中低氪完全失去体验。
4. **给每一层明确目标**：大 R 追求霸业排名，平民追求参与奖励和赛季保底。

## 三、知识点二：SLG 全球市场本地化

### 3.1 主要市场特征

| 市场 | 玩家偏好 | 文化注意点 | 商业化特点 | 代表产品/案例 |
|------|----------|------------|------------|----------------|
| **欧美** | 偏好简洁 UI、即时反馈、公平竞技感、副玩法买量 | 避免文化挪用、宗教/政治敏感、重视隐私合规 | 付费曲线较平缓，IAP + IAP 混合，订阅制接受度高 | 《Last War》《Whiteout Survival》 |
| **中东** | 重社交、强家族/部落认同、高 ARPU、喜欢奢华展示 | 斋月/宗教节日、阿拉伯文化、女性形象保守、RTL 语言适配 | 重氪用户集中，喜欢限定、排行榜、身份象征 | 《苏丹的复仇》《Puzzles & Survival》中东版 |
| **东南亚** | 价格敏感、社交活跃、喜欢 PVP 和 GVG、移动端为主 | 多语言（泰/越/印/菲）、宗教与文化节日、网络环境差异 | 低 ARPU 但用户基数大，依赖活动与 KOL 营销 | 《Rise of Kingdoms》《Mobile Legends》 |
| **日韩** | 重视品质、角色收集、剧情与世界观、社群口碑 | 高美术标准、声优/角色塑造、运营活动精细 | 高 ARPU，抽卡与养成付费成熟 | 《三国志真战》《Lineage》系列 |
| **中国** | 三国/历史题材接受度高、强同盟社交、能接受重肝重氪 | 版号与合规、未成年人保护、强运营节奏 | 月卡/战令/抽卡/礼包组合，社交裂变强 | 《率土之滨》《三国志战略版》《三国：谋定天下》 |

### 3.2 本地化不只是翻译

| 本地化维度 | 具体内容 |
|------------|----------|
| **语言与 UI** | 翻译、RTL 适配、字体、文案长度、UI 布局 |
| **文化与题材** | 文明选择、历史背景、角色设计、节日活动、宗教禁忌 |
| **玩法偏好** | PVE/PVP 比重、战斗节奏、社交强度、付费点设计 |
| **商业化** | 定价策略、礼包结构、订阅/通行证、本地支付方式 |
| **运营节奏** | 开服节奏、活动排期、客服与社区运营、KOL 合作 |
| **合规** | 隐私政策、数据存储、未成年人保护、宗教内容审查 |

### 3.3 结合三谋的全球化思考

- 三谋的「降肝降氪 + 职业分工」在国内是差异化，但在全球市场是否通用需验证。
- 欧美玩家可能对「自动铺路/自动攻城」的接受度较高，因为减负是普世需求。
- 中东玩家可能更看重同盟领导地位和身份展示。
- 东南亚玩家可能对低门槛、快节奏赛季更敏感。

## 四、知识点三：SLG 赛季制理解

### 4.1 赛季制的本质

赛季制是 SLG 的**周期性重启机制**，核心解决三个问题：

1. **防止滚雪球垄断**：避免老玩家/大盟无限积累导致新玩家无法追赶。
2. **制造新目标**：每个赛季提供新的剧本、新的武将、新的竞争环境。
3. **降低回流门槛**：赛季重启让弃坑玩家和新玩家有重新加入的机会。

### 4.2 赛季制的核心设计要素

| 要素 | 说明 |
|------|------|
| **周期** | 通常 1-3 个月，三谋约 7 周，ROK 的 KVK 周期更长 |
| **继承内容** | 核心养成（武将、战法、装备、皮肤）保留，给玩家积累感 |
| **重置内容** | 地块、城池、赛季进度、部分资源，制造公平竞争环境 |
| **新内容** | 新剧本、新武将、新机制、新活动，提供新鲜感 |
| **结算奖励** | 根据同盟/个人排名发放奖励，强化目标感 |

### 4.3 赛季制 vs 滚服模式

| 维度 | 赛季制 | 滚服模式 |
|------|--------|----------|
| 生命周期 | 单服生命周期长，靠赛季续命 | 单服生命周期短，靠开新服拉动 |
| 新老玩家关系 | 赛季重启降低差距 | 老服新玩家难以追赶 |
| 内容消耗 | 需要持续产出新剧本 | 内容复用度高，但玩家流失快 |
| 社交稳定性 | 同盟关系跨赛季延续 | 每服重新建立社交关系 |
| 付费设计 | 赛季限定内容驱动持续付费 | 开服礼包驱动一次性付费 |

### 4.4 三谋赛季制的特点

- **短周期**：约 7 周一赛季，节奏快。
- **强继承**：武将/战法跨赛季保留，降低玩家流失损失。
- **剧本化**：不同赛季有不同剧本主题和胜利条件。
- **公平重启**：地块/城池重置，新玩家有机会追赶。

## 五、知识点四：SLG 核心系统框架设计

### 5.1 SLG 核心系统模块

```
SLG 核心框架
├── 大地图系统
│   ├── 地块系统
│   ├── 行军系统
│   ├── 城池/关卡系统
│   └── 视野/迷雾系统
├── 战斗系统
│   ├── 武将/英雄系统
│   ├── 兵种/克制系统
│   ├── 战法/技能系统
│   └── 战斗结算系统
├── 养成系统
│   ├── 城建系统
│   ├── 科技系统
│   ├── 装备系统
│   └── 抽卡/招募系统
├── 社交系统
│   ├── 同盟/联盟系统
│   ├── 聊天系统
│   ├── 指挥系统
│   └── 外交系统
├── 赛季系统
│   ├── 剧本系统
│   ├── 结算系统
│   └── 继承/重置系统
└── 商业化系统
    ├── 抽卡系统
    ├── 月卡/战令
    ├── 礼包系统
    └── VIP/特权系统
```

### 5.2 系统设计优先级方法

1. **核心循环优先**：占地 → 发育 → 打仗 → 占地，先保证这个循环顺畅。
2. **痛点驱动**：针对目标用户最大痛点（肝/氪/社交压力）设计减负功能。
3. **数据验证**：上线后用留存、付费、活跃数据验证系统设计。
4. **模块化迭代**：每个赛季可替换/新增模块，保持游戏活力。

## 六、知识点五：跨部门协作与项目推进

### 6.1 系统策划的协作对象

| 部门 | 协作内容 |
|------|----------|
| **程序** | 系统逻辑、数据结构、接口设计、性能优化 |
| **美术** | UI/UX、场景、角色、特效、表现反馈 |
| **运营** | 活动策划、商业化节奏、用户反馈、版本排期 |
| **QA** | 测试用例、边界情况、回归测试 |
| **数据分析** | 埋点设计、指标定义、数据复盘 |

### 6.2 高效协作要点

1. **文档先行**：GDD、策划案、数值表、流程图完整后再进入开发。
2. **接口清晰**：与程序明确输入输出、状态同步、异常处理。
3. **用例具体**：给 QA 提供具体场景和边界条件。
4. **数据闭环**：上线前定义好关键指标和埋点。
5. **反馈迭代**：收集运营和玩家反馈，快速形成优化方案。

## 七、知识点六：数据驱动优化

### 7.1 SLG 核心数据指标

| 指标类型 | 具体指标 | 意义 |
|----------|----------|------|
| **留存** | 次日/7日/30日留存 | 验证核心玩法吸引力 |
| **活跃** | DAU、MAU、在线时长、登录频次 | 验证玩家粘性 |
| **付费** | ARPU、ARPPU、付费率、LTV | 验证商业化健康度 |
| **行为** | 占地数、攻城参与率、同盟加入率、赛季完成率 | 验证系统参与度 |
| **社交** | 同盟留存、官员活跃度、语音使用率 | 验证社交粘性 |

### 7.2 数据驱动设计案例

| 问题 | 数据表现 | 优化方向 |
|------|----------|----------|
| 新手次日留存低 | 新手保护期内流失高 | 简化前期引导、增强自动功能、降低战损挫败感 |
| 大 R 付费后劲不足 | 赛季中后期付费下滑 | 增加赛季限定内容、排行榜竞争、限定皮肤 |
| 平民玩家流失高 | 中低氪赛季中后期活跃度低 | 增加保底奖励、职业贡献认可、赛季重启公平感 |
| 同盟管理负担重 | 盟主流失率高 | 自动攻城、一键集结、战功自动化统计 |

## 八、知识点七：主流 SLG 品类理解

| 品类 | 代表产品 | 核心特点 | 适合用户 |
|------|----------|----------|----------|
| **COK-like** | 《列王的纷争》《阿瓦隆之王》 | 全球同服、英雄养成、自由行军、GVG | 喜欢即时对抗、强社交、全球化 |
| **率土-like** | 《率土之滨》《三国志战略版》 | 地块化沙盘、赛季制、深度策略、重氪重肝 | 喜欢深度策略、历史题材、强同盟社交 |
| **ROK-like** | 《万国觉醒》 | 多文明、自由行军、即时战斗、KVK | 喜欢 RTS 操作感、多文明、全球竞技 |
| **三谋-like** | 《三国：谋定天下》 | 职业分工、降肝降氪、短赛季、自动功能 | 喜欢 SLG 但厌倦重肝重氪的玩家 |
| **副玩法 SLG** | 《Last War》《Whiteout Survival》 | 休闲副玩法 + SLG 内核、买量友好 | 泛用户、轻度玩家 |

### 8.1 品类融合趋势

当前 SLG 市场呈现以下趋势：
- **减负**：自动铺路、自动攻城、一键操作成为标配。
- **降氪**：扩大付费用户基数，降低单用户付费压力。
- **副玩法**：通过休闲玩法降低获客成本。
- **短赛季**：加快内容更新节奏，保持新鲜感。
- **职业/职能分工**：让平民玩家有更多贡献维度。

## 九、结合三谋项目的案例分析

| JD 要求 | 三谋项目对应设计 |
|----------|------------------|
| 大地图沙盘 | 地块化十三州、洛阳中心、关隘通道、连城机制 |
| 赛季制玩法 | 约 7 周赛季、剧本主题、武将战法继承、地块城池重置 |
| 用户分层 | 六大职业让平民有贡献、20 抽保底照顾中低氪、赛季排名满足大 R |
| 全球化本地化 | 三谋目前主要国内市场，但降肝降氪设计具备全球化潜力 |
| 跨部门协作 | 职业系统需要程序支持职业技、美术支持职业表现、运营设计赛季节奏 |
| 数据驱动 | 自动铺路使用率、新手 48 小时占地数、攻城参与率等关键指标 |

## 十、面试与能力准备建议

### 10.1 必备知识体系

1. 至少深度体验 1-2 款主流 SLG（建议三谋 + ROK/率土/三战）。
2. 能画出一套 SLG 核心循环和系统架构图。
3. 能针对具体系统设计给出优缺点分析和优化方案。
4. 理解不同市场的用户差异和本地化要点。
5. 会用数据指标衡量系统设计效果。

### 10.2 加分能力

- 有全球发行项目经验。
- 能输出规范的 GDD 和系统设计文档。
- 有数值设计基础或能跟数值策划高效协作。
- 了解客户端/服务端技术边界，能与程序顺畅沟通。
- 具备跨文化沟通经验，理解欧美/中东/东南亚玩家心理。

## 十一、总结

SLG 高级系统策划的核心能力可以概括为：**懂系统、懂用户、懂市场、懂数据、懂协作**。结合《三国：谋定天下》的拆解可以看到，一款成功的 SLG 需要在核心循环、用户分层、赛季节奏、全球化适配、商业化设计之间找到平衡。对于应聘者而言，最重要的是能把这些知识点落到具体的系统设计和案例分析中，而不是停留在概念层面。
