# SLG 系统设计案例分析集

> 将 SLG 高级系统策划知识点落到具体案例，以《三国：谋定天下》为背景，结合用户分层、赛季制、全球化、数据驱动、跨部门协作等核心能力展开。

---

## 案例一：用户分层需求落地 —— 平民玩家参与感系统设计

### 1.1 背景

SLG 长期存在一个问题：**大 R 玩家碾压一切，平民玩家没有存在感和贡献空间**，导致中低氪玩家流失严重。《三国：谋定天下》通过职业系统尝试解决这个问题。

### 1.2 问题拆解

| 问题 | 表现 |
|------|------|
| 平民玩家战力低 | 在 PVP 中无法与大 R 抗衡 |
| 同盟贡献单一 | 只有战力高的玩家被重视 |
| 赛季中后期边缘化 | 平民玩家觉得"打不赢、没贡献" |
| 流失率高 | 中低氪玩家在第一个赛季后大量流失 |

### 1.3 设计目标

- 让平民玩家在同盟中有不可替代的价值。
- 降低战力作为唯一评价标准的权重。
- 提升平民玩家的赛季参与度和留存。

### 1.4 具体设计方案

#### 方案 A：职业分工系统（三谋核心设计）

| 职业 | 平民玩家价值 | 设计要点 |
|------|--------------|----------|
| **青囊** | 治疗、降低战损 | 高战也需要青囊续航，职业技可直接支援队友 |
| **司仓** | 资源产出、后勤运输 | 同盟战争需要资源支撑，司仓是战争基础 |
| **天工** | 建造攻城器械、战场设施 | 攻城离不开天工的器械和设施 |
| **神行** | 侦查、骚扰、断粮道 | 不需要高战力也能影响战局 |
| **奇佐** | 控制、陷阱、计策 | 战场节奏控制，策略价值高于战力 |

#### 方案 B：战功与贡献多维评价

- 不再只看杀敌数，增加：
  - 资源捐献贡献
  - 攻城参与次数
  - 治疗量
  - 建造/修复设施数量
  - 侦查报告次数
- 赛季结算时，平民玩家也能获得可观的功勋和奖励。

#### 方案 C：平民保底奖励

- 同盟占领城池后，所有成员均可获得奖励，不只看输出排名。
- 赛季个人目标中设置"参与型任务"，如：
  - 参与 X 次攻城
  - 为同盟捐献 X 资源
  - 建造 X 个设施

### 1.5 关键数据指标

| 指标 | 目标 |
|------|------|
| 平民玩家赛季完成率 | 提升至 60% 以上 |
| 平民玩家 30 日留存 | 提升 10-15% |
| 职业系统使用率 | 各职业均达到 10% 以上选择率 |
| 同盟平均活跃成员数 | 提升 20% |

### 1.6 风险与应对

| 风险 | 应对 |
|------|------|
| 某个职业过强或过弱 | 赛季数据监控，动态调整职业平衡 |
| 平民贡献难以量化 | 建立多维贡献统计系统，可视化展示 |
| 大 R 觉得投入回报降低 | 保留大 R 在战场上的统治力，只是增加平民参与维度 |

### 1.7 案例总结

> **核心思路**：把玩家价值从单一战力扩展到多维贡献，让平民玩家在战略、后勤、工程、辅助中找到自己的位置，从而提升整体留存和同盟凝聚力。

## 案例二：SLG 赛季制落地 —— 三谋式短赛季设计

### 2.1 背景

传统 SLG（如《率土之滨》《三国志战略版》）赛季周期较长，中后期容易出现"定局后无聊"的问题。三谋通过短赛季（约 7 周）尝试解决这个问题。

### 2.2 设计目标

- 缩短单赛季无聊期。
- 降低新玩家/回流玩家追赶门槛。
- 每个赛季提供新内容和新目标。

### 2.3 具体设计方案

#### 方案 A：赛季节奏划分

| 阶段 | 时间 | 核心目标 | 关键系统 |
|------|------|----------|----------|
| **开荒期** | 第 1-3 天 | 快速发育、加入同盟 | 新手保护、自动铺路、主线任务 |
| **发育期** | 第 4-14 天 | 城建、武将养成、同盟协作 | 资源系统、养成系统、同盟系统 |
| **州战期** | 第 15-28 天 | 争夺州府、扩张势力 | 攻城系统、州府争夺 |
| **洛阳期** | 第 29-42 天 | 跨州整合、争夺洛阳 | 连城机制、跨州加盟、霸业系统 |
| **结算期** | 第 43-49 天 | 赛季结算、奖励发放、进入新剧本 | 结算系统、继承系统 |

#### 方案 B：继承与重置规则

| 内容 | 规则 | 设计意图 |
|------|------|----------|
| **保留** | 武将、战法、装备、皮肤 | 让玩家投入有长期价值 |
| **重置** | 地块、城池、赛季进度、部分资源 | 制造公平竞争环境 |
| **结算** | 根据同盟排名、个人功勋发放奖励 | 强化目标感和成就感 |

#### 方案 C：剧本差异化

- S1：经典群雄割据，争夺洛阳。
- S2：加入新武将、新战法，调整地图资源分布。
- S3：引入特殊机制，如天气系统、限时事件等。
- 问鼎赛季：特定剧本主题，如阵营对抗、资源争夺战。

### 2.4 关键数据指标

| 指标 | 目标 |
|------|------|
| 赛季完成率 | 达到 70% 以上 |
| 新玩家首赛季留存 | 30 日留存达到 25% 以上 |
| 回流玩家转化率 | 赛季重启后回流率达到 15% 以上 |
| 赛季中后期活跃度 | 最后两周 DAU 下滑不超过 20% |

### 2.5 风险与应对

| 风险 | 应对 |
|------|------|
| 赛季节奏过快，玩家疲惫 | 提供阶段性目标和奖励缓冲 |
| 内容产能跟不上 | 建立赛季内容模板，提高制作效率 |
| 赛季后期定局无聊 | 增加赛季事件、个人目标、小团队玩法 |

### 2.6 案例总结

> **核心思路**：用短周期 + 强继承 + 剧本差异化，让 SLG 从"长周期消耗"变成"阶段性重启"，持续制造新鲜感和追赶机会。

## 案例三：全球化本地化落地 —— 三谋出海中东市场适配

### 3.1 背景

假设《三国：谋定天下》计划出海中东市场，需要在保留核心玩法的基础上进行本地化适配。

### 3.2 市场特征分析

| 维度 | 中东市场特点 |
|------|--------------|
| **用户画像** | 高 ARPU、重社交、强家族/部落认同、喜欢身份展示 |
| **题材偏好** | 对三国题材认知较低，但对历史战争、帝国争霸、部落对抗接受度高 |
| **文化禁忌** | 宗教敏感、女性形象保守、斋月等节日重要 |
| **付费特点** | 喜欢限定、排行榜、身份象征、大额礼包 |
| **社交特点** | 喜欢语音、家族联盟、线下熟人组队 |

### 3.3 本地化方案

#### 方案 A：题材与美术本地化

| 原设计 | 本地化调整 |
|--------|------------|
| 三国武将 | 调整为阿拉伯/波斯历史英雄或原创帝国将领 |
| 中式建筑 | 调整为中东城堡、沙漠绿洲、清真寺风格建筑 |
| 角色立绘 | 女性角色着装保守化，符合当地文化 |
| UI 配色 | 增加金色、深红等奢华感配色 |

#### 方案 B：玩法偏好调整

| 原设计 | 本地化调整 |
|--------|------------|
| 职业系统 | 保留，但职业名称改为更符合部落文化的称谓 |
| 同盟系统 | 强化家族/部落概念，增加盟主权威展示 |
| 赛季节奏 | 适当拉长赛季，满足中东玩家喜欢长期养成的习惯 |
| 排行榜 | 强化全服排名、同盟排名、个人荣誉展示 |

#### 方案 C：商业化与运营调整

| 原设计 | 本地化调整 |
|--------|------------|
| 月卡/战令 | 保留，但增加大额限定礼包 |
| 抽卡系统 | 增加"神兽/传奇坐骑"等高价值身份象征道具 |
| 活动节奏 | 配合斋月、开斋节、国庆日等本地节日推出活动 |
| KOL 营销 | 与当地游戏主播、家族社群合作 |

#### 方案 D：技术与合规

- RTL（从右至左）语言适配。
- 本地支付方式接入。
- 隐私政策符合当地法规。
- 服务器部署在中东地区，降低延迟。

### 3.4 关键数据指标

| 指标 | 目标 |
|------|------|
| 首日留存 | 达到 35% 以上 |
| 7 日留存 | 达到 15% 以上 |
| 付费率 | 达到 8% 以上 |
| ARPPU | 高于全球平均水平 30% |

### 3.5 风险与应对

| 风险 | 应对 |
|------|------|
| 三国 IP 在当地认知度低 | 重新包装题材，强调战争策略而非三国历史 |
| 文化冲突 | 建立本地化审查流程，避免宗教/政治敏感内容 |
| 社交氛围差异 | 加强语音和家族系统，迎合当地强社交习惯 |

### 3.6 案例总结

> **核心思路**：本地化不是翻译，而是**题材重构 + 玩法适配 + 商业化调整 + 运营本地化**的全方位改造。中东市场的关键是尊重文化、强化身份认同和社交归属感。

## 案例四：数据驱动优化落地 —— 新手 48 小时流失问题

### 4.1 背景

假设三谋上线后数据发现：**新玩家次日留存低，新手保护期内流失严重**。

### 4.2 数据分析

| 数据现象 | 可能原因 |
|----------|----------|
| 新玩家平均占地数低于预期 | 引导不清晰，玩家不知道要做什么 |
| 首次战斗失败率高 | 武将搭配不合理，兵种克制未讲清楚 |
| 50% 玩家未加入同盟 | 引导不足，新手对同盟价值无感知 |
| 48 小时内流失率 60% | 成长感不足、目标感缺失 |

### 4.3 设计目标

- 让新玩家在前 48 小时内清晰知道该做什么。
- 降低前期挫败感，提升成长感。
- 提升同盟加入率，建立社交连接。

### 4.4 优化方案

#### 方案 A：强化新手目标引导

| 优化前 | 优化后 |
|--------|--------|
| 主线任务分散 | 增加"48 小时新手目标"进度条，清晰展示阶段目标 |
| 玩家不知道该优先升级什么 | 高亮推荐建筑和科技，一键升级功能 |
| 自动铺路功能隐藏深 | 新手强制引导使用一次自动铺路 |

#### 方案 B：降低前期战损挫败感

| 优化前 | 优化后 |
|--------|--------|
| 新手打高级地容易失败 | 增加"推荐攻打等级"提示 |
| 战败后没有恢复指导 | 战败弹窗直接引导"征兵"和"升级战法" |
| 兵种克制不明显 | 战前增加兵种克制提示 |

#### 方案 C：促进同盟加入

| 优化前 | 优化后 |
|--------|--------|
| 同盟入口不明显 | 主城等级达到 3 级时强制弹出同盟推荐 |
| 新手不知道同盟好处 | 展示"加入同盟后立即获得资源加成" |
| 找不到活跃同盟 | 推荐同州活跃度前 10 的同盟 |

### 4.5 关键数据指标

| 指标 | 当前 | 目标 |
|------|------|------|
| 新手 48 小时占地数 | 15 块 | 25 块 |
| 次日留存 | 25% | 40% |
| 7 日留存 | 12% | 20% |
| 同盟加入率 | 50% | 75% |
| 首次攻城参与率 | 30% | 50% |

### 4.6 A/B 测试方案

- A 组：原版本
- B 组：增加"48 小时新手目标"进度条
- C 组：B 组 + 战败恢复引导 + 同盟推荐优化
- 观察指标：次日留存、7 日留存、同盟加入率

### 4.7 风险与应对

| 风险 | 应对 |
|------|------|
| 引导过强导致玩家厌烦 | 提供"跳过"选项，但保留奖励激励 |
| 同盟推荐不准确 | 根据活跃度和语言偏好智能推荐 |

### 4.8 案例总结

> **核心思路**：数据驱动优化需要**先定位问题漏斗，再设计针对性实验，最后用 A/B 测试验证效果**。新手流失问题通常不是单一原因，需要引导、反馈、社交三管齐下。

## 案例五：跨部门协作落地 —— 职业系统从设计到上线

### 5.1 背景

职业系统是《三国：谋定天下》的核心创新，涉及系统策划、数值策划、程序、美术、运营多个部门协作。这个案例展示如何把一个核心系统设计推进到上线。

### 5.2 项目阶段

#### 阶段 1：策划案输出（第 1-2 周）

| 产出 | 负责人 | 内容 |
|------|--------|------|
| GDD 系统设计文档 | 系统策划 | 职业定位、技能设计、与玩法联动 |
| 数值表 | 数值策划 | 职业平衡参数、成长曲线、技能数值 |
| 美术需求文档 | 系统策划 + 美术 | 职业图标、特效、角色形象 |
| 运营节奏表 | 运营策划 | 赛季职业使用率目标、活动配合 |

#### 阶段 2：原型与评审（第 3 周）

- 程序搭建职业技基础框架。
- 美术输出 2-3 个职业的视觉风格稿。
- 策划组织跨部门评审，确认方向。

#### 阶段 3：开发实现（第 4-8 周）

| 模块 | 程序工作 | 策划配合 |
|------|----------|----------|
| 职业选择界面 | UI 界面开发 | 确认交互流程 |
| 职业技系统 | 技能触发、效果计算 | 提供详细技能规则 |
| 大地图联动 | 职业技在大地图上的使用 | 设计使用场景和限制 |
| 平衡性调试 | 参数调整接口 | 持续测试并反馈 |

#### 阶段 4：测试与调优（第 9-10 周）

- QA 进行功能测试、边界测试。
- 数据分析埋点评审，确认关键指标。
- 小规模测试服验证职业平衡性。

#### 阶段 5：上线与迭代（第 11 周起）

- 全量上线。
- 监控各职业选择率、胜率、玩家反馈。
- 根据数据动态调整职业平衡。

### 5.3 协作关键点

| 协作对象 | 关键沟通内容 |
|----------|--------------|
| **程序** | 技能触发时机、状态同步、性能开销、异常处理 |
| **美术** | 职业辨识度、技能特效表现、UI 视觉风格 |
| **数值** | 职业间平衡、成长曲线、与付费系统的耦合 |
| **运营** | 赛季节奏、活动包装、玩家反馈收集 |
| **QA** | 测试用例、边界情况、回归测试范围 |

### 5.4 可能遇到的问题

| 问题 | 解决方案 |
|------|----------|
| 程序反馈职业技性能开销大 | 简化特效表现，减少同步频次 |
| 美术认为职业辨识度不够 | 增加职业专属颜色、武器、坐骑 |
| 数值认为某个职业过强 | 调整技能冷却、效果范围、成长系数 |
| 运营担心玩家不接受新机制 | 新手引导强化，增加体验关卡 |

### 5.5 案例总结

> **核心思路**：核心系统上线不是策划单点完成，而是**文档先行 → 跨部门对齐 → 分阶段实现 → 数据验证 → 持续迭代**的协作过程。系统策划需要在技术可行性、美术表现力、数值平衡性、运营节奏之间找到最优解。

---

## 总结

以上五个案例分别覆盖了：

1. **用户分层需求落地**：职业系统与多维贡献设计。
2. **赛季制落地**：短赛季节奏与继承重置规则。
3. **全球化本地化落地**：中东市场题材与玩法适配。
4. **数据驱动优化落地**：新手流失问题的分析与 A/B 测试。
5. **跨部门协作落地**：职业系统从策划到上线的全流程。

每个案例都包含了**背景、问题、目标、方案、指标、风险、总结**，可以直接用于面试准备或工作参考。
