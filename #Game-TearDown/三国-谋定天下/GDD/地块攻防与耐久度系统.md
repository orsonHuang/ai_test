# 三国：谋定天下 — GDD：地块攻防与耐久度系统

> 文档类型：游戏设计文档（GDD）
> 主题：地块攻防规则、宣战流程、耐久度机制
> 适用范围：地块化 SLG 战争策略手游

---

## 一、系统定位

地块攻防与耐久度系统是 SLG 大地图对抗的基础规则层。它定义了玩家如何攻击敌方地块、地块如何被占领、以及宣战流程如何运转。该系统的核心目标是：**让领地攻防成为有策略、有组织、有成本的战争行为，而不是无限制的偷袭骚扰**。

---

## 二、地块的防御属性

### 2.1 空地 vs 资源地 vs 城池

| 地块类型 | 是否有系统守军 | 主要防御方式 |
|----------|----------------|--------------|
| **空地** | 否 | 地块耐久度 + 玩家驻守部队 |
| **资源地** | 是 | 守军部队 + 地块耐久度 + 玩家驻守部队 |
| **城池/关隘** | 是 | 城墙守军 + 高耐久度 + 同盟集结防御 |

### 2.2 空地的防御来源

空地本身没有系统守军，但它仍然具有以下防御属性：

- **地块耐久度**：空地也有耐久度，需要攻击方消耗
- **玩家驻守**：防守方可以派兵驻守，形成实际抵抗
- **同盟/新手保护**：可能处于保护状态，暂时不可攻击
- **地理位置**：空地常作为缓冲带，增加攻击方推进成本

## 三、宣战流程

### 3.1 宣战对象

宣战不是针对单个地块，而是针对**地块所属的势力**。

| 宣战层级 | 对象 |
|----------|------|
| **个人领地战** | 某个玩家的领地 |
| **同盟战争** | 敌方同盟 |
| **城池战** | 目标城池 |

### 3.2 宣战流程

```text
选择目标（玩家/同盟/城池/地块）
    ↓
发起宣战（消耗宣战令或满足冷却条件）
    ↓
进入宣战倒计时（防守方收到预警）
    ↓
倒计时结束，地块/领地进入可攻击状态
    ↓
攻击方派遣部队前往目标
    ↓
击败驻守部队（如有）并消耗地块耐久度
    ↓
地块耐久度归零 → 地块归属变更
```

### 3.3 宣战倒计时的作用

- 给防守方组织防御的时间
- 让同盟成员有时间上线响应
- 明确战争窗口，避免无限偷袭
- 制造战略节奏和紧张感

## 四、空地攻防流程

### 4.1 空地无驻守时的流程

```text
攻击方派兵 → 行军到达空地 → 无驻守部队 → 直接攻击地块耐久度 → 耐久度归零 → 占领成功
```

**关键说明**：
- 不是"防守方没派兵就自动胜利"
- 攻击方仍需实际派兵并消耗耐久度
- 一块空地可能需要多支部队轮流攻击才能占领

### 4.2 空地有驻守时的流程

```text
攻击方派兵 → 行军到达空地 → 遭遇驻守部队 → 发生战斗
    ↓
战斗胜利 → 继续攻击地块耐久度 → 耐久度归零 → 占领成功
    ↓
战斗失败 → 部队撤退/溃败 → 需要重新组织进攻
```

### 4.3 多块空地连续进攻

自动铺路遇到敌方空地阻断时，攻击方需要：

1. 先宣战/进入战争状态
2. 一块一块打掉敌方空地
3. 每占领一块地，领地边界推进一格
4. 直到打通通往目标资源地的路径

## 五、地块耐久度机制

### 5.1 耐久度属性

| 属性 | 说明 |
|------|------|
| **耐久度上限** | 地块等级越高/越重要，上限越高 |
| **当前耐久度** | 被攻击后减少，未攻击时缓慢恢复 |
| **每次攻击损耗** | 由攻击方部队战力决定 |
| **恢复速度** | 脱离攻击状态后按时间恢复 |

### 5.2 耐久度计算因素

- 攻击方部队数量与战力
- 攻击方武将/战法加成
- 地块自身等级和类型
- 是否有防守加成（如城池科技、同盟加成）

### 5.3 耐久度恢复规则

- 当地块脱离战斗一段时间后，耐久度开始缓慢恢复
- 高级地/城池恢复速度更快或更慢，取决于设计
- 恢复机制防止"打了就跑"式的骚扰过于有效

## 六、防守方的选择

### 6.1 防守方可选策略

| 策略 | 适用场景 |
|------|----------|
| **派兵驻守** | 关键空地、资源地、关隘周围 |
| **放弃空地** | 普通边界空地，战略价值低 |
| **组织反击** | 等攻击方部队疲惫后反攻 |
| **请求同盟支援** | 大规模进攻或重要目标 |

### 6.2 防守方不派兵的原因

- 空地数量多，无法处处设防
- 驻守部队占用兵力和体力
- 普通空地战略价值有限，可以后续夺回
- 集中兵力防守关键城池和资源地

---

## 七、与自动铺路系统的关系

### 7.1 自动铺路遇到敌方空地

- 自动铺路会识别敌方领地为不可通行区域
- 系统会尝试绕行，若无路可走则中断
- 不会自动宣战或攻击敌方领地

### 7.2 打通敌方空地后的影响

- 占领敌方空地后，该地变成己方领地
- 自动铺路可以继续从新的边界向前推进
- 这是「蚕食推进」战术的基础

---

## 八、设计目标与意义

### 8.1 为什么需要宣战和耐久度机制

| 风险 | 机制作用 |
|------|----------|
| 高战无限偷袭 | 宣战倒计时给防守方预警 |
| 新手被瞬间拆光 | 保护机制 + 耐久度延缓占领速度 |
| 同盟无法组织防御 | 宣战让同盟有时间集结 |
| 战争缺乏节奏 | 宣战窗口制造战略周期 |

### 8.2 空地作为战略缓冲的价值

- 即使无资源，空地也能阻挡敌方推进
- 空地控制范围影响同盟版图形状
- 空地可以保护主城和关键资源区
- 空地攻防是小规模摩擦的高发区

---

## 九、潜在问题与优化方向

| 问题 | 优化方向 |
|------|----------|
| 宣战流程过于繁琐 | 对低价值空地可简化宣战规则 |
| 耐久度恢复过慢 | 可能导致防守方难以重建缓冲区 |
| 空地攻防奖励不足 | 可增加摧毁敌方空地的战功/功勋奖励 |
| 自动判断过于保守 | 可提供"自动绕行敌方领地"选项 |

---

## 十、总结

地块攻防与耐久度系统是 SLG 战争规则的基石。它通过**宣战倒计时、地块耐久度、驻守机制、保护规则**的组合，让领地攻防既有策略深度，又避免无限制骚扰。空地虽然没有资源产出，但因其**领地属性**而成为重要的战略缓冲和推进障碍，是大地图博弈中不可忽视的要素。
