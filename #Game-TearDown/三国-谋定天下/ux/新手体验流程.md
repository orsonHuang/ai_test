# 三国：谋定天下 — 新手体验流程（从 0 开始）

## 一、体验流程总览

```
进入游戏 → 选服创角 → 职业选择 → 新手引导/首次战斗 → 48小时新手保护期 → 加入同盟 → 首次攻城/州战 → 赛季中后期 → 赛季结算/重启
```

## 二、各阶段核心体验内容与系统引导

### 阶段 1：进入游戏与创角（0-10 分钟）

**核心体验：建立预期、降低门槛**

| 维度 | 内容 |
|------|------|
| **主要体验系统** | 登录/选服系统、创角系统、福利展示系统 |
| **玩家在学什么** | 游戏题材、美术风格、服务器选择、福利预期 |
| **系统如何引导** | 开服福利弹窗/页面直观展示新手卡池、签到奖励、限时活动，建立"良心"第一印象；简洁创角流程，避免复杂选项。 |

- 玩家下载安装后进入选服界面。
- 创建角色，选择出生州/出生地。
- 首次接触游戏美术风格与三国题材氛围。

**设计意图**：
- 快速让玩家进入三国 SLG 的世界观。
- 选服阶段即开始制造社交预期（同服竞争/合作）。

**关键设计**：
- 开服福利展示：新手卡池、签到奖励、限时活动，建立"良心"第一印象。
- 简洁的创角流程，避免冗长捏脸或复杂选项。

---

### 阶段 2：职业选择（10-20 分钟）

**核心体验：身份认同与差异化定位**

| 维度 | 内容 |
|------|------|
| **主要体验系统** | 职业系统 |
| **玩家在学什么** | 六大职业的定位差异、技能作用、自身游戏风格匹配 |
| **系统如何引导** | 每个职业有明确的标签（战斗/辅助/机动/工程/资源/谋略）和技能预览；推荐新手选择青囊/司仓等友好职业；用简短描述暗示"这个职业在后期同盟战中扮演什么角色"。 |

- 玩家从六大职业中选择主职业：镇军、青囊、神行、天工、司仓、奇佐。
- 每个职业有明确的定位描述与技能预览。

**设计意图**：
- 这是游戏最核心的差异化时刻，玩家第一次感受到"我和别人不一样"。
- 通过职业选择暗示玩家的游戏风格：想打架？想种田？想辅助？

**新手建议导向**：
- 青囊/司仓通常被推荐为新手友好职业（青囊多体力、司仓资源稳）。
- 镇军/奇佐更适合有经验的玩家或同盟需求。

**潜在风险**：
- 职业选择后赛季内切换成本高，选错可能导致挫败感。
- 新手可能不理解职业对长期体验的影响。

---

### 阶段 3：新手引导与首次战斗（20-40 分钟）

**核心体验：学习核心操作、验证战斗爽感**

| 维度 | 内容 |
|------|------|
| **主要体验系统** | 新手引导系统、战斗系统、武将/战法系统 |
| **玩家在学什么** | 地块占领、武将上阵、战法释放、兵种克制、胜利反馈 |
| **系统如何引导** | 强制引导玩家完成首次占地；用视觉/文字演示兵种克制；赠送徐盛、孙策等初始武将形成第一支队伍；战斗胜利后立即反馈资源/经验收益。 |

- 引导玩家完成首次地块占领。
- 演示武将上阵、战法释放、兵种克制等基础战斗逻辑。
- 赠送初始武将（如徐盛、孙策），让玩家快速形成第一支队伍。

**设计意图**：
- 用最低操作成本让玩家理解"占地 → 拿资源 → 变强"的核心循环。
- 通过赠送武将和战法，让玩家立刻体验到配队乐趣。

**关键设计**：
- 新手期**置换武将免费、重置战法免费、占地时间减半**。
- 大幅降低试错成本，鼓励玩家大胆尝试不同阵容。

---

### 阶段 4：48 小时新手保护期（第 1-2 天）

**核心体验：快速成长、建立成就感**

| 维度 | 内容 |
|------|------|
| **主要体验系统** | 资源系统、城建系统、任务系统、研究所科技系统、征兵系统、自动铺路系统 |
| **玩家在学什么** | 资源获取与消耗、建筑升级优先级、科技研究、征兵恢复、战损控制 |
| **系统如何引导** | 主线任务按步骤解锁城建/研究所/征兵所/集市；48小时内置换/重置免费、占地时间减半；自动铺路减少操作；任务奖励不断给予正反馈。 |

- 玩家持续占领资源地、升级主城、提升武将等级。
- 跟随主线任务解锁功能：城建、研究所、征兵所、集市等。
- 体验自动铺路、自动攻城等减负功能。

**设计意图**：
- 在玩家最容易流失的前 48 小时，用保护期和福利制造快速成长感。
- 让玩家在不被老玩家碾压的情况下，熟悉游戏节奏。

**核心循环**：
```
占地 → 获得资源 → 升级建筑 → 提升战力 → 打更高级的地
```

**关键数值**：
- 建筑升级资源比例：铁 : 木 : 石 ≈ 3 : 3 : 4，石料是前期瓶颈。
- 粮食主要用于征兵，控制战损是开荒关键。

---

### 阶段 5：加入同盟（第 2-3 天）

**核心体验：社交接入、目标升级**

| 维度 | 内容 |
|------|------|
| **主要体验系统** | 同盟系统、聊天/社交系统、同盟科技/资源加成系统 |
| **玩家在学什么** | 同盟的功能、职业在同盟中的价值、集体目标、指挥语言 |
| **系统如何引导** | 主动推荐/引导加入同盟；展示同盟资源加成；同盟任务/城池目标提供清晰集体目标；不同职业的玩家在同盟频道被需要，强化身份价值。 |

- 游戏引导或玩家主动加入同盟。
- 首次体验同盟频道、指挥系统、城池目标。
- 职业分工开始显现价值：同盟需要不同职业的玩家。

**设计意图**：
- 把个人成长转化为集体目标。
- 通过同盟制造归属感和长期留存动力。

**关键体验**：
- 同盟资源加成让个人发育加速。
- 首次参与同盟组织的攻城/集结。
- 玩家开始理解"我不是一个人在玩"。

---

### 阶段 6：首次攻城与州战（第 3-7 天）

**核心体验：GVG 高潮、职业协作验证**

| 维度 | 内容 |
|------|------|
| **主要体验系统** | 攻城系统、战场设施系统、职业技系统、PVP 遭遇系统 |
| **玩家在学什么** | 攻城宣战流程、集结机制、职业协作、战场设施使用、PVP 对抗 |
| **系统如何引导** | 同盟对城池宣战进入倒计时，给玩家准备时间；自动攻城让低活跃玩家也能参与；首占+参与奖励激励全员；职业技在战场中自动/手动释放，让玩家感受自己的职业价值。 |

- 参与首次攻城战，体验倒计时、集结、攻城器械、职业配合。
- 可能遭遇敌对同盟的骚扰或拦截，体验 PVP 张力。
- 职业系统价值最大化：镇军扛线、青囊治疗、天工建器械、神行骚扰。

**设计意图**：
- 这是从"个人发育"到"同盟战争"的关键转折点。
- 让玩家第一次感受到三谋"多职业协作"的核心魅力。

**关键设计**：
- 自动攻城降低参与门槛。
- 首占奖励 + 参与奖励结合，鼓励普通玩家参与。
- 战场设施（箭塔、拒马）让战争有策略变化。

---

### 阶段 7：赛季中期发育与州府争夺（第 2-4 周）

**核心体验：策略深化、阵容迭代**

| 维度 | 内容 |
|------|------|
| **主要体验系统** | 抽卡/卡包系统、武将养成系统、战法系统、多队编成系统、州府争夺系统、外交系统 |
| **玩家在学什么** | 多队搭配、战法联动、阵容克制、资源分配、同盟外交、赛季节奏 |
| **系统如何引导** | 赛季卡包/限时卡池引导抽新武将/战法；军演/贼寇等 PVE 玩法提供养成材料；州府目标制造同盟阶段性目标；跨州加盟、外交谈判等机制自然涌现。 |

- 玩家开始组建第二、第三支队伍。
- 根据赛季卡池抽新武将、新战法，迭代阵容。
- 参与州级战争，争夺州府、关键关卡。

**设计意图**：
- 让玩家从"新手"过渡到"核心玩家"。
- 通过新武将/战法持续提供养成目标。

**核心体验**：
- 配队策略：针对敌方阵容调整自己的队伍。
- 资源管理：平衡建筑、科技、征兵、战法的资源消耗。
- 同盟政治：外交、合纵连横、跨州加盟。

---

### 阶段 8：洛阳争夺与赛季后期（第 5-7 周）

**核心体验：终极对抗、赛季叙事高潮**

| 维度 | 内容 |
|------|------|
| **主要体验系统** | 霸业系统、功勋/排名系统、赛季事件系统、连城/跨州系统 |
| **玩家在学什么** | 最终战略目标、服务器级对抗、功勋获取、赛季奖励预期 |
| **系统如何引导** | 洛阳/霸业目标在赛季中后期高亮；连城与跨州加盟推动服务器整合；排行榜、功勋展示激发竞争；同盟指挥系统组织最终决战。 |

- 服务器进入最终阶段：争夺洛阳、完成霸业。
- 大盟之间展开最终决战，小盟选择站队或整合。
- 赛季排名、功勋、奖励结算。

**设计意图**：
- 为整个赛季提供明确的终点和目标感。
- 通过赛季结算制造成就感和炫耀点。

**潜在问题**：
- 若局势提前明朗，最后几周可能出现"垃圾时间"。
- 大盟垄断可能让小散人失去参与感。

---

### 阶段 9：赛季结算与重启（赛季末）

**核心体验：总结、传承、新的开始**

| 维度 | 内容 |
|------|------|
| **主要体验系统** | 赛季结算系统、养成继承系统、新剧本/新赛季入口 |
| **玩家在学什么** | 赛季奖励规则、哪些养成会保留、新赛季如何开始 |
| **系统如何引导** | 结算界面清晰展示同盟/个人排名与奖励；继承界面告知武将/战法/装备保留；新剧本预告制造期待；无缝进入下一赛季，开启新循环。 |

- 根据同盟/个人表现获得赛季奖励。
- 核心养成（武将、战法、装备）保留。
- 地块、城池、赛季进度重置，进入新剧本。

**设计意图**：
- 让玩家感到"投入没有白费"。
- 通过重启降低追赶门槛，为新玩家和回流玩家创造机会。
- 开启下一个赛季循环。

## 四、系统引导的整体逻辑

三谋的新手引导可以概括为 **"先个人、后社交、再集体"** 的三层递进：

1. **个人操作层（0-2 天）**：通过新手引导、保护期、主线任务，让玩家掌握占地、战斗、城建、征兵等基础系统。
2. **社交接入层（第 2-3 天）**：通过同盟系统，把玩家从单机式发育拉入集体，学习协作与职业价值。
3. **集体目标层（第 3 天-赛季末）**：通过攻城、州战、洛阳争夺等 GVG 内容，让玩家在同盟框架下追求赛季级目标。

每一层都依赖前一层的熟练度，系统通过 **任务、奖励、倒计时、目标高亮、自动功能** 等方式降低学习成本，让玩家在"做中学"。

## 五、设计亮点

1. **48 小时保护期**：在新手最脆弱期提供试错自由和成长加速。
2. **职业选择前置**：让玩家开局就有"我是谁"的明确身份。
3. **自动功能降低焦虑**：自动铺路、自动攻城减少操作负担。
4. **同盟目标清晰**：从加入同盟到攻城到霸业，目标层层递进。
5. **赛季制闭环**：既有积累感，又有公平重启，适合长周期留存。

## 六、潜在优化点

- **职业选择说明**：可在选职时增加更多"这个职业在 7 天后会怎么玩"的预览。
- **战报教学**：自动战斗结算对新手较抽象，可加强战报解读引导。
- **中后期动力**：赛季后期定局后，可增加更多个人/小团队目标。
- **回流玩家体验**：赛季中期入坑的新手追赶机制可进一步强化。
