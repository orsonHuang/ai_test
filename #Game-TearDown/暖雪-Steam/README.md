# 暖雪 · Steam 本体

## 项目描述

为系统案例库研究 Steam 本体的动作、构筑、永久成长与碎片叙事。资料截止 2026-10-16；本批采用公开资料研究，没有宣称实际游玩或核验当前构建号。历史指南只证明其记录时点的本体机制，不能用于当前数值配装。

## 工作规则

- 用户指定 Steam 本体；排除烬梦、终业、手游以及 DLC 的清明值／梦魇秘籍／无尽玩法。
- 买断、单人、完整作品体验。DLC 作为商业边界说明，不写入本体系统。
- 通用规范见上级 README 与 `_framework`。所有数字须标来源日期；不输出未经实测的最优构筑结论。
- 系统名称按设计职责拆分；圣物装配不直接归类为通用背包。

## 目录结构

## 三层循环与模块入口

以下是根据资料整理的I分析结构；P原型按各模块规格执行，不把参考数值混入原作。

- 秒级：判断位置→近战/飞剑→效果触发→命中与危险反馈。入口：[战斗](systems/战斗.md)。
- 单局：宗派方向→房间奖励→秘籍/圣物/神兵组合→休整预算→首领检验。入口：[宗派秘籍](systems/宗派与秘籍.md)、[圣物装配](systems/圣物装配.md)、[神兵词条](systems/神兵词条.md)、[章节首领](systems/章节与首领.md)、[商店休整](systems/商店与休整.md)。
- 跨局：重试积累→永久天赋→新的能力与理解→再次挑战。入口：[永久成长](systems/永久成长.md)、[叙事收集](systems/叙事收集.md)。熟练度是玩家学习，不当作存档数值。

## 覆盖与采证边界

已找到依据的8个系统组均有正文。设置、成就、完整新手教学、存档实际交互、当前难度档、仓储和精炼细则仍待采证；没有把这些空白写成不存在。完整原作清单需要当前本体实机遍历，当前交付是公开资料系统地图。

## 注意事项

本体历史样本与截至研究日的商店说明可能不同步。图鉴数量、伤害系数、掉落概率、解锁条件、按键与 UI 布局必须单独核验，不能从旧资料推为“最新版”。
