# 英雄没有闪 · 微信小游戏

## 项目描述

用户于 2026-10-16 指定微信小游戏，研究刷宝、装备处理、技能构筑、永久成长与运营循环。当前进行公开资料与平台适用性核验；不把 App 版本号或共用官网机制自动当作微信当前实测。

## 工作规则

- 官方共用介绍只能作为产品定位与候选系统线索；具体机制须标记微信证据是否成立。
- 微信登录的 APK 仍是 App，不能当微信小游戏证据。
- 资料截止 2026-10-16；具体服、账号阶段、热更号目前未知。
- 无证据的背包容量、自动分解规则、抽取概率、广告上限与充值数值保持未知。

## 系统地图与当前采证

| 候选系统 | 已定位资料 | 尚需核实 |
|---|---|---|
| 放置战斗／离线收益 | 开发商与发行官网 | 微信实际收益上限、结算边界 |
| 装备／词缀／套装／处理 | 官网一图流与新手攻略 | 微信现行流程与误操作保护 |
| 技能／符文／职业 | 开发商介绍、官方攻略 | 微信版本解锁与装配限制 |
| 养成／祝福／资源 | 官网原图已核读，早于微信上线 | 当前微信规则与开服阶段 |
| 主线／秘境／挑战 | 官网及官方论坛 | 微信端模式范围与门票 |
| 商业化／活动／社交 | 待定向补证 | 微信独立证据，不能直接抄 App |

## 三层循环与平台证据

- 秒级I：战斗消耗→伤害结果→掉落与经验→装备处理。资源消耗细则目前来自共用旧图，微信当前边界U。
- 阶段I：装备/技能/侍从组合→主线与资源副本→祝福和头衔→更高层目标。不是精确解锁顺序。
- 长期I：暗能等新成长线、日常资源与活动形成持续目标；当前微信公会/竞技/付费/广告细则仍U。

P参考可按IDLE→BAG→GROW→SKL/PET→CHAL/DARK→OFF/HOPS顺序实现。共用[公共契约](../_framework/参考实现公共契约.md)提供事务与存储约定。示例角色、装备、套装、概率、门票、UI和接口均为新增参考设计，不作为原作事实标签。

## 覆盖与采证边界

9份文档覆盖已找到证据或共用官方线索的模块组。元数据将只有共用线索的案例设为`presence: unknown`；默认原作筛选不命中这些机制。技能/刷宝/暗能的存在性由微信首发时期媒体支持，仍不等于当前构建实测。职业切换、完整符文养成、竞技场、公会权限、神器、设置、成就及全部商业入口列待采证，不根据App截图补齐事实。

## 注意事项

官方攻略 2025-02-12 发布，官网同时面向多端。即使内容可读取，也必须继续核对其微信适用性；本目录名称只表示用户研究目标，不给来源自动赋予平台可信度。
