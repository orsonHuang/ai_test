# 产品定位与长青归因

## 一、赛道坐标

| 维度 | 梦幻西游电脑版 | 同期竞品（魔兽世界 / 剑网三 / FF14） | 共同点 / 差异 |
|------|---------------|------------------------------------|--------------|
| 表现 | 2D 俯视、水墨 Q 版 | 3D 自由视角 | 梦幻用低美术成本换**内容迭代速度** |
| 战斗 | 回合制、5 人队、阵法 | 实时 / 半实时 | 回合制把「数值差距」放大为**可见的胜负** |
| 收费 | 点卡（时间）+ 可交易资产 | 点卡 + 商城（多为外观绑定） | 梦幻的资产**可人民币流通**，是最大差异 |
| 数值膨胀 | 不压缩，靠经济阀门管控 | 版本「属性压缩」拉平新老 | 梦幻选择**兼容存量**，代价是门槛越来越高 |
| 生命周期 | 20 年+，活跃仍增长 | 长线但多经重制 / 怀旧服 | 梦幻**不开重制**，靠经济续命 |

**结论**：梦幻西游不是靠「内容更新」续命，而是靠**一个玩家时间、金钱、资产三者可互换的封闭经济体**续命。内容只是给这个经济体提供新的「货币黑洞」和「资产标的」。

## 二、设计原点：三个逆向选择

这三个选择在当时看都是「逆潮流」，但正是长青的根基。

### 1. 为什么选回合制？
- **把操作技巧的方差压到最低，把养成数值的方差放到最大**。当胜负主要由数值决定，玩家变强的动机从「练操作」转移到「练数值」。
- 数值 = 时间 + 金钱。于是**玩家的两种资源被天然地变成了同一个东西**，付费与不付费玩家的动作高度同构：都在「攒资源变强」。
- 设计后果：战斗节奏慢、操作门槛低 → 对**上班族、多开、边做其他事边玩**极其友好，这是梦幻用户年龄上移（学生 → 30+ 成年人）后依然留存的关键。

### 2. 为什么坚持 2D？
- 美术成本低一个数量级 → 可以把预算压在**系统与数值**上，而非资产生产上。
- 直接后果：梦幻能维持**20 年不停服、不开重制**的连续性。连续性正是资产保值的前提（账号不被版本作废）。

### 3. 为什么是点卡制（时间收费）而非免费制？
- **点卡是时间的价格标签**。它让「在线」这个行为本身有成本，于是：
  - 玩家倾向于「在线时间要产出价值」→ 自然形成**产出导向的玩法习惯**；
  - 工作室的成本可被调节（点卡＝产出端的税）；
  - 玩家心理账户上，「花钱 = 买时间」，而不是「花钱 = 买数值强弱」，**付费的羞耻感更低**，付费与不付费玩家在同一套目标下共存。
- 2025-07-04 推出**畅玩服**（在线免点卡），本质是承认：新用户对「先付费才能玩」的心理门槛过高，用免点卡的入口承接新用户，同时把收费点后移到道具侧。**这是 20 年来最重大的商业模式变更**（参见 `notes/待核实清单与数据源.md`）。

## 三、用户结构：一个自带分工的生态

梦幻的用户不是「付费 / 不付费」两层，而是**四类角色互相供养**的结构性生态：

| 角色 | 核心诉求 | 主要行为 | 在经济中的位置 |
|------|---------|---------|--------------|
| **散人（单开）** | 休闲、社交、日常 | 师门、抓鬼、副本、帮派 | 消费内容 + 少量产出，稳定性来源 |
| **五开 / 职业玩家** | 时间 → 现金 | 多开刷日常、副本、搬砖 | **主要产出方**，也是金价的定价者 |
| **商人** | 信息差 → 利润 | 摆摊、跨区套利、囤货 | 流通层，价格发现者 |
| **老板 / 大 R** | 成就感、社交地位、上限追求 | 藏宝阁买号买装备、追求极品 | **需求方 / 最终买单者**，金价的支撑者 |

**关键洞察**：散人与五开是「生产者」，老板是「消费者」，商人是「做市商」。**老板的消费力是这套体系的顶层支撑**——一旦顶层需求萎缩，整套经济会向下塌陷。所以官方所有保护行为（保金价、保账号资产、保老玩家）本质都是**在保护顶层需求**.

## 四、长青归因（五条）

1. **资产可流通与保值**：藏宝阁把游戏资产接上了人民币，账号与极品装备可卖 → 玩家的心算模型是「投资」而非「消费」，**流失成本极高**。
2. **经济闭环可控**：产出、消耗、回收、调控四段阀门（详见 `numbers/经济系统维持机制.md`），使金价 20 年「浮而不崩」。
3. **养成阶梯不断加高**：每次资料片新增一条**高阶消耗线**（神兽升星、进阶坐骑、圣品变身…），把存量玩家的资源重新变成「不够用」。
4. **社交沉没成本**：帮派、固定队、五开小号群、师徒、结拜——社交关系绑定在角色上，角色不能轻易换服/换号。
5. **低操作门槛 + 时间可转化为收益**：让「成年人的碎片时间」有确定性的正反馈，形成日常习惯（习惯比内容更抗衰减）。

## 五、这一定位带来的代价（必须一起看）

- **新用户门槛极高**：老区经济成熟、装备要求高，新人「不被嫌弃」都很难（玩家标准：日常不被嫌弃、副本能通刷、点卡能保住、账号不贬值）。
- **数值膨胀不可逆**：培养门槛指数级上升，只能靠新线继续加高，形成路径依赖。
- **工作室与脚本是结构性伴生问题**，不可能根除，只能「提高单号成本」抑制。
- **新老体验撕裂**：老区/新区、时间服/畅玩服的玩家心理契约并不统一。

> 这五点代价，恰恰是理解「大/中/小 R 体验差异」的前提——差异不只是「花多少钱」，而是**各自处在经济体中的不同位置**。见 `systems/付费分层与大中小R体验.md`。
