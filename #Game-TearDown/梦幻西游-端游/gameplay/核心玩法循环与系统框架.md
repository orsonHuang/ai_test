# 核心玩法循环与系统框架

## 一、一句话核心循环

> **投入时间/金钱 → 产出可交易资源 → 沿养成阶梯变强 → 挑战更高门槛内容 → 产出更高价值资源 → （部分）通过藏宝阁变现或转化为社会地位**

这个循环的特殊之处：**每一步的产物都可以被「交易」**。因此循环不是闭合在个人身上，而是闭合在**整个服务器经济体**上。个人循环与经济体循环互为因果。

## 二、六层系统架构

```
┌─────────────────────────────────────────────────────────┐
│ L6 社交层   帮派 / 固定队 / 师徒 / 结拜 / 五开小号群      │
│             武神坛 / 剑会 / 帮战 / 服战  → 地位与荣誉      │
├─────────────────────────────────────────────────────────┤
│ L5 经济层   梦幻币 / 储备金 / 点卡 / 藏宝阁 / 珍宝阁       │
│             摆摊 / 商会 / 拍卖 / 手续费  → 价值流转与回收   │
├─────────────────────────────────────────────────────────┤
│ L4 养成层   角色线 / 召唤兽线 / 装备线 / 增值线（四条）      │
│             每条线 = 资源消耗 + 概率 + 台阶                │
├─────────────────────────────────────────────────────────┤
│ L3 战斗层   回合制 / 18 门派 / 阵法 / 召唤兽出战 / 特技      │
│             数值差距的「显示终端」                         │
├─────────────────────────────────────────────────────────┤
│ L2 内容层   日常（师门/抓鬼/押镖） / 副本 / 活动 / 周常      │
│             资源的「供给端」，带次数上限与超限衰减           │
├─────────────────────────────────────────────────────────┤
│ L1 时间层   点卡（在线扣点） / 体力 / 活力 / 在线时长        │
│             一切产出的「总闸门」                            │
└─────────────────────────────────────────────────────────┘
```

**架构原则**：越往下越是「约束」，越往上越是「动机」。L1 控制供给总量，L2 分配资源，L3 显示差距，L4 消化资源，L5 回收与定价，L6 提供非数值的长期动机（地位）。

## 三、各层关键系统清单

### L1 时间层 —— 一切经济的总闸门
- **点卡**：时间服在线扣点（2013-02-10 起 6 点/小时）。点卡既是玩家的成本，也是官方调控金价的工具（点卡 ↔ 梦幻币双向流动）。
- **体力 / 活力**：随时间恢复，用于制造类操作（打造、鉴定、炼药、烹饪等，具体映射待核实）。作用：**把「在线时长」进一步转化成「产出配额」**，多开玩家的产出不是线性的，而是被活力上限约束。
- **在线时长**：几乎所有资源的隐性前置条件。这是时间收费游戏的共同特征，也是「时间 → 收益」心理的根源。

### L2 内容层 —— 资源的供给端
- **日常**：师门（20 轮）、抓鬼、押镖、宝图、封妖、副本等。
- **周常 / 周期**：副本（乌鸡国、金兜洞等）、神器任务、周末活动、节日活动。
- **活动**：资料片新玩法（如 2026 年「百兽争鸣」衍生玩法）。
- **关键设计：超限产出衰减**——
  - 抓鬼：每周累计 > 200 次，**金钱奖励变为储备金**；> 300 次不再获得第 10 环额外物品。
  - 押镖：可选择「现金模式」或「**储备金模式**」（储备金模式收益不同，用于隔离流通货币）。
  - **意义**：这是把「产量上限」从「硬次数限制」改成「**产出形态降级**」——玩家的时间成本照付，但产出不再进入流通市场。既不打压肝度，又切断通胀来源。**这是梦幻经济调控最精巧的一环之一。**

### L3 战斗层 —— 差距的显示终端
- 回合制 + 18 门派 + 阵法 + 召唤兽出战 + 特技特效。
- **作用**：把 L4 养成的所有投入，在 PVE 副本门槛与 PVP（武神坛/剑会/帮战）中**显性化**。没有战斗层的显性化，养成投入就失去了社会意义。
- 2026-04 门派大改（18 门派技能/经脉调整）→ 说明战斗层被持续用作**版本节奏的调节器**（改变强势门派 → 刺激资源需求与转职消费）。

### L4 养成层 —— 资源的消化端
四条线并行：**角色线 / 召唤兽线 / 装备线 / 增值线**。详见 `systems/养成系统拆解.md`。
- 设计要点：每条线都具备「**确定性台阶**（花钱/时间必然变强）+ **概率性跃迁**（炼妖、打书、鉴定，成本不确定）」的双结构。
- 前者保证付费有保底回报（大众可接受），后者制造上限与金币黑洞（大 R 的舞台）。

### L5 经济层 —— 回收与定价
三币种 + 双交易平台的架构，详见 `numbers/经济系统维持机制.md`。
- **要点**：梦幻币（流通、通胀容器）、储备金（账号绑定、不可交易，通货膨胀隔离区）、点卡（时间凭证，与梦幻币双向兑换）。
- **双平台**：藏宝阁（人民币交易，2009-07 游戏币费率 1%→5%）、**珍宝阁**（2025-08 全服上线，梦幻币交易，5% 手续费，首期品类：≥5 级非吸收宝石、≥3 级五色灵尘、≥4 级星辉石）。

### L6 社交层 —— 非数值的长期动机
- **组织**：帮派（帮战）、固定队（日常效率）、师徒/结拜（情感绑定）、五开小号群（效率工具）。
- **荣誉**：武神坛（服战）、剑会（跨服 PK）、服务器排名。
- **作用**：
  1. 给「已经很强」的玩家提供**继续投入的理由**（数值饱和后转向地位竞争）；
  2. 社交绑定提高流失成本（角色 = 关系网）；
  3. 帮派/团队门槛倒逼个体养成，形成**群体压力驱动的付费**。

## 四、系统咬合的关键接口（拆解重点）

| 接口 | 咬合方式 | 设计意图 |
|------|---------|---------|
| 点卡 ↔ 藏宝阁梦幻币 | 金币价高 → 上层玩家买点卡换金币（增供给）；金价低 → 买金不充点卡（增需求） | **自动稳定器**：让玩家行为自己把金价拉回区间 |
| 日常产出 ↔ 储备金 | 超限 / 押镖模式选择 | 把过量产出「降级」为不可交易形态，切断通胀 |
| 养成消耗 ↔ 概率池 | 炼妖 / 打书 / 洗练 / 鉴定 / 圣品变身 | **金币黑洞**：把玩家固定资产吸入概率池，回收流通货币 |
| 战斗门槛 ↔ 装备需求 | 副本/PVP 门槛提高 → 装备/召唤兽需求提高 | 靠内容难度创造**对经济产物的需求** |
| 藏宝阁资产价格 ↔ 留存 | 账号保值 → 玩家心算为「投资」 | 流失成本 ↑，回流门槛 ↓（可买号回归） |
| 新资料片 ↔ 存量资源 | 新线让旧资源「不够用」 | 周期性重启资源消耗，防止玩家进入「无事可做」 |

## 五、日常/周常节奏（时间预算视角）

典型日常顺序（玩家实践总结，非官方）：
1. **师门任务**（20 轮，必做，稳定收益 + 储备金）；
2. **抓鬼**（开双前 N 轮，控制在每周 200 次内以避免收益转储备金）；
3. **押镖**（选储备金模式）；
4. **宝图**（单号日均可打约 100 张，直接卖约 200–250 万梦幻币量级）；
5. **副本 / 周末活动**。
6. 参考量级：单号完成基础日常 + 宝图，日收益约 **250–300 万梦幻币**量级（2026 年玩家统计，波动大，仅作量级参考）。

**设计观察**：日常的收益结构与「次数/衰减」绑定得很紧，玩家要**主动规划不越线**。这让「懂规则」本身成为一种收益差——信息差 → 交易利润，是商人层的生存基础。

## 六、这一架构的三个设计结论

1. **梦幻的核心不是「玩法好玩」，而是「产出有确定性价值」**。回合制的低操作门槛是让「时间→产出」这条链路最大化可复制的必要条件。
2. **经济层是主系统，其他层是它的从系统**。内容层负责供给，养成层负责消耗，战斗层负责让消耗有意义，社交层负责让消耗持续。**任何新玩法都要先回答「它回收什么货币、创造什么需求」**。
3. **调控优先用「软手段」**：超限转储备金、手续费、品类限制（珍宝阁只开放部分高等级品类）——尽量少用直接的数值削弱（会让存量玩家资产贬值）。这既是经济策略，也是**资产信任策略**。
