# 经济系统维持机制

> 核心问题：一个 20 年不重置、不断增发资源的 MMORPG，为什么没有崩盘？
> 答案：**三币种隔离 + 双平台定价 + 四段阀门调控 + 自动稳定器**。

## 一、货币架构：三币种 + 双平台

| 币种 / 平台 | 属性 | 是否可交易 | 在经济中的角色 |
|------------|------|-----------|---------------|
| **梦幻币（游戏币）** | 游戏内流通货币 | 可交易 | **通胀容器**——所有超发首先冲击这里 |
| **储备金** | 账号绑定货币 | **不可交易** | 通胀隔离区，只能用于养成消耗 |
| **点卡** | 时间凭证（人民币购买） | 可交易（可换梦幻币） | **双向调节器** |
| **藏宝阁** | 官方人民币交易平台 | 人民币结算 | 价值出口，把游戏资产接上现实货币 |
| **珍宝阁** | 官方梦幻币交易平台（2025-08 全服上线） | 梦幻币结算 | 梦幻币级的价值出口 + 回收阀门 |

**分层隔离的意义**（第三方分析核心观点）：
> 游戏币的价值波动**难以逆向影响到人民币**；金价剧烈波动时，玩家反而能通过人民币来稳定物价和金价。
> 官方表述：**「点卡与藏宝阁梦幻币的双向流动能用于稳定物价和金价。」**

即：**玩家看到的是「金价」，官方掌握的是「三个可互相兑换的池子」**。调控时动的是池子之间的闸门，而不是直接改数值。

## 二、四段阀门

### 阀门 1：供给端「降供」
| 手段 | 具体做法 | 目的 |
|------|---------|------|
| 下调掉落概率 | 降低游戏币或等值物品掉落 | 直接压低产出速率 |
| 活动次数限制 | 对活动做次数上限 | 控制单位时间的产出 |
| 脚本号筛选 | 用图形测试等筛除脚本号，强制下线/限权 | **提高工作室单号成本** |

关键结论（第三方分析）：单号产出上限被拉低后，「**即使是账号总数增长，游戏币也很难出现井喷状况**」。→ 这是**抑制工作室的正确姿势**：不打总量，打**单位账号效率**。

### 阀门 2：需求端「提求」（金币黑洞）
把玩家的固定资产吸入概率池，从而回收流通货币：

| 黑洞 | 机制 |
|------|------|
| 炼妖 | 合成召唤兽，材料消耗高、结果随机 |
| 打书 | 兽决打技能，可能顶掉已有技能 |
| 洗练 / 鉴定 | 装备与坐骑属性随机洗练（如坐骑洗练 100 万起、每次 +10 万、封顶 200 万） |
| 圣品变身 | 第三方资料称解锁全部变身需约 **24 亿游戏币**量级 |
| 神兽合成（2026 新增） | **2 只相同神兽合成 1 只**升星，指数级消耗同类神兽 |

**设计精髓**：这些黑洞消耗的是**玩家自愿投入的货币**，而且伴随「可能一夜暴富/血本无归」的刺激。它同时满足三个目的：回收货币、制造交易需求、提供娱乐性。

### 阀门 3：回收端「收税」
| 平台 | 费率 | 节点 |
|------|------|------|
| 藏宝阁（游戏币交易） | **1% → 5%** | **2009 年 7 月起** |
| 珍宝阁（梦幻币交易） | **5%**（成交价） | 2025-08 全服上线 |

- 官方定性：收税是「**对虚拟经济进行宏观调控的一种调节手段**」。
- 作用原理：**收税直接提高「卖币成本」→ 等价于抬高金价**，是防止游戏币贬值的直接手段。
- 珍宝阁补充效果（第三方观察）：5% 手续费**直接销毁梦幻币**，部分服务器上线后金价出现明显涨幅；同时**压缩商人利润空间**（减少信息差获利），并**分流**部分藏宝阁交易。

### 阀门 4：调控端「自动稳定器」
**点卡 ↔ 梦幻币双向流动**：

```
金价过高（币太贵） → 上层玩家用点卡换金币投放市场 → 金币供给增加 → 金价回落
金价过低（币太便宜）→ 玩家买金而不冲点卡 → 金币需求增加 → 金价抬头
```

**为什么这是「自动」的**：因为两侧的行为都由**玩家自身利益驱动**——不需要官方出手，套利行为本身就把金价推回区间。官方只需要设定**手续费与兑换规则**这两个参数。

### 补充阀门：产出形态降级（超限转储备金）
| 玩法 | 规则 | 效果 |
|------|------|------|
| 抓鬼 | 每周累计 > 200 次，**金钱奖励变为储备金**；> 300 次不再得第 10 环额外物品 | 保留玩家「可继续玩」，但产出退出流通 |
| 押镖 | 可选**现金模式 / 储备金模式** | 玩家自己选择是否把产出投入流通 |

**这是最值得学习的一环**：它**不打压肝度**（不禁止多玩），只**降级产出形态**。玩家的时间照样花，情绪不受挫，但通胀被切断。比「硬性次数上限」体验好得多。

## 三、金价维持的完整链路

```
[供给] 日常/副本产出 ──超限─→ 储备金（退出流通）
                    └─正常─→ 梦幻币（进入流通）
                                │
[需求] 养成消耗（修炼/技能/乾元丹）←──┘
       概率黑洞（炼妖/打书/鉴定/神兽合成）
                                │
[回收] 摆摊/交易税 + 藏宝阁/珍宝阁手续费（5%）→ 销毁
                                │
[调价] 点卡 ↔ 梦幻币 双向兑换 ←→ 藏宝阁人民币定价
                                │
[结果] 金价「浮而不崩」
```

第三方分析的原话总结：**「降供提求，币种调控——经济命脉便牢牢掌握在官方手中。」**

## 四、区服：独立经济体的生命周期

梦幻的经济不是全局的，而是**每个服务器一个独立经济体**（区服间不能自由交易），因此会出现**经济体生命周期**现象：

| 区服状态 | 特征 | 成因 |
|---------|------|------|
| **新服** | 物价飙升、机会多、工作室扎堆 | 产能稀缺，需求旺盛 |
| **烟花区 / 红区** | 经济繁荣、金价高、人气旺 | 人口集中，需求旺盛；**准入有门槛**（转入成本高），形成「准入壁垒 → 稀缺性 → 保值」 |
| **普通区** | 平稳 | —— |
| **鬼区** | 人口稀少、物价低迷、产出无处消化 | 新区虹吸 + 工作室刷完即走 |

**转区系统 = 动态供需平衡器**（第三方定性）：官方通过「平转（基础转区）」等机制调控服务器人口与经济，本质是**用移民政策调节区域经济**。

**结构性矛盾**：**「有些新区看着火爆，其实里面大量工作室只刷开区那个月的 18 门，出完就走」**（玩家原话）。→ **新区繁荣可能是伪繁荣**，这是区服经济治理的难点。

## 五、工作室与脚本：结构性的伴生问题

- 工作室不是「bug」，而是**点卡制 + 产出可变现**的必然产物：只要「单位时间产出 > 点卡成本」，就存在套利空间。
- 官方的应对**不是封堵，而是提成本**：图形验证、掉落下调、超限转储备金、手续费。核心逻辑是**压缩「单位账号利润率」**。
- 经济后果：工作室是**主要产出方**，也是金价的压力源；但同时也是**新区人气的假象来源**。这使治理必须在「抑制通胀」与「维持人气」之间取平衡。

## 六、这套系统的三个脆弱点

1. **依赖顶层需求**：老板（大 R）的消费力是整套体系的支撑。若高净值玩家流失，藏宝阁价格与金价会同步塌陷。
2. **依赖新用户持续流入**：储备金机制只能处理「存量玩家的过量产出」，无法解决「总需求萎缩」。因此必须持续拉新（畅玩服即为此而生）。
3. **信息差红利会被工具吃掉**：自动化脚本与数据工具会压缩商人利润，使中间层（中小 R 与商人）的体验变差，形成「上重下轻」的结构压力。
