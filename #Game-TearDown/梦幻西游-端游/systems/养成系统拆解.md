# 养成系统拆解

> 说明：仅拆解**电脑版（端游）**机制。注意端游与《梦幻西游》手游在经脉、货币等系统上并不相同，勿混用。

## 一、四条养成线总览

| 养成线 | 养成对象 | 主要维度 | 主要消耗资源 | 结构特征 |
|--------|---------|---------|-------------|---------|
| **角色线** | 人物本体 | 等级、门派技能、人物修炼、召唤兽修炼、经脉、飞升/渡劫/化圣、辅助技能 | 经验、梦幻币/储备金、修炼果、乾元丹 | 确定性台阶 + **复合门槛** |
| **召唤兽线** | 召唤兽/神兽 | 资质、成长、技能数量、内丹、兽决、神兽星级 | 梦幻币、兽决、炼妖材料、同类神兽 | 概率为主（炼妖/打书） |
| **装备线** | 装备/灵饰 | 打造属性、特技特效、宝石、符石、星辉石 | 梦幻币、宝石、符石、星辉石、鉴定费 | 概率 + 镶嵌叠加 |
| **增值线** | 法宝/坐骑/外观 | 法宝等级、坐骑技能与属性、锦衣祥瑞 | 梦幻币、专属道具、福缘 | 后置解锁 + 洗练 |

**设计逻辑**：四条线覆盖「必然变强」「赌运气」「可交易投资」「纯身份象征」四种动机，任何一类玩家都能找到自己的投入出口。

## 二、角色线

### 2.1 等级 —— 一切的前置门
- 等级上限长期停在 **175 级**，是「化圣」等一系列高阶系统的准入门槛。
- 等级不靠单一玩法：师门、抓鬼、副本、环任务、活动都在供经验，**让所有玩法都指向同一个进度条**，避免内容割裂。

### 2.2 门派技能
- 每个门派有 7 个门派技能，高阶要求（如化圣）为 **7 个技能全部≥180 级**。
- 消耗经验 + 金钱（**可用储备金**）→ 这是储备金最主要的出口之一。
- 设计意图：把「等级」和「技能」拆成两条需要同时推进的进度条，**避免单线堆等级带来的强度尖峰**。

### 2.3 人物修炼
- 类别：攻修、法修、防修、法防修、猎术等（玩家俗称「修炼」）。
- 化圣前置：**人物修炼总和 ≥ 60 级**；召唤兽修炼各项（除育兽术外）**≥ 20 级**。
- 玩家视角中，修炼属于「**性价比最高**」的核心投入（8 大必点项之一），因为它直接放大所有装备与宠物的收益。
- **数值设计观察**：修炼的收益是**乘法型**的（提升攻防系数），而装备是**加法型**的（加属性）。乘法型投入优先被点满，是「老玩家共识」——说明梦幻的养成梯度里，**低门槛高杠杆的项负责拉留存，高门槛低杠杆的项负责拉开付费上限**。

### 2.4 奇经八脉（乾元丹）
- 开放等级：**69 级**，在门派师傅处消耗**经验 + 金钱（可用储备金）**炼化乾元丹，用于激活经脉点。
- 端游前期数据（2011 年官方：69 级可换 7 颗，需经验 22,341,872、金钱 4,468,371）——**注意此为早期数值，现已变**，仅用于说明「消耗量级随等级段上升」的结构。
- **首次重置免费** → 降低试错成本，鼓励玩家研究流派（也制造后续**转流派的重复消耗**）。
- 2026-04 门派大改对经脉做了大幅调整 → 说明官方把经脉当作**版本节奏调节器**：调整强势流派会直接刺激转流派与相关装备需求。

### 2.5 飞升 / 渡劫 / 化圣
经典的**多级跃迁形态**：

| 阶段 | 性质 | 前置条件（化圣为例） |
|------|------|---------------------|
| 飞升 | 中段转型 | 等级 + 剧情 |
| 渡劫 | 中高阶 | 等级 + 剧情 + 修炼 |
| **化圣 1–9** | 顶级目标 | 175 级、7 门派技能 180 级、人物修炼总和≥60、召唤兽修炼各项≥20、通关「后羿陵墓（上/下）」副本、完成巫月与后羿剧情；累计消耗约 **135 亿经验**量级 |
| 化圣奖励 | —— | 新造型、专属技能、潜能点、**额外四级法宝栏位** |

**设计要点**：
1. **复合门槛（系统性锁）**：化圣不是「升到某等级」，而是**多条养成线同时达标**。这强制玩家全面发展，避免出现「只堆一条线」的畸形角色，也保证了各养成线都有需求。
2. **奖励为「新槽位」而非单纯数值**：额外法宝栏位是**打开新的养成空间**，而不是给一个固定加成。这为后续版本预留了继续加高的容器——是梦幻最典型的「**用奖励扩容，用扩容续命**」手法。

### 2.6 辅助 / 帮派技能
- 强身、冥想、养生、烹饪、炼药、打造、裁缝、炼金等（生活技能）。
- 与 **体力/活力** 绑定 → 把在线时长转化为产出能力，是散人和五开的重要经济来源。

## 三、召唤兽线（最典型的概率线）

### 3.1 基础结构
- 一只召唤兽的强度由 **资质（各项基础值）+ 成长（系数）+ 技能数量与品质 + 内丹 + 装备** 决定，是典型的多维复合体。
- **炼妖 / 打书**：通过合成获取高资质多技能，通过兽决「打书」把技能打上去——**有概率顶掉已有技能**，是纯概率赌博。
- 官方定性（第三方分析引用）：炼妖、打书被称为**金币黑洞**，让玩家把固定资产投入概率池。

### 3.2 神兽体系（2026 年「百兽争鸣」资料片大幅强化）
- **升星**：二转神兽 → 升星为一星（解锁「神兽秉性」与进场特效）；**2 个相同一星 → 1 个二星**（解锁专属技能/赐福、属性点、内丹数）；**2 个相同二星 → 三星**。
- **神兽秉性**：可视为特性池，三星池共 15 个秉性；可消耗「神兜兜」修改。
- **普通宝宝临时体验**：消耗 10 个丸子临时变为随机神兽，持续 24 小时（不可指定）。
- **坐骑统驭**（进阶坐骑同步改动）：每将一条坐骑技能学满 3 级，提升「玉魄奇袭法术」触发几率 1%；触发后可额外召唤，**每位玩家最多同时控制 2 只召唤兽**。

**设计解读**：
- 「2 只相同神兽合成 1 只更强神兽」是**指数级消耗结构**——合成次数越多，需求越大，回收货币与交易额越可观（并且天然制造**同类神兽的抢购需求**，抬高其市场价）。
- 「10 个丸子临时体验神兽 24 小时」是**体验式转化设计**：先让玩家尝到强度，再转化为永久追求（且随机不可指定，制造反复消费）。
- 「多控一只召唤兽」改变战斗层：既是战力上限提升（付费动机），又让五开玩法的收益面扩大（留存动机）。

### 3.3 召唤兽装备与兽决
- 独立于人物的装备与技能体系 → **每加一条线，就多一份消耗出口**，且这些产出可以全部在玩家间交易。

## 四、装备线

### 4.1 打造与鉴定（概率入口）
- 低等级用体力打造，高等级（高级装备）需要**鉴定**：产出属性**完全随机**（可能极品，也可能废品）。
- 这是**金币黑洞之二**：鉴定成本 + 报废率，构成巨大的货币与物品消耗。

### 4.2 宝石镶嵌
- 部位 + 宝石类型组合（太阳石、月亮石、光芒石、黑宝石、红玛瑙、舍利子、翡翠石、神秘石等），宝石可逐级合成。
- **可交易** → 高等级宝石（珍宝阁首期开放 ≥5 级非吸收宝石）是重要交易标的。

### 4.3 符石与门派符石组合
- 装备可镶嵌符石，特定符石组合可触发**门派技能相关加成**。
- 作用：**把「装备」和「门派」耦合**，使门派大改时装备需求随之变化（版本刺激交易）。

### 4.4 灵饰 + 星辉石
- 灵饰分前排/后排，镶嵌**星辉石**，镶嵌按「段数」计（玩家口径如「5 段星辉石的双气血」）。
- 灵饰属性条（气血/防御/伤害/暴击等）随机 → 又一条**概率 + 镶嵌双重消耗**线。
- 珍宝阁首期开放 **≥4 级星辉石**，说明它是高价值核心交易品。

### 4.5 洗练 / 熔炼 / 无双 / 特技特效
- 特技与特效是装备的「第二条属性轴」，可通过洗练类操作调整。
- **设计观察**：装备的价值不只在数值，还在**稀有组合的稀缺性**——这使装备具备收藏与投机属性，藏宝阁上万级交易多来自此类极品。

## 五、增值线

| 子系统 | 机制要点 | 设计作用 |
|--------|---------|---------|
| **法宝** | 法宝等级/灵性培养；化圣奖励**额外四级法宝栏位** | 为顶级玩家预留扩容空间 |
| **坐骑（2026 进阶）** | 进阶回收原坐骑但继承灵气/技能点/主属性/经验；成长上限提至 **1.35**、等级上限 **+5**；可洗练五项属性（首次 100 万梦幻币，每次 +10 万，封顶 200 万，消耗福缘）；6 卷技能分别统驭召唤兽 | 洗练费用**递增且封顶**＝典型「边际成本递增」设计，兼顾回收与体验 |
| **变身卡 / 变身术** | 战斗中变身获得增益，卡可交易 | 消耗品循环（持续回收） |
| **圣品变身** | 第三方资料称解锁全部变身需约 **24 亿游戏币**量级 | 极端金币黑洞，服务于大 R |
| **锦衣 / 祥瑞（外观）** | 不影响战力，但**限量款具备保值/增值属性**（第三方称部分稀有外观账号溢价超 50%） | 把「付费」变成「**资产配置**」，是最强的留存与保值工具 |

**关键洞察**：外观类资产是梦幻经济里**唯一「只涨不跌」的品类**（因供给被官方永久冻结）。它的存在使玩家整体心算为「投资」，从而对数值通胀有更高容忍度。

## 六、养成设计的四个核心手法（可迁移）

1. **双结构**：每条线都同时提供「确定性台阶」（点修炼、升等级，有保底）与「概率跃迁」（炼妖、打书、鉴定，无保底）。**保底给大众安全感，概率给上层上限与货币回收**。
2. **复合门槛**：高阶目标要求**多线同时达标**（化圣需要等级+技能+人物修炼+召唤兽修炼+剧情）。防止单点突破，保证所有养成线都持续有需求。
3. **奖励即扩容**：高阶奖励优先给**新槽位/新容器**（额外法宝栏位、多控一只召唤兽），而非固定数值。为后续版本持续加高预留接口。
4. **消耗形态多样化**：经验、梦幻币、储备金、专属道具（乾元丹、神兜兜、福缘）、概率池。**不同形态对应不同人群与不同回收目的**——储备金回收「过量的时间产出」，概率池回收「流通的梦幻币」。

## 七、数值膨胀的必然与官方取舍

- 梦幻**不做属性压缩**（与魔兽/剑三/FF14 的版本压缩策略相反），原因：压缩会作废存量资产，破坏「资产保值」这一核心信任。
- 代价：养成门槛指数级上升（玩家抱怨「培养门槛指数级提升」），新人进场困难。
- 官方的解法不是压缩，而是**不断加新线 + 用经济手段回收**，形成路径依赖。这是「长青」与「门槛」的一体两面。
