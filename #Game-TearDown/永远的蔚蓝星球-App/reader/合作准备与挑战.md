# 合作准备与挑战

永远的蔚蓝星球 · 手机 App · 多人玩法 / 协调与资源获取

合作系统首先要解决一个很具体的问题：**两个人是否知道要打什么，并且都已经准备好。** 战斗之前的界面不是一段可以忽略的等待，它决定了配装、成员状态和开战权限能否被双方理解。

## 设计目的与范围

我把合作拆成三个连续阶段：找到合适参与者、确认共同挑战条件、完成挑战并理解收益。本文重点研究第二阶段，因为它有明确的 App 公告和界面依据。队伍规模、门票和奖励不应从一个历史截图推广到所有合作模式。

2026-03-05 的 App 公告说明，彩虹副本增加准备功能，队员调整方案并准备后，由队长发起挑战。[公告及原图](https://www.taptap.cn/moment/778714788971675862)。这使“在房间里”和“同意以当前配置开战”成为两种不同状态。

## 系统功能与原作流程

| 功能 | 已有依据 | 设计作用分析 |
|---|---|---|
| 挑战信息 | 公告配图展示关卡与两条战斗条件 | 先说明挑战要求，再让玩家判断配置 |
| 成员展示 | 两名参与者、队长标记、各自的数值信息 | 表达谁在参与及谁拥有发起权限 |
| 方案入口 | 图中右下方有方案按钮 | 让配置调整留在开战前的任务范围内 |
| 准备与开始 | 未准备提示和灰色挑战按钮 | 解释当前不能开始的原因 |
| 成员管理 | 队长画面中有请离入口 | 区分队长管理与普通参与者操作 |

上述内容来自同一张已查看的队长视角配图。它支持界面观察，不能证明准备后修改方案、掉线或战后留房的行为。

线框保留了原图的信息层级，省略装饰，并对布局作了简化；它不是逐像素复刻。原图可通过上方公告查看。

**① 规则区域：先告诉玩家本层有什么不同。** 两条条件位于首领上方，玩家进入战斗前就有机会判断是否需要换方案。我认为这一信息比单独展示推荐战力更有用：战力只能提示强弱，具体条件才能帮助选择阵容。

**② 首领区域：强调本次共同目标。** 原图把首领作为画面中心，能将挑战氛围和目标联系起来。装饰面积较大，也意味着规则与状态必须在有限空间里保持清楚。

**③ 成员区域：身份和状态需要同时清楚。** 原图把队长标记放在对应角色附近，能表达管理关系。不过战力数字不能替代合作适配度；若两人承担不同功能，仅比较数字可能误导组队判断。这是信息设计上的评价，不是对原作匹配算法的推断。

**④ 开始区域：禁用按钮要有原因。** 图中挑战按钮灰置，同时显示队友未准备。玩家知道下一步需要队友行动。对比只让按钮变灰，这种写法减少了猜测；但后续仍需核查准备成功、成员退出和资源不足是否同样有清楚反馈。

## 详细状态设计建议

以下是补充设计，供复现和讨论使用；原作未核实的行为没有因此被视为已确认。

| 状态 / 事件 | 建议处理 | 用户看到什么 |
|---|---|---|
| 等待成员 | 不允许开始 | 空位与邀请入口，说明需要几名参与者 |
| 成员配置中 | 保持未准备 | 该成员旁显示配置中；队长看到开始条件 |
| 已准备后换方案 | 取消该成员准备 | 明确告知配置已变，需要重新确认 |
| 队长更换挑战 | 取消双方准备 | 新关卡条件突出显示，避免带着旧理解开战 |
| 点击开始 | 校验当前成员、准备和所需资源 | 显示进入中，避免反复点击 |
| 开始失败 | 留在可解释的房间状态 | 说明成员变化、资源不足或连接失败 |
| 有效战果产生 | 展示基础与身份相关奖励 | 玩家能解释为何双方收益可能不同 |

这里最关键的是让准备绑定当前方案与挑战，而不是一个永久有效的勾选。技术实现参数与完整异常规格放在文末可展开的开发附录中。

## 收益、节奏与代价

合作可以让不同养成阶段的玩家产生联系，也会增加找人、等待和反复确认的成本。我会分别测量真正的配合时间与没有决策的等待时间；后者才是优先减负的对象。

历史更新曾加入奖励预览和队长额外奖励说明。这类信息有助于玩家理解参与身份的价值。[2025-06-10 更新](https://www.taptap.cn/moment/681511296339807133)。我的判断是，奖励说明应该服务组队决策，而不是只在结算后揭晓差异。否则玩家可能在完成一次合作后才发现预期不一致。

## 我的评价与适用条件

这个案例最值得借鉴的是准备状态与方案调整的关联。对于开局选择会明显影响双方结果的游戏，确认能减少误开；对于低风险、重复性很强的内容，则应避免每局让双方重复同样的手续。是否保留房间、哪些变化必须重新准备，需要结合具体玩法决定。

原作的当前掉线恢复、准备回退和战后房间状态仍需实机确认。相关减负公告中包含计划项，本版没有把预告直接当成已上线。[减负预告](https://www.taptap.cn/moment/844263068358673457)
