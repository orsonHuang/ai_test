# 永远的蔚蓝星球 · 手机 App

## 项目描述

研究手机 App 的局内合成塔防、局外成长、竞技合作与持续运营。用户于 2026-10-16 指定 App；不混用微信小游戏规则。公开商店当日显示 Android 3.0.7（66）、2026-09-29 更新；这是商店登记信息，不等于已核验全部热更或 iOS 构建。

## 工作规则

研究截止 2026-10-16。官方公告与官方转载玩家攻略分别标记；历史上线与未来预告分开。新英雄／赛季不自动覆盖旧版本。三分钟一局属于官方宣传承诺，未实测计时。

## 目录结构

`systems/` 10份模块文档；`roles/` 岗位导航；`assets/` 图文材料；`sources.json` 来源台账；`game.json` 检索数据。原作资料与P参考切片并列，所有玩法验收用例尚未运行。

## 三层循环与关联

- 局内I：召唤→占用格子→合成与技能选择→守住防线→获得局内资源，收益反过来支持新的召唤。
- 单次目标I：主线/竞技/合作选择→准备对应方案→挑战→模式奖励→检视阵容短板。
- 长期I：英雄和装备成长→新关卡/赛季目标→日常与团体资源→形成新的配置选择；实际成长速度与付费效率未测量。

P整合顺序：英雄/装备快照→TD塔防→关卡→合作或竞技→资源与社交→招募与运营。所有模式显式覆盖单人暂停、初始城堡、波次和门票，不能同时套用互相冲突的默认值。共用[公共契约](../_framework/参考实现公共契约.md)。

## 覆盖与采证边界

10组覆盖有资料的战斗、成长、图腾、主线赛季、竞技、合作、领地四子系统、社交榜单、招募和运营。国王完整成长、背包、设置、成就、当前教学、遗迹、巅峰竞技等未获得完整规则的入口保留待采证；计划中“快战/扫荡”不自动记成已存在。整份资料不是所有当前服务器的实机全量盘点。

## 注意事项

2025 领地攻略与后续竞技场公告存在规则差异，必须按日期引用，不拼成一份无日期的规则表。名称含“赛季”不意味着系统全量重置；预告不代表已经上线。
