## 2. 全等级费用与成长效果

从等级 L 升至 L+1（L=1..34）：金币=100×L、对应碎片=2×L。攻击系数=10000+500×(L−1)基点。一次升一级，资源全部足够才提交；不支持超出上限或部分扣款。1→35合计59,500金币、1,190碎片。

普通天赋从 N 升到 N+1（N=0..19）：金币=200×(N+1)，天赋石=5×(N+1)。国王基础攻击=10+2N，普通攻击每2000ms一次，打距离终点最近敌人；同距按enemyId。它不继承英雄局内星级、英雄三选一增伤或英雄暴击。

特殊天赋从 T 升到 T+1（T=0..9）：金币=500×(T+1)，传说天赋石=T+1。T≥1开启剑气；第10000ms起每10秒攻击本路距终点最近的最多2个敌人，每个伤害为国王攻击×(10000+1000T)/10000，向下取整，并将敌人沿路径后退1m，位置最低0。首领免位移但承受伤害。普通攻击与剑气同tick先普通后剑气。

| 功能节点 | 明确效果 | 防重复条件 |
|---|---|---|
| 英雄5级 | 本局首次召唤该英雄额外+5召唤币 | battleId＋heroId去重；合成不触发 |
| 英雄10级 | 第一次该英雄达2星时+5召唤币 | 每英雄每局一次 |
| 英雄20级 | 此英雄普通攻击冷却由1000ms变900ms | 开战固定，不与重复召唤叠加 |
| 英雄30级 | 此英雄普通攻击冷却由900ms变800ms | 覆盖20级档，不是再次减200ms |
| 普通天赋20级 | 持续基础攻击50 | 无额外隐藏效果 |
| 特殊天赋10级 | 剑气倍率20000基点 | 无无限缩短冷却 |

## 3. 培养流程、方案与重置

1. 查询当前状态及目标一级费用；显示现有、需要、缺口。
2. 提交对象ID、目标等级、expectedRevision及requestId。
3. 服务器检查拥有、上限、配置版本和全部资源；一次扣费、升阶、写记录。
4. 返回前后属性与新解锁效果。失败保持所有资源与等级不变。
5. 更新大厅方案预览；已经开始的战斗保留原快照。

参考不提供等级重置返还；界面明确“本版本培养不可退回”。方案更换免费，不能把换方案与撤销养成混为一谈。更换装备先校验引用仍存在，遇到缺失物品返回INVALID并指明槽位，不静默用另一件代替。

演示技能在通关s1后免费获得：开局补给（开局+10召唤币）和护墙（城堡基础上限+2）；方案最多选一项。共享城堡模式下两人的护墙加成相加，开战即满血到新上限。其他皮肤图鉴、坐骑和原作全外观不在该参考内容集内。

## 4. 接口与异常

| 接口 | 输入 | 成功输出 | 失败 |
|---|---|---|---|
| UpgradeHero | heroId, targetLevel | 等级、钱包、功能变化 | 满级、材料不足、旧版本 |
| UpgradeKingTalent | branch, targetLevel | 天赋状态、钱包、下一费用 | 非法分支、跨级、材料不足 |
| SavePreset | presetId, heroIds, equipmentIds, skillId | 新方案revision | 重复英雄、缺装备、技能未拥有 |
| BuildLoadout | presetId, expectedRevision | 不可变能力快照与hash | 方案过期、配置缺失 |

断网后查询原requestId，不重发新ID。配置提升上限允许继续成长；降低上限必须有迁移表，缺表则拒绝配置上线。原始培养记录保留，不用新费用重算历史扣款。

## 5. UI 与资产交接

| 页面/状态 | 必须展示 | 交互与资源 |
|---|---|---|
| 英雄卡 | 当前等级、下一等级、属性差值、功能节点 | 三头像、对应碎片图标、节点锁/已开状态 |
| 国王天赋页 | 两条树、当前节点、下一费用 | 普通/特殊石不同形状；节点连线对应前置 |
| 材料不足 | 持有、需要、缺口和获取入口 | 禁用升级仍保留费用，不能只显示红色数字 |
| 提交中 | 当前对象与等待状态 | 禁止二次提交；动画结束不控制发奖 |
| 方案变更 | 受影响玩法和新版本 | 合作准备失效提示由房间模块处理 |

升级动效建议300ms、可跳过；节点解锁用图标加文字，不能只换颜色。资产为原创占位，不复制原作角色与声音。
