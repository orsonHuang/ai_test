# 阴阳寮与师徒协作 · 开发参考附录

2026-10-18 · 补充设计 v2 · 默认参数均非原作配置


## 对象与权限

参考版寮上限50人，一个账号只能加入一个寮；创建消耗10000金币，退出或被移除后24小时不能重新加入。寮长1、管理员最多2；寮长可任免和转让，管理员可批准申请/移除普通成员，普通成员可捐赠、祈愿和参与挑战。管理员不能移除彼此与寮长；寮长离开前必须转让，最后一人退出可解散。

师徒关系：师傅账号40级，最多2名未毕业徒弟；徒弟1—29级且未毕业、仅能绑定1师傅，双方确认。30级且共同完成5次参考PVE挑战后可毕业：双方各10000金币＋1召唤券；同账号终身只领一次徒弟毕业奖。主动解除后48小时可重新绑定，已累计共同挑战清零。

## 祈愿与捐赠

| 行为 | 自设限额与规则 |
|---|---|
| 发起祈愿 | 每日1次、指定已有至少1片的SR角色，需求上限2片；日切05:00后过期 |
| 赠送 | 每人每天总共2片，不可给自己；扣捐赠者碎片与记入请求已收数量同一事务 |
| 领取 | 每份收到的碎片独立领取，仅本人可领；到期未领转30天邮件 |
| 普通捐赠 | 每日最多3次，每次1000金币换10贡献；不与祈愿次数共用 |
| 集体挑战 | 每日开放18:00—22:00；每人参与1次，胜利得20贡献；结束按已提交记录计数 |

退出寮后旧请求关闭，未领取合法所得仍归本人；同一天入退寮不重置个人额度。贡献不可直接转给其他人，寮解散不删除个人已得资源。

## 结界、寄养与分钟结算

结界是独立子系统：账号10级解锁，自己6个育成位，好友寄养位1个，卡持续6小时；一张参考经验卡消耗1卡，给每个未满级对象每分钟10经验，累计容量每槽3600。材料卡则只给拥有者每分钟1金币、容量360。卡型只能选一种，不叠加运行。

1. 放卡时记录开始/结束时间、卡版本和槽位对象。收益按完整分钟计算，不在客户端每分钟写账。
2. 查询或领取时，结算至`min(服务器时间,结束时间)`；新增分钟数取整、乘速率后受容量限制。结算游标移动到已处理整分钟，余下秒数保留。
3. 更换对象先结算旧对象，再更换；未领取经验绑定旧对象，不转移给新对象。对象满级后停止生成经验，不自动给其他槽位。
4. 换卡必须先领取当前收益，明确确认终止剩余时间；旧卡不返还，新卡重新计时；领取与换卡同一事务。
5. 寄养仅允许好友的空闲寄养位，双方关系仍有效且卡剩余≥60分钟；一次锁定最多4小时，最多同时寄养1处。寄养对象收益属于寄养者，主人不额外获得同一份；撤回时结算，槽位释放。
6. 双方同时申请同一槽位只有首个成功；删除好友不取消已经开始的寄养，结束后不可新建；卡提前终止结算至终止时刻。

这些时间和收益均为自设默认值，不是原作寄养攻略。结界突破归入战斗关卡配置，不复用定时育成账本。

## UI与验收

寮界面分成员/权限、祈愿、任务；师徒页展示对方、进度与解除后果；结界页显示卡、对象、剩余时间、可领量、容量、寄养者与返还时间。错误区分无权限、额度已用、对象满级、卡过期、位置被占。

- 经验卡运行1小时每个有效槽位600经验，6小时3600；6小时后再离线10小时不再增长。
- 1分59秒收取10经验；再过1秒收取10，不能因上次收取丢掉59秒余量。
- 两人争同一寄养位只成功1人；同一收取重复不再增加经验。
- 祈愿上限2片，三人同时各送1片只接受前2笔，第三笔不扣；退出重入不刷新额度。

## 公共提交契约与实现状态

本附录的数值、对象结构与异常策略全部属于补充参考设计。正文单独说明有来源的原作机制。当前交付为规则文档；除另行标注的前端演示与计算校验外，账号服务、数据库并发、支付和完整游戏客户端尚未实现，以下服务用例均为待执行验收要求。

- 输入含账号、请求号、动作参数、配置版本和对象预期版本；验证身份与所有权，再计算规则，最后一次提交资源、对象和收据。预览不扣费，取消没有副作用。
- 同号同参数返回原收据，同号不同参数拒绝；并发冲突不部分提交。客户端连接中断先按请求号查询，不能把超时当成失败另开一笔。
- 状态统一区分编辑、待确认、提交中、成功、明确失败、结果未决。未决禁用重复确认但允许查询；刷新从服务端收据恢复。
- 错误至少区分非法输入、权限不足、资源不足、资格不符、版本冲突、已过期、已完成与容量不足，并给可理解的处理入口。
- 资源全为非负整数；百分比使用明确精度，所有舍入点在规则中定义。随机过程由服务器生成并落盘，重试不重抽；服务器时间决定周期与到期。
- 埋点只记录必要的规则版本、阶段、耗时、错误与资源变化；分析转化时区分新手/回流/成熟账号、玩法和活动期，不把模拟数据当真实留存。
