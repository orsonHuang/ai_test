# 斗技与阵容应对 · 开发参考附录

2026-10-18 · 补充设计 v2 · 默认参数均非原作配置


## 模式和资格

参考模式固定5式神＋1主角，账号10级、至少6名可用式神；主角战前选定不可在选人期间变更。匹配、禁用、选五、战斗及积分构成完整流程。角色表使用战斗附录默认能力，可按同一字段增加角色，不声称覆盖原作全部斗技段位。

| 配置 | 默认值 |
|---|---|
| 积分 | 初始1000；胜+20、负−20，最低0；平局0；无隐藏分 |
| 匹配 | 前30秒±100；30—60秒±200；60—120秒±400；120秒取消并提示重新匹配 |
| 段位 | <1200入门、1200—1599熟练、1600—1999进阶、≥2000高手；名称与门槛自设 |
| 赛季 | 28天，结束后积分回1000；最高分段分别奖金币10000/20000/30000/40000，仅一次 |
| 选人计时 | 双方确认15秒；禁用20秒；每次选择20秒；战斗手动20秒 |

## 禁用与选择顺序

1. 匹配后冻结双方可用角色及御魂快照，双向确认后开始。未确认退回队列，不扣分；连续3次未确认冷却5分钟。
2. 双方同时提交一个对手拥有的角色类型禁用，双方都提交或超时后一起公开；超时默认禁用对方按类型号排序第一项。禁用只影响本场，不影响资产。
3. 服务端种子随机决定先选方A；选人轮次为A1→B2→A2→B2→A2。角色类型同队不可重复，跨队允许；选择只从己方剩余合法角色中取。
4. 每次轮次要求选足数量；超时从当前已选补入按角色号排序的合法候选，提交后不能撤回；可选不足则判该方准备失败，扣20分，对手不加分，防止刷分。
5. 阵容锁定后显示双方完整配置可读摘要，再进入同一战斗引擎。战前退出按失败扣20分，对手加20分；服务故障取消双方不变。
6. 断线由自动策略接管，重连恢复当前行动，不回退选择。主动投降立即判负；同时全灭或500行动上限按平局。

## 赛季与结算

一个对局绑定开战赛季号；赛季截止后不得创建该赛季新局，已开局有10分钟结算宽限，未完成则平局。最终奖励等宽限结束按最高分段结算，之后创建新赛季积分，避免旧对局污染新赛季。收据键包含赛季、对局、玩家。

## UI与反馈

匹配展示已等时长和取消；禁用展示己方选择已锁、对方未公开占位；选人明确当前操作者、剩余名额、倒计时、禁用和已选；战斗显示自动接管状态；结算显示分数前后、段位和终局原因。不得把服务取消展示成玩家认输。

## 验收

- 双方任何一方先提交禁用，都不能提前看到另一方选择；超时使用同一固定默认规则。
- A1+B2+A2+B2+A2合计双方各5名；重复角色和被禁角色不可提交。
- 1190分胜→1210，跨入熟练；0分负仍0；平局不变；结算重放不重复加分。
- 截止前开战在宽限内完成计入旧赛季；结束后最高分奖励只发一次，新赛季从1000开始。

## 公共提交契约与实现状态

本附录的数值、对象结构与异常策略全部属于补充参考设计。正文单独说明有来源的原作机制。当前交付为规则文档；除另行标注的前端演示与计算校验外，账号服务、数据库并发、支付和完整游戏客户端尚未实现，以下服务用例均为待执行验收要求。

- 输入含账号、请求号、动作参数、配置版本和对象预期版本；验证身份与所有权，再计算规则，最后一次提交资源、对象和收据。预览不扣费，取消没有副作用。
- 同号同参数返回原收据，同号不同参数拒绝；并发冲突不部分提交。客户端连接中断先按请求号查询，不能把超时当成失败另开一笔。
- 状态统一区分编辑、待确认、提交中、成功、明确失败、结果未决。未决禁用重复确认但允许查询；刷新从服务端收据恢复。
- 错误至少区分非法输入、权限不足、资源不足、资格不符、版本冲突、已过期、已完成与容量不足，并给可理解的处理入口。
- 资源全为非负整数；百分比使用明确精度，所有舍入点在规则中定义。随机过程由服务器生成并落盘，重试不重抽；服务器时间决定周期与到期。
- 埋点只记录必要的规则版本、阶段、耗时、错误与资源变化；分析转化时区分新手/回流/成熟账号、玩法和活动期，不把模拟数据当真实留存。
