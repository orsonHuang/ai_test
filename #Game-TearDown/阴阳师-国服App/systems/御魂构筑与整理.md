# 御魂构筑与整理 · 开发参考附录

模块 onmyoji-souls · 修订1 · 2026-10-17 · 补充参考设计

## 目标与边界

候选面板与两个必要条件的前端对比；不含真实六位置求解、强化随机和全库优化。所有实体、数字与处理策略均为自设参考，不表示原作实现。原作事实及证据见公开正文。除御魂前端对比外，本切片未实现，以下用例为待执行规格。

## 对象与配置

- 对象：`candidate{id,attack,speed,crit}; currentId; selectedId; supportSpeed`。
- 默认配置与合法域：辅助speed=130；A=(attack3000,speed125,crit100)；B=(3400,135,100)；C=(3300,122,85)；D=(3200,128,95)；所有值自设。
- 所有资源/数量为非负整数；对象ID非空且唯一，引用不存在则拒绝操作；缺少必要配置则不创建会话。时间由服务端提供，本地演示仅使用固定相对时间。

## 规则规格

| 规则 | 类型 | 条件、动作与状态变化 |
|---|---|---|
| R1 | 补充设计 | 选择候选只更新预览；辅助速度必须严格大于输出，输出暴击必须>=90%；两个条件通过才允许应用；应用不改候选数据；重置恢复初始方案 |
| R2 | 补充设计 | 预览不产生持久变更；确认前再校验条件和版本；校验失败返回原因且不部分扣除 |
| R3 | 补充设计 | 同一变更请求使用同一requestId；已提交重复请求返回原收据，未提交失败可重试；用户刷新按服务端状态恢复 |

算例：A→B攻击+400但顺序失败，禁止应用；A→D攻击+200且两项满足，可应用。

## 状态与异常

| 状态/事件 | 处理 |
|---|---|
| 编辑或预览 | 展示结果预测，允许取消返回 |
| 确认中 | 禁止重复提交，保留同一请求标识 |
| 校验失败 | 不扣资源，显示具体原因，返回可编辑状态 |
| 提交成功 | 展示已提交结果与收据，再更新界面 |
| 连接中断 | 不猜成功与否；按请求标识查询后恢复，未决时不发第二笔 |
| 多端状态改变 | 版本不符时重新预览，不用旧价格或旧对象强制提交 |

前端御魂比较没有服务器事务，R3只作为未来接入契约；当前重置和离开页面会清除演示状态。

## 系统接口

本地内存状态；SelectCandidate → PreviewChanged；Apply → CurrentChanged；不存真实游戏数据。参考数据归属按本段定义；资源变更与发放由同一事务边界执行。输入包含请求ID、账户/会话ID及预期版本，输出包含状态、错误码与新版本。非法输入返回INVALID，余额不足返回INSUFFICIENT，版本冲突返回STALE，无权限返回FORBIDDEN，已结束返回CLOSED；错误均不产生部分变更。原作技术栈未知。

## UI、美术与反馈

整体面板差值、逐条件通过/失败、应用按钮、当前方案与重置。采用正文编号图解定位信息；选择、不可用、处理中、成功、失败五种状态同时使用文字与形态表达。关键操作可键盘到达；首屏安全区和320/390像素文字需实际检查。正式资源数量、尺寸和音效另由项目确定；本参考不要求复刻原作美术。

## 平衡旋钮与验收

- 配置改变只作用于本切片，先验证条件与反馈，再评估时间/收益，不把演示默认值当平衡结论。
- T1 → R1：选择B禁止应用；选择C暴击失败；D可应用且当前更新；重置回A。本用例由网页专项测试执行，结果见验收记录。
- T2 → R2：分别取消、传入非法值和过期版本，资源与对象均保持原状。
- T3 → R3：成功请求重复、断线后查询同请求，结果只能有一次；服务器实现后执行。
- 当前原作概率、服务器优先级、库存边界及全量资产未核实；不得由本附录推断。
