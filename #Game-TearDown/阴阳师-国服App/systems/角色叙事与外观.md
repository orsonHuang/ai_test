# 角色叙事与外观 · 开发参考附录

模块 onmyoji-story · 修订1 · 2026-10-17 · 补充参考设计

## 目标与边界

三段故事进度和两套外观预览；不还原原作剧情与资产。所有实体、数字与处理策略均为自设参考，不表示原作实现。原作事实及证据见公开正文。除御魂前端对比外，本切片未实现，以下用例为待执行规格。

## 对象与配置

- 对象：`story{id,page}; unlocked; cosmetic{id,owned}; equippedId`。
- 默认配置与合法域：pages=3；unlocked=true；base owned=true,alt owned=false；初始page0,equipped=base。
- 所有资源/数量为非负整数；对象ID非空且唯一，引用不存在则拒绝操作；缺少必要配置则不创建会话。时间由服务端提供，本地演示仅使用固定相对时间。

## 规则规格

| 规则 | 类型 | 条件、动作与状态变化 |
|---|---|---|
| R1 | 补充设计 | 故事需unlocked=true，页索引0..2；前进保存进度，返回不清除；外观预览不消耗不保存为装备；只有owned可应用；切回初始外观始终允许 |
| R2 | 补充设计 | 预览不产生持久变更；确认前再校验条件和版本；校验失败返回原因且不部分扣除 |
| R3 | 补充设计 | 同一变更请求使用同一requestId；已提交重复请求返回原收据，未提交失败可重试；用户刷新按服务端状态恢复 |

算例：阅读到page1返回再进入恢复page1；预览alt不改变base；应用alt被拒绝。

## 状态与异常

| 状态/事件 | 处理 |
|---|---|
| 编辑或预览 | 展示结果预测，允许取消返回 |
| 确认中 | 禁止重复提交，保留同一请求标识 |
| 校验失败 | 不扣资源，显示具体原因，返回可编辑状态 |
| 提交成功 | 展示已提交结果与收据，再更新界面 |
| 连接中断 | 不猜成功与否；按请求标识查询后恢复，未决时不发第二笔 |
| 多端状态改变 | 版本不符时重新预览，不用旧价格或旧对象强制提交 |

前端御魂比较没有服务器事务，R3只作为未来接入契约；当前重置和离开页面会清除演示状态。

## 系统接口

SaveReading(storyId,page)；PreviewCosmetic(id)本地；EquipCosmetic(id)校验拥有权。参考数据归属按本段定义；资源变更与发放由同一事务边界执行。输入包含请求ID、账户/会话ID及预期版本，输出包含状态、错误码与新版本。非法输入返回INVALID，余额不足返回INSUFFICIENT，版本冲突返回STALE，无权限返回FORBIDDEN，已结束返回CLOSED；错误均不产生部分变更。原作技术栈未知。

## UI、美术与反馈

阅读进度、预览标识、未拥有原因、退出与返回。采用正文编号图解定位信息；选择、不可用、处理中、成功、失败五种状态同时使用文字与形态表达。关键操作可键盘到达；首屏安全区和320/390像素文字需实际检查。正式资源数量、尺寸和音效另由项目确定；本参考不要求复刻原作美术。

## 平衡旋钮与验收

- 配置改变只作用于本切片，先验证条件与反馈，再评估时间/收益，不把演示默认值当平衡结论。
- T1 → R1：越界页拒绝；未拥有不能装备；预览退出恢复原外观；重进恢复读到的位置。
- T2 → R2：分别取消、传入非法值和过期版本，资源与对象均保持原状。
- T3 → R3：成功请求重复、断线后查询同请求，结果只能有一次；服务器实现后执行。
- 当前原作概率、服务器优先级、库存边界及全量资产未核实；不得由本附录推断。
