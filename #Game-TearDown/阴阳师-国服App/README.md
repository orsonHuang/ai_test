# 阴阳师 · 中国大陆手机 App

## 项目描述

2026-10-18修订：整游、战斗、养成加入7张历史原图/局部截取；养成正文分别覆盖式神和阴阳师，给出历史消耗与独立参考配置、180行逐级经验表及计算器。开发附录扩为基础养成全流程，计算检查419项通过，账号服务器/真实并发与完整客户端尚未实现。参考数值不能当原作当前攻略。

研究网易《阴阳师》本体的角色收集、回合战斗、御魂构筑与长线运营。2026-10-17 首版供用户验收，公开入口为 reader/游戏分析.md，系统地图连接十篇独立系统文章。不是《决战！平安京》《百闻牌》或《妖怪屋》。

## 工作规则

- 国服 App 为正文范围，Android 与 iOS 商店信息分开记录。TapTap 登记 Android 2.8.87（260928），更新日期 2026-10-07；服务器热更及 iOS 构建未实测。
- 2021—2024 玩家攻略用于机制历史样本，2026 官方公告用于具体活动与新区变更；旧配队推荐、概率、养成材料表不写成当前通用结论。
- 公开正文用作者分析视角；读图、资料事实、分析与补充设计分别说明。未取得当前实机账号体验，不编造体验时长和付费效果。
- 海外仅作为发行差异核验入口，不混用日服或港澳台规则。所有自设参数、演示状态与参考接口均不属于原作事实。

## 目录结构

- reader/：整游与十篇系统分析；reader.json：地图、摘要、图解配置。
- systems/：各系统有限范围的开发参考附录。
- assets/：原创机制图；sources.json：来源与范围；game.json：案例元数据。
- roles/：策划、开发、美术阅读路径，链接同一篇正文。

## 注意事项

已覆盖核心战斗、式神与阴阳师养成、御魂、召唤、PVE、斗技、阴阳寮与师徒、资源与商店、活动商业化、角色叙事与外观。日常模式按功能归组；百鬼棋、每期小游戏、完整成就、现世交互和当前设置细节未作全量实机盘点。参考设计可用于明确范围的开发，不是原游戏服务器还原。交付质量与运行结果见框架验收记录。
