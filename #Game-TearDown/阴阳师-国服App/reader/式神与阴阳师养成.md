# 式神与阴阳师养成：从拥有，到能够承担职责

阴阳师 · 国服 App · 局外养成

## 设计目的

养成把一次角色获取变成多阶段投入。分析重点是每一步到底补了什么：面板、技能效果，还是进入某个阵容所需的条件。**“等级满了”不应自动等于“这名角色已经可用”。**

## 系统功能与层次

| 层次 | 已有资料支持的内容 | 我的分析重点 |
|---|---|---|
| 式神成长 | 等级、星级、技能培养 | 功能节点与纯面板增长是否清楚 |
| 适用角色的觉醒 | 觉醒材料与能力变化 | 不把所有稀有度都套成相同路线 |
| 阴阳师成长 | 技能选择与御灵提升 | 主角能力如何与式神队伍配合 |
| 育成便利 | 材料、经验与一键育成相关入口 | 少点几次是否仍保留清楚的消耗确认 |

基础层次参考[历史玩家操作说明](https://www.taptap.cn/moment/15220000474270426)；具体升星材料表和当前转换规则不由旧攻略推定。2025 年更新已介绍新的新手成长任务，说明获取与培养起点会随版本改变。[维护公告](https://bbs.4399.cn/thread-view-tid-50384879)

## 玩家流程

1. 先确定角色将承担的任务，例如先行动、供火、输出或生存。

2. 检查缺的是功能、基础能力还是装备条件，选择对应培养入口。

3. 查看投入和前后变化，再确认消耗。

4. 回到目标玩法验证；若仍失败，避免无差别继续加等级。

## UI 与材料保护

```ui-analysis
yy-growth
```

- **① 材料区：** 历史截图把候选材料列表与目标角色分开，减少对象混淆。补充设计建议同时显示锁定和使用中标记，批量操作默认排除受保护对象。

- **② 目标角色：** 保留人物展示，让培养对象始终明确；同时呈现将改变的能力，不能只有动画和总分上涨。

- **③ 成长方式：** 升级、升星、转换属于不同操作意图，切换时应重新解释成本与结果。

- **④ 确认区：** 确认前列出消耗与提升；原图的等级前后关系可见。保护与二次确认是本版补充建议，不宣称已经在当前原作逐项验证。

## 数值与设计取舍

- 技能节点的收益可能不连续：补足关键能力会改变一整支队伍的运作。因此资源引导最好告诉玩家“达到后能做什么”。

- 材料复用能减少资源种类，却会增加误用成本。角色既是收藏对象又可能进入消耗流程时，保护、预览和反悔机会尤其重要。
