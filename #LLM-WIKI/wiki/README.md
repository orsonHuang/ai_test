# wiki · 综合知识页规则

Wiki 是 LLM 维护的综合层。它整合多个 raw、处理冲突并形成可复用命题。

## 新建条件

- 存在稳定、可独立命名的问题或概念。
- 至少一份可靠 raw；单来源时明确证据边界。
- 无合适既有页面可吸收。

## 维护要求

- 使用同目录 `wiki.template.md`。
- 每个主要章节用 `> 📍 来源：[[raw-sources/...]]` 标明证据。
- 新来源冲突时并列成立条件，不静默覆盖旧结论。
- `domains` frontmatter 与 domain 导航双向一致。
- Wiki 间链接遵循 `system/protocols/WIKI-LINK-STANDARD.md`。
- 约 300 行开始拆分评估；500 行必须拆分，除非记录明确豁免。
- `## 相关页面` 只保留不可替代的强关系，建议不超过 5 条。

空目录是合法状态，Lint 不得因零 Wiki 报错。
