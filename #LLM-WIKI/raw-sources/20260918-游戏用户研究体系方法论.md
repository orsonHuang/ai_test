# 腾讯游戏用户研究体系方法论

> 本文合并自两篇 TGDC 演讲：付彪《游戏用户研究的进化之路》（第二届 TGDC 2018）和郑宇《聚用户之力，做更好游戏》（首届 TGDC 2017）。两篇来自同一用研体系（腾讯 MUR），一篇偏方法论框架与趋势洞察，一篇偏全生命周期实操案例，合并后形成完整方法论。

## 核心内容

> 📍 原文位置：付彪演讲第一至三章；郑宇演讲第一至四章

### 模块一：用研体系的三个核心问题

- **载体**：框架定义
- **命题**：游戏用户研究的核心是回答三个问题：
  1. **产品方向判断**：产品布局、定位、运营——"做什么给谁？"
  2. **产品体验打磨**：让产品体验达到目标用户期望甚至超越——"做得够不够好？"
  3. **市场趋势洞察**：抓住行业趋势不漏掉——"外部环境在怎么变？"
- **推导**：三个问题对应产品生命周期的不同阶段，但并非线性——需要持续循环迭代。

---

### 模块二：产品布局判断——市场细分与品类洞察

> 📍 付彪演讲：产品布局部分

- **载体**：方法论 + ACT 市场案例
- **命题**：市场细分是布局的基础，关注三个方向：①用户规模显著增长或缩减的品类；②独特性强的品类；③用户结构产生融合变化的品类。
- **例证/数据**：
  - ACT 市场细分为 10 个用户群体，每个群体对应不同产品设计和市场策略。
  - "探索刷图用户"占比高且贡献核心价值，后续几年持续加大供给形成良性循环。
  - "动作难度挑战用户"规模小且当时技术难以满足 → 推动决策层停运该产品，是商业应用成功案例。
- **推导**：清晰的产品布局下，能发现"哪些用户服务有问题"或"哪些重要用户未进入服务范畴"。

---

### 模块三：目标用户研究——体系化四环节

> 📍 付彪演讲：目标用户研究部分

- **载体**：流程框架 + 王者荣耀案例
- **命题**：清晰的目标用户定位 = 对前景的明确预期。用户定位不清晰的产品，上线后的可能性近乎为 0。
- **推导**：体系化工作包含 4 个环节：
  1. **用户细分维度输入**：与制作人/主策深入沟通 + 基础研究。
  2. **评估**：玩法吸引度、体验门槛、持续性。
  3. **迭代测试**：前期/中期/后期不同方式测试。
  4. **共识落地**：目标用户研究不只制作人关心，下沉到每个策划/运营/市场推广。
- **例证/数据**：
  - 《王者荣耀》：从轻松休闲用户定位调整到更核心更偏端游的强竞技 5V5 方向，是整个产品最关键的定位转折。
  - 《圣斗士》：新增 IP 结构和情感元素分析模块——拆解"悲情守护 + 热血逆袭"双线情感，通过"小宇宙爆发"串联，产品设计需将 IP 核心情感元素充分体现。

### 模块四：全生命周期用研体系

> 📍 郑宇演讲：第一至二章

- **载体**：流程体系 + 案例集
- **命题**：用研贯穿单产品完整生命周期——概念期 → 初始版本期 → 迭代优化期 → 推广运营期。
- **推导**：
  - **概念期**：行业/品类/竞品基础信息支持 + 概念测试筛选方向。
  - **初始版本期**：确定美术风格和核心玩法。
  - **迭代优化期**：结合留存数据验证目标用户、找到流失原因。
  - **推广运营期**：重点模块拆解、精细化研究。
- **例证/数据**：
  - **《魂斗罗》经典 IP 手游化**：IP 评估 → IP 用户分析 → 美术/玩法概念测试 → 发现 IP 用户老化、上手门槛高、美术过时 → 重新锁定枪战/飞行射击/跑酷/动作格斗品类用户 → 多轮测试发现动作格斗用户接受度最好 → 调整角色外观和 PVP 玩法。
  - **《天天爱消除》改版**：经典限时用户不接受改版（找不到常用入口 + 鄙视链导致落差感）→ 重新设计 → 不同玩家对新版本接受度均提高。

### 模块五：产品质量打磨——美术与剧情

> 📍 付彪演讲：产品质量打磨部分

- **载体**：美术研究 + 剧情工业化
- **命题**：美术不仅影响新用户获取，也成为用户留存的重要原因。审美标准在快速上升。
- **推导**：
  - 美术重要性提升的三个原因：①现实生活中审美变化；②线上娱乐活动的共鸣认可；③审美从"欣赏美"变为"表达自我价值观和个性"。
  - 玩家越来越将美术当作整体设计的一部分——角色搭配与性格/经历不符会被吐槽。
  - 剧情打磨引入好莱坞工业化体系：概念测试（几百字）→ 剧本测试（分情节）→ 分镜测试（线稿）→ 采风研究（实地）。
- **例证/数据**：
  - 《王者荣耀》李白重构：用户觉得"靠剑动作过于浮夸、不够真实" + "酒仙不是酒鬼，酒仙是英气的感觉" → 采取平行持剑方式，得到好评。
  - 动作维度测试最低：用户觉得动作与"酒仙"人设不符。

---

### 模块六：体验设计研究——闭环与共性原则

> 📍 郑宇演讲：体验设计部分

- **载体**：方法论 + 设计原则
- **命题**：单产品体验设计研究要形成闭环——专家评估 → 用户测试（收集/确定问题严重性/提供建议）→ 产品快速落地反馈 → 跟进效果。
- **推导**：
  - 除单产品支持外，还需研究共性设计原则（如重度手游新手引导设计、移动游戏 UI 提示反馈标准）。
  - 掌握用户行为模式，将"评估问题"变成"规避问题"。
  - 体验设计问题存在于产品各阶段，重点不同：概念/Demo → 美术和 UI 风格；版本初期 → 单局体验；删档测试 → 新手引导和 UI 障碍；运营期 → 改版前测。

---

### 模块七：市场推广与运营的用研支持

> 📍 郑宇演讲：市场推广 + 运营部分

- **载体**：案例集
- **命题**：用研不仅支持研发，也贯穿市场推广和运营。
- **例证/数据**：
  - **DNF 品牌刷新**：品牌直接出的创意素材玩家不买单 → 通过用户札记和深访获取"玩家如何面对挫折、如何变强"的真实故事 → 提炼创意方向 → 广告角色原型来自真实玩家 → slogan 测试筛选 → 营销效果反响好。
  - **DNF 长线运营**：数据下滑 → 流失调研定位产品问题（非竞品/客观原因）→ 分等级研究发现中后期"成长"问题 → 平滑难度 → 发现高等级用户中工作者占比增加 → 建议关注用户结构变化。
  - **二次元玩家研究**：用研经理长期融入二次元社区 → 发现四类细分人群 → 游戏宅偏好强策略性（"好玩第一"）→ 对画面极致细节的追求（如战舰拟人化中弹位置与历史档案一致）。

---

### 模块八：行业趋势洞察与标准化评估

> 📍 付彪演讲：行业趋势 + 标准化；郑宇演讲：行业把握

- **载体**：方法论 + ASMR 案例
- **命题**：
  - 持续的行业追踪体系：市场竞争性趋势 + 用户行为发展趋势。
  - 标准化评估体系：将产品拉出来横向对比，更早精确推断哪个环节的哪个部分需要修改。
  - 创新是一个过程，需做最早最源头的文化信号捕捉。
- **例证/数据**：
  - **ASMR 信号捕捉**：2017 年 4 月从海外音频社区捕捉 → 8 月国内厂商开始在广告中运用 → 2018 年春节女性化产品成熟运用。从信号发现到业务落地有时间间隔，用研使命是做最早的文化信号捕捉者。
  - **消除品类判断**：品类规模良性 + 头部产品有细分空间（用户双峰分布）+ 竞争威胁低（用户结构与 MOBA 重合度低，不像跑酷被 MOBA 挤压）→ 判断消除市场具有长期发展潜力。

## 适用边界

- 本文方法论基于腾讯 MUR（80 人团队、年上千项目）的资源和组织规模，中小团队的落地方式需简化。
- 演讲时间分别为 2017 年和 2018 年，部分案例（如消除品类趋势、女性市场变化）的市场环境已变化。
- 用研方法论偏"发现问题"而非"解决问题"，策划仍需自行将洞察转化为设计决策。
- 部分案例（如王者荣耀 5V5 定位调整）的成功依赖特定团队执行力，不可简单复制。

## 批注

- ✅ 亮点：「用户定位不清晰的产品，上线后可能性近乎为 0」——用研不是锦上添花而是立项前提，这个判断标准对所有团队适用。
- ✅ 亮点：「从评估问题到规避问题」的转变——通过共性设计原则研究，在问题发生前就建立标准，而非事后补救。
- ✅ 亮点：ASMR 信号捕捉案例——展示了从文化信号到业务落地的完整时间线和用研使命定位。
- ✅ 亮点：DNF 品牌刷新案例——品牌直接出素材玩家不买单，通过深入用户故事获取真实情感诉求再转化为创意，是"走近用户"的典范。
- ✅ 亮点：消除品类三维判断框架（品类规模 + 头部细分空间 + 竞争威胁）——可复用于任何品类的市场前景评估。
- ⚠️ 存疑：两篇演讲来自同一体系，部分方法论描述存在重叠（如全生命周期框架），合并时已去重但视角差异需注意。
- ⚠️ 存疑：标准化评估体系的"横向对比"基准未详细说明，跨品类对比的可操作性存疑。
- 🔗 可延伸：与 CF 长青之路 raw 中"坚持用户研究导向""走进用户"的实践互为印证——CF 团队的 1024 分辨率案例正是本文"走进用户"方法论的具象化。
- 🔗 可延伸：IP 情感元素分析方法（圣斗士案例）与现有 Wiki 叙事设计主题关联，可作为 IP 改编产品的用研支撑方法。
