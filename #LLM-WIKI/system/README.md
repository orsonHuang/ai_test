# system · 运行机制

这里集中知识库的协议、登记表、可选集成与维护工具。普通使用者从根目录 `README.md` 与 `NOW.md` 进入；AI 收到具体任务后先读 `protocols/RUNTIME_ROUTING.md`，再按分类读取对应协议。

- `protocols/`：运行分发、Query、Ingest、评分、模型与链接规则。
- `registry/`：范围、索引、状态和来源登记表。
- `integrations/`：IMA 等可选外部连接。
- `maintenance/`：初始化、模板维护、检查清单与变更记录。

本目录与正式 Knowledge 运行实例同构，不把运行机制重新摊回根目录。
