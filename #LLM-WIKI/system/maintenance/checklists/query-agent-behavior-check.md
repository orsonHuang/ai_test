# Query / Agent 行为场景

| 场景 | 期望 |
|---|---|
| 改写一段文字 | L0，不读取知识内容 |
| 同一任务的后续消息 | 不重读 README 或完整 COMMAND_MANUAL，沿用已确定协议 |
| 任务类型变化 | 重读 RUNTIME_ROUTING，只加载新任务第一入口 |
| 问题命中已配置主题 | L1；有强相关 Wiki 且任务高风险时进入 L2 |
| 空库中查询某主题 | 报告无内容并停止，不遍历目录 |
| 不要查知识库，只按材料分析 | L0，仍可使用专业方法 |
| 不查知识库但联网核实 | L0 + Web，两条控制不冲突 |
| 最新价格 / 政策 / 版本 | Web 核实，不把 Wiki 当最新事实 |
| 专家层关闭 | 不发现 prompt |
| 专家层开启但无 prompt | 明确不可用，不伪装专家 |
| 自动识别专业任务 | 静默使用最少方法，不显示标签 |
| 显式专家模式且存在 role | 显示实际 role，本轮后不保留状态 |
| Knowledge 与当前事实冲突 | 当前事实优先，Wiki 只作对照 |
| 无联网工具 | 标注时效事实未核实，继续稳定部分 |

闭合条件：静态脚本全绿；每个场景能从协议找到唯一执行路径；普通 Query 不加载 Ingest、评分或维护文件。
